# 공격전 보상 상자 열기 음원

사용자가 2026-11-09 제공한 `/Users/qf/Downloads/0242-00001106.mp3`를 공용 보상 상자의 실제 열기 동작에 연결한다. 원본은 수정하지 않는다. 출처·원본/출력 SHA-256·도구 해시는 `manifest.json`에 기록한다.

- 이벤트: `destiny:loot.chest.open`
- 파일: `assets/destiny/sounds/loot/chest_open.ogg` (**52,667바이트**)
- 원본 MP3: 48kHz, 스테레오. 컨테이너 길이 2.573333초, 전체 디코더 출력은 채널당 123,264프레임(**2.568초**).
- Vorbis quality 6으로 변환한다. MP3의 표준 지연/패딩 처리를 반영한 전체 PCM 프레임 수를 보존하며, 임의 자르기·리믹스·정규화·샘플레이트/음높이 변경을 하지 않는다.
- `python3 scripts/art/build_reward_chest_audio.py`로 생성한다. 기존 libvorbis 지원 ffmpeg를 사용한다. `--source`, `--ffmpeg` 지정 가능.

`LootChest.open()`의 실제 성공 경로에서 소유자에게만 PLAYERS 카테고리, volume=1, pitch=1로 한 번 보낸다. 기존 바닐라 임시 열림·분출음은 교체하며, 재클릭·사거리 밖·등장 중·미개봉 정리에는 새 열기 음원을 재생하지 않는다. 아이템을 실제로 줍는 순간의 희귀도별 획득음은 별도 동작을 유지한다.

## 보상 상자 확률

사용자 확인에 따라 **보상 상자**에만 전설 이상 80%를 적용한다. 완료 확정 보상과 적 처치 드랍은 유지한다. 공용 `strike_chest`는 빈 결과 없이 1회 뽑으며 가중치는 희귀 무기 5 / 전설 엔그램 12 / 전설 무기 6 / 경이 엔그램 2(합계 25)다. 상자당 희귀 20%, 전설 72%, 경이 8%이며 전설 이상은 정확히 80%다. 상위 등급 안의 전설:경이 9:1과 전설 엔그램:무기 2:1 비율은 유지한다.

악마의 소굴은 완료 전설 장비 1개, 엑소더스의 추락은 2개를 계속 확정 지급한다. 미광체 범위도 각각 40–60 / 80–120을 유지한다. 원작의 확정 드랍률이라고 주장하지 않는 사용자 지정 조정이다.
