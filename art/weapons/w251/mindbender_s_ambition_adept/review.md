# 정신왜곡자의 야망 W251

원작 기본 안료 사진과 기존 리핑 FBX·diffuse를 참고했다. 긴 금속 총몸에 실제 경사면을 만들고, 앞 뼈대의 어깨·손바닥 파지·갈고리 끝·뒤 뼈 개머리판을 굵기가 다른 둥근 단면으로 구성했다. 뼈 홈과 Hive 문자는 원래 방향별 diffuse에서 유지하며 무관한 문양이나 노이즈를 추가하지 않았다.

1024 atlas, 면별 UV와 제한적인 림 명암을 사용한다. 파지 원점·display·총구·조준기·탄약·장전 모션은 유지한다. 비교는 같은 CPU 조명/카메라의 이전/이후이며 실제 게임 검수와 PBR 복원을 뜻하지 않는다. 실제 자원팩·1/3인칭·ADS·장전 검수는 master가 기록한다.

출력: 189 cubes / 0 triangle adapters; 이전 104.
