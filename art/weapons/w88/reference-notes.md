# W88 — ordinary-bow fatigue exact-source investigation

Decision: **no new trustworthy numerical maximum hold, forced-release timer, imperfect-draw curve, late-damage curve or late-accuracy curve was established. All remain `null`.** This pass does not make exact fatigue gameplay implementation ready. No four-second ordinary-bow timer is justified.

Research started 2026-10-24 18:27:48 UTC. The three-minute checkpoint had no new ordinary-bow fatigue quantity; searching stopped and only these artifacts were finalized. No builds, source/runtime edits, app launches/control or world changes. Parent QA remains independent.

Newly verified contract:

- Bungie 8/11/2022 article **full text**, lines 127–131 in the saved web response, explicitly ties exceeding the perfect-draw window to loss of both accuracy and damage. Its lightweight 0.50/0.80-second endpoints describe that window, not maximum hold. This historical article does not specify late-loss magnitude, shape, floor, forced release, or current engine interpolation.
- Bungie 10/06/2022 developer Q&A **full text**, lines 213–217, confirms any Stability stat change affects perfect-draw window; the question explicitly names Rapid Hit. It does not establish how Stability affects maximum hold, nor when a perk change takes effect during an already active draw.
- Current official manifest identifies Biting Winds 1621657423 as Precision (intrinsic 715195141), Stability 43, displayed draw 667ms; Whispering Slab 211938782 as Lightweight (2108556049), Stability 53, displayed draw 567ms. These match W74's selected hashes, rather than a reprised item with the same name. Precision is described as a compound bow optimized for damage; lightweight as a quick-drawing recurve with movement benefit. Both official frame descriptions explicitly allow Reload to cancel while drawn. No quantitative distinction in maximum hold or late decay was found.
- Current official Adamantine Brace 1449897496 explicitly permits indefinite Perfect Draw. The separately fetched 2018 a_dmg04 developer post also confirms indefinite holding with Perfect Draw after long holds. This exception cannot be generalized to normal bows.
- **New relative quantity only:** current DDC `Weapon Perks!D205` and pinned live Clarity `/908147344/descriptions/en/4/linesContent/0/text` agree that crouched Sneak Bow adds **25% hold time**. Its baseline is unknown, so 1.25 times an unknown remains unknown. Enhanced Clarity has the same 25% and unresolved extra Stability/Reload. No such perk is granted to either selected configuration by this investigation.
- DDC `Exotic Armors!D85` and Clarity Adamantine Brace distinguish indefinite Perfect Draw from a **four-second PvE damage-bonus expiry**. That number is not ordinary fatigue or forced release. Their progression text is not equivalent: DDC lists a 0.35s onset, 0.5s increments and maximum by 2s, whereas Clarity lists 37.5% per 0.5s up to 200%; their timer origins also differ. Preserve the source wording, do not invent a unified Oathkeeper curve. Oathkeeper details are exceptions, not normal-bow late penalties.
