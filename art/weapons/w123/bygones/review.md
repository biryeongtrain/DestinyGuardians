# Bygones W134 — offline art review

**129 opaque authored cuboids**, full-only candidate, zero triangle/contour adapters and zero alpha body cards. Broad filled walnut comb/toe, forearm, grip, receiver and rear magazine define the weapon. A few thick rails/posts provide functional hollow geometry; screws, panel borders, small muzzle ports and grip slits are opaque UV artwork. Six side vents are deliberately faceted octagons rather than exact circular source bores.

The actual default-paint photo was inspected: walnut brown furniture, green-black machined metal, ported short muzzle, raised compact tube optic and rear magazine. Photo SHA-256: `b03f6a5e805876a0e75c62fab3922ef437bce3f496c4a69cdf6f4aa4fff0a0a8`; Bungie item 2712244741, matching `art/weapons/w31/references.json`. The atlas reconstructs this paint; it does not call the largely neutral BFrame diffuse a recovered default shader. Selected grayscale wood-relief rectangles are cleaned/recolored and placed using world-aligned continuous face coordinates. Metal panels, fasteners, collars and shallow grooves are authored. Each of 774 faces has a separate opaque rectangle, with 2-pixel edge-extruded gutters in one 1024 atlas. No source UV-shell or triangle transplant is used for the new model.

Original source: read-only `Bygones/Bygones.fbx` and `.blend` both match the W30 metadata hashes. The inert FBX parser matches all six retained source objects and 19,052 triangles; source bounds match within 0.000002 native units (FBX float export drift). Reticle object Bygones.02.000 remains excluded. The raw comparison renders Frame/Sight/Decals diffuse and original source UV; the decal texture is evidence only. We did not open Blender or execute the supplied shader script. This proves local source matching, not independent Bungie asset authenticity.

Coordinates retain the actual Bygones basis `[raw X, raw Z, raw Y]`, scale 26.396705547274056, anchor [8.0, 8.0, 8.0], original hand origin and muzzle -Z. The authored muzzle tip is exactly -8.538193969375246 and butt tip 16.461806030624757. Canonical display data is copied exactly. The canonical comparison is the existing 242-cuboid W30 reconstruction and its W30 texture, clearly separate from raw FBX and the W134 candidate. No item registration, ADS, generic reload, combat, audio or timing files are changed. No invented body/magazine split is emitted.

`comparison.png` contains the default photo, side/front/rear CPU views at the same camera and scale per row, and focused muzzle/guard/optic/stock views. `inspection.bbmodel` embeds the final atlas and editable cube groups with matching face UVs. Real openings include the deep muzzle bore, trigger bow, front sight, optic optical channel, side vents and stock cutaway. The optic omits physical glass/refraction/source reticle; the original photo's smooth curves, patina and dynamic metallic reflections are simplified.

Targeted Python QA covers valid schema/budget, frame/display, representative real empty channels and filled depth, opaque UV/gutters, current input/output hashes, editable inspection parity and deterministic regeneration. These checks are intentionally not an all-angle aesthetic gate. Native resource-pack/parser/registration, first/third-person holding, ADS, generic reload and 10–20 simultaneous weapons remain **pending master**. CPU art inspection is not native acceptance or a performance measurement.
