# sunshot — W350 revision 2

Initial R1 cuboid drafts were rejected and are preserved under rejected-r1/. Revision 2 rebuilds source-shaped closed solids, crowned sections, physical apertures and material panels using the accepted W327 native polygon adapter. No source mesh vertices were converted. Native element count is 485; this count is a budget check, not art or in-game acceptance.

Calibrated read-only source projection, pinned Bungie base icon, and source side/oblique images guide the shapes and restrained face UV markings. Material previews use the actual exported native JSON and PNG. Offline renderer omits the coincident reverse plane only for rendering, matching the accepted W327 reviewer; the product contains both mirrored native faces. Sunshot diamond openings were ray-checked through the authored solids.

Source .blend SHA and evaluated weapon bones/actions remain recorded. No source player wrist/elbow rig or reload action exists. All 61 reload poses and 21 aim poses are authored approximations; contact/pivot anchors were revised against the new geometry. 61 samples do not imply native continuous 60fps interpolation. Master still owns first Vision, delegated review/fixes and second Vision; pack load, hands, ADS, reload contact, third person, shots and 10–20 item observation remain unverified.
