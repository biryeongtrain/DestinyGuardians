# Material revision 2

Latest user request: materials must read distinctly; the earlier uniformly flat finish was rejected.

Actual source .blend was evaluated with auto-execution disabled. Source high-frequency seams and relief are filtered from six calibrated views. Layout mapping is an approximate affine guide, not the original mesh UV layout. Default material colors also use the official icon stored in review/official_icon.jpg.

Steel and gunmetal use directional satin highlights and restrained brushed grain; coated surfaces retain broad calm planes, limited source panel detail and subtle edges; rubber uses fine dark crossing grooves; ivory uses warm source-filtered relief, local navy markings only where present, and gold fittings. This is baked RGBA appearance under vanilla lighting, not restored dynamic PBR.
