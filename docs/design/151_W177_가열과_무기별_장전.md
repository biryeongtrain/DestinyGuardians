# W177 — 가열과 무기별 장전

## 범위와 자료

기본 Heating Up1570042021만 구현한다. 강화판2748258257은 제외한다. 기존 자동 장전 총집은 W60에서 이미70틱으로 구현돼 있어 새 구현으로 중복 계산하지 않는다. 현재 선정65무기의 공식 randomized/currentlyCanRoll 소켓만 조사하며 catalog를 임의로 넓히지 않는다.

고정 Clarity 원문은 무기 처치로 **최대2중첩·5.5초**, 안정성15/30, 반동 방향20/40, 정확도 원뿔 크기와 성장15/25% 감소를 명시한다. 수납 중 유지도 원문에 명시돼 있다. 직접 피해·조작성·장전 속도 보너스는 없다.

## 서버 연결

- 실제 탄을 지불한 원본 token의 양수 적 피해와 최종타에만 귀속한다. 일반 능력·빗나감·무적0피해·비치명은 제외한다. 원본 session의 corpse identity를 공유하여 여러 pellet/projectile/callback이 같은 처치를 중복 보상하지 못하게 한다.
- 같은 원본 equipped stack/owner/level/GuardianData/runtime/class/선택 소켓에 묶는다. backpack·복사NBT·소유권 교체·편집·정리 후 낡은 token은 새 source에 보상을 주지 못한다. 조회/HUD는 source를 새로 만들지 않는다.
- 처치마다110틱을 갱신하고 정확한 deadline에 만료한다. 수납 중 시계는 흐르며 held HUD만 숨긴다. 장전 중 보존·token 수명과 유한틱 경계는 원문과 구분한 로컬 정책이다.
- 안정성은 기존 서버 recoil/bloom/flinch 경로에 합산한다. 반동 방향은 기존 bounded horizontal kick의0..100 stat에 더한다. 정확도 크기 scalar와 성장 scalar는 서로 다른 위치에 적용한다. 원작 엔진의 반동/정확도 함수를 추출했다는 뜻은 아니다.

## HUD와 장전

실제1..2중첩/1..110틱일 때만 기존8노드 COUNT_TIMER를 표시한다. 원작에 없는 자동 장전 카운트다운은 추가하지 않는다. 기존4행 우선순위와 이전 snapshot25/24/23/21/20/19/18/16/14인자를 보존한다. HEATING UP은 시스템 글꼴로 만든118×24 저작 label이지 공식 sprite가 아니다.

별도 worktree에서 여우의 물기와 나쁜 징조의 실제 플레이 장전 영상을 찾아 각 무기용 모델/가동부를 구성한다. 원래 정돈된 외형·UV·안료·탄약·음원을 기본 보존하고 숨겨진 부품의 저작 근사는 명시한다. 손IK·추출 bone·새3인칭 장전으로 보고하지 않는다.

단계별 구현·실패·자동 검사와 Vision/청취 미검증 범위는 [W177 QA](../qa/2026-10-27/w177/README.md)에 기록한다. 오프라인 렌더와 실제 서버 테스트를 월드PNG나 native 입력의 대체로 쓰지 않는다. 전체 무기/HUD/audio 목표는 진행 중이다.
