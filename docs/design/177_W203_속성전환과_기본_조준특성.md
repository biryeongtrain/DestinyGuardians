# W203 — Osmosis, Hip-Fire Grip, Moving Target

직전 손 기능 확인 턴은 새 제품 변경이 없었다. W203은 실제 무기 속성 전환과 기본 조준 특성을 추가한다. 사용자 DDC와 정확한 공식 소켓을 사용한다.

## 소유 범위와 수락 조건

- Osmosis worker: 독립 profile/cycle/runtime helper·공식 소켓 증거·새 발동/탄약 cycle 테스트. master는 AbilityService 성공한 grenade-use 경계, Runtime lifecycle와 paid emission 속성, HUD 연결을 소유한다. DDC는 사용 시 발동이므로 성공한 activate 시 변환하며, 이후 애니메이션 중단을 능력 미사용으로 소급하지 않는다. 50% 탄창은 실제 예비탄 이전이고 stow 전 재지급하지 않는다.
- Hip-Fire Grip worker: stateless 수치 profile/helper와 소켓/DDC 증거. master는 실제 hipfire accuracy, recoil/flinch stability, falloff 적용. 기존 미구현 reticle stickiness/aim assist와 precision angle은 이번에 구현한 것으로 쓰지 않는다.
- Moving Target worker: stateless profile/helper와 소켓/DDC 증거. master는 실제 ADS movement penalty 적용과 소유 modifier 갱신/해제를 소유한다. AA 수치를 저장하는 것만으로 aim-assist 구현을 주장하지 않는다.
- 세 dirty-seeded CoW worktree를 사용하고 통합 후 compact export를 남겨 같은 배치에서 정리한다. main/dependency source는 seed 중 변경하지 않는다.

## 검증

단순 stat 값에는 퍽별 수치 테스트를 만들지 않는다. Osmosis grenade-use/한번 refill/stow/paid element와 movement modifier lifecycle 새 동작에 관련 검증을 집중한다. 기존 퍽 전체 gate는 최종 1회만 수행한다. Mac 잠금과 포트 확인 후 가능한 경우 Vision 1세션에 취합하고, 미실행은 명시한다.

## 범위 제한

기존 native combat의 kinetic-vs-elemental PvE 보너스나 aim-assist 시스템이 없는 곳에 수치를 임의 가정하지 않는다. 변환된 지원 속성은 paid shot과 HUD에 연결하고 미구현 범위를 기록한다.
