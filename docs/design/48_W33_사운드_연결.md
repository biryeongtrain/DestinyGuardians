# W33 — 무기·헌터 사운드 연결

## S1 — 범위와 계약 (2026-10-23)

- 사용자가 제공한 D2 Master SFX Drive의 공개 폴더를 직접 확인했다.
- 무기 모델 63종을 실제 서버 전투에 연결하는 작업과 음원 수집을 병렬 진행한다.
- W32 검수용 preview는 비발사를 유지하고 별도 실전 장착 명령을 둔다.
- 무기군별 발사·장전과 헌터 속성별 수류탄·근접·궁극기의 **접촉/릴리스 시점**에 소리를 붙인다.
- 원본 파일명·Drive ID·SHA256·클립/변환 정보를 남긴다. 이름으로 확인되지 않은 샘플을 정확한 해당 무기의 소리라고 표기하지 않는다.
- 서버의 커스텀 sound registry를 바닐라 클라이언트에 동기화하지 않는다. `Holder.direct(SoundEvent)` 패킷 + Polymer의 sounds.json/Ogg만 사용한다.
- 위치형 효과는 같은 차원, 최대 청취 거리 안의 플레이어에게만 전송한다. 궁극기 준비 알림은 본인에게만 보낸다.
- 무한 루프/매틱 재생은 사용하지 않는다. 취소된 스킬은 기존 cast validity 규칙에 따라 접촉 소리를 내지 않는다.
- 원본은 ignored run/private-sources/w33에 보존하고 공개 원격 저장소에는 업로드하지 않는다. 배포 저작권 허가를 새로 확보했다는 의미가 아니다.

## 검증 계획

1. 음원과 sounds.json 참조/코덱/채널/길이/SHA 점검.
2. JUnit으로 전 이벤트·무기군 범위와 pack 파일 점검.
3. GameTest로 inline vanilla packet 형식, 본인 전용 알림·중복 방지, 실제 능력 접촉 훅 점검.
4. Vision 26.3에서 실전 장착·발사·장전·능력 화면과 native 입력 확인. 패킷 전달/화면과 **실제 청음**은 구분한다.

## S2 — 전송·타이밍·후보 정책

- `DestinySounds`: sounds.json 키 검증, inline holder vanilla sound packet, 같은 차원/32블록 필터, 개인 청음/준비알림, 누락 시 기존 native fallback. `-Ddestiny.sound.qa=true`에서만 실제 connection send 키/수신자를 로그로 남긴다. 이 로그는 청음 증거가 아니다.
- 헌터 수류탄은 release/detonate, 근접은 실제 cast/contact/impact, 궁극기는 성공한 발동·공격 contact·그림자 화살 release/anchor·end에 연결했다. 능력 쿨다운/애니메이션 타이밍은 바꾸지 않았다.
- `SuperHudCue.sample()`이 새로운 충전 edge만 true를 반환한다. 같은 틱 HUD 갱신64회, 만충전으로 접속/속성 교체 시 준비 알림은 재생하지 않는다.
- OP `/destiny sound list`, `/destiny sound play <event> [player]`: 번들에 있는 키만 본인/지정 한 명에게 청음. 전체 사용자 볼륨이나 마이크를 조작하지 않는다.
- 사용자 추가 확인: **숫자 파일명 궁극기는 후보를 임시 연결하고 문서에 표시**. 소스 궁극기 정체성과 개별 동작 추정의 신뢰도를 구분한다. 청음으로 확인한 것처럼 적지 않는다.
- 독립 검토에서 native consumable의 기본 이동0.2/스프린트 제한, charged-crossbow의 hold/release 차이와 sound attenuation16 기본값을 발견했다. 무기 입력을 바닐라 재사용 패킷6틱 bounded lease와 실제 native use로 분리하는 보정, sound entry attenuation32를 진행한다.

## S3 — 최종 선별과 실제 연결

- 84키/61OGG/1,374,917bytes. MonoVorbis32kHz,decodedpeak<=-1dBFS,clippedsample0. sounds.json은attenuation32를명시.
- 무기군대표fire18/reload16,정확catalogIDalias23(일치하는ID만우선선택),일반능력·궁극기후보와UI준비음연결.
- Arc/GoldenGun전용폴더의숫자파일동작은임시추정. Shadowshot전용원음은미식별이라UnderYourSkin활/일반화살대체.
- UI준비음은ClanXP알림대체,Arc근접/Arc·Solar수류탄은super레이어대체,Void근접은D1legacy.
- fusion1.05s/linear0.65s원본분할은envelope추정이며청감검증이아님. 발사는burst첫탄에만sound,폭발/접촉은실제좌표.
- Arc근접impact는유효적접촉당1회,여러대상에중복재생하지않고miss에는미재생.
- 회피/점프와미매핑이벤트의fallback은[음원README](../qa/2026-10-23/w33/audio/README.md)에명시.

## S4 — 검토·검증 기록

- inlinepacketcodec,개인준비edge/중복/접속,같은차원/32블록필터,OP청음권한을GameTest로검사.
- 독립리뷰에서공개`destiny`루트병합의predicate유지문제를찾아`sound`노드자체에OP요구추가. 병합dispatcher로비OP3분기거부/OP허용회귀검사.
- 후보빌드18무기군native조작/서버탄약·피해,실제56PNG검토,서버send로그확보.
- 원본→JAR→Polymer팩→클라이언트다운로드팩61OGG일치. 소리디스패치/오디오엔진시작은청음증거로보지않음.
- 최종수정후gate및추가실게임범위는[W33QA](../qa/2026-10-23/w33/README.md)에기록.
