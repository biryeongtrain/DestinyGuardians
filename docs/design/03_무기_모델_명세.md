# 03. 무기 모델 명세

무기는 **플레이어가 손에 드는 아이템 모델**입니다. BetterModel이 아니라 바닐라 아이템 모델 정의(`assets/<ns>/items/*.json`)로 만듭니다. 바닐라 클라이언트가 1인칭에서 직접 그리므로 지연이 없고 가장 자연스럽습니다.

## 1. 구현 방식

### 1-1. 아이템 모델 정의 ✅

26.3 클라이언트의 `items/bow.json`, `items/spyglass.json`과 같은 구조를 씁니다. (✅ 2026-10-21, 26.3 JAR에서 확인)

- `minecraft:select` + `display_context`: 인벤토리 아이콘과 손에 든 모델을 나눔
- `minecraft:condition` + `using_item`: **우클릭을 누르고 있는 동안** = 자동 사격 중 상태
- `minecraft:select` + `custom_model_data`: 서버가 정하는 상태(정조준, 재장전 단계)

```json
{
  "model": {
    "type": "minecraft:select",
    "property": "minecraft:display_context",
    "cases": [
      { "when": ["gui", "ground", "fixed"],
        "model": { "type": "minecraft:model", "model": "destiny:weapon/hand_cannon/ace_of_spades_icon" } }
    ],
    "fallback": {
      "type": "minecraft:select",
      "property": "minecraft:custom_model_data",
      "index": 0,
      "cases": [
        { "when": "ads",      "model": { "type": "minecraft:model", "model": "destiny:weapon/hand_cannon/ace_of_spades_ads" } },
        { "when": "reload_1", "model": { "type": "minecraft:model", "model": "destiny:weapon/hand_cannon/ace_of_spades_reload_1" } },
        { "when": "reload_2", "model": { "type": "minecraft:model", "model": "destiny:weapon/hand_cannon/ace_of_spades_reload_2" } }
      ],
      "fallback": { "type": "minecraft:model", "model": "destiny:weapon/hand_cannon/ace_of_spades" }
    }
  }
}
```

> 위 JSON은 구조 예시입니다. `custom_model_data`의 문자열 목록 인덱스는 서버 코드와 맞춰야 합니다.

### 1-2. 상태 모델

| 상태 | 전환 조건 | 모델 차이 | 필수 여부 |
|---|---|---|---|
| 기본 (hip) | 기본 | 1인칭에서 오른쪽 아래 | 필수 |
| 정조준 (ads) | 좌클릭 토글 → 서버가 `custom_model_data` 변경 | 1인칭 디스플레이 변환을 **화면 중앙**으로 이동, 조준경이 눈 앞에 오게 | 필수 |
| 재장전 1~3 | Q → 서버가 틱마다 단계 변경 | 탄창 빠짐 → 비어 있음 → 탄창 들어감 | 필수 (최소 2단계) |
| 사격 반동 | 발사 틱 | 총구 위로 2~4도 기울어진 모델 1프레임 | 선택 (저연사 무기만) |
| 아이콘 | GUI | 측면 실루엣이 잘 보이는 각도 | 필수 |

- 같은 텍스처를 공유하고 **디스플레이 변환(display)만 다른 모델**을 여러 개 두는 방식입니다. 큐브를 새로 만들지 않아도 됩니다.
- 재장전처럼 부품이 움직이는 상태만 큐브 위치를 바꾼 모델을 따로 만듭니다.
- 1인칭 정조준 체감은 모델 이동 + **FOV 축소**(minigame-lib `CameraEffects.setFov`) + 저격총은 **조준경 포스트 이펙트**(07)로 만듭니다.

### 1-3. 총구 화염·탄 궤적

- 아이템 모델 안에 화염을 넣지 않습니다. 발사 위치에 **파티클 + 1틱 디스플레이 엔티티**로 그립니다. (06 참고)
- 총구 위치는 무기 명세서에 "총구 오프셋"으로 적어 두고 서버가 씁니다.

## 2. 무기 명세서 템플릿

```

표시 이름:          
종류 / 프레임:       예) 핸드캐논 / 적응형(150 RPM)
속성:               Kinetic / Arc / Solar / Void
등급:               전설 / 경이
포인트(1~2개):       
레퍼런스 메모:       art/refs/<id>.md
큐브 상한 / 텍스처:   120 / 64×64
상태 모델:           hip, ads, reload_1, reload_2, (fire), icon
총구 오프셋(1인칭):   x, y, z (블록 단위)
재장전 단계 틱:      reload_1 = 0~8틱, reload_2 = 9~20틱 ...
사운드:             발사 / 재장전 / 빈 탄창
VFX:               총구 화염 색, 탄 궤적 색 (06)
```

## 4. 3인칭에서 보이는 모습

- 다른 플레이어가 볼 때는 바닐라가 `thirdperson_righthand` 디스플레이 변환으로 그립니다. 바닐라 플레이어는 총을 "드는" 자세가 없으므로 **팔을 앞으로 뻗는 바닐라 자세(활 당기기·석궁 장전)를 빌릴 수 없는지** 확인합니다. 🧪
  - 우클릭 사용 중(`using_item`)에는 아이템 종류에 따라 팔 자세가 바뀝니다. 아이템의 사용 애니메이션 종류를 활·석궁·망원경 중 무엇으로 두느냐에 따라 3인칭 자세가 달라집니다. 무기별로 가장 총을 겨누는 것처럼 보이는 것을 고릅니다. `[결정 필요]`
- 궁극기·회피처럼 몸 전체 연출이 필요한 순간에는 BetterModel 플레이어 모델로 바꿉니다. (04)
