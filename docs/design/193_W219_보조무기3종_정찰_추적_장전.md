## 원본과 표현

SSD 원본 `.blend`5개를 별도 Blender5.4.0Alpha에서 읽기 전용 평가했다. 어깨→팔꿈치→손목과 무기 본을 확인하고61개 평가 pose와 체인 이미지를 남겼다. 원본 입력은 변경되지 않았다. 원본은 ARMATURE만 포함하며 무기 메시·카메라·손가락 IK나 정확한 부품 접촉 이벤트는 없다. Frontier Justice의 동명 장전 action3개 중80A8A345를 검토 후 선택했으며 유일한 원본 selector를 복구했다고 주장하지 않는다.

5종 모두 원본 손목의 무기 상대 변위가 LEFT 처리 손을 가리킨다. 기존 W205 캐시를 덮어쓰지 않고 `art/weapons/w219/rigs/`와 해당5ID 전용 로더 override를 사용한다. 일반 플레이어 스킨의 손가락 없는 양팔 전체 체인으로 적용한다. 팔 늘이기·축별 감쇠·손 숨김으로 맞추지 않는다.

부품 접촉/파지점과 원본에 없는 내부 탄창 축은 명시적인 authored 보정이다. 새 탄창 해석은 자기 무기의 기하·UV를 기준으로 하며 다른 총의 탄창이나 궤적을 복사하지 않는다. 장전 bank는61pose/60구간이고 원본 키와 hold를 보존한다. 이것만으로 바닐라60fps 연속 보간을 인증하지 않는다.

## 샷건 오디오 후속 수정

W210의 탄 삽입음/마지막 탄+마무리음 분리는 보존한다. 각 실제 탄약 이전에만 음원을 내보내므로 중도 발사 취소를 정상 완료로 오인하지 않는다. 추가로 마지막1.35초 cue를 플레이어별 빈 client-only item-display emitter에 연결한다. 장전 flag가 내려가도27tick 동안 자연 재생할 수 있지만, 승인된 샷건 발사는 발사음보다 먼저 자기 emitter를 제거한다. 기존 무기 교체·스킬·사망/종료 cleanup도 같은 세션을 정리한다. 전역 StopSound로 다른 플레이어의 동명 장전음을 끊지 않는다.

음원 샘플·피치·gain과 실제 탄약/연사/장전 타이밍은 이 수정으로 바꾸지 않는다. 서버 패킷·native 입력·실제 PNG·청취 증거를 구분한다. 패킷 제거만으로 스피커에서 들은 결과라고 쓰지 않는다.
