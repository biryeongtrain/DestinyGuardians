# W202 머리 추적기와 흔들림 없는 손

2026-10-27. 기존 DDC 고정 원문과 공식 소켓 풀을 사용한다. Headseeker / Steady Hands / HUD의 dirty-seeded CoW worktree 세 개로 병렬 제작하고 master가 실제 유료 피해·교체·수명 경로를 통합한다.

## 완료 조건

- Headseeker: 실제 유료 직접 비정밀 피해 뒤 0.55초(11틱) 갱신. 정밀 피해 전체가 아닌 정밀 보너스만1.2배. 같은 emission의 몸통 피해가 그 emission의 정밀 피해를 소급 강화하지 않는다. 현재 원본6종의 기본 소켓만 제공한다. DDC의 불확실3?% AA와 원작 weakspot/precision 차이는 완전 구현으로 주장하지 않는다.
- Steady Hands: 원본 선택 무기 처치 뒤 장착 무기 모두+100Handling/.825준비·수납 시간. 첫8.5초(170틱), 추가 처치6.5초(130틱), 수납 유지. 기존 법적 시간 스칼라와 원시 곡선에서 합성 후 한 번 틱 양자화. 지원하지 않는 검 곡선을 임의 생성하지 않는다.
- 새 실제 상태를 읽는 HUD 두 행. 기존 순서·네 행 상한·제거 규칙 유지. Headseeker는 짧은 준비 flag, Steady Hands는 실제 남은 시간.
- 기존 W200 Pulse Monitor HUD를 유효한 수납 원본까지 집계하도록 수정하고 미완료 중앙 검증을 수행한다.
- 새 이벤트·수명과 탄약/피해 동작에만 필요한 회귀, 대표 시나리오를 한 격리 Vision 세션에 취합한다. 단순 스탯별 테스트는 늘리지 않는다.
- 완료된 이번 워크트리는 고유 delta를 보존하고 같은 배치에서 제거한다. 메인·다른 IdeaProjects·SSD 원본은 보존한다.

## 단계

1. W201 손 구현·QA·정리 증거를 확인했다. W200의 실제 회복 상태와 HUD 설명 사이의 수납 불일치를 확인했다. 기존 결과를 통과로 재분류하지 않고 W202에서 별도 후속 증거를 남긴다.

2. 86,947개 입력 파일을 CoW 독립 워크트리 세 개에 복제했다. 기준 SHA256 `71fb435da16f4bdcf45b870728ff5ed27e68934fa19da32e279a0234cf7d09f1`. worker의 허용 경로만 delta로 수집한다.
3. master가 Pulse Monitor의 실제 수납 원본을 읽는 순수 HUD 관찰을 수정했다. 기존 회복 퍽 단위검사19개 통과. 첫 서버 실행은12개 중1개 실패: 원본을 실제 inventory.setItem으로 교체하는 동작을 단순 읽기로 간주한 테스트 기대였다. InventoryAceMixin의 실제 stow callback을 확인하고 재삽입으로 준비 상태가 부활하지 않는 기대값으로 바로잡았다. 수정 후12개 모두 통과했다. W200과 새 W202 증거는 혼합하지 않는다.
4. HUD worker의12개 소유 delta를 해시 기준선 대조 후 통합했다. Headseeker FLAG와 Steady Hands TIMER, 신규6개 팩 자산을 추가했다. 기존38필드·모든 과거 생성자와 종류 순서를 보존하고 신규40필드만 뒤에 붙였다. 순수 투영4개 검사와 자산 파싱/재현 검사는 worker에서 통과했다.
5. master는 실제 유료 emission에만 부착하는 두 token과, 실제 피해 뒤의 발동 callback, 최외곽 교체/ADS 계산, 편집·수명 정리 hook을 연결했다. 서버 GameTest4개를 작성했으며 이 시점에는 worker runtime 통합·중앙 실행 전이다.
6. Computer Use preflight는 Mac 잠금을 확인했다. 인증을 우회하거나 같은 native client를 반복 기동하지 않았다. 실화면 검증은 잠금 해제 뒤 별도 단계로 남긴다.

7. 세 worker의 총28개 소유 delta를 통합하고 agent를 종료했다. 통합 scoped JUnit38개 통과 후 GameTest fixture의26.3 setter를 수정했다. 실제 새 서버4개, 전체 JUnit2,008개·assemble·GameTest컴파일, 최종 회복 서버12개가 모두 통과했다. 새 회복·피해·교체 동작의 범위 검증이며 단순 수치마다 테스트를 늘린 것이 아니다. 상세 실패/결과는W202 QA README에 분리 기록했다.
8. 일반 무기/HUD 목표는 계속 진행 중이다. Mac 잠금 때문에 신규 실제 PNG·native 입력 검증은 미실행이며 전용 대기열로 남겼다. 완료 worker 작업본은 고유 결과를 보관하고 정리한다.

9. 완료 워크트리3개를 삭제했다. 원본과 다른 IdeaProjects 디렉터리 보존을 대조했고 가용 공간 약1.40GB 증가를 관측했다. 상세 증거와 native 미검증 큐는 [W202 QA](../qa/2026-10-27/w202/README.md)에 있다.
