# W79 — 지형 파동의 모델 VFX

## 범위와 출처

W78의 Deafening Whisper / Dimensional Hypotrochoid 지면 전파에 별도 모델을 붙인다. 피해·발사·탄약·지형·프레임 수치는 바꾸지 않는다. [W78 설계](93_W78_파동_프레임_지면_전파.md), [원작 픽셀 조사](../../art/weapons/w79/reference-notes.md), [현재 QA](../qa/2026-10-24/w79/README.md).

시공은 실제 담당 아티스트 Ben Platnick의2023 in-engine presentation을 참고했다. 얼음 바늘, 떠 있는 칩, 지면 균열/안개를 분리한다. 공허는 오래된 gameplay의160×90 storyboard에서 라벤더/흰색 융기와 보라 테두리까지만 확인했다. 상세 curl은 창작 근사이며 원작 추출 mesh·현재2026sandbox 전수재현이 아니다.

## 구조

- `WeaponRuntime.Shot` → `WeaponWavefront` → `WaveCrestVfx` 단방향 소유. 별도 gameplay clock·세계 collider 없음.
- Polymer `ElementHolder` + `ManualAttachment` + `ItemDisplayElement`. BetterModel의 기존 Hunter tracker pool을 사용하지 않는다. .5block 지형 lane을 개별 제거해야 하므로 직접 display가 더 단순하다.
- 공허6/시공10개의 live lane. lane당24개 thin native cuboid panel, 4frame64×64 atlas, 2tick/frame, interpolation=false. 무기 자체의 모델과 오디오는 보존한다.
- 양면 UV/alpha hole, native0/±22.5/±45도, shade=false/light_emission15, display brightness15/15. `NONE`의 y중앙 보정을 scale fade와 함께 적용한다.
- impact에 holder를 두고 상대 translation으로 실제 authoritative tip을 따라간다. display interpolation1tick. 새 지면 위치를 시각효과가 계산하지 않는다.
- 서버 update에 들어오는 tip 배열은 읽기만 한다. null lane은 되살리지 않는다. 벽/틈/연결되지 않은 옆lane은 W78판정 그대로다.

## 관전자와 비용

같은 dimension에서 live tip까지48block이하인 플레이어를5tick마다 갱신한다. owner도 유효한 연결과 거리 조건을 만족해야 한다. global128/owner32 **cosmetic element reservation** 한도이며 전체lane할당 또는 거부다. 거부 시 유료 shot은 그대로 작동하고 sparse native particle로 대체한다. 주 모델이 있으면 particle는4tick/격lane accent만 남긴다.

이 cap은 시각 entity payload를 제한할 뿐, 모든 피해 검색·packet수·CPU시간의 상한이나 성능보증이 아니다. 여러 관전자에서의 최대부하 실측은 남는다. 반복lane 패턴/얇은 cutout이 보이며 volumetric bloom은 구현하지 않았다.

## 수명과 장애 경계

자연만료/막힌lane/owner cleanup/차원이동/clearAll/서버종료는 display를 닫는다. `close()`는 idempotent다. 원래 할당한 모든 entityID를 별도로 보존한다. Polymer의 detach후send 예외로 ID를 잃지 않도록 detachedlane은 명시remove를 보낸다.

close는 watcher별 정리를 독립 시도하고 holder/attachment를 해제한다. 실패 연결은 원래ID와 예산을 유지한 closed session으로 남기며 END_SERVER_TICK에서 재시도한다. 성공하거나 연결이 닫히면 해제하고, SERVER_STOPPED는 죽은 서버참조를 제거한다. cosmetic runtime예외를 gameplay로 전파하지 않는다. 관측 snapshot에서는 closed/pending을 제외하지만 budget에는 포함한다.

## 편집·재현

`scripts/generate_wave_crest_w79.py`가 native model/texture/item과 별도 editable `.bbmodel`을 같은 panel 정의에서 생성한다. `--verify`는 bytecompare만 한다. Pillow는 Codex bundled Python을 사용한다. 생성기와 asset manifest를 함께 보존한다.

Blockbench MCP에서는 별도 소유 프로젝트2개만 만들고 검토후 닫았다. 원래 unsaved Duke/3탭/선택과 semantic SHA를 복원했다. 저장된 MCP preview는 native -16bound 수정 이전의 근접형태이며 최종 모델과 byte동일 preview라고 하지 않는다. 최종native자산은 nativeparser, 전체gate, Vision실제PNG로 검증했다.

최종 Gate2/3 각각665requiredGT/578JUnit, 신규18GT/3JUnit. 실제 Vision6입력(4피해/차단+2가독성)은 별도 QA참조. 원작전체 VFX·음향·다인부하·다른 무기/경이/HUD 목표는 남는다.
