# W109 — 다중 대상 피해 특성: 모두를 위한 하나 · 포위

## 범위와 근거

Minecraft 26.3 Fabric 서버사이드 제품 기능이다. 클라이언트에는 기존 Polymer 리소스팩과 Display-HUD만 전달한다. 별도 클라이언트 게임 로직은 추가하지 않는다.

| 특성 | 정확한 기본 hash | 적용 소켓 | 커뮤니티 수치 |
|---|---:|---:|---|
| One for All / 모두를 위한 하나 | 4049631843 | 기존 선정 무기 중 8개, socket4 | 서로 다른 적 3개에 무기 적중 → 피해35%, 10초, 활성 시간 갱신 불가 |
| Surrounded / 포위 | 3708227201 | 기존 선정 무기 중 8개, socket4 | 15m 내 적3개 이상 → 피해40%, 조건 상실 후1.5초 잔류; 검은35% |

공식 Bungie 데이터는 **선정된 정확한 무기 hash / socket / currentlyCanRoll / plug-set**만 입증한다. 수치는 Clarity의 커뮤니티 조사이며 공식 Bungie 수치라고 표현하지 않는다.

- **포위**: Steelfeather Repeater, First In Last Out, Hollow Words, Dream Breaker, Hammerhead, **Crown-Splitter, Falling Guillotine, Temptation's Hook**.

- 아이템은 자동 선택하지 않는다. `/destiny perk select one_for_all` 또는 `surrounded`로 선택하며 같은 소켓의 기존 선택만 교체한다. 탄약을 지급하지 않는다.

## 로컬 게임 적응 정책 — 원작 확정 사실과 구별

### 모두를 위한 하나

- 서로 다른 UUID의 **실제 양수 HP/흡수 피해**만 세고, 처치된 대상도 적중으로 인정한다. 무적·헛발사·미지급 공격은 인정하지 않는다.
- `within 3 seconds of each`의 로컬 해석: 새 고유 대상이 적중할 때60tick 수집 창을 갱신한다. 같은 대상 반복 적중은 수집 창을 갱신하지 않는다. 따라서0/59/118tick의 세 고유 적중은 발동한다. 총3초 해석과 다른 선택이며 추후 실제 원작 계측으로 조정할 수 있다.
- 세 번째 적중을 일으킨 **그 발사/휘두르기 전체**는 이전 피해 snapshot을 쓴다. 같은 산탄·폭발·검 cleave 안의 뒤늦은 대상만 갑자기 강화되지 않는다.
- 활성200tick 동안 새 수집이나 갱신은 없다. 만료 경계 `now >= deadline`에서 종료한다.
- 같은 소유자·차원·실제 ItemStack 참조가 유지된 보관 무기는 세션이 유지되고, 발사 후 무기를 바꿔도 기존 유료 투사체가 원래 소스에 적중을 기록한다. HUD는 들고 있는 소스만 보인다.

### 포위

- 과거8m가 아니라 고정 근거의 **15m**를 쓴다. 로컬 기하 판정은 발 위치 간3차원 구, 경계 포함이다. 시야선 조건은 추가하지 않는다.
- 이미 로드된 엔티티만 조회한다. 자신·플레이어·방어구 거치대·죽거나 제거된 개체·관전·동맹·길들인 동물은 제외하고 기존 PvE 적 필터를 따른다. 원작의 전투원 분류를 Minecraft의 모든 Mob과 동일시하지 않는다.
- 조건이 처음 사라진 관측 tick부터30tick이 남는다. 마지막 충족 tick부터 세는1tick 부족 구현이 아니다. 재진입하면 잔류가 아닌 충족 상태로 돌아온다.
- 보관 시 실시간 버프/HUD는 즉시 해제한다. 이미 지불·발사된 투사체는 원래 소스의 피해 snapshot을 유지한다. 소스 소유권·편집 epoch가 무효화되면 token은 무효다.
- 선정된 유탄/로켓에는 포위 소켓이 없으므로 원본의 유탄·로켓 impact/explosion 예외를 지원한다고 주장하지 않는다. 선정된 검의35% 예외는 적용한다.

## 통합 규약

1. 실제 비용 지불 후 발사/검 접촉 단위로 소스 token을 캡처한다.
2. 총기 즉발·차지/버스트·유탄 파동/폭발·검 light/heavy/caster 경로가 동일 snapshot 계약을 쓴다. 빈 검 약공격·능력·월도 근접은 제외한다.
3. 기존 살상 탄창/광란과 별도로 실제 피해 요청에 배율을 반영한다. 같은 socket4 특성끼리는 동시 선택할 수 없다.
4. 피해 확정 후 양수 실제 피해일 때만 One for All의 고유 대상 callback을 실행한다.
5. 선택 편집/해제, 소스 상실, 소유자·차원 변경, 죽음·연결 종료·궁극기·loadout 폐쇄 시 세션을 검증·폐기한다. 상태는 아이템 데이터로 복사하지 않는다.
6. HUD 조회는 상태를 생성하거나 시간을 갱신하지 않는다. 모두를 위한 하나는 실제 남은 시간, 포위는 지속 조건/잔류 중인 활성 행을 표시한다. 아직 원작에서 계측하지 않은 수집 HUD는 임의로 만들어 원작이라고 주장하지 않는다.

새 HUD 라벨2개는 시스템 폰트로 생성한 오리지널 PNG/SVG다. 공식 스프라이트를 복사한 것이 아니다. 아이템 atlas에 포함되는 `textures/item/hud` 아래에 두며, 두 label의 pack 증분은 정확히6개 파일이다.

## 병렬 구현·수용 기준

- 독립 dirty-snapshot Git worktree 두 개가 상태기계·프로파일·wrapper·자기 단위 테스트를 각각 소유한다.
- master는 공유 레지스트리/Runtime/HUD, 중앙 회귀, 모든 Vision/CU 입력을 소유한다. 작업자는 같은 런타임 fixture를 조작하지 않는다.
- 단위 테스트 통과, 생산 GameTest 통과, native 입력, 실제 PNG 관측은 서로 다른 증거다. 각 결과와 실패는 [W109 QA](../qa/2026-10-25/w109/README.md)에 구분한다.
- W107/W108 봉인 QA는 그대로 보존한다. 이 두 특성 추가가 전체 데스티니 무기 시스템 완성을 뜻하지 않는다.
