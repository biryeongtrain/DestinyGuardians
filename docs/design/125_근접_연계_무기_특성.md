## 무뢰한 / Swashbuckler

- 기본 trait hash `4082225868`. 유료 무기 피해의 실제 최종타 → 1중첩, 최대5; 직접 근접 처치 → 즉시5.
- 매 proc마다4.5초/90tick 갱신. **모든 중첩이 함께 만료**, 광란의 중첩별 decay와 다르다. 단계별 피해 배율1.067/1.133/1.2/1.266/1.333. 활성화시킨 같은 emission에는 소급하지 않는다.
- 무기를 집어넣으면 live buff 즉시 제거. accepted hotbar/inventory stow hook으로 같은 tick 복귀도 처리한다. 지불한 투사체의 emission damage snapshot은 유지하지만 edit/lifecycle은 폐기한다.
- LOCAL 정책: source가 stow된 동안에는 새 live kill buff를 얻지 않는다. 근접은 accepted cast의 원래 무기가 계속 손에 있어야 하며, 도중 stow/복사/교체/선택 편집은 근접 token을 폐기한다.
- 정확8무기: gnawing_hunger, steelfeather_repeater, cold_denial, bug_out_bag, lonesome, biting_winds, whispering_slab, mindbender_s_ambition_adept. 전부 socket4.

## 묘지 도굴꾼 / Grave Robber

- 기본 trait hash `1631667848`. 이번에 고정한 설명은 **강화 근접 적중** 및 일반·월도 근접 **처치** → 탄창 보충, 내부 cooldown3초/60tick이다. 과거의 강화근접 처치 전용 버전으로 구현하지 않는다.
- 유한 특수탄은 예비탄·보존 overflow만 이전하며 총량을 보존한다. 주무기의 기존 infinite reserve 정책은 그대로이며 화면에 가짜 유한 reserve를 만들지 않는다.
- reload animation/사운드/살상 탄창·무법자 등의 manual reload callback을 발생시키지 않는다. 원래 무기의 진행 중 reload/charge를 취소해 이중 credit을 막되 firing cadence를 초기화하지 않는다.
- LOCAL 정책: cooldown은 owner-wide이며 stow·특성 편집으로 초기화되지 않는다. 유효한 적중에서 full/no-reserve로 이동량0이어도 cooldown을 소비한다. 원문은 이0이동·scope 세부까지 입증하지 않으므로 로컬 결정으로 분리한다. true lifecycle cleanup만 reset.
- 정확9무기: steelfeather_repeater(3), cold_denial(3), claws_of_the_wolf(4), patron_of_lost_causes(3), bug_out_bag(3), ikelos_smg_v1_0_1(4), lonesome(3), dead_man_walking_xx7463(4), dust_rock_blues(4).
- 두 trait가 서로 다른 socket인 무기는 공존 가능하다. 자동 장착/탄약 지급은 하지 않는다.

## 실제 근접 출처

무기·수류탄·궁극기도 `playerAttack` DamageSource를 쓰므로 generic onKill에서 melee를 추측하면 안 된다. `HunterMelee`의 accepted cast에서 source를 capture하고 실제 Arc contact/Solar knife 직접 HP·흡수 피해 확인 후에만 보상한다. 연막의 상태 부여와 knife scorch DoT는 직접 강화근접 피해로 세지 않는다. 월도 melee도 명시적 contact hook을 거치지만 현재 선정된 월도에는 두 특성 소켓이 없으므로 다른 stowed 무기에 보상을 주지 않는다. 일반 비강화 주먹 melee 시스템은 기존 제품에 없어 새로 구현했다고 주장하지 않는다.
