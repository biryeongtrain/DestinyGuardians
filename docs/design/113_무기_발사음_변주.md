# W98 무기 발사음 변주

## 적용 대상과 동작

W98은 아래 전설 무기 **3종의 기존 발사 이벤트**에 같은 무기 폴더의 `Fire_2`와 `Fire_3`를 추가한다. 무기별 선택지는 기존 `Fire_1`을 포함해3개이며, 새 제품 파일은 **Ogg6개**다.

| 무기 / 정확한 카탈로그 ID | 유지하는 이벤트 | 출처 폴더의 원본 |
|---|---|---|
| Seventh Seraph Officer Revolver / `seventh_seraph_officer_revolver` | `weapon.seventh_seraph_officer_revolver.fire` | `Fire_1.wav`, `Fire_2.wav`, `Fire_3.wav` |
| Steelfeather Repeater / `steelfeather_repeater` | `weapon.steelfeather_repeater.fire` | `Fire_1.wav`, `Fire_2.wav`, `Fire_3.wav` |
| The Recluse / `the_recluse` | `weapon.the_recluse.fire` | `Fire_1.mp3`, `Fire_2.mp3`, `Fire_3.mp3` |

클라이언트는 발사 이벤트 하나를 받을 때 기본 동일 가중치의 음원 하나를 고른다. 1→2→3 순환이나 매3발마다 전부 재생하는 규칙은 없다. `stream=false`, 감쇠 거리32와 기존 자막을 유지한다. 서버의 발사 횟수·탄약·연사 간격·피치·장전 동작을 바꾸지 않는다.

기존 W33 `Fire_1` Ogg는 재인코딩하지 않고 각 이벤트의 첫 항목으로 남긴다. 세 family 이벤트(`hand_cannon`, `auto_rifle`, `submachine_gun`)와 다른 무기의 매핑도 유지한다. 전체162개 이벤트 키를 추가·삭제·개명하지 않았으며, 그중 위3개 정의만 바꿨다. **런타임 Java 소스 변경은 없다.**

새 파일 경로는 `src/main/resources/assets/destiny/sounds/w98/<정확한 ID>/fire_2.ogg`, `fire_3.ogg`다. 기존7,013개 자산 중 `sounds.json`만 수정하고6개를 추가해7,019개가 됐다.

## 출처와 검토용 음원

사용자가 제공한 [Drive 원본 루트](https://drive.google.com/drive/folders/1kWVlvhqvFkf_If5Q9Zd0mMIM1haa6u4l)에서 기존 W33 선정 무기 폴더를 확인했다. [폴더 목록](../../art/weapons/w98/audio/folder-discovery.json)과 [원본9개 pin](../../art/weapons/w98/audio/source-pins.json)에 정확한 파일명·Drive ID·원본 해시를 남겼다. 선정은 업로더의 무기명/행동명에 근거하며, 독립 청취 식별이나 재배포 라이선스를 뜻하지 않는다. `Fire_Burst`, `Fire_Multi`, `Fire_Full_Mag`를 대안으로 섞지 않았다.

[생성기](../../scripts/audio/build_fire_variants_w98.py)는 고정한 W33 변환 helper·ffmpeg를 사용한다. 새 제품 음원은 mono32kHz Vorbis이며, 변환 구간·gain·fade·출력 측정값과 해시는 [음원 구현 manifest](../../art/weapons/w98/audio/implementation.json)에 기록했다. 제품 클립을 이어 붙이거나 반복 재생하도록 만들지 않았다.

사용자는 아래 WAV로 **Fire1→Fire2→Fire3**를 비교할 수 있다. 각 클립 뒤1초 무음을 붙인 mono32kHz/16bit 검토 파일이며 게임 리소스가 아니다. 이 문서 작성자는 재생·청취하지 않았다.

- [Seventh Seraph 비교 WAV](../../art/weapons/w98/audio/audition/seventh_seraph_officer_revolver_fire_123.wav)
- [Steelfeather 비교 WAV](../../art/weapons/w98/audio/audition/steelfeather_repeater_fire_123.wav)
- [The Recluse 비교 WAV](../../art/weapons/w98/audio/audition/the_recluse_fire_123.wav)

## 검증과 남은 범위

새2GT는 실제 유료 발사→W92 PLAY 인코더/클라이언트 의미 decode 경로에서 정확한 이벤트·탄약3→2→1·거절 입력 무음·첫 cadence 경계, 거리2/32/32.25 및 Austringer family fallback을 검사한다. 실제 인증 클라이언트나 유지 자동사격·다른 차원 수신자 검증은 아니다.

새5JUnit은 정확한3이벤트/6Ogg와 원본 보존, 출처/출력 측정, 다른 무기·장전 매핑 격리, 검토 WAV 구조를 검사한다. 기존 W33/W56 시험은6개 음원명/3개 이벤트만 유한 목록으로 이관했다. namespace 전체 허용은 없다.

[최종 QA 검토](../qa/2026-10-25/w98/final-review.md): 강제 gate1/2 각각820GT·704JUnit 통과, 동일 JAR. FOVtrue 서버 생성 팩12,171항목의 변경도6개 추가와 `sounds.json` 수정으로 제한했다. 소스와 팩의 JSON 직렬화 차이는 정확한146경로의 과거/현재 예상 compact 바이트로 검사하고 나머지6,873개는 원시 바이트로 비교했다.

**Native 다운로드 캐시·클라이언트 재생·선택 분포·실청취는 미수락**이다. W98은 클라이언트를 시작하지 않았다. [N3 조사](../qa/2026-10-25/w98/n3-source-review.md)에서 속성별 Dragonfly 원음을 식별하지 못했으므로 기존 임시 수류탄 impact를 유지한다. W97 HUD 후보와 전체 원작 재현 목표도 이 변경으로 완료되지 않는다.
