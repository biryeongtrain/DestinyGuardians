# 캐릭터 장비 화면(실제 데스티니 인벤토리) 기획

작성 2026-11-04 · 상태: **검토 대기** (사용자 평가 후 착수)

## 1. 목적

지금 E 키로 여는 장비 창은 개발용이다. 슬롯 → 새 무기 → 무기군 → 무기 → 퍽 → 추가 순서로 아무 무기나 만들어 넣는 "테스트 무기고"가 중심이다. 이것을 데스티니 2의 **캐릭터 장비 화면**으로 바꾼다. 플레이어는 자기가 실제로 가진 장비만 보고, 슬롯을 골라 교체하고, 툴팁과 상세 화면에서 능력치·특성을 확인한다.

테스트 무기고는 없애지 않고 관리자 전용 도구로 남긴다.

## 4. 화면 구성

원본 장비 화면 배치(`PREVIEW.png`)를 따른다. 기준 캔버스는 기존과 같은 1920×1080, 가운데 정렬이다.

```
┌──────────────────────────────────────────────────────────────────┐
│ [직업 표식] 캐릭터 이름 · 직업          전투력 ◆ 1810   [능력치 6종] │
│                                                                    │
│  [하위직업]                                           [헬멧]       │
│  [기본 무기]                                          [건틀릿]     │
│  [에너지 무기]          (수호자 모델)                 [가슴 방어구] │
│  [파워 무기]                                          [다리 방어구] │
│  [고스트]                                             [직업 아이템] │
│                                                                    │
│  ← 슬롯 옆으로 펼쳐지는 보관 칸 3×3                    툴팁 →      │
│                                                                    │
│ [E] 닫기   [좌클릭] 장착   [F 길게] 상세 보기                      │
└──────────────────────────────────────────────────────────────────┘
```

### 4.1 장비 슬롯 (10칸)

- 왼쪽 5칸: 하위직업, 기본(키네틱), 에너지, 파워, 고스트 의체.
- 오른쪽 5칸: 헬멧, 건틀릿, 가슴 방어구, 다리 방어구, 직업 아이템(망토·표식·완장).
- 각 칸은 96px 아이콘 + 원본 슬롯 프레임(`80A9F583` 계열). 희귀도는 배경색으로 표시한다(전설 보라, 경이 금색, 희귀 파랑, 일반 녹색/흰색).
- 칸 아래쪽 띠에 무기는 속성 아이콘과 전투력, 방어구는 전투력만 쓴다.

### 4.2 보관 칸 (슬롯별 9칸)

데스티니처럼 슬롯마다 **장착 1개 + 보관 9개**를 갖는다. 슬롯에 커서를 올리면 그 옆에 3×3 보관 칸이 펼쳐진다. 왼쪽 슬롯은 오른쪽으로, 오른쪽 슬롯은 왼쪽으로 펼친다.

- 보관 칸에 올리면 툴팁에 장착 중인 아이템과의 **능력치 비교**가 함께 나온다(올라간 값 녹색, 내려간 값 빨간색 막대, 원본 `comparison_bitmap`).
- 좌클릭하면 바로 장착한다. 기존 장착 아이템은 보관 칸의 그 자리로 간다.
- 보관 칸이 다 찬 상태에서 새 장비를 얻는 규칙은 5.3에 둔다.

### 4.3 툴팁

원본 툴팁(`80A9F799` 래퍼, `80A9F72A` 본문)의 구성을 따른다. `PREVIEW.png` 오른쪽 패널과 같다.

1. 머리: 아이콘, 이름, 종류 · 희귀도 · 속성 (희귀도 색 배경)
2. 설명 문구 (`flavour`)
3. 전투력, 탄약 종류
4. 능력치: 이름 + 막대 + 값. 막대 없는 값(분당 발사 수, 탄창, 반동 방향 등)은 숫자만
5. 특성: 현재 장착된 프레임·총열·탄창·특성 1·2와 마스터워크, 아이콘 포함
6. 입력 안내: `좌클릭 장착`, `F 길게 상세`

표시·숨김은 175ms 페이드다. DisplayHud 텍스트 불투명도를 틱마다 보간하므로 실제로는 3–4틱에 걸쳐 바뀐다.

### 4.4 상세 화면 (F 길게 누르기)

무기 하나를 크게 보는 화면이다.

- 가운데에 무기 3D 모델 (기존 인게임 무기 모델을 아이템 디스플레이로 표시, 천천히 회전).
- 왼쪽에 능력치 전체, 아래에 특성 열(소켓별 한 열). 무작위 옵션이 있는 무기는 열마다 선택 가능한 대안을 보여 주고, 지금 고른 것을 강조한다.
- 특성 교체는 이번 범위에 넣을지 결정이 필요하다 (10장 질문 3).

### 4.5 하위직업 화면

하위직업 슬롯을 누르면 지금의 "캐릭터" 탭 기능(직업·하위직업·수류탄·근접·직업 능력·궁극기·점프 선택)을 데스티니 하위직업 화면 배치로 다시 그린다. 저장·검증 경로(`guardian.CharacterLoadouts`)는 그대로 쓴다.

### 4.6 상단 정보

- 캐릭터 이름, 직업 표식, 전투력(장착한 무기 3 + 방어구 5의 평균, 소수점 버림).
- 캐릭터 능력치 6종: 원본 샘플 기준 **생명력, 근접 공격, 수류탄, 궁극기, 직업, 무기**. 방어구 기능이 연결되기 전에는 숨기거나 0으로 보이지 않게 한다 (7장 참고).

### 4.7 가운데 수호자 모델

본인의 플레이어 모델(실제 스킨)을 화면 가운데에 세운다. **구현 결정(2026-11-04):** 원작 캐릭터 렌더나 사전 렌더 초상 대신 플레이어 본인 모델을 쓴다.

- 방식: 카메라를 옮기지 않는다. 공용 `inventory/PlayerFigure`가 BetterModel의 플레이어별 스킨 부위 아이템(DynamicUV, 개인별 팩 없음) 12개를 steve 리그 본 위치에 놓고 DisplayHud 화면 좌표로 정사영한다. 깊이는 납작하게 눌러 HUD 층 하나 안에 머문다. 1인칭 시야와 월드 패킷은 그대로라 전투 중에도 열 수 있다.
- 자세: 약간 돌아선 대기 자세(`PlayerFigure.Pose.STANDING`). 오른손에 장착 중인 기본 무기 모델을 3인칭 손 표시로 쥔다. 다른 무기를 장착하면 손의 무기도 바뀐다.
- 스킨이 없는 계정(오프라인 QA 계정 등)은 BetterModel 대체 스킨으로 보인다.
- 남은 것: 원본 72본 대기 클립 리타기팅, 커서를 올린 보관 무기 미리 쥐기, 방어구 외형(7장 3단계).

## 5. 아이템과 데이터

### 5.1 아이템 인스턴스

장비 하나하나를 인스턴스로 저장한다.

| 필드 | 설명 |
|---|---|
| `id` | UUID |
| `definition` | 무기 정의 id (`destiny/weapons/*.json`) 또는 방어구·고스트 정의 id |
| `power` | 전투력 |
| `plugs` | 소켓별 선택 특성 |
| `masterwork` | 마스터워크 능력치와 단계 |
| `locked` | 잠금 (분해 방지) |
| `acquiredAt` | 획득 시각, 새 아이템 표시 판단용 |

저장 위치는 기존 수호자 데이터 첨부(GuardianData 계열)에 새 필드로 둔다. 슬롯별 `equipped` 1개와 `stored` 최대 9개를 갖는다.

### 5.2 실물 아이템과의 연결

전투 코드(`WeaponRuntime`, 탄약, 장전)는 지금처럼 핫바 0–2의 실물 무기 스택을 읽는다. 장비 화면에서 장착을 바꾸면 해당 핫바 칸의 스택을 새 인스턴스로 다시 만든다. 스택에는 인스턴스 id를 넣어, 스택을 버리거나 복제해도 실제 소지 목록은 바뀌지 않게 한다. 보관 중인 장비는 실물 스택으로 존재하지 않는다.

장착 교체 시 지켜야 할 것:
- 장전·사격·궁극기 중에는 교체를 거절하거나 끝난 뒤 적용한다.
- 탄약 규칙: 같은 탄약 종류 안에서의 교체는 남은 탄약을 유지하고, 파워 무기는 예비 탄약을 공유한다 (현재 `AmmoEconomy` 규칙과 맞춤).

### 5.3 획득과 가득 찬 경우

이번 단계에서 실제 획득처(활동 보상·상점)는 없다. 대신 아래 경로만 만든다.
- 관리자 명령과 테스트 무기고가 "획득" 경로를 거쳐 인스턴스를 만든다.
- 보관 칸이 가득 차면 **우편함**(최대 20개)으로 보낸다. 우편함은 장비 화면 한쪽 버튼으로 열고, 거기서 받기만 한다. 금고는 이번 범위 밖이다.

### 5.4 기존 플레이어 이전

처음 접속할 때 인벤토리에 있는 무기 스택을 인스턴스로 바꾼다. 핫바 0–2는 장착, 나머지는 해당 슬롯 보관 칸, 넘치면 우편함. 이전 후 원래 스택은 지운다. 이전은 한 번만 실행되고 결과를 기록한다.

### 5.5 아이콘

- 원본 묶음의 아이콘은 37종뿐이다. 우리 무기 정의는 96개다.
- 나머지 아이콘을 만드는 방법은 두 가지다 (10장 질문 5).
  - **가. 공식 아이콘 사용:** 원작 아이템 해시로 같은 규칙(배경 + 전경 레이어)의 아이콘을 추가 추출해 받는다. 원작과 가장 가깝다.
  - **나. 인게임 모델 렌더:** 우리 무기 모델을 측면에서 렌더해 희귀도 배경 위에 합성한다. 바로 만들 수 있지만 원작 아이콘과는 다르다.
- 크기: 96px 아이콘 + 상세 화면용 160px. 아이콘 100종 기준 리소스팩 증가는 약 3–4MB로 추정한다 (250MB 목표 안).

### 5.6 한국어 문구

이름·종류·설명은 무기 정의의 기존 한국어 이름을 쓰고, 원작에 있는 무기는 `items-ko.json`과 같은 방식으로 원문 설명을 채운다. 능력치 이름은 원본 표기(충격, 사거리, 안정성, 조작성, 재장전 속도, 조준 지원, 확대/축소, 반동 방향, 공중 효율, 탄약 생성, 분당 발사 수, 탄창)를 쓴다.

## 6. 입력

| 입력 | 동작 |
|---|---|
| E / `/메뉴` / GCB 0 | 열기·닫기 (기존과 같음) |
| 마우스 이동 | 커서 이동 (기존 `WeaponScreenControls` 방식) |
| WASD | 칸 단위 이동 |
| 좌클릭 / Space | 선택·장착 |
| F 길게 (0.5초) | 상세 화면 |
| 우클릭 / Esc | 한 단계 뒤로, 최상위에서는 닫기 |
| Q 계열 | 지금처럼 버리기만 취소, 장전하지 않음 |

GCB 사용자와 일반 사용자의 키 표기는 기존 분리 규칙을 따른다.

## 7. 방어구와 고스트: 단계 나누기

방어구는 지금 게임에 존재하지 않는다. 화면만 만들고 기능을 비워 두면 빈 칸이 된다. 그래서 단계를 나눈다.

| 단계 | 내용 | 비고 |
|---|---|---|
| 1 | 슬롯·툴팁·보관 칸은 만들고, 방어구는 기본 세트 1벌(직업별 원본 샘플 세트)만 장착된 상태로 표시. 능력치 영역 숨김 | 이번 구현 범위 |
| 2 | 방어구 능력치 6종을 실제 능력에 연결 (생명력→체력 회복, 근접·수류탄·직업·궁극기→재사용 대기, 무기→무기 피해/장전). 수치는 DDC 대조 | 별도 기획 |
| 3 | 방어구 외형을 수호자 모델에 입힘 (헬멧·가슴 등 부위 모델) | 별도 기획, 모델 작업 큼 |

고스트 의체는 1단계에서 외형 선택만 한다(튜토리얼·브리핑에 나오는 고스트 모델 교체). 고스트 개조 기능은 넣지 않는다.

## 8. 제약

- **성능:** 화면을 연 상태의 디스플레이 엔티티를 120개 이하로 유지한다. 커서가 움직일 때는 바뀐 요소만 다시 보낸다. 툴팁 하나에 텍스트 디스플레이 20개 이하.
- **리소스팩:** 신규 UI 텍스처는 원본 259장 중 실제 쓰는 것만 고른다(예상 40장 내외, 1MB 이하). 글꼴은 이미 쓰는 Noto Sans KR 계열을 공유하고, 새 글꼴 파일은 추가하지 않는 것을 목표로 한다.
- **상황 제한:** 궁극기 사용 중, 시네마틱, 다운 상태, 탑승 중에는 열지 않는다. 활동 중 전투에서 여는 것은 허용 여부를 정해야 한다 (10장 질문 2).
- **공용 코드:** 슬롯·보관 칸·툴팁 위젯은 다른 화면(금고, 상인, 보상 화면)에서도 쓰도록 `inventory` 공용 위젯으로 만든다.

## 9. 구현 순서와 확인 기준

| 순서 | 작업 | 확인 기준 |
|---|---|---|
| 1 | 아이템 인스턴스 저장, 장착·보관·우편함, 기존 무기 이전 | 단위 테스트: 장착 교체, 가득 참, 이전 1회, 복제 스택 무효 |
| 2 | 장비 화면 배치·슬롯·보관 칸 (아이콘 임시) | 실화면: 10칸과 3×3 펼침, 장착 교체가 핫바에 반영 |
| 3 | 툴팁·능력치 비교·전환 | 실화면: 175ms 페이드, 비교 막대 색 |
| 4 | 아이콘 (5.5에서 고른 방법) | 96종 모두 아이콘 있음, 팩 크기 증가 기록 |
| 5 | 상세 화면 | 실화면: 무기 모델 회전, 특성 열 |
| 6 | 하위직업 화면 재배치 | 기존 캐릭터 탭 기능 전부 동작 |
| 7 | 가운데 수호자 모델과 대기 모션 | 실화면: 6개 직업·체형 클립 재생, 손에 장착 무기 |
| 8 | 테스트 무기고를 관리자 전용으로 이동 | 일반 플레이어에게 보이지 않음 |

각 단계는 격리 서버에서 Vision 실화면으로 확인하고, 마지막에 1인·3인 동시 열기와 재접속 후 상태 유지를 확인한다.
