# W179 — 기관총·융합소총·샷건 장전 확대

## 변경 범위

- **Fixed Odds**: 개별 기관총 장전 모션. 탄통·탄띠·급탄부의 방향과 결합을 확인한다.
- **Null Composure**: 개별 에너지 셀 교체 모션. 기존 Dream Breaker 동작을 이름만 바꿔 재사용하지 않는다.
- **Mindbender’s Ambition (Adept)**: 처음 들어 올리기 → 같은 자세에서 한 발씩 반복 삽입 → 짧은 복귀의 세 단계. 기존 5발 탄창과 16틱 삽입 간격을 유지한다.

세 작업은 현재 미커밋 파일까지 복제한 독립 Git worktree에서 진행한다. master가 공유 라우팅·실제 서버 테스트·통합 Vision QA를 담당한다. 기존 모델의 정돈된 입체·UV·안료·ADS와 음원은 기본적으로 보존한다. 조립체당 출력 요소 상한은 1,000이다. 새 손 IK나 3인칭 장전 애니메이션을 구현한 것으로 표현하지 않는다.

## 상태 권한과 게임 동작

whole-magazine 두 모델은 기존 float1 실시간 소유권을 사용한다. Mindbender는 기존 float4 initial/loop/return을 사용하고 Long Arm·First In Last Out과 다른 item graph로 연결한다. 기존 accepted reload plan·탄약 지급 시점·취소 처리는 수정하지 않는다. 장식용 셀/셸은 탄약 권한을 갖지 않는다. 복사한 아이템·OP 미리보기·저장된 selector만으로 장전 모션을 활성화할 수 없다.

native/twohand와 양쪽 1인칭 display context를 지원한다. 비1인칭·ADS·inspect는 기존 canonical fallback을 유지한다. 재장전 뒤 ADS 회복·취소 소유권·원본 스택 교체는 master QA에서 확인한다.

## 후처리 경고 조사

실제 26.3 바닐라 GameRenderer는 매 프레임 요청 목록에 `minecraft:end_of_frame`을 먼저 추가하지만 바닐라 JAR에 같은 이름의 post_effect JSON은 없다. ShaderManager는 이 항목을 경고하고 유효하지 않은 효과만 건너뛴다. 이 경고만으로 `destiny:super/*`가 실패했다고 판단하지 않는다.

경고를 지우기 위한 빈 효과·로그 필터·클라이언트 패치를 넣지 않는다. 제품의 9개 궁극기 post-effect는 실제 26.3 config CODEC 테스트와 별도 native GPU/framebuffer 관측으로 확인한다. CODEC 통과는 GLSL 컴파일 증거가 아니며, 서버 add/remove 성공도 실제 화면 적용 증거가 아니다.
