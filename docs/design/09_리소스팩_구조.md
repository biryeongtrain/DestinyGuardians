# 09. 리소스팩 구조

플레이어는 접속할 때 서버 리소스팩 하나를 받습니다. 이 팩은 **Polymer가 여러 모드의 리소스를 합쳐서** 만듭니다. 여러 출처가 같은 파일을 쓰면 하나만 남으므로, 파일 소유권을 미리 정해 둡니다.

## 1. 팩을 이루는 출처

| 출처 | 넣는 것 | 비고 |
|---|---|---|
| 이 프로젝트 (`destiny` 모드) | 무기 모델, 아이콘, 폰트, 장비 텍스처, 포스트 이펙트, 사운드 | 직접 관리 |
| BetterModel | 플레이어 limb·적·보스 모델 (자동 변환) | `.bbmodel`에서 자동 생성. 코어 셰이더 없음 ✅ |
| minigame-lib 2.0.0 | DisplayHud·ShaderFX용 **코어 셰이더 덮어쓰기**, `entity_outline` 포스트 효과, 전환 텍스처, 음악 | ✅ 26.3 포팅 완료 |
| Polymer | 자동 생성 아이템 모델 매핑 | |

## 2. 폴더 구조 (destiny 네임스페이스)

```

│  │  └─ weapon/hand_cannon/ace_of_spades.json
│  ├─ models/
│  │  ├─ weapon/<종류>/<이름>[_상태].json
│  │  └─ projectile/...
│  ├─ textures/
│  │  ├─ item/weapon/...
│  │  ├─ font/hud/...            # HUD 글리프 (08)
│  │  ├─ entity/equipment/...    # 방어구 텍스처 (04-6)
│  │  └─ effect/...              # 포스트 이펙트 텍스처 입력 (스코프 마스크 등)
│  ├─ equipment/                 # 방어구 장비 에셋 정의
│  ├─ font/hud.json
│  ├─ post_effect/
│  │  ├─ super/arc_active.json
│  │  ├─ keyword/...
│  │  ├─ state/...
│  │  ├─ hit/...
│  │  └─ raid/...
│  ├─ shaders/post/*.fsh         # 포스트 이펙트 셰이더 (07)
│  └─ sounds/ + sounds.json
└─ minecraft/
   ├─ post_effect/end_of_frame.json   # 소유: destiny (07-5) ⚠️ 하나뿐
   ├─ post_effect/entity_outline.json # 소유: minigame-lib (손 위 HUD) ⚠️
   └─ shaders/core/...                # 소유: minigame-lib (DisplayHud) ⚠️
```

## 3. 파일 소유권과 충돌

| 파일 | 소유 | 충돌 위험 | 대응 |
|---|---|---|---|
| `minecraft:post_effect/end_of_frame.json` | destiny | 다른 모드·팩이 정의하면 하나만 적용 | 서버 팩 안에서 destiny만 정의. 다른 모드가 필요하면 destiny 디스패처에 합침 |
| `minecraft:shaders/core/text.*`, `entity.vsh`, `item.vsh`, `block.vsh`, `rendertype_outline.vsh` | minigame-lib | 다른 코어 셰이더 모드와 충돌 | 코어 셰이더를 덮어쓰는 모드는 minigame-lib 하나만 허용 |
| `minecraft:post_effect/entity_outline.json` + `shaders/post/displayhud_*.fsh` | minigame-lib | 바닐라 발광 테두리 동작이 바뀜 | 발광 효과 사용 시 확인 (11 결정 항목) |
| `minecraft:shaders/include/*` | minigame-lib (`hud.glsl` 등 추가 파일) | 낮음 | 추가 파일 이름에 접두어 사용 |
| BetterModel 생성 모델 | BetterModel | 낮음 (자체 네임스페이스) | – |

## 4. 26.3 셰이더 공통 규칙 ✅

- `#version 330` + `#extension GL_ARB_separate_shader_objects : require`
- `#include <minecraft:...>` (`#moj_import` 사용 불가)
- 모든 입출력에 `layout(location = N)`
- uniform은 `layout(std140) uniform <블록이름> { ... }`
- OpenGL·Vulkan 둘 다 ShaderC로 컴파일됨 → 한쪽에서만 되는 문법 금지
- 근거: 26.3 클라이언트 `shaders/post/blit.fsh`, `shaders/core/text.vsh`, 26.3 공식 변경 사항

## 5. 빌드

1. `art/` 원본 → 빌드 스크립트가 `src/main/resources/assets/destiny/`로 복사
2. 글리프 CSV → `font/hud.json` 생성, 상태 모델 목록 → `items/*.json` 생성
3. 서버 시작 시 Polymer가 모든 출처를 합쳐 팩 생성 → 자동 호스팅
4. 생성된 팩을 CI에서 26.3 클라이언트로 열어 **셰이더 컴파일 로그**를 확인 (헤드리스 검증이 어려우면 수동 체크리스트)

## 5-1. 확인 결과 ✅ (2026-10-22, W1-02)

테스트 서버(`./gradlew runServer`)에서 Polymer 0.18.4, BetterModel 3.5.1, minigame-lib 2.0.0을 함께 로드하고 리소스팩 생성까지 확인했습니다. 생성된 팩에는 minigame-lib 셰이더만 코어 셰이더를 덮어쓰고, BetterModel은 셰이더를 넣지 않습니다. 화면 표시(W1-04)는 아직 확인 전입니다.
