# W38 — 월도 3인칭 전방 조준·양손 파지

## 최우선 인수조건 (사용자 스크린샷 피드백 반영)

**3인칭 칼끝이 1인칭처럼 캐릭터의 조준 전방을 향해야 한다.**
가슴 앞에 가로로 받치는 자세를 우선한 r1/r2는 잘못된 방향이므로 최종안이 아니다.
정면에서 칼이 짧아 보이는 원근은 정상이며, 측면에서 얼굴/조준 방향과 칼끝이 같은 쪽이어야 한다.
W37 1인칭 hip/ads/inspect 및 원본 246큐브·안료는 그대로 보존한다.

## S2 최종 구현

- 기본 그립에 월도 추가: 양손 기본 46장총+1월도=47종, 선택 가능 56종. 활·검 제외.
- 기존 Polymer wire-only CROSSBOW + CHARGED_PROJECTILES 경로로 바닐라 양팔 자세를 사용한다.
  실제 서버 무기에 석궁 탄약을 넣거나 실제 오프핸드를 바꾸지 않는다.
- `art/weapons/w38/thirdperson-pose.json`: 회전 `[95.729578,0,-162.811266]`,
  이동 `[-2.5,-2,0]`, 크기 `1.1`. 총기 -Z축과 달리 월도는 local +Y가 칼끝 방향이다.
- 26.3 `ItemInHandLayer`의 Rx(-90)Ry(180) 및 crossbow main arm 행렬을 포함해
  **local +Y를 avatar 전방 -Z로 변환**했다. 주먹 사이를 통과하도록 자루를 1.5 모델픽셀 안쪽으로 보정한다.
- 회귀 기준: pitch -25/0/25 및 양손에 대해 칼끝·조준 내적 >0.999, 좌우 편향 <0.03.
  주손 중심에서 자루축 거리 <1.5픽셀, 보조손 <1.2픽셀 (일반 주먹 반폭 2픽셀).
  이는 head/body yaw가 일치하는 표준 idle 계산이며 임의의 회전/스윙까지 푸는 IK는 아니다.
- W37 1인칭 구도에 기존 W32 carrier 역변환을 그대로 적용한다.
  전체 63종×3포즈×좌우손의 native/보정 행렬 회귀도 유지. **1인칭 양팔 생성 아님.**
- 런타임 에셋 변화는 월도 `_twohand` parent 3개뿐. 원본·텍스처·GUI·다른 무기는 바이트 보존.

## 적용 및 경계

새 월도는 기본 양손. 기존 저장 아이템의 NATIVE 설정은 강제로 덮어쓰지 않는다.
기존 월도를 든 OP는 `/destiny weapon grip two_hand`로 전환한다(탄약/pose/오프핸드 유지).
`/destiny weapon grip native`는 이전 한손 fallback이다.

바닐라 팔을 쓰는 전방 준비/이동 자세이며, 원작 관절·손가락·콤보 IK 재현은 아니다.
큰 head/body yaw 차이·극단 pitch에서는 보조손 접점 오차가 생길 수 있다.
근접 휘두름 중에는 바닐라 우선순위로 양손 hold가 잠시 풀린 뒤 복귀한다.
오프핸드 장비를 숨기거나 제거하지 않으며 dual-wield 보정은 지원하지 않는다.
실제 입력·화면 검수는 오른손, 왼손은 수학 회귀다.
