# W125 — 원본 UV와 정돈된 표면 재질

## 목적
에이스/이자나기처럼 큰 면과 UV 디테일로 무기를 읽히게 한다. 1,000요소는 상한이지 목표 수량이 아니다. 이번 배치는 Ammit960/Recluse808 geometry를 유지하며 UV/정적 RGBA만 보강한다. 전체 무기/HUD/사운드 목표는 계속 진행한다.

## 원본 사용
사용자가 제공한 Drive rip의 로컬 FBX/이미지와 W31 Bungie/light.gg 참조를 사용한다. Ammit .blend의 material/image 연결은 별도 Blender background/factory-startup/disable-autoexec로 읽었다. 원본 Python을 실행하거나 사용자 미저장 GUI scene을 덮어쓰지 않는다.

## Ammit 방식
- FBX UV0 polygon-vertex index를 복원하고 source connected-component별 앞/뒤 표면을 depth projection한다.
- undyed diffuse RGB를 그대로 쓰지 않고 밝기 디테일 + normal relief를 참조 blue-alloy/navy/steel/teal에 bake한다. source vent/fastener/panel seam 위치를 사용한다.
- 양면 cap별 UV와 edge gutter를 따로 두고 작은 relief를 위해 geometry를 더 쪼개지 않는다. fluid window swirl은 참조 기반 고정 그림이다.
- 출력은 보통 RGBA. 동적 normal/PBR shader·원작 반사·굴절·fluid animation 복원이 아니다. W124의 일정 두께 component/일부 작은 lettering/곡면 한계가 남는다.

## 통합과 검증
같은 W123 6-target Polymer output migration을 사용하며 최종 texture/model hash를 재생성한다. geometry fingerprint/part union/display/1,000cap/이미지 기본검사를 targeted로 수행한다. 실제팩·1/3인칭·ADS·분리장전과 짧은20display 관측은 master가 한 세션으로 취합한다. 오프라인 이미지와 실제 PNG를 구분한다.
