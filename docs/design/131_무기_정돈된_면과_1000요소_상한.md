# W124 — 정돈된 무기 표면과 합산 1,000요소 상한

## 최신 사용자 방향

- 에이스/이자나기 같은 정돈된 면 구성이 목표이며 원본 실루엣과 특징은 보존한다. 기술적 불가능이 아니라 저작 방식 선택의 문제다.
- 현재 기존 canonical 모델을 확인한 결과 Ace 87요소, Izanagi 79요소다. 이 숫자가 새 무기의 의무 예산은 아니며 1,000개도 채워야 할 목표가 아니라 최대치다.
- 조립된 무기 1개의 본체+탄창 전체에서 큐브와 삼각/윤곽 출력 요소를 합쳐 1,000개 이하. full과 분리 모델은 동일 형상이므로 중복 계산하지 않는다. 삼각 어댑터가 2요소를 내보내면 2개다.

## 구성 원칙

1. 긴 총몸·레일·개머리판은 연속된 큰 회전 큐브/패널로 정리한다. 불필요한 미세 원본 bevel을 전부 옮기지 않는다.
2. 사선·곡면·복잡한 윤곽과 열린 구멍에만 선택적 alpha contour/triangle panel을 쓴다. 평면에 잘게 겹치는 조각을 쌓지 않는다.
3. 작은 표식·표면 디테일은 텍스처 중심으로 유지하고, 파지/장전/탄창의 실루엣은 입체 구조로 남긴다. 무기 전체를 한 상자로 근사하지 않는다.
4. 원본 fitting 기준축·anchor·default paint와 기존 display·ADS·장전 partition·게임플레이는 보존한다.

## 적용/검증

이번 대상은 W123 아미트/은둔자이며 공유 output converter는 같은 6개 경로를 사용한다. 생성기와 pack manifest 생성 단계에 조립체 cap을 둔다. 관련 모델/팩 targeted 검사와 비교 이미지를 우선하며 전체 gate나 전각도/FPS 인증을 반복하지 않는다.

실제 진행·통과/미검증 범위: [W124 QA](../qa/2026-10-25/w124/README.md). 기존 W115 opt-in 후보 등 다른 과거 고밀도 자산을 이번 두 자산 검사만으로 1,000개 이하라고 주장하지 않는다.
