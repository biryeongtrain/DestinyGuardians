# W213 — 보조무기·소총 원본 리그 장전

Lonesome / Steelfeather Repeater / Aisha’s Embrace / Chattering Bone의 원본 팔 체인과 61포즈 장전을 적용했다. 실제 원본 Blender 평가 → 61포즈 생성 → 1차 Vision → 담당 에이전트 피드백 → 통합 → 2차 Vision 순서를 마쳤다. 독립 워크트리 4개에서 무기별 generator/profile/review를 병렬 작업하고 master가 공유 코드·팩 생성·검수를 맡았다.

Lonesome은 탄창이 삽입된 뒤에도 후반 손 동작을 따라가는 문제를 발견해, 손·팔 FK는 유지하고 탄창 추종만 .60~.75 구간에 종료했다. 나머지 세 종은 원본 동작·실화면이 일치해 추가 수치 변경 없이 수락했다. 기존 형상·UV·ADS·전투/탄약/장전시간·오디오는 유지한다.

관련 JUnit 13/13, source binding 1/1, 두 차례 native 입력 시나리오 각 12/12와 실제 캡처 검수를 완료했다. 팔 포함 최대 출력은 각각 684/687/665/660개다. 공유 무기군의 bone-only 소스여서 원작 메시·카메라·고유 IK 복원으로 주장하지 않으며, 61포즈와 표본 PNG는 연속 60fps 보증이 아니다.
