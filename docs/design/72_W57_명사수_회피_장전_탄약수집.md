# W57 명사수 회피: 전체 장비 재장전·주변 탄약 수집

## 현재 상태와 원작 근거

기존 명사수 회피는 짧은 cooldown과 구르기만 구현돼 있었으며 일반 무기를 재장전하지 않았다.
W57에서는 **성공한 회피 발동 즉시 모든 장착 무기를 실제 예비탄으로 재장전하고, 주변 개인 탄약 상자를 수집**한다.

- [Bungie 9.1.5](https://www.bungie.net/7/en/News/Article/destiny_update_9_1_5),2025-10-07:
  발동 시 주변 탄약 수집과 모든 무기 재장전으로 변경. 구형 주손 전용 설명 대신 이 버전을 따른다.
- [Bungie 9.5.0](https://www.bungie.net/7/en/News/Article/destiny_update_9_5_0),2025-12-02:
  수집 반경10m→15m. 이 모드에서는15블록으로 대응한다.
- Bungie 공식 inventory definition426473316의 설명도 두 효과를 확인한다. 라이브 Manifest metadata는
  기존W51의2026-10-13버전/path와 일치하며199MB기존캐시SHA와선정정의를검사했다. 새inventory다운로드는 하지 않았다.

[출처·획득법·검증 경계](../../art/weapons/w57/references/README.md), [구조화 근거](../../art/weapons/w57/references/sources.json).
공식 원문은privatecache, 짧은근거/해시만문서에남긴다. 모든 중간 패치를 빠짐없이 조사했거나 현재 원작을 실플레이했다고 주장하지 않는다.

## 입력과 적용 대상

기존 class ability 입력(C 또는 Shift 두번), `AbilityService.use`의실제승인경로를사용한다.
HunterSkillCast.begin 성공후/물리이동전효과를확정한다. 뒤의T+2먼지/소리cue나Tasks가탄약전송을반복하지않는다.
거절된cooldown/dead/spectator/super중입력은전송/수집까지도달하지않는다. Gambler의근접충전/탄약미변경은그대로다.

- 3슬롯장비활성시:정규KINETIC/ENERGY/POWER의현재진짜ItemStack만적용한다. 선택손이건축블록이어도정규장비는적용한다.
- 가방/보조손/프리뷰/잘못된슬롯은제외하고아이템복사/이동/비밀탄약풀을만들지않는다. 같은참조는identity로1회처리한다.
- 기존OP standalone프리뷰검증모드호환은현재든live무기하나만대상이다. 이를원작의전체장비동작이라고표현하지않는다.
- 검은단일탄약pool이므로재장전대상에서제외한다. 회피가검energy·heavy회복을채우지는않는다.
  기존heavy brick의검탄약획득자체는W51의단일pool규칙을유지한다.

## 원자적 처리와 탄약 보존

한서버콜스택에서다음의유한transaction을실행한다.

1. 기존State의pendingreload/charge/burst/holding/emptyreload후보와cosmetic재장전을정리한다.
   State자체나WeaponCycle을새로만들지않아공유readyAt/cadence를보존한다. 활use해제전holding을취소해발사되지않게한다.
2. 장착탄창을기존reserve/legacyoverflow로채운다. Primary는기존무한reserve정책만이용하고유한Special/Heavy는보유량이상채우지않는다.
3. 소유자개인brick목록(기존최대24개)에서몸기준15블록구체에있는실제상자를한번수집한다.
4. 새reserve에서아직비어있는탄창공간을채운다. 활은loadedidle로돌리고기존장전바/전용모델을없앤다.
5. 실제인벤토리변경을전파한다. AbilityService의기존CombatHud.update가현재장탄수·예비탄·보조두줄을즉시반영한다.

2→3→4는**자체구현순서**다. 예비탄이가득찬빈탄창은먼저장전해서수집공간을만들고,
예비탄0이면방금얻은탄약도남은공간으로장전한다. 공식노트는두효과를명시하지만이내부알고리즘을보증하지않는다.
정규장전음/장전모션을억지로중첩하지않고기존회피소리를유지한다. 별도음원/geometry/HUDlayout은바꾸지않는다.

## 개인 탄약 수집

기존AmmoEconomy의개인owner·level·만료·loadedchunk·정규탄종·중복수집방지·doubleSpecial분할을그대로사용한다.
역사meter를다시현금화하거나다른유저brick을훔치지않는다. reserve와탄창이진짜가득차거나장착탄종이없으면상자는남는다.
특별수집은서버몸위치이며원격camera위치가아니다. 새반복자석task/무한범위쿼리/강제chunkload없음.

**정확15블록경계포함·3D구체·벽통과는자체정책**이다. 원작의실제벽/층간조건이나충돌shape를확인했다고주장하지않는다.
기존일반접근수집은1.5블록+LOS로유지한다. 특수동작의sphere를일반pickup경로에누출하지않는다.
