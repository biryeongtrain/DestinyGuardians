# W193 — 퍽 집중 배치

## 범위와 진행

사용자 지시에 따라 애니메이션 조사·추출·구현은 Windows 파일 수령까지 중단한다. 기존 handoff는 보존한다. 이번 배치는 무기 기본 Trait 다섯 종류를 격리 worktree 세 곳과 master 공유 구현으로 진행한다.

| 기능 | 담당 | 실제 연결 범위 |
|---|---|---|
| Ambitious Assassin · 야심찬 암살가 | master | 13개 실제 기본 Trait 소켓; 처치 누적 → 실제 timed reload 탄약 지급 때 초과 장전 |
| Clown Cartridge · 광대 탄약통 | overflow-magazines worker | 3개 소켓; 실제 timed reload 완료 시 10~50% 초과 장전 |
| Overflow · 범람 | overflow-magazines worker | 3개 Primary 소켓; 소유 Special/Heavy 벽돌 획득 시 stow 포함 2배 탄창 |
| Adagio · 아다지오 | adagio worker | Aisha’s Embrace·Canis Major; 실제 최종타 후 7초 피해·사거리·발사 간격 |
| Impulse Amplifier · 충격 증폭기 | impulse-amplifier worker | Canis Major·Code Duello·Nezarec’s Whisper; 재장전과 투사체 속도 |

- 기준: 사용자 Destiny Data Compendium Weapon Perks 탭. 기본/강화 구분 및 정확한 무기·소켓은 각 `art/weapons/w193/*/source.json`에 원문·해시와 함께 보존한다.
- 수치만 추가하는 충격 증폭기는 출처와 실제 적용 경로를 확인한다. 테스트 개수나 Vision 시나리오를 늘리기 위한 수치 반복 검사는 만들지 않는다.
- 탄약·최종타·발동/만료·불변 발사 스냅샷은 필요한 동작 회귀를 수행한다. native 입력·화면/청취 검증을 수행했다고 주장하지 않는다.

## 단계 1 — 격리와 데이터

- 기존 dirty/untracked 제품 66,413파일을 hash 기준선으로 복제. SHA256 `aeb964012681d92d2cce3435a19aa88ab5019f241978fcc4c8fc100dd450999c`.
- `w193-adagio`, `w193-impulse-amplifier`, `w193-overflow-magazines` 각각 전용 GCB 의존성·build/run 및 배타 파일 소유권을 사용한다.
- master는 공유 레지스트리·Runtime·탄약 저장과 통합 회귀를 소유한다. 이전 W192 봉인은 변경하지 않는다.

## 단계 2 — 탄약 기반

- 기존 `WeaponMagazine.overflow()`는 용량 축소 때 보존한 legacy debt다. 이를 탄창에 적재한 퍽 탄약과 혼용하지 않는다.
- `WeaponItems.LOADED_LIMIT`를 별도 저장하고, 정확히 선택한 지원 퍽 한도 내에서만 초과 적재를 복원한다. 퍽 변경 뒤 초과분은 예비/legacy debt로 보존한다.
- `reloadOverflow(target)`는 기존 유한 예비/보존 탄약에서만 옮긴다. Primary는 기존 무한 예비 정책이다. 일반 reload·정밀타 환급은 계속 기본 탄창 한도까지만 적용한다.
- HUD는 실제 loaded count를 표시한다. 기존 `WeaponAmmoState`의 rounds≤capacity 계약은 표시용 capacity에 현재 적재 수를 반영해 유지한다.

## 단계 3 — 퍽 이벤트 연결

- 정확한 공식 기본 Trait 풀 총 24개 소켓 조합(AA13/CC3/Overflow3/Adagio2/Impulse3)을 연결했다. 레지스트리는 49→54종이다. 무기를 들고 `/destiny perk list`, `/destiny perk select <id>`로 선택한다. 기본 선택을 자동 부여하지 않는다.
- Runtime은 실제 timed reload 시작 성공 후 CC/AA 토큰을 저장한다. 양의 실제 탄약 지급 콜백에서 한 번만 목표 탄창을 계산하고 예비 탄약으로 추가 장전한다. 기존 ammo-credit 시점은 recovery 종료보다 빠를 수 있으며 그 권위 있는 지급 경계를 재사용한다.
- AA는 Primary 처치당 20%, Special/Heavy 10%, 최대 150% 증가(총 250%)를 올림한다. 카운터는 stow로 지우지 않으며 별도 만료 창을 만들지 않는다. CC는 10~50%를 한 번 추첨한다. 정수 균등 추첨은 로컬 구현 정책이며 DDC가 RNG 분포까지 명시한 것은 아니다.
- 취소·질의·회피 장전·능력 장전은 CC/AA를 새로 발동하지 않는다. 유한 탄약은 기존 예비 및 legacy debt에서만 지급한다.
- Overflow는 실제 개인 Special/Heavy 벽돌 지급 안에서 정확히 장착된 원본 Primary를 2배까지 채운다. stow된 무기도 포함하며, Heavy 예비가 가득 차 있어도 Primary에 실제 이득이 있으면 벽돌을 소비한다. 어느 수령자에게도 이득이 없으면 벽돌을 남긴다.
- Adagio는 실제 유료 무기 최종타 후 140틱 동안 피해×1.3, Range+10, 발사 주기×1.2를 적용한다. 첫 처치를 낸 emission이 자기 자신을 소급 강화하지 않으며 직접/폭발이 같은 피해 토큰을 공유한다. stow/자연 만료는 이미 발사한 피해 스냅샷을 바꾸지 않으며 새 발사 간격은 cycle.fire 전에 고정한다.
- Impulse Amplifier는 +20 Reload와 시간×0.85(로켓×0.8)를 원본 곡선에 적용하고, 동일 무기의 실제 다른 소켓 Frenzy 합산 후 한 번만 clamp/ceil한다. 로켓 속도×1.10은 유료 Shot 생성 때 한 번만 적용한다.
- **미확정 범위:** 현재 DDC와 조회한 light.gg 연구에서 Canis Major(유탄)·Nezarec’s Whisper(월도)의 Impulse 속도 수치가 누락돼 있다. 해당 두 종류의 재장전 효과는 연결했지만 속도는 입력값을 유지한다. 이를 원작 효과가 없다는 뜻으로 해석하지 않는다. 과거의 범용 35%를 임의로 소급하지 않는다.
- 새 세션은 edit/clear, owner/world/class/runtime 교체·죽음·연결 종료·서버 종료 때 무효화한다. 이미 자금을 지불한 loaded ammo는 아이템 저장 상태로 보존한다.

## 검증

- 생성기 다섯 개의 deterministic `--verify` 통과. 기본/강화·원본 소켓·DDC 원문과 속도 미확정 상태를 확인했다.
- 새 상태/탄약 JUnit 19/19 통과. 최초 server-targeted GameTest 5/5 통과: AA 최종타→취소/stow→장전, CC 실제 유한 탄약 지급/중복 방지, NBT 복원과 퍽 해제 시 보존, Adagio 실제 다음 발사 피해, Overflow stow/full-Heavy 실제 개인 벽돌.
- 첫 전체 회귀는 `WeaponUseTraceTest`의 읽기 함수 소스 고정 계약 1개가 W193 생성자 인자 추가를 반영하지 않아 실패했다. `loadedLimit`가 exact-roll/saved-count 읽기만 수행함을 검토하고 기존 계약을 갱신했다. 이 실패 로그도 보존한다.
- 최종 전체 JUnit **1,901/1,901 통과**, 실패·오류·skip 0. 전체 서버 **1,281개 중 1,257 통과 / 24 실패**. 실패 ID 24개는 W192와 동일하고 새 W193 실패는 없다. 과거 모델/reticle/wire 계약과 간헐적 ThreatDetector ADS 실패는 미해결 상태다. 이전에 관찰된 다른 실패가 이번에 보이지 않는다는 이유로 수정 완료라고 판정하지 않는다.
- `test build`는 위 서버 실패 때문에 exit 1이며 **전체 gate는 green이 아니다**. `assemble`은 통과했고 JAR를 생성했다. 관련 원문·JUnit XML·서버 실패 비교는 `docs/qa/2026-10-27/w193/`에 보존한다.
- JAR: `build/libs/destiny-guardians-0.1.0+26.3.jar`, 48,830,774 bytes, SHA256 `34ac7e97588f90cd75e4c6609d7e4259b86bf9a4606030bca7f43ee767c6f45a`.
- 전체 무기/HUD 목표는 계속 진행 중이며 이번 결과를 목표 전체 완료로 표시하지 않는다.
- W192 봉인 291개 파일은 해시가 모두 그대로다. worker 세 개는 통합 후 종료했고 worktree는 보존했다.
- Vision/native 입력·렌더링·청취 검증은 이번 배치에 수행하지 않았다. 애니메이션 보류를 유지한다.
