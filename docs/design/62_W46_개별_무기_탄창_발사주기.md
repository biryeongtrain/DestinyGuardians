# W46 — 개별 무기 탄창 · 발사주기 · 충전 · 재장전

## 목표
W45 이후 남은 군별 고정 장탄수/발사간격을 선택63종의 공식 base stat과 검증된 커뮤니티 수식으로 교체한다.
전체 무기 목표의 진행 단계이며 원작 전체 완성으로 세지 않는다.

## 인수 기준
- 공식 아이템 hash·stat 이름·단위·pinned source SHA를 저장한다. Reload Speed stat을 초로 오인하지 않는다.
- 수치는 base-item 기준. 장착 perk·magazine plug·masterwork·모드가 적용된 원작 roll과 같다고 주장하지 않는다.
- 20Hz 정수 반올림으로900RPM을600RPM으로 낮추지 않는다. 소수 잔여시간을 보존하되 중복패킷/idle/lag로 추가 사격 크레딧을 만들지 않는다.
- Pulse/sidearm은 bullet마다1발, Stormchaser·fusion은 trigger/burst당1발. 마지막1발로도 예약된 bolt가 끝까지 나간다.
- sub-tick burst는 bounded loop로 해당 burst만 처리한다. 취소/무기교체는 예약만 취소하고 소비한 탄을 반환하거나 cooldown을 초기화하지 않는다.
- Shotgun은 shell마다 실제1발을 이전하고 HUD에 갱신, 취소 시 아직 넣지 않은 예비탄을 보존한다.
- 군별 damage/physics는 기존 Minecraft balance이며 실제 Destiny damage 숫자 복제 아님.
- 실제 입력·서버 HP/탄약·HUD PNG·받은 pack/JAR/class provenance를 나누어 검증한다.

## 현재 연결한 근거 / 제한
- 데이터/API: `art/weapons/w46/README.md`, 공식 base stat63개와 실제 stat definition 단위를 검증했다.
- 공식 [Update2.1.0](https://www.bungie.net/7/en/News/article/47462) Shotguns 섹션은 shell 단위 재장전과 첫shell/이후shell의 구분을 명시한다.
  shell별 이전 자체는 근거가 있지만 특정 source곡선을 insert에 사용하는 것은 근사이고 첫동작 지연은 아직 미구현.
- Long Arm에 일반 scout곡선42tick을 한 발마다 적용하면14발을 채우는데 약29초로 악화되므로 적용하지 않았다.
  현재 whole-mag 근사를 유지하며 실제2발씩 넣는 동작/정확한 insert 타이밍은 후속이다.
- 재장전은 pinned May20 community quadratic 근사, base stat은 Oct13공식 snapshot이다. 최신sandbox/roll과의 완전 일치 아님.
- Fusion5/7/9bolt는 기존 charge당 총damage를 보존하도록 bolt당localdamage를 나눈다. 원작damage 주장이 아니다.
- 샷건 탄환 분포는 기존8pellet 근사 유지. 실제12pellet/frame고유패턴·개별reloadanimation·rapidframe reloadmodifier는 후속이다.
- 구형 저장탄이 새 capacity를 넘으면 기존 clamp정책이 적용된다. 용량 증가가 저장탄을 채워주지는 않는다.
  데이터migration 중 초과탄의 무손실 재배분까지 구현한 것은 아니므로 운영 반영 전 저장아이템 audit이 필요하다.
