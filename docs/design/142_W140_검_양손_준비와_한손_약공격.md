## 사용자 요청

검을 낮게 한손으로 드는 기존 공통 자세 대신 높게 양손 파지하고, 약공격은 한손으로 베도록 수정한다. 원작 프레임별 차이는 남기되 사용자 요청한 공통 표현을 먼저 만든다.

## 제품

- `scripts/build_sword_pose_w140.py` → `art/blockbench/animations/guardian_sword_w140.bbmodel` / `src/main/resources/destiny/animation/sword_w140.animation.json`.
- 기존 rig/pivot 그대로, 양손을 같은 손잡이에 연결. 약공격 접촉 시 왼손 분리 후 복귀. ready/guard/air/move12clip 총체계와 기존8공격 cue·duration 보존.
- `SwordPoseW140Assets`가 새 이름으로만 설치하고 `PlayerAnimations` sword renderer를 새 모델로 연결. 역사적 W53/W55 art/runtime와 사용자 수정 설치본은 보존한다.
- 독립 CoW worker의 `SwordHandModelAssets`는 출력 아이템5개의 first-person mesh만 차단한다. 원래 fallback을 통째로 보존하며 canonical 모델 소스는 수정하지 않는다. 캐시된 vanilla hand overlay 대책이며 서버 native use에 필요한 combat item/components는 유지한다.
