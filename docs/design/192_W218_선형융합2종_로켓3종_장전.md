# W218 — 선형 융합2종·로켓3종 장전

이번5종은 FIRST 검수에서 발견한 로켓 적재 손 오류를 수정한 뒤 SECOND Vision을 마쳤다. 전체 무기 시스템 목표는 계속 진행 중이다.

기존21포즈 경로를61포즈/60구간으로 바꾸고 정지점마다 멈추던 보간 대신 C1 weighted harmonic PCHIP를 적용한다. 기존 작성한 knot/hold, 무기별 탄통·로켓 분할과 경로, 기하/면별 UV, 기본 파지/ADS, 장전 시간/탄약/사운드는 보존한다. 팔은 손가락 없는 플레이어 스킨으로 원본 어깨–팔꿈치–손목 방향 및 보통 길이를 사용한다.

원본 Blender5.4 background 평가에서 기존 행렬오차0과 입력 불변을 확인했다. 원본에는 리그만 있으므로 숨은 탄통 치수/파지점/카메라까지 복원했다고 하지 않는다. W218 리그는 별도 경로에 보관하고 이번5종만 override한다. 이전 W205 캐시를 덮어쓰지 않는다.

독립 worktree5개에서 생성기/profile/review 각3파일만 worker 소유, 공통 라우팅·리그 loader·출력·빌드·Vision/CU는 master 소유다. FIRST actual PNG를 같은 worker에게 전달하고, 수정 또는 근거 있는 무변경 후 SECOND actual PNG를 확인한다. 팔을 포함한 실제 조립 대안 경로 최댓값은1,000이하다. 대안들을 중복 합산하지 않는다.

검증·진행·실패·잔여 한계와 복구/정리는 [W218 QA](../qa/2026-10-28/w218/README.md)에 기록한다. W210 샷건 분리 음원의 실제 바이트/레지스트리를 유지하며 과거 청취/게임 증거를 새로운 검증으로 반복 계수하지 않는다.

FIRST에서 로켓 원본은 오른손 적재인데 공유 빌더가 왼손으로 고정한 문제를 발견했다. 프로필별 hand 선택을 추가하고3종을 right로 지정했다. Bellowing은 첫 로켓 표시 .35부터 손에 완전히 부착되도록 접근 구간만 보정했다. SECOND actual PNG에서 들린 로켓/탄통·장착 접근·손 복귀와 최종 탄약을 확인했다. 두 패스 native각15회, 수정본 JUnit13개 및 hand regression4개가 통과했다. 팩/실게임 증거와 손바닥 가림·offscreen·비연속 프레임·미청취/미실시3P/성능 범위는 QA에 명시했다.
