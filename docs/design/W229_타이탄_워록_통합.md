# W229 타이탄·워록 통합

## 구현 범위
Fabric 26.3 서버사이드/Polymer 구조에 타이탄·워록의 전기·태양·공허 기본 세트를 추가한다. 각 직업의 점프1·직업능력1·수류탄3·근접3·궁극기3으로 11개씩이다. `/guardian class titan|warlock` 후 `/guardian subclass arc|solar|void`로 선택하며, 직업별 로드아웃은 따로 저장한다. 헌터 황금총의1인칭 예외는 유지하고 새 궁극기6종은 후방3인칭을 사용한다.

타이탄: lift/높은 방벽, pulse·fusion·suppressor 수류탄, 전기 전방타격·투척망치·방패투척, 대혼란의 주먹·태양의 망치·파수병 방패.
워록: glide/치유 균열, storm·solar·vortex 수류탄, 연쇄번개·소각 스냅·소형 특이점, 폭풍몰입·새벽칼날·신성 폭탄.

## 원본과 재생
승인된 모델 Drive와 사운드 Drive에서 필요한 소품·음원을 선별 확보했다. SSD의 Super-Animation-VFX 전달본을 읽기 전용으로 사용한다. 실제 `.blend`를 별도 headless Blender에서 평가하고 72본/30fps 원본을 기존 Steve 스킨 리그에 61pose로 retarget한다. 원본 재생시간을 유지하며 root 이동은 플레이어 실제 이동으로 적용하지 않는다. 1차 구현에서 하체가 고정되는 결함을 확인하여 타이탄 3종의 이동 루프와 새벽칼날의 칼 든 대기·이동·공중 루프를 분리했다. 파수병 이동 하체는 전용 sprint 원본이다. 새벽칼날 대기는 실제 일반 sword-catch idle을 사용한 임시 캐리 루프이며 Daybreak 전용 state 연결은 미확정이다. 워록 공허는 전체 cast 단발만 사용한다. 설치 모델 ID는 `guardian_classes_w229_r3`다.

대혼란의 주먹은 source family 미식별이다. 헌터나 Thundercrash로 대체하지 않는다. 사용자가 작업 후 다른 궁극기와 함께 추가 전달하기로 했다. 새 state machine과 임시 파티클은 전용 원본 모션 완료와 구분한다. 미해독 event를 원작 충돌시점으로 주장하지 않고 kinematic 후보+게임 내 조정을 임시값으로 기록한다.

## 통합 경계
AbilityService가 두 직업의 tick·사망·차원변경·logout·서버종료를 통합 관리한다. 서로 다른 직업 또는 잘못된 슬롯의 persisted ability는 실행 전에 거절한다. 직업전환은 실제 인벤토리를 바꾸지 않는다. BetterModel 장비 override는 표시만 바꾸며 플레이어 스킨을 사용한다. 수류탄/강화근접은 기존 퍽 귀속 훅을 공유한다.

수치 단위는 HP·block·tick이다. 최신 DDC15개 기본 능력 행의 초 단위 cooldown/duration과 조건을 조사했다(`art/classes/w229/sources/ddc-class-values.md`). 직접 대응하는 시간값은20TPS로 반영하고, 피해·회복·거리·현재 스탯별 회복은 Minecraft 임시 환산과 구분한다. 사용자 지정 DDC를 전수 대조했다고 주장하지 않는다. PvE 대상·LOS·bounded 수명·투사체 수·소유자 cleanup의 새 동작을 GameTest와 취합 native QA로 검증한다. 단순 수치퍽 개별 테스트는 추가하지 않는다.

## 수락 기록
검증 진행과 결과는 `docs/qa/2026-10-28/w229/step-log.md` 및 최종 QA README에 기록한다. 1차 Vision의 실제 PNG를 담당 agent에 전달한 뒤 반환을 반영하고2차 Vision으로 검수한다. 오디오 packet 로그·decode 검증과 실제 청취를 구분한다.

## 적군용 붉은 변형 — 향후 PvP 준비

타이탄·워록 소품/VFX 6종과 근접 alias 2개(20자산), 헌터 BetterModel VFX 8종 및 능력 item 10루트의 실제 의존 자산(37파일)을 `_enemy`로 분리했다. 원본 실루엣·UV·alpha·animation은 보존하고 붉은색 계열로 변환했다. 로컬 HUD와 화면 PostEffect는 적군 월드 표시가 아니므로 바꾸지 않는다. 기존 속성 파티클도 별도이며 이번 텍스처 준비 범위에 포함하지 않는다.

`AbilityVisualVariants.item(stack, hostile)` / `.model(name, hostile)`가 표시만 선택한다. `ClassAbilityEffects.item(path, hostile)`도 같은 API를 쓴다. 기존 호출은 원래 속성색이며 적군용 item을 요청해도 원본 stack은 변이하지 않는다. 없는 변형은 원래 모델을 유지한다. 헌터 enemy BetterModel 자산은 원본과 함께 install-if-absent 정책으로 설치한다.

현재 전투판정은 PvE여서 플레이어를 적 대상으로 삼지 않는다. 실제 관전자별 팀 관계·팀 변경·중립 FFA 정책·중복 모델 억제는 이후 PvP 런타임에서 연결해야 한다. 한 공유 display를 적군색으로 바꾸면 아군도 같은 색을 보게 되므로, 향후 연결 시 관전자별 표시 소유권을 분리해야 한다. 이번에는 실제 리소스팩의 일반/적군 방벽·균열·신성폭탄을 정적 전시 fixture로 확인했다. 이를 실제 다인 PvP 검증으로 보고하지 않는다.

최종 결과와 비교 화면은 [W229 QA](../qa/2026-10-28/w229/README.md)에 있다.
