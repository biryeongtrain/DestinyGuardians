# 캐릭터 로드아웃

메뉴를 열고 상단 **캐릭터** 탭을 선택한다. `/메뉴` 또는 기본 E(인벤토리) 키로 메뉴를 열고 닫는다. E를 다시 누르면 닫히며, GCB 사용자는 기존 0 키도 보조 입력으로 사용할 수 있다. 마우스 또는 WASD로 포커스를 옮기고 좌클릭/Space로 선택한다. 우클릭으로도 닫을 수 있다.

Shift+Q로 메뉴를 여는 기능은 제거했다. 메뉴가 닫힌 상태에서 일반 무기의 Q·Shift+Q는 일반 장전이다. 이자나기의 짐은 Q로 일반 장전, Shift+Q로 특수 장전을 시도한다. Ctrl+Q(`DROP_ALL_ITEMS`)는 장전하지 않고 무기 버리기만 취소한다. 장전 성공·거절과 무관하게 실전 무기는 버려지지 않는다. 메뉴가 열려 있으면 Q 계열 입력은 버리기만 취소하며 메뉴를 닫거나 장전을 시작하지 않는다.

- 직업: 헌터·타이탄·워록 중 선택한다. 다른 직업으로 전환했다 돌아오면 그 직업의 마지막 저장 구성을 복원한다.
- 하위직업: 현재 구현된 전기(아크)·태양(솔라)·공허 중 선택한다. 바꾸면 원소가 맞지 않는 능력을 해당 하위직업 기본 능력으로 교체한다.
- 수류탄·근접 능력·직업 능력·궁극기: 항목을 눌러 현재 직업과 하위직업에 등록된 능력만 선택한다. 공통 직업 능력과 점프는 해당 직업에서 모든 빛 하위직업에 호환된다.

선택은 즉시 적용되고 기존 수호자 데이터에 저장된다. 옵션이 하나인 슬롯도 현재 선택을 확인할 수 있다. 메뉴는 새 능력을 구현하거나 원작 전체 능력 목록을 보장하지 않는다.

직업·하위직업·궁극기가 실제로 바뀌면 궁극기 에너지는0으로 초기화한다. 동일한 선택은 유지된다. 능력 재사용 대기시간은 변경으로 초기화하지 않는다. 궁극기 사용 중이거나 사망·관전자 상태일 때는 변경할 수 없다.

**로드아웃** 탭으로 돌아오면 기존 슬롯→새 무기→무기군→무기→퍽→슬롯에 추가 흐름을 계속 사용할 수 있다. 캐릭터 선택은 무기 아이템이나 퍽을 교체하지 않는다.

개발 연결: `guardian.CharacterLoadouts`가 메뉴와 `/guardian class`, `/guardian subclass`, `/guardian equip`의 공통 검증·변경 경로다. 하위직업은 저장된 SUPER 능력의 원소로 판별하며 기존 GuardianData/Loadout codec을 재사용한다.
