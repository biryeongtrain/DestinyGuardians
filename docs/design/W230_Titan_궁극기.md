# W230 타이탄 궁극기

대혼란의 주먹 원본 시전·공중 진입·착지 연결과 천둥충돌·불타는 망치·새벽의 수호물을 구현한다. 각 신규 궁극기는 일반 SUPER 장착 슬롯과 에너지 소비 경로를 사용하며, 새로운 게임모드·이동 권한·실제 손 아이템 변경을 요구하지 않는다.

## 대혼란의 주먹

지상 시전은 전체 31틱 동안 공격을 차단하고 근접한 모든 방향의 적에게 활성화 충격을 한 번 준다. 공중 시전은 15틱의 진입이 끝나도 가상의 지면 충격을 만들지 않는다. 실제 `onGround`와 발밑 충돌 지지를 함께 확인한 뒤 원본 19틱 착지 동작을 재생하고, 해당 동작의 접촉 후보에서 한 번만 충격을 준다. 지면을 끝내 만나지 못하면 대기는 60틱 후 해제하며 피해를 만들지 않는다.

`80A8AD9D`, `80A8AD93`은 전진 **시전**이므로 약공격에 연결하지 않는다. 독립 약공격 원본은 이번 전달에서 식별되지 않았다. 빠른 기본 공격은 기존 authored/native fallback을 사용하며 원본 모션으로 표기하지 않는다. 지상 대기·이동은 기존 authored 루프를 유지한다.

## 천둥충돌

원본 시전 종료 후 서버 시선 방향으로 비행하고, 방향을 틱마다 완만하게 갱신한다. 카메라의 별도 WASD 전진은 비행 중 차단한다. 이동 전에 실제 플레이어 AABB를 최대 0.1블록 간격으로 전 구간 검사한다. 블록·천장·살아 있는 엔티티·월드 경계에 걸리면 마지막 안전 위치까지만 `MoverType.SELF`로 이동하고 충돌 충격을 한 번 발동한다. 원본 루트 이동을 별도 서버 이동으로 중복 적용하지 않는다.

피해는 PvE 적에게만 주며 타격점에서 LOS를 확인한다. 비행은 기본 90틱 및 64블록으로 제한한다. 중력과 속도만 해당 세션이 임시로 소유하며 충돌·취소·사망·차원/장착 변경에서 원래 상태를 반환한다. `flying`, `mayfly`, `noPhysics`, 인벤토리는 변경하지 않는다. 충돌 종료 모션은 한 번 재생하고 회복 이후 일반 종료 helper가 다시 재생하지 않게 한다. 비행 중 전용 아크 방전 body aura를 위치+(0,.9,0), scale1.2의 단일 item_display로 표시하고 비행 종료와 함께 제거한다. 생성 실패 시 공유 파티클을 유지한다.

충격 뒤 15틱 지연, 80틱 유한 후속 전기장을 별도 소유권으로 둔다. 시전 세션이 자연 종료되어도 후속장은 지속하지만 explicit cleanup이나 소유자 epoch 변경에는 해제된다.

## 불타는 망치

시전 이후 이동형 궁극기다. 기본 좌클릭은 한 번의 회전 타격, 웅크리기+좌클릭은 지면 강타와 전방 화염파다. 타격 전 지연과 전체 동작 회복을 각각 지켜 반복 클릭으로 공격·화염파를 복제할 수 없다. 화염파는 최대 3개, 개별 80틱/14블록, 벽·지지 없는 낭떠러지에서 종료되며 각 적을 파동당 한 번만 때린다. 실제 타격에 SUPER 소유자 귀속과 LOS를 적용한다.

시전 외 두손 대기·이동·공중·회전·강타는 **MC-authored 임시 모션**이다. 원작 공격 전체를 확보했다고 주장하지 않는다. 망치는 오른손 item bone에 연결하고 왼손은 포즈로 받친다. `PlayerAnimations.superItem(..., true)`는 두손 옵션이 아니라 활의 왼손 옵션이므로 사용하지 않는다. 타격 전체는 authored clip 12/15틱, 접촉 후보는 6/7틱이며 약공격 간격은 DDC 0.67초를 올림한 14틱 이상으로 둔다.

화염파는 art 담당자의 자체 제작 `titan/burning_maul_wave`를 scale1로 사용한다. 지면 원점 `[8,8,8]`, +Z 진행 방향을 실제 수평 조준 방향으로 회전하고 item_display 기본 Y=PI 회전을 보정한다. 높이 약 .631블록이며 손에 드는 대형 망치와 별개다. 이는 원본 VFX 리핑이 아닌 임시 구현이다.

## 새벽의 수호물

지상/공중 시전과 실제 착지를 분리하고, 시전 종료 전에 지면 중심에 정적인 반구를 설치한다. 공중 대기는 기본 80틱 후 종료되어 영구적인 카메라 고정이 남지 않는다. 시전 이후 플레이어 포즈와 후방 카메라는 해제하며 돔만 기본 600틱 남는다. 같은 소유자는 한 개의 돔만 유지한다.

돔 중심은 지면, 반경 기본 4블록이다. raw 원점 `[8,8,8]`, 반경 8units 반구에 `scale=2R`을 적용해 시각·피해 보호 영역을 맞춘다. 손 장비에 돔을 넣지 않는다. 소유자·실제 동맹·소유한 길들인 동물이 안에 있을 때 외부 기점의 피해를 차단한다. 돔 안에서 시작한 공격, 돔 밖 피해자, 방향 없는 환경 피해, `BYPASSES_INVULNERABILITY` 피해는 통과한다. 내구도 0이 되는 마지막 한 번의 타격까지 흡수한다. Fabric boolean 이벤트이므로 남은 피해를 부분 통과시키지는 않는다.

외부에서 반구를 가로지르는 native projectile을 sweep하여 제거하며 소유자/동맹의 발사체는 유지한다. 플레이어에게 능력 피해를 가하지 않는다. 원작의 코어 획득·빛의 무기·스탯별 수명 증가는 이번 기본 보호막에 포함하지 않는다.

## 소유권·공유 연결

`TitanAbilities.register()`만 `TitanExpandedSupers.register()`를 호출한다. master가 공유 AbilityService에 `tick(server)`, `cleanup(player)`, `clearAll()`을 명시적으로 연결한다. TitanAbilities의 tick/cleanup에 신규 구현을 중복 연결하지 않는다. `ALLOW_DAMAGE`는 `TitanExpandedSupers.allowDamage(LivingEntity, DamageSource, float)`를 한 번 연결한다. QA만 `status(player)`를 읽는다.

소유자 UUID 외에 정확한 player/connection, level, GuardianData/runtime/loadout 및 tuning 객체 identity를 캡처한다. 소유자가 같은 직업으로 돌아와도 explicit cleanup으로 취소된 필드가 부활하지 않는다. tick은 실제 gameTime에 멱등이다. 오래된 callback이나 다른 소유자의 필드는 취소하지 않는다. 지속 효과의 음원은 presentation 수명과 독립적으로 `sound(player, element, path, action)` 경로를 지정한다.

## 검증 상태와 다음 순서

`TitanW230GameTests` 6개는 지상/공중 주먹 시전 timegate와 1회 접촉, 천둥충돌 벽/천장 sweep·상태 복원·동일 틱 멱등·epoch, 망치 spam/실제 피해/wave 벽·만료, 수호물 외부/내부/동맹/native projectile·수명·epoch를 검사한다. fake player는 실제 Rot packet handler로 카메라 watchdog을 갱신하고 실제 지면 패드를 만든다. 상승 시나리오는 `skyAccess=true`로 격리 구조물의 테스트 천장을 피한다.

worker는 중앙 Gradle·게임·Vision을 실행하지 않는다. 현재 소스/JSON 초안이며 중앙 컴파일·GameTest·1차 Vision·worker 검수·2차 Vision 결과는 master가 QA에 별도로 기록한다. W229의 '타이탄11능력' 개수 및 '주먹6틱 시전' 기대는 이번14능력/31틱 시전에 맞춰 master가 공유 회귀 테스트를 갱신해야 한다.

## R1 이후 공격 모션 보완

대혼란의 주먹 지상 약공격에는 별도 authored 0.5초·61pose 펀치를 추가했다. 전달된 전진 시전을 약공격으로 사용하지 않는다. 공중 primary는 기존 하강/피해를 유지하면서 원본 shared air를 사용하고, 실제 접지 시 원본 land를1회 재생하며 해당 회복 동안 추가 입력을 차단한다. R1 native체력400→376과공중강타 입력은 확인했으며 R2 모션 재검수는 통합 QA 결과를 따른다.
