# W60 — 실제 특성 소켓과 자동 장전 총집

## 범위

장탄수 시스템의 첫 무기 특성이다. 새/기존 무기에 자동으로 붙이지 않는다.
63개 대표 무기의 **선정된 정확한 Bungie hash**를 같은 Manifest의 공식 소켓/플러그 집합과 대조했다.
실제 trait category의 randomized plug set에서 `currentlyCanRoll=true`인 기본 Auto-Loading Holster만 허용한다.
지원은 **18종**, 나머지45종/경이/검/프리뷰/강화 특성은 제외한다.
완전한 원작 랜덤 롤·제작·특성 획득 경제가 아니라, 소유한 프로토타입 무기의 허용된 특성을 직접 선택하는 서버 정책이다.
기존 황금총 1인칭 방향·모델/음원·탄창/예비탄 및 3슬롯 HUD는 변경하지 않는다.

## 사용

일반 플레이어가 실제 전투 무기를 들고:

```text
/destiny perk list
/destiny perk select auto_loading_holster
/destiny perk status
/destiny perk clear
/destiny loadout equip
```

`/destiny weapon load <id>`는 기존처럼 OP용 준비 명령이다. 특성 명령은 소유 아이템만 바꾸며 무기/탄약을 만들지 않는다.
예: Bad Omens, Duke Mk.44, Gnawing Hunger, First In Last Out, Dust Rock Blues, Dream Breaker.
Austringer에는 해당 특성을 붙일 수 없다. 같은 이름의 다른 시즌/재발행 버전의 소켓을 혼합하지 않는다.
원작 전체4특성열 UI/동시 여러 특성/무작위 획득은 미구현이다.

## 서버 동작과 소유권

- `WeaponPerks`는 live item의 exact weapon+허용 socket+unsigned trait hash를 검증한다.
  저장된 trait는 LongTag, socket은 IntTag만 받는다. 문자열/실수/잘못된 소켓은 효과가 없다.
- 아이템 모델·이름·사용자 lore·기존 ammo/custom data는 보존한다. 특성 clear는 특성 키2개만 제거한다.
- `WeaponHolster`는 owner/level별 실제 정규3슬롯 참조만 보관한다. 가방/보조손/잘못된 슬롯/standalone debug 수납은 제외한다.
- 주 손에 계속 들고 있던 시간은 누적하지 않는다. 실제 수납 시점부터70tick 뒤 `WeaponMagazine.reload()`로 장전한다.
- Primary는 기존 무한 예비탄 정책을 사용하되 탄창은 유한하다. Special/Heavy는 실제 reserve/보존 overflow만 사용한다.
- 한 수납당 한 번만 시도한다. 가득 찼거나 예비탄이0이어도 완료한 시도는 반복하지 않는다.
  **완료 후 새 예비탄을 얻었다면 다시 꺼냈다 수납해야 한다**는 보수적 자체 정책이며 원작 세부 재시도 실측이 아니다.
- 검증된 native slot mutation 직전과 loadout command selection에 연결했다. 같은tick 꺼내기→재수납도 이전 타이머를 취소한다.
  인벤토리 교체는20Hz 관찰하며 서로 다른 실제 ItemStack은 같은 컴포넌트라도 새 수납 시간을 갖는다.
- 죽음/접속 종료/차원 변경/관전/장비모드 해제/서버 종료는 transient 상태를 버린다. 오프라인 시간은 보상하지 않는다.
- 궁극기는 일반 무기의 수납으로 추측하지 않고 타이머를 버린다. 종료 후 새 수납 관찰부터 시작한다.
  회피/일반 스킬은 정규 장비가 유지되는 동안 별개다. 명사수 회피로 이미 채웠다면 특성은 추가 비용을 지불하지 않는다.
- 사격 cadence·W58 Handling·pending shot/charge/shell timer를 저장하거나 초기화하지 않는다. 자동 발사/입력은 생성하지 않는다.
- 기존 HUD가 현재 무기를 다시 선택할 때 실제 탄창/예비탄을 표시한다. 수납 행은 **총탄약**이므로 유한탄 전송 전후 같은 값이 정상이다.
  가짜 수납 진행바/가상의 예비탄/원작으로 확인되지 않은 특성 사운드는 추가하지 않았다.
