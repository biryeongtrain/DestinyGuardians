# 시련의 장 PvP 피해와 탄약 — W263

## 피해 계산

1. 발사 시점의 무기·퍽 정보와 실제 충돌 대상을 기준으로 계산한다.
2. 플레이어 대상이면 원작 기본 피해와 정밀 피해를 사용한다. 정밀 배율은 무기별 `precision / body`이며, 모든 무기에 같은 배율을 쓰지 않는다.
3. 당김·공격 배율 → 거리 감쇠 → 발동한 퍽·버프 → 약화·가드를 적용한다. 폭발탄의 PvE 폭발 보너스 30%는 PvP에서 제외하며, Headseeker도 대상별 정밀 배율을 사용한다.
4. 원작 230 HP를 서버 체력 바에 비례 환산한다: `D2 피해 × 대상 최대 체력 / 230`. 표시 피해 숫자는 D2 단위로 되돌리고, 실제 체력 소모·처치·퍽 처리는 서버 단위를 유지한다.
5. PvP 전용 피해 유형은 바닐라 갑옷·Protection·Resistance를 우회한다. 아군 피해 차단, 스폰 보호, 능력 상태와 검·월도 가드는 유지한다.
6. 보호막·초과보호막이 있어도 플레이어 머리는 정밀 대상이다. 몬스터의 기존 방어·정밀 경로는 유지한다.

230 HP는 사용자 지정 DDC Game Mechanics C157 기준이다. 기본 Health 스탯 100 이하의 회복 지연·속도를 적용하고 경기 월드의 음식 자동 회복을 대체했다. 고스탯 회복과 능력별 피해 전수 보정은 아직 적용하지 않았다.

## 특수탄 생애주기

- 경기 최초 입장: PvE 유한 탄약을 회수하고 시작 특수탄을 한 번 지급한다. 주무기 예비탄은 기존처럼 무제한이다.
- 사망: 남은 특수탄과 시작량의 3배 중 작은 양을 보존한다. 빈 탄창에 새 탄약을 지급하지 않는다.
- 리스폰: 사망 시 확정된 장비·탄약을 새 플레이어 객체에 넘긴다. 임시 오버월드의 `keep_inventory=false` 때문에 장비가 사라지던 문제도 수정했다.
- 처치·지원: PvP 게이지를 채워 개인 탄약을 생성하고 가까이 가서 획득한다. PvE 게이지와 분리한다.
- 최초 특수탄 상자는 30초 후 생성되며, 바닥 탄약은 60초 후 사라진다. 반복 주기·공유 정책은 아래 QA 문서의 로컬 설정을 따른다.
- 장비 교체: 유한 탄약을 회수해 새 무기·보관함으로 무료 보충하는 것을 막는다. 단순 핫바 선택은 탄약을 유지한다.

## 적용 범위와 남은 작업

**65개 중 50개 무기**에 PvP 기본 피해를 연결했다. DDC가 연결한 PvP 표의 ‘업데이트 중’ 경고를 보존하고 공식 패치 수치를 우선했다. 나머지 15개는 최신 피해값 또는 발사 패턴이 확인되지 않아 기존 로컬값을 유지한다.

게이지 절대 점수, Ammo Generation/Finder 곡선, 상자 공유·반복, 쌍특수 분배와 개별 능력·경이·퍽의 전용 계수는 원작과 완전히 같지 않다. 확인된 규칙과 로컬 정책을 [W263 QA](../qa/2026-10-30/w263/README.md)에 구분했다. 데이터는 `src/main/resources/destiny/weapons/w263-pvp-damage.json`에 있다.

관련 단위 검사 57개와 서버 통합 테스트 2개는 통과했다. 전체 단위 검사에는 기존 자산 검사 실패 4개가 남아 있으며, Mac 잠금으로 Vision 화면 검증은 진행하지 못했다.
