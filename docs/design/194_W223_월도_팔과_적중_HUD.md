# W223 — 월도 팔 등록과 적중 확인 HUD

상태: W223 범위 수락. 전체 무기 시스템/HUD 목표는 계속 active다.

## 월도

W222는 장전 중 무기 본체를 복구했지만 팔이 화면 중앙을 크게 가리는 문제가 남았다. 기존 shortest-arc 등록은 두 파지점의 축만 맞춰 원본 상체의 rest 방향을 잃었다. W223은 원본 shoulder/elbow/wrist/weapon 체인을 새 Blender 프로세스에서 재평가한 뒤, 원본의 기존 X-forward/Z-up 좌표 관례와 현재 메시의 파지축에 근거해 등록 회전을 구한다.

원본 메시/카메라는 전달물에 없다. 따라서 이 회전은 강체 좌표 등록 보정이며 원작 카메라 extrinsic 복원이 아니다. 메시·UV·현재 display·손 접촉점·소스 관절 길이·61 pose 장전·게임 시간·오디오는 보존한다. 팔 숨김/늘림이나 화면을 피하기 위한 카메라 offset은 추가하지 않는다.

## 적중과 처치 확인

기존 피해 숫자에 더해 화면 중심 주변에 짧은 확인 표시를 추가한다. 실제 HP+흡수 체력 감소를 관측한 무기 피해 transaction만 입력하며, 빗맞음·차단·무적·0 피해에는 표시하지 않는다. 혼합 산탄의 몸통/정밀 숫자가 둘로 나뉘어도 확인 이벤트는 transaction당 한 번이다. Dragonfly/Firefly의 별도 폭발 경로도 실제 피해/처치 결과를 관측한다.

큐는 정확한 플레이어 객체/접속/월드에 귀속하고, 살아 있는 처치 표시를 뒤따르는 보통 적중이 낮추거나 무한 연장하지 않는다. 일반 플레이어도 무기 HUD를 볼 수 있다. 그림은 독자 제작한 참조 기반 HUD이며 원작 추출/픽셀 일치를 주장하지 않는다. 원본 근거와 로컬 지속시간 조정은 art/hud/w223/SOURCE.md에 기록한다.

## 검수와 커밋

master만 실제 Vision 입력을 제어한다. 최초 월도 장전/ADS와 적중·무적·빗맞음·처치의 PNG/서버 결과를 담당 워커에게 전달하고 수정 또는 근거 있는 무변경 반환 뒤 두 번째 동일 검수를 진행한다. 회귀는 변경된 시간/수명 동작과 리깅 경로에 한정한다. 61 pose는 연속60fps 인증이 아니다. 완료한 관련 변경은 master가 커밋하고, 기존 미커밋 자료는 보존한다.

증거·단계 기록: docs/qa/2026-10-28/w223/.

필수 시퀀스를 완료했다. FIRST6완료/처치1중단을 보존하고, 동일 worker 피드백 뒤 SECOND7개 native 시나리오를 완료했다. JUnit23/23+assemble 및 짧은 Python source contract2/2 통과. 제품 출력은 피드백 전후 동일하다. 흰 cue는 FIRST실화면과 SECOND서버 결과를 구분하고, 붉은 처치/만료는 SECOND에서도 확인했다. 월도 하단 팔 가림과 소스의 빠른 전환, 원본 카메라 부재는 남아 있다. 자세한 증거/수락 범위는 docs/qa/2026-10-28/w223/review-second.json을 따른다.
