# W127 — 정돈된 무기 입체와 기존 가동부

에이스87/이자나기79 연구를 담은 `minecraft-weapon-art-design`을 적용해 망치머리·용광로·Duke Mk.44를 독립 dirty-seeded CoW worktree에서 재설계했다. rip의 source 섬을 복제하지 않고 큰 기능별 볼륨과 면별 UV로 정돈했다. 삼각 어댑터/alpha 외장0, 실제 opaque cubes 기준이다. 1,000개는 목표가 아닌 상한이다.

| 무기 | 본체 | 가동부 | 조립 출력 | 유지한 특징 |
|---|---:|---|---:|---|
| Hammerhead | 70 | 탄창/rigid feed65 + cover14 |149| 긴 검정/적색 shroud, twin drums, 실제 열린 carry/stock/sight/muzzle |
| Blast Furnace |92| 탄창5 |97| Black Armory 적색 barrel/breech, 검정 receiver, olive lower, 열린 stock/optic |
| Duke Mk.44 |78| cylinder/yoke69 |147| 높은 shroud, 6개 실제 관통 chamber, 열린 guard/underlug, blue lacquer/dark grip |

모든 면은1024² atlas의 독립 UV. 얕은 패널/vent/금속 마모/checkering은UV, 포구 깊이/가늠쇠와 실린더 구멍/동작 부품은 실제 입체다. 세부 곡면과 작은 bevel은 faceted approximation이며 PBR/원본골격곡선 복원이 아니다. Hammerhead belt는 기존처럼 rigid feed다.

Duke worker 초안의 근거 없는 금색/목재 안료는 master가 반려하고 W31 실제 light.gg screenshot·기존 palette에 근거한 파랑/검정으로 재도색했다. 최종 geometry/UV배치/display는 초안과 동일하다. W64 기존232 canonical 대234reload의2yoke차이를 명시하고 새full=body+cylinder로 일관되게 구성했다. yoke 상부만 새 chamber 아래로 내려 구멍을 막지 않게 했고 pivot `[8,10.2,5.17]`은 유지했다. 망치머리 cover 원래힌지와 모든 display/axis/scale도 유지했다.
