# W279 신규 수호자 튜토리얼 (「새로운 빛」)

## 목표
처음 접속한 플레이어가 직업 선택부터 궁극기까지 직접 해 보면서 배운다. 설명을 먼저 읽히지 않고, 한 번에 한 가지만 열어 주고 바로 써 보게 한다.

## 참고한 데스티니 2 구조
- **New Light / 붉은 전쟁 오프닝**: 고스트가 수호자를 되살리는 장면으로 시작하고, 빛이 하나씩 돌아오는 구성. 능력은 처음부터 다 주지 않고 장면마다 하나씩 해금한다.
- **좌측 목표 추적기**: 현재 목표와 진행 수(0/3)를 왼쪽에 둔다.
- **고스트 대사 자막**: 화면을 막는 대화창 대신 짧은 무전 형태로 흘러간다.
- **「전설이 되십시오」**: 마지막에 타워로 보내며 끝낸다.

## 게임 디자인 원칙
| 원칙 | 적용 |
|---|---|
| 한 번에 하나 | 14단계. 각 단계는 목표 1~3개, 조작 키 1개만 보여 준다. |
| 직접 해 보기 | 모든 단계는 실제 입력으로만 완료된다. 대사를 넘기는 버튼이 없다. |
| 즉시 피드백 | 목표 달성 시 효과음·초록 체크, 단계 전환 시 토스트, 빛 선택 시 섬광 포스트이펙트. |
| 실패 비용 없음 | 피해를 받지 않는다. 낙하 시 직전 체크포인트로 복귀, 틈에 빠지면 고스트가 위로하고 재시도 지점으로 옮긴다. |
| 막힘 방지 | 35초 안에 틈을 못 건너면 빛의 다리가 생긴다. 2분 동안 무기를 못 장착하면 고스트가 기본 무기를 빌려준다. |
| 보상 | 궁극기는 마지막 훈련장에 들어설 때 가득 채워 주고, 적 6기를 상대로 「힘의 환상」을 준다. |
| 공간 흐름 | 닫힌 각성실 → 넓어지는 홀 → 하늘이 보이는 파편실 → 사격장 → 좁은 질주로 → 열린 훈련장 → 빛의 문. 방이 점점 열리며 해방감을 준다. |

## 단계
1. **각성**: 어둠 효과 속에서 고스트를 바라본다.
2. **각성**: 몇 걸음 걸으면 첫 문이 열린다.
3. **수호자의 길**: 타이탄·헌터·워록 원 안에 1.5초 서 있으면 선택. 오른쪽에 아이콘·색·한 줄 설명.
4. **여행자의 빛**: 회전하는 파편 앞에서 아크·솔라·공허 선택. 빛을 받는 섬광.
5. **무장**: 실제 장비 창(E 또는 /메뉴)에서 1번 칸에 무기 추가 → 1번 키로 들기.
6. **사격 훈련**: 가까운 표적 3기.
7. **정조준**: 먼 표적 2기를 정조준 상태로 처치(조준 없이 쓰러뜨리면 고스트가 다시 세운다).
8. **재장전**.
9. **기동 훈련**: 질주 12블록 → 점프 능력 해금 → 7블록 틈 건너기.
10. **수류탄** 해금·사용.
11. **근접 능력** 해금·사용.
12. **직업 능력** 해금·사용.
13. **궁극기**: 마지막 훈련장 입장 시 에너지 가득, 발동 후 적 6기 처치.
14. **빛의 문** 통과 → 완료 표시 후 타워로 이동.

## 공간과 기술 구성
- 전용 임시 월드 `destiny:tutorial` (Fantasy, void 생성기). 타워·오버월드·시련의 장을 바꾸지 않는다.
- 플레이어마다 독립 레인(x 간격 128블록). 레인은 재사용하며 시작할 때 문만 다시 닫는다.
- 블록 지형은 코드로 생성(`TutorialCourse`). 장식·직업 아이콘·파편·고스트는 디스플레이 엔티티(Polymer VirtualEntity)로 표시해 월드 저장에 남지 않는다.
- 표적은 AI가 없는 허스크(발광). 레인 밖 다른 플레이어와 상호작용하지 않는다.
- HUD는 DisplayHud(`TutorialUi`): 좌측 추적기, 그 아래 키 안내와 고스트 자막, 상단 토스트, 우측 선택 정보.
- 능력 잠금: `AbilityService.use`에서 `Tutorial.allows` 확인. 사용 성공은 `Tutorial.abilityUsed`로 단계에 전달.

## 진입·종료
- 직업이 없고 튜토리얼을 마치지 않은 플레이어는 접속 시 자동 시작(타워 대신).
- `/튜토리얼`로 다시 할 수 있다. `/튜토리얼 나가기`로 타워 복귀.
- 관리자 QA: `/튜토리얼 단계 <step>`.
- 완료 여부는 `destiny:tutorial_completed` 첨부 데이터에 저장.
