# W84 — 이자나기의 짐과 연마된 칼날

## 범위와 근거

- 기존 전설 63종·스페이드 에이스를 보존하고 `izanagis_burden`을 추가한다.
- 공식 무기 `3211806999`, 고유 특성 `1070100196`. 고정 플러그 적용 Range58 / Stability56 / Handling47, 4발·90RPM, 물리·특수탄·키네틱 슬롯.
- [조사와 출처](../../art/weapons/w84/reference-notes.md), [수치 추출](../../art/weapons/w84/data/extraction.json). 촉매는 기본 장착하지 않는다.
- DDC/Clarity의 배율은 **동일 무기의 비강화 동일 부위 피해** 대비 반올림된 커뮤니티 값이다. 공식 원본 HP나 완전한 현재 샌드박스 복원으로 표현하지 않는다.

| 합친 탄수 | PvE 몸 / 정밀 | PvP 몸 / 정밀 |
|---|---|---|
| x2 | 1.12 / 1.79 | 1.20 / 1.91 |
| x3 | 1.25 / 2.31 | 1.45 / 2.67 |
| x4 | 2.12 / 3.91 | 2.65 / 4.89 |

Minecraft 기본 피해16HP·기본 정밀2.5·타기팅/사거리96block 상한은 기존 로컬 정책이다. 강화 정밀 배율은 기본 정밀 계수에 더하는 값이 아니다.

## 입력·탄약 트랜잭션 — 미확정 원작 경계는 로컬 정책

26.3 바닐라 서버는 Destiny의 R 유지 시간을 받지 못한다. **Q 일반 재장전 / Ctrl+Q 연마된 칼날**로 매핑하며 실제 `DROP_ITEM` / `DROP_ALL_ITEMS` 패킷을 구분하고 무기 버리기는 취소한다. Vision native-input v1에는 Q가 없으므로 패킷 GameTest와 실제 키보드 검증을 혼동하지 않는다.

1. 일반 탄약이 최소 2발 있어야 시작한다. 시작 시 탄창+예비+기존 overflow의 `min(4,total)`을 캡처한다.
2. 일반/연마 장전은 각61tick. 역사적 Sniper/default Reload40 곡선 3.02015168초를20Hz 올림한 **시뮬레이션 기준**이다. 실측한 현재 Destiny 시간은 아니다. 연마는 재장전 버프로 가속하지 않는다.
3. 완료 전에는 탄약 이동·강화탄을 지급하지 않는다. 완료 시 원래 탄창 수가 유지되고 같은 플레이어·차원·정확한 ItemStack을 보유해야 한다.
4. 원래 탄창 우선, 부족분은 예비·overflow에서 가져와 n발을 하나의 유료 발사체로 합친다. 일반 `finishReload`가 추가로 탄창을 채우지 않는다. 도중 습득한 탄약은 보존하되 이미 캡처한 x2를 x4로 올리지 않는다.
5. 완료 전 교체·실제 인벤토리 교환·스킬 취소·사망·연결 해제·차원 변경은 pending 권한을 취소한다. 완료된 강화탄은 아이템에 저장되어 교체·저장/복구·정상 소유권 이동 후에도 남는다.
6. 실제 발사 1회에 강화탄 하나를 지불하고 카운터를 없앤다. 빗나가도 소모한다. 추가로 n발을 다시 청구하지 않는다.
7. 이미 강화된 상태의 일반/연마 재장전과 Marksman 탄창 보충은 거절해 기존 유료 강화탄을 유지한다. 이는 **일반 재장전 중 강화탄의 원작 처리 미확정에 따른 제한**이다. 발사하면 정상 장전할 수 있다.
8. 빈 탄창 자동 일반 장전이 이미 시작되어도 Ctrl+Q로 연마 장전으로 바꿀 수 있다. 일반 장전에는 조기 탄약 credit가 없으므로 추가 지급 없이 취소하고61tick을 새로 시작한다. 중복 Ctrl+Q는 진행 중 연마 장전을 다시 시작하지 않는다. 정확한 원작 버퍼·전환 프레임을 재현한 것은 아니다.

서버가 ItemStack 전체를 복제하면 그 탄약과 완료 강화 상태도 함께 복제된다. 이 시스템은 관리자 NBT 편집이나 서버 아이템 복제 방지 기능이 아니다. 클라이언트가 임의로 강화 상태를 요청하는 패킷은 없다.

## 모델·HUD·음향

- 사용자 원본 `izanagi.bbmodel`: **79/256큐브, 474 UV face, 30 회전, 3개 원본 atlas**. 원본은 읽기 전용으로 보존한다. 네이티브 좌표 경계용5/8 균등 축소와 stale lens UV 메타데이터 보정은 [모델 manifest](../../art/weapons/w84/model/manifest.json)에 기록한다.
- 양손 기본 자세, hip/ADS/inspect/scope와21단계 ADS sample. 기존 W70 경로의 중앙 정렬 3D 렌즈/원본 붉은 리티클 fallback이다. 전용 full-screen scope의 원작 복원을 주장하지 않는다.
- DisplayHud에 실제 `Honed Edge x2/x3/x4`만 표시한다. 가짜 만료 타이머나 촉매 상태를 넣지 않는다.
- [음원 미리듣기](../../art/weapons/w84/audio/audition.html), [출처·가공 기록](../../art/weapons/w84/audio/implementation.json). 사용자가 제공한 Drive `Izanagis_Burden` 폴더의 일반/연마 발사와 장전 이름이 붙은 후보를 사용한다. 동일 PCM의 `Reload_Honed_1`/`Reload_3`는 의미가 모호해 이벤트 풀에서 제외한다. 파일명 근거와 실제 청취 판정은 별개다.
- 일반61tick/연마61tick 장전은 별도 이벤트. pitch-preserving 오프라인 길이 조정, 소유자별 entity-bound emitter를 재사용해 다른 플레이어의 같은 장전음을 함께 끊지 않는다.

## 검증 상태와 남은 작업

현재 진행·실패·최종 결과는 [W84 QA](../qa/2026-10-25/w84/README.md)와 [작업 로그](13_헌터_구현_로그.md)를 기준으로 한다. 오프라인 렌더·원본 UV 검사·모델 codec·생성팩 일치는 실제 framebuffer 검증이 아니다.

No Distractions flinch, 정확한 추가 사거리·Barrier 동작, 촉매, 원작 reload/Honed 애니메이션·빛나는 총신 VFX는 이번에 구현했다고 주장하지 않는다. 이전 Vision 첫 SDL 출력 정지 원인은 미확정이며, 새 화면/잠금 상태 확인 없이 동일 실행을 반복하지 않는다.

### 저장 호환성 회귀

실제 JSON ItemStack codec가 정상 IntTag4를 ByteTag4로 최소폭 변환하는 사례를 전체 GameTest에서 발견했다. 완료 강화탄은 Byte/Short/Int/Long의 정확한 정수2..4를 읽는다. 부동소수점·문자열을 정수로 변환해 허용하지 않는다. JSON/NbtOps 저장·복구를 모두 검사하며, 관리자 복제 방지 기능으로 설명하지 않는다.
