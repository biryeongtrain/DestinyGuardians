## 근거와 frame
각 `art/weapons/w123/<id>/design.json`, `manifest.json`, `review.md`, `comparison.png`에 실제 rip/default photo와 원본 hash, 출력과 근사 범위를 기록했다. 총기 source triangle은 각각 12061/10404/20296, 월도 34330(34246 textured+84 auxiliary)로 W30와 일치한다. 월도 원본 Blender/FBX object 이름은 W30 import label과 다르다. 잘못된 이름 filter probe가 실패한 사실을 숨기지 않고 [진단](../qa/2026-10-26/w143/source-reference-diagnosis.md)에 남겼다. 빈 결과를 성공으로 받아들이지 않았고 읽기 전용 FBX reader로 실제 5개 record를 확인했다.

총기는 기존 축, 월도는 canonical +Y shaft/blade를 유지한다. 원래 scale/anchor/display와 ordinary/ADS/twohand/glaive item parent, 기존 generic reload·탄약·피해·소리는 변경하지 않았다. 월도는 총기 ADS가 아닌 guard/근접 경로다. 본체 분할 장전을 억지로 만들지 않았다. 기본 안료는 원본 Diffuse의 회색을 그대로 복제하지 않고 실제 기본 photo의 재질 대비를 반영했다.
