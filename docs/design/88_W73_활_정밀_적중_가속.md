## 사용과 서버 흐름

Whispering Slab을 들고 `/destiny perk select archers_tempo`. 기본/구형 아이템에는 자동 선택하지 않는다. `/destiny perk status`로 확인, `/destiny perk clear`로 해제. 같은 소켓에는 한 특성만 저장한다. 선택 자체는 탄약이나 버프를 지급하지 않는다.

1. 실제 사격 비용으로 생성된 화살만 현재 owner/level/exactstack/session 토큰을 캡처한다.
2. 실제 충돌과 정밀 판정 후 **positive actual damage**가 있을 때1회 토큰을 소비해60틱 창을 갱신한다. 처치는 필요 없다. body/miss/면역/선택 없음은 보너스 없음.
3. 실제 당김 시작에서 유효 profile을1회 캡처한다. 직접 누르기뿐 아니라 실제 nock가 끝난 뒤 이어지는 buffered draw에서도 새로 캡처한다.
4. 부분 당김의 위력/속도/중력 정규화와 기존 시위 selector가 **동일한 캡처 기한**을 사용한다.9틱 완전 당김 위력은 기존 기본값과 같다. 탄약 비용1/탄창 용량/기본 nock·cadence·ADS/FOV는 변경하지 않는다.
5. 실제 남은 시간을 기존 DisplayHud 버프 feed의6cachednode로 표시한다. `ceil(ticks/20)`이며 만료시0:00행을 남기지 않는다. timer를 읽는 것으로 갱신/가속/탄약 변화가 생기지 않는다.

## 소유권과 취소

바닐라 hotbar packet의 실제 slot변경 **전**에 창을 무효화한다. 같은 서버틱 hotbar/offhand away/back도 수납이며, 이미 비행 중인 옛 화살은 피해를 주더라도 새 세션에 특성을 부여하지 못한다. copy/NBT/거래/owner·level·exactstack 교체와 trait edit에 시간/토큰을 상속하지 않는다. 동일한 선택을 다시 고르는 no-op은 새 특성 변경이 아니다.
nonGuardian의 실제 offhand swap은 창/토큰과 진행 중 bow charge/nock를 즉시 정리한다. Guardian의F능력 입력은 실제 수납이 아니므로 이 경로에 넣지 않는다. Q let-down/스킬취소는 기존 charge와 ghost shot을 정리한다. 일반 스킬 자체를 모든 경우 특성 수납으로 취급한다는 원작 규칙은 추가하지 않았다. 궁극기/관전/사망·접속종료/cleanup은 기존 무기 사용 eligibility와 세션 정리를 따른다.

## 명시적인 프로젝트 정책과 미구현

- **당김 도중** 특성 발동/만료는 이미 승인된 당김을 재시간화하지 않는다. 다음 실제 당김에 반영한다. 이 snapshot 정책은 공개 근거로 원작 엔진 동작이 입증된 것이 아니다.
-60틱 refresh와 단일 비중첩 창, 토큰/동일틱 처리 순서, runtime 소유권은 서버 구현 정책이다.
- 완전 당김 유지·안정성별 perfect-draw window·피로/강제 발사는 정확한 근거가 부족하여 **미구현**이다. 일반 활의 기존 무한 유지가 원작과 같다는 뜻이 아니다.
- 현재 partial damage/velocity/gravity 곡선은 기존 Minecraft 튜닝이며 원작 곡선 추출값이 아니다. 이 특성은 그 곡선의 진행 시간만 바꾼다.

SDL/title/world 문제와 실제 클라이언트 입력·화면·청취·FPS 검증은 남는다. **전체 무기/HUD 목표는 active**다.
