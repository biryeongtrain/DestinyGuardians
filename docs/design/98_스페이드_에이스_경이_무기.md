## 추가형 데이터

`w30/w40/w43/w44/w46/w58/w65/w75`의 기존63행 원본은 변경하지 않는다. 별도 `w83-exotics.json`의 각 field를 해당 loader가 append하고, 기존 중복·범위·완전성 검사를 그대로 수행한다. `WeaponExotics`는 JSON-only 초기화로 정적 loader 순환을 피한다.

정확한 공식 무기 **347366834**, Kinetic/Primary/Exotic, 메멘토 모리 **647617635**와 Ace 전용 Firefly **1561789734**를 사용한다. 기본13발/140RPM. 공식 무기 stat75/40/40에 고정 플러그 보너스10/10/10을 합한 Range85/Stability50/Handling50을 적용한다. 이미 표시된 RPM·탄창을 다시 보간하지 않는다. historical Hand Cannon/default 곡선의 재장전55tick·Firefly39tick, ADS5tick은 **커뮤니티 곡선을 20Hz로 변환한 근사**이지 원작의 최신 정확 프레임 측정이 아니다.

기본 한손 native grip이고, 기존 명시적 two-hand 전환도 지원한다. 경이 제한은 기존 loadout 경로를 사용한다. 전설 퍽 선택 소켓에 Ace를 임의로 넣지 않는다. 기본 촉매 소켓은 비어 있으므로 Funeral Pyre를 자동 부여하지 않는다.

## 메멘토 모리

1. 실제 지불한 Ace 직접 타격이 양의 HP/흡수 피해와 최종 처치를 확인할 때만 해당 원본 stack에 kill 시각을 기록한다.
2. 처치 후 **72서버 tick(3.6초/20TPS)** 안에 실제 양의 탄약 이전을 포함한 재장전을 **완료**하면 6발을 부여한다. 이 구현은 W65 ammo-credit 시점과 full-ready 시점을 분리하고, 후자를 완료로 선택한다. 원작의 두 프레임 중 어느 것인지는 자료로 확정하지 못했다. 정확72 경계 포함도 로컬 정책이다.
3. `WeaponCycle.fire`가 실제 탄약을 지불한 뒤 단 한 emission이 강화탄 하나를 소모한다. 빗나감·지형 명중도 소모한다. 거절·중복 use·HUD 읽기는 소모/부여하지 않는다. 세션 토큰에 강화 여부를 고정해 마지막 여섯째 발도 강화한다.
4. 확인된 커뮤니티 수치 **PvE1.68×/PvP1.29×**, 활성 발의 감쇠 시작·종료 거리 **.85×**를 적용한다. 기존 Minecraft HP/정밀/방어 판정을 사용하는 것이지 원작 표시 피해 단위 복제는 아니다.
5. 넣기는 **장전된 강화탄만 제거**한다. 남은 kill→reload 기회와 Firefly120tick 창은 같은 owner/level/원본 stack이 실제 인벤토리에 있는 동안 유지한다. 실제 hotbar/offhand/container 선택 슬롯 변이 직전에도 넣기를 관찰해 동일tick 왕복을 놓치지 않는다.
6. 새 kill 없는 재장전은 남은 강화탄 유지, 새 유효 재장전은 6으로 교체(누적하지 않음)를 **자료 미확정 로컬 정책**으로 선택한다. Marksman Dodge의 실제 instant ammo 이전도 완료로 처리하고 holster fill은 처리하지 않는다.

원본 stack별 메모리는 실제 인벤토리 소유에 한정된다. 복사·교체·버림·다른 owner/level·죽음/로그아웃/관전/궁극기는 권한을 이어주지 않는다. stow generation은 예전 emission 토큰을 재활성화하지 않는다. 인벤토리 밖 또는 만료된 stowed 메모리는 제거한다. Grenade/melee가 실제 무기 넣기와 같다는 미확인 가정으로 무조건 지우지 않는다. 다른 능력/Firefly 처치까지 kill 기회에 포함되는지는 미확정이며 현재 **실제 직접 Ace 처치만** 인정한다.

## Firefly

- 실제 정밀 최종 처치가 **Solar** 폭발을 만든다. 주탄의 Kinetic과 구분한다.
- 커뮤니티 Ace 전용 **반경7.5m/감쇠 시작3.75m/PvE끝점20%**. Minecraft에서는 entity center sphere와 1m→1block을 사용한다. **최대15HP와 core 이후 선형 보간**은 로컬 PvE 설계다. 원작436 피해를 Minecraft15로 환산했다고 주장하지 않는다. 자료의 “272% stronger” 설명을 임의 수치로 곱하지 않는다.
- 실제 collider LOS·로드된 전체 segment·동맹/펫 제외·거리 정렬·실제 입장 후128cap. 파동·폭발 탄약·정밀 환급/다른 퍽에 재귀 호출하지 않는다. 주변 폭발 처치가 다시 Firefly나 강화탄을 만들지 않는다.
- 정밀 처치는 **+50 Reload Speed/120tick**도 부여한다. 재장전 시작 시 유효 stat과 곡선으로39tick을 고정하며, 도중 만료로 애니메이션/오디오/탄약 deadline이 점프하지 않는다. 근거 없는 .8×시간 스칼라를 추가하지 않는다.
- 기존 Solar item-display VFX/입자/피해 숫자, 제공 음원의 Solar grenade impact를 **명시적 임시 대체음**으로 사용한다. 전용 Firefly 음원이라는 주장은 하지 않는다.

## 외형·음향·HUD

사용자 원본 `Ace.bbmodel`87큐브/522면 UV와 임베디드 texture를 보존해26.3native 모델로 변환한다. 256cube 한도 이내다. hip/ADS/inspect/third-person·양손 변환 및 W70 ADS21샘플을 새 자산으로 추가한다. 수학/소프트웨어 preview는 실제 framebuffer 성공과 구분한다. 사용자 Blockbench/Blender 프로젝트는 열거나 변경하지 않는다.

제공 Drive 내부 **Ace of Spades** 폴더의 `Fire_1.mp3`·`Reload_1.mp3`를 실제 내려받고 SHA를 고정했다. 원본은 ignored private cache에만 둔다. 모노32000Hz/Vorbis·안전 피크·경계 fade·유휴 절단을 적용하고55/39tick reload에는 pitch-preserving atempo를 쓴다. 이는 업로더 무기/동작 명칭에 근거한 선택이며 독립 청취나 Memento 전용 변형의 식별은 아니다. 새 sound key4개만 추가하고 기존 event 정의는 보존한다. emitter 종료/취소는 기존 재장전 오디오 수명주기를 그대로 사용한다.

DisplayHud buff feed에 **Memento Mori x6→x0**의 실제 잔여 발 수를 표시한다. 존재하지 않는 초 단위 만료 타이머를 만들지 않는다. 새로운 Arial Narrow glyph는 직접 래스터화한 근사다. 레이더/원작 font/무기 불꽃 material/새 전용 재장전 모션/촉매는 이 단계에서 구현 완료로 주장하지 않는다.
