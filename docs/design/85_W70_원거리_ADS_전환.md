# W70 — 전체 원거리 무기 ADS 전환

## 목표와 범위

기존 HIP/ADS가0.5에서 한 번 바뀌던 시각적 전환을 개선한다. 무기57종(검5/월도1 제외)에 기존 first-person HIP→ADS 끝점 사이21개 pose를 생성했다. 새 geometry/texture는 없고 기존 모든 모델·UV·음원을 보존한다. 좌/우 손 및 기존 두 손 carrier 보상을 적용한다.

[출처와 근사 한계](../../art/weapons/w70/reference-notes.md) · [QA](../qa/2026-10-24/w70/README.md) · [단계 미리보기](../qa/2026-10-24/w70/ads-transition-contact.jpg).

## 실제 state 연결

- `WeaponAiming`의 기존 단일 raw progress → FOV/ballistics/pose/HUD 및 W70 sampled presentation. 새 독립 타이머를 만들지 않았다.
- `floor(progress*20)/20`를 CMD float3에 쓴다. 실제 틱 수가7이면7개 정도만 통과하며21프레임을 모두21tick 재생한다는 뜻이 아니다. render-frame 연속 보간은 아니다.
- float1 reload/float2 bow/flag0 grip/string0 pose/다른 component는 독립 유지한다. 원본 ITEM_MODEL identity도 바꾸지 않는다.
- 실제 owner/level/exact ItemStack/유효 Aiming session만 바닐라 wire의 W70 graph를 승인한다. copy/NBT/preview/저장 selector 자체는 권한이 아니다. 읽기 getter는 state를 진행시키거나 수정하지 않는다.
- 취소/이탈/수납/소유상실/level불일치/관전에서 binding을 정리한다. 원래 float3 값/부재 길이를 복원하며 active bow/reload/higher float를 덮어쓰거나 밀지 않는다.
- 동등한 saved sample과 Polymer cache가 충돌하지 않게 live grid offset을0/.001/.002 중 선택한다. 모든21sample이 원래 값과 직전 owner sample 둘 다와 달라야 한다. exact-stack 반복 이전은 최초 original floats를 계승하며 늦은 donor cleanup은 recipient를 건드리지 않는다.

## 모델 우선순위

1. 실제 개별 reload(Beloved/Duke/Ammit)
2. 실제 W70 ADS. 단, sniper는 기존0.5 scoped 시점부터 W45 opaque route.
3. 실제 W50 ordinary bow draw/nock
4. 기존 W45 scope
5. 원래 base item graph

- 저격총3종: 0.5 이전에는 W70 무기를 이동하고 이후에는 기존 opaque scope/HUD 그대로.
- LFR2종: 0.5에서 scope geometry로 전환하지만 W70 display 진행도는 계속 유지. 끝점은 W45 scope display이며 원본 geometry/tint는 보존한다. geometry/HUD threshold 자체는 여전히 이산적이다.
- 일반 활2종: actual W50 binding일 때만 `_bow` wrapper. ADS21×draw/nock44상태를 독립 합성한다. float2를 임의 저장해도 이 wrapper는 활성화되지 않는다.
- non-first-person은 정확한 기존 graph로 fallback하므로3인칭/GUI/바닥 파지 변경은 없다.

## 검증 기준

실제 서버 입력/tick/Polymer wire/탄약/HUD/FOV/Snapshot/취소/소유권과26.3 item-model codec/cuboid parser, 끝점·보상행렬·bow2축·nonFP fallback을 별도로 검사한다. GameTest는 네이티브 화면/키 입력/청취 증거가 아니다.
최종 gate 및 asset보존 수치는 QA 기록에 고정한다. 일반 QA에 배포하거나 사용자 profile/options/MCP를 바꾸지 않는다. 전체 데스티니 무기 목표는 active이며 개별 장전/손 IK/실게임 검증 등은 남는다.
