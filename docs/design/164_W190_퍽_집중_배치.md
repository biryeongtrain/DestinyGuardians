# W190 — 퍽 집중 배치

## 범위

2026-10-27 사용자 지시: 애니메이션은 Windows 추출 파일을 받을 때까지 보류하고 퍽만 작업한다. 기존 handoff와 봉인 QA는 보존한다. 이번 목표는 Compulsive Reloader / Iron Reach / Under Pressure / Ensemble 기본형4종이다.

## 단계 기록

1. 현재 구현36종과65무기의 기존 고정 공식 manifest(245114.26.10.13.2000-1-bnet.66137) randomized trait socket을 대조했다. 새 후보는 현재 제품의 실제 허용 무기에만 등록한다. 오늘 최신 manifest 전체를 새로 내려받아 소켓을 재갱신했다는 뜻은 아니다.
2. 사용자 DDC Weapon Perks gid1662574278을 다시 받았다. row54 Compulsive Reloader,86 Ensemble,129 Iron Reach,239 Under Pressure 원문을 각 source.json에 보존한다. Under Pressure의30? Stability는 확정 수치로 격상하지 않는다.
3. dirty snapshot worktree3개를 생성했다. 공통 기준65728files, SHA256 a0d883d258e5d769fbf540289140654cdb6517b6dc66706413d7fb71e2ce8693. 각자 dependency/build와 소유 파일을 분리한다. master는 Iron Reach와 공유 registry·적용 경로를 소유한다.
4. 단순 수치 퍽별 테스트와 Vision은 추가하지 않는다. Ensemble에 새로 생기는1.5초 잔류 상태만 작은 동작 검증 대상으로 둔다. 출처 수치·실제 스탯 소비 경로·컴파일을 확인한다.

5. 소유 경로의 main 기준 해시가 바뀌지 않았음을 확인한 뒤20개 worker 파일만 통합했다. Iron Reach는 master가 별도로 구현했다. 퍽 목록/선택 명령·실제 안정성/탄퍼짐/사거리·장전 수락 경로와 Ensemble의 관측/교체/해제/cleanup을 연결했다. 신규 단순 수치 퍽에 별도 HUD 타이머나 애니메이션을 만들지 않았다.
6. Java25 compileJava/JAR 생성 통과. Ensemble 잔류·재진입·무효화·시계역행 테스트4개 통과(실패/오류/skip0). 공통 profile resource 로드에서1/10/5/1소켓과 등록40종을 확인했다. 수치별 신규 테스트0개, 전체 회귀/Vision/실게임 실행0회다.
