## 실측과 디자인 방향

2026-10-25 현재 native JSON의 에이스는 87큐브/522UV면, 이자나기는 79큐브/474UV면이다. 두 예시에는 삼각 mesh가 없다. PNG atlas도 확인했으며 이자나기는 본체·장식 512², 렌즈 128²로 분리된다. 상세 경로·hash·관찰과 해석의 한계는 스킬 연구 문서에 한 번만 유지한다.

원본 작은 조각을 그대로 옮기는 대신 긴 연속 면, 의미 있는 부품 분할, 중요한 실루엣·빈 공간·깊이를 먼저 설계한다. 얕은 홈·나사·그립 패턴·문양은 UV로, 시차/실루엣/동작에 필요한 부분은 실제 입체로 남긴다. 26.3 회전과 삼각 경로는 실제 exporter가 지원하는 방식으로 선택한다.

유사 복잡도는 약 80~120개 초안부터 시도하되 고정 개수는 아니다. 본체+탄창+기타 동시 부품의 **최종 출력 1,000요소 이하**는 계속 적용한다. 800~1,000개를 채운 자동 변환이 상한을 통과했다는 이유만으로 이 스타일을 달성한 것으로 세지 않는다.

## 독립 forward-test

새 에이전트에 스킬과 실제 Ammit/비교 모델 자료를 주고 ‘원작 기본 외관을 살리면서 에이스/이자나기처럼 정돈되게 재설계’라는 요청의 계획을 작성하게 했다. 실제 자산·UI·게임 실행과 레포/스킬 수정은 금지했다. 산출물은 [독립 설계 계획](../qa/2026-10-25/weapon-art-skill/forward-test.md)에 보존했다.

- 결과는 **예상 114개 = 본체106 + 탄창8**의 입체 큐브 초안이며, 이는 제작 완료나 실제 export 결과가 아니다.
- 큰 열린 프레임·가늠자·포구 깊이·주황 유체창과 원작 색 구분은 유지하고, 얕은 패널/나사/문양은 UV로 배분했다.
- 120개를 강제 cap으로 해석하지 않았고, 삼각 adapter 출력 팽창·full/split 중복 집계·기존 장전 인덱스/팩 참조 위험을 구분했다.
- 전체 전투 gate/FPS 인증을 새 미술 작업의 선행조건으로 요구하지 않고 대표 시점의 통합 확인을 제안했다.
- master가 계획 산출물을 읽고 위 의사결정을 검토했다. 스킬 적용을 막는 모순은 발견되지 않았다. 실제 미학·native·성능 수락은 후속 모델 제작 이후의 별도 검증이다.
