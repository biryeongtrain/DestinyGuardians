# W44 — 실제 ADS · 카메라 반동 · 무기군 리티클

## S1 범위와 인수 기준
- W43 정밀/거리감쇠/피해숫자 이후 단계. 전체 무기 목표 완료 아님.
- 웅크리기 유지 ADS, 우클릭 발사, 모든 live 무기 Q 재장전(드롭 취소). 월도 웅크리기 방패 유지, 검 ADS 제외.
- Guardian 웅크리기+좌클릭 근접/F 궁극기/더블탭 구르기 우선. 스킬/재장전 시 조준 취소, 웅크리기를 놓아야 재진입.
- Handling 기반 전환시간과 공식 Zoom 기반 시야 배율. ADS 거리감쇠 scalar는 Zoom과 별도.
- 카메라 반동은 26.3 `ClientboundPlayerRotationPacket` 상대 yaw/pitch 사용. 위치 텔레포트/클라이언트 이동능력 위조 없음.
- 실제 마우스 입력을 덮어쓰는 강제 원점복귀 없음. Stability/Recoil Direction은 제한된 Minecraft 튜닝으로 사용; 원작 반동곡선 재현 주장 아님.
- 원작 무기군을 참고한 자체 리티클: ADS 축소/연사 bloom/회복, 재장전/궁극기 정리. 월도 기존 방패 HUD 보존.

## 데이터와 렌더 경계
- 공식 W40 개별 아이템 stat + W43과 동일하게 고정한 Foundry 공개곡선. 2026-05 이후 전체 최신 밸런스라고 주장하지 않음.
- 기존 HIP/ADS JSON selector를 전환 중간에 변경. FOV/리티클은 매 tick 전환하되 모델 자체는 연속 보간 아님.
- minigame-lib `CameraEffects` FOV는 `config/minigame-lib/shaderfx.json`의 `dynamic-fov-shader:true`가 필요. 라이브러리 기본 false는 유지. 검증한 이 프로젝트 로컬 서버 설정은 true로 유지하며, 다른 배포 서버도 opt-in과 팩 재생성이 필요.
- 바닐라 클라이언트의 개인 FOV 설정을 서버에서 읽을 수 없음. FOV override가 없으면 70도 기준, override가 있으면 해당 값 기준. 해제 시 실제 원래 상태 복귀.
- 다른 CameraViews/궁극기/외부 FOV 소유자를 침범하지 않으며 자신의 마지막 값일 때만 reset/restore.
- Q는 현 Vision native 키 목록에 없어 GameTest packet route로 검증하고, 실제 키보드 검증이라고 보고하지 않음.

## 검증 기록
최종277/277GameTest·214/214JUnit·native18통과. 세부 실제HP/확대/반동 및 한계는 QA기록 참조. 전체 목표는 active.

## S2 최종 구현과 검증 주의
- `WeaponAiming`은 owner 객체/stack reference/차원과 연결. 스킬·reload·swap·죽음·spectator·차원 이동·disconnect 정리.
- 발사 직전 ADS감쇠를 평가, 투사체는 원래 발사 profile 저장. 성공한 첫 샷/각 burst subshot 뒤에만 카메라 kick. 거부된샷은 kick 없음.
- bloom은3틱회복유예 후0.04/tick, 최대1. 카메라 원위치 강제회복 없음. 샷의 작은 결정론적 분산과 산탄 ADS축소에 실제 반영.
- 두 reticle node는 `setAboveHand(true)`를 써서 중앙 무기 모델보다 위에 보임. reload에는 숨김.
- 원래 모델542개를 이번단계에서 수정하지 않음. 저격총 렌즈 중심 정렬·scope mask·스무스 모델 보간은 미완료.
- 원작PC 우클릭ADS/좌클릭사격 바인딩과 동일하지 않음. 바닐라서버 입력 타협안은 위 조작표 기준.
- 개인FOV70 이외 설정은 초기 진입시 서버고정기준과 차이가 날 수 있음. 원래개인FOV설정파일은 변경하지 않고 ADS해제시 vanilla복귀.
- 실제 QA 원본/권위HP/반동각/marker배율측정/팩hash는 `docs/qa/2026-10-24/w44/README.md`에 보관.
