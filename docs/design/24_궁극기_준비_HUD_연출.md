# 24. H17 — 궁극기 준비 HUD와 발동 피드백

## 단계 1: 레퍼런스와 범위 (2026-10-22)

사용자 요청: 실제 데스티니처럼 궁극기가 찼을 때 HUD로 알리고 VFX의 흐름을 보강한다.
일반 총기/탄약/재장전(로드맵5)은 별도다. 피해·에너지·쿨타임 밸런스는 변경하지 않는다.

- 원작 HUD 아티스트 MacKay Clark의 [Destiny 2: HUD](https://mackayclark.artstation.com/projects/2XYDe),
  [Super Charged 모션 컴프](https://player.vimeo.com/video/234896661?dnt=1).
  해당 페이지와 영상 표지(1920×1080)를 열어 얇은 황금색 직사각형·넓은 자간·단색 문구를 확인했다.
  영상 프레임 타이밍을 실측한 것은 아니다.
- [Lightfall 플레이 화면](https://www.toomuchgaming.net/blog-news/destiny-2-lightfall-guide-unfinished-business-quest-steps)의
  750×422 스크린샷을 열어 조준점 위 배너, 좌하단 황금색 궁극기 아이콘/막대를 확인했다.
- 메시/텍스처/폰트를 추출하지 않는다. 문구는 원작처럼 `SUPER CHARGED` (궁극기 준비).
  직접 그린 기하학 대문자·얇은 프레임·보조 마름모로 재해석한다.

## 단계 2: 구현 계약

- `SuperHudCue`: 서버 tick 기반 56틱 준비 배너, 12틱 발동 주변부 액센트.
  같은 tick의 반복 update는 수명을 늘리지 않는다. `int` tick 래핑에 안전한 차이 계산.
- 첫 관측 시 이미100%면 정적 준비 아이콘만. 아래100→100%에서만 알림.
  사용/에너지 감소/장착 궁극기 변경은 이전 배너를 취소한다.
  공허처럼 즉시 끝나는 궁극기는 정상 세션 종료 후에도12틱 발동 액센트를 마무리한다.
- 중앙 (960,402), 560×112 쿼드 내부에 얇은 프레임과 문구.
  0~5틱 전개,6~43틱 유지,44~55틱 단계 감쇠. 좌하단 다이아몬드 확산/게이지 스윕은20틱.
- 준비 중 좌하단80px 마름모를 황금색 채움+어두운 무기 실루엣으로 바꾼다.
  활성 중은 기존 황금 테두리/실제 잔량 게이지. 기존 확대 크기를 유지한다.
- 발동은 Arc/Solar/Void 밝은 속성색의 주변부 필라멘트. 가운데70%는 완전 투명.
  기존 H15 BetterModel 모델/포스트 펄스를 유지하며 새 준비 연출은 post effect를 조작하지 않는다.
- HUD owner에게만 전송. 새 월드 엔티티·BetterModel tracker·매틱 파티클 없음.
  기본15노드(흡수 시16)+준비3=최대19; 발동1=최대17. 준비/발동은 배타적.
- 스프라이트 캐시 키에 높이/z/정렬을 포함해 같은 너비의 높이/레이어 변경도 반영한다.
- 사망/관전자/직업none/차원 이동/접속 종료/서버종료에서 HUD와 cue 맵을 정리한다.
  기존 cleanup 계약을 이용한다. 직업none에도 실제 체력 대체 HUD는 남긴다.
- 알파 텍스처의 단계 감쇠는 클라이언트 머티리얼에 따라 cutout 변화로 보일 수 있다.
  진짜 bloom/동적광원/볼류메트릭이나 원작 음향을 구현했다고 표현하지 않는다.

## 단계 3: 검증

구현 후 자동 테스트와 Copper Golem Vision26.3 실제 프레임버퍼 검증 결과를 이곳과 QA에 추가한다.

### 첫 화면 검토와 수정

- JVM1은 stdin이 닫힌 실행 세션이라 명령 주입 전에 종료했다(SIGTERM143). 렌더링 검증으로 집계하지 않는다.
- JVM2 실제1708×956 화면에서 준비 배너/확산/스윕/Arc 발동 필라멘트와 자연 만료를 확인했다.
  밝은 하늘에서 얇은 글자/테두리가 약했다. 배너480→560px, 획 두께2→3, 자간26→30,
  국소 흑연색 스크림(알파95/255)을 추가했다. 원래 체력/능력 HUD 크기는 그대로다.
- 새18모델의 particle 텍스처 참조를 명시해 새 에셋의 기존 유형 경고를 제거했다.
- 독립 검토에서 공허 세션이 즉시 끝나면12틱 발동 cue가 잘리는 문제를 발견했다.
  정상 종료는 유지하고 lifecycle/loadout 취소는 그대로다. 순수 unit/실제 공허 GameTest를 추가했다.
