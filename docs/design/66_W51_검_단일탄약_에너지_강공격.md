# W51 — 검: 단일 탄약·에너지·프레임별 강공격

상태: **354 GameTest/348 JUnit**, 최종 동일 JAR full gate 2회 통과. 전체 무기 목표는 **active**.
실제 클라이언트의 3인칭/입력/음향 검증과 정확한 원작 애니메이션은 별도 잔여 작업이다.

## 근거와 역사 구분

[공식 조사 보고](../qa/2026-10-24/w51/reference-report.md), [기계 판독 규칙](../../art/weapons/w51/references/mechanics.json),
[출처와 SHA](../../art/weapons/w51/references/sources.json), [5개 원본 intrinsic](../../art/weapons/w51/references/official-manifest.json).

- 2020: 탄약과 검 에너지는 별개. 가드는 탄약 대신 활성 시간 동안 에너지를 쓰며 탄약 1개 이상 필요.
- 2023: **에너지 > 0이면 정상 위력 강공격**. 예전 ‘부분 에너지=부분 위력’ 설명을 그대로 적용하지 않는다.
- 2023: 피격에 따른 추가 가드 에너지 비용 삭제. 피격/피해 계산 getter에는 에너지 mutation이 없다.
- 2023: PvE 가드 DR 범위 82.5–95%, charge rate에 따른 회복 대기 1.05–2.7초. 개별 계산식 미확인.
- 2024: 무에너지 adaptive 강공격은 1탄약, 다른 무에너지 강공격과 동일하다는 공식 문구.
- 2026-06-09: vortex 강공격 탄약은 6→**4**. 옛 6발을 현재 값으로 사용하지 않는다.
- 원본 raw capacity는 50/70/40/46/23. 최종 perk/roll 반영 탄약량 인증은 아니다.
- 단일 finite pool/no-reload는 W46와 manifest에 근거한 서버 설계 번역이며 현재 D2 실플레이로 측정하지 않았다.

## 컨트롤·공격

| 입력 | 동작 |
|---|---|
| LMB | 유료 약공격, 빈 검은 약한 무료 타격 |
| RMB | 실제 native press 한 번에 강공격 한 번 |
| 웅크리기 | 양수 에너지+탄약+공통 공격 회복 완료 시 가드 |
| Q / Ctrl+Q | 드롭/재장전/탄약/에너지 변경 없음 |
| 웅크리기+LMB (헌터) | 기존 Guardian 근접 스킬 우선 |
| 궁극기 중 | 기존 PRIMARY 우선, 장착 검 소비 없음 |

RMB는 실패한 press도 native use 세션을 유지해 held 상태가 뒤늦게 새 강공격으로 승격되지 않는다.
continueUse는 검 강공격을 반복하지 않는다. 강공격의 탄약·에너지는 cooldown/탄약/투사체 상한 검사 뒤만 원자적으로 소비한다.
피격/명중이 없어도 받아들인 유료 공격은 비용을 낸다.

| 검 | 프레임/형태 | 정상 강공격 탄약 | 지역 구현 |
|---|---|---:|---|
| Abide the Return | adaptive/uppercut | 4 AUTHORED | 전방 단일 타격 |
| Goldtusk | lightweight/dash | 3 AUTHORED | 짧은 수평 서버 대시+전방 타격 |
| Crown-Splitter | aggressive/slam | 4 AUTHORED | LOS 검사 범위타격 |
| Falling Guillotine | vortex/spin | **4 공식 2026 patch** | LOS 검사 방사형 범위타격 |
| Temptation’s Hook | caster/projectile | 4 AUTHORED | 충돌·범위·수명·소유자 상한 있는 투사체 |

다른 프레임의 charged cost는 최신 공식 값으로 인증하지 않는다.
1탄약 약공격, 3타 finisher 1.25배, 빈 약공격 HP3, 무에너지 강공격 .35배,
정상 heavy multiplier1.8/2.4/3.5/2.9, cadence16–30tick, 대시1.6블록, 범위·속도·폭발은 **Minecraft authored PvE tuning**.
순수 로직 테스트는 선택한 튜닝을 검사하는 것이지 원작 수치를 검증하는 것이 아니다.

대시는 0.1블록씩 최대16단계, 신체 AABB 네 모서리 loaded chunk/월드 경계/충돌을 검사한다.
고체 벽을 뚫거나 벽 뒤 적에게 피해를 주지 않는다. 엔티티 밀어내기/상대 충돌 이동은 별도 미구현. 실제 원작 lunge/추적/계단 이동과 같다고 주장하지 않는다.
전방 타격은 AABB.clip 시작점이 적 margin 내부인 접촉도 처리하며 거리0 고체벽 판정은 우선한다.
slam/spin은 대상마다 한 번의 HP transaction; 원작 다단히트 횟수/히트스톱 재현이 아니다.

## 에너지·소유권

SwordCycle + SwordItems: 100000 단위 에너지, 남은 회복 대기를 실물 아이템에 저장.
- 활성 가드: 500/tick, 최대 약10초. 피격 추가 소모 없음.
- 비가드: 마지막 사용 후20tick 대기, 이후1250/tick, 약4초 회복.
- 수치와 가드 중 regen 금지는 **authored**. 개별 guard resistance/charge-rate 보간은 미구현.
- 정면 PvE mob 피해 95% 감소는 **authored 공통 상한값**. 개별 guard roll 반영 아님.
- PvP/후면/환경/동맹/길들인 동물/방패 무시 피해에는 가드 미적용.
- swap/skill/death/차원/재접속 취소는 guard/combo를 제거하고 회복 snapshot을 저장한다.
- 취소 후 inactive state가 매 tick 옛 snapshot을 덮어쓰지 않도록 active-binding 플래그로 1회 저장.
- 다른 실물 검으로 바꿔도 owner의 공격 회복 시간은 초기화하지 않는다.
- stowed/offline의 에너지 catch-up 없음. 새 검만 full energy, 누락/손상 저장값은 자동 full grant 안 함.
- HUD/guard getter는 bind/tick/저장/회복을 수행하지 않는다.

## 탄약·마이그레이션·획득

새 검은 reserve=0, finite 단일 pool. WeaponItems.magazine은 레거시 rounds/reserve/overflow를 로컬 projection에서만 합산한다.
합계는 보존하고 capacity 밖 초과분은 overflow에 남긴다. 읽기/inspect/HUD는 원본 NBT를 쓰지 않는다.
실제 소비/획득 mutation에서 canonical snapshot을 한 번 저장한다. 초과 legacy ammo가 있으면 사용하면서 자연스럽게 승격된다.
새 Heavy brick은 사용 가능한 검 pool에 직접 더한다. 다른 총은 기존처럼 reserve-only.
범용 addLoaded는 reserveCapacity0인 유한 pool에서만 가능해 일반 총 자동 재장전으로 악용되지 않는다.

## HUD·모델·소리

- 선택 검은 큰 단일 탄약 숫자. reserve 숫자/구분선/무한 아이콘 제거.
- Guardian의 기존 MELEE 타일을 검 아이콘+실제 에너지로 대체. 스킬 cooldown 자체는 변경하지 않는다.
- 비Guardian은 탄약 패널 아래 에너지 바. 장비 해제/궁극기에는 제거.
- 기존 3슬롯 stowed UI·탄종·속성 표시는 보존.
- 모델/UV/원본542에셋/기존 W50 활 모델 변경 없음.
- 서버 swing은 26.3 SwingAnimation(WHACK,4/6) 사용. 원작 motion clip/손 IK/강제 검 3인칭 카메라는 아직 없다.
- 기존 weapon.sword.fire 매핑만 사용. 제공 Drive의 Guard/Tornado 후보는 목록·ID만 확인했고 청취/새 event 매핑은 하지 않았다.
