# W77 — 잠자리(Dragonfly) 정밀 처치 폭발

## 구현 목표

공식 base 특성 hash2848615171의 확인된 소켓에서만 `/destiny perk select dragonfly`를 허용한다.
기본 지급/프리뷰/특성 미선택 무기에 효과를 만들지 않는다. 일반 플레이어의 소유 무기 편집이며 탄약을 새로 주지 않는다.

실제 유료 원거리 발사에서 양수 HP/흡수 감소와 정밀 최종타를 확인한 뒤 처치한 적 중심에 폭발한다.
단순 조준, 정밀 비치명타, 몸통 처치, 스킬 처치와 피해 거부로는 발동하지 않는다.
보조 폭발은 비정밀 피해이며 새 발사/잠자리 폭발/정밀 탄약 반환/무법자를 재귀 호출하지 않는다.
현재 공식4개 소켓은 모두4번 특성 열이어서 Rampage/Kill Clip 등 같은 열과는 배타적이다.

## 출처와 수치 경계

- [공식2025-07-03 TWID](https://www.bungie.net/7/en/News/Article/twid_07_03_2025): 폭발 피해를 무기군별 계수 대신 별도 특성 계수로 정규화한 변경.
- [light.gg base 특성](https://www.light.gg/db/items/2848615171/dragonfly/): 정밀 처치/무기 속성 폭발, 커뮤니티 조사 반경4.5m.
- 정확한 소켓/고정 manifest/수송 SHA 및 조사 해석은 [W77 자료](../../art/weapons/w77/reference-notes.md)에 기록한다.

**Minecraft 튜닝:**1m→1block, 중심10HP·선형감쇄·반경 내 최소30%. 원작 피해 단위나 적 등급별 정확한 계수 복제가 아니다.
벽 너머·범위 밖·플레이어·동맹·길들인 동물은 피해 대상이 아니다. 범위 admission과 감쇄는 모두 실제 bounding-box 중심을 써서 열린 shulker처럼 위치에서 box가 이동하는 적도 일관되게 판정한다. 폭발은 지형을 파괴하지 않고 불을 붙이지 않는다.
공식 반경과 로컬 피해/감쇄/차폐 정책은 리소스에서 별도로 표기한다. 강화형 특성을 섞지 않는다.

## 귀속과 중복 방지

발사시 실제 owner/level/ItemStack/무기를 캡처한다. 발사체의 수납 후 명중은 원본을 계속 소유하고 특성이 유효한 경우만 허용한다.
다른 무기를 들었다고 해당 무기 속성으로 바뀌지 않는다. 동일 stack의 무기 ID를 다른 eligible 무기로 편집해도 원본 캡처와 달라져 무효다. 드롭/복사본 교체/특성 해제/사망/관전/차원 이동은 무효다.
같은 발사 토큰과 같은 처치 대상의 중복 callback은 한 번만 처리한다. 전역 UUID 세션이나 별도 저장 데이터는 없다.

## 연출과 HUD

기존 BetterModel의 솔라 burst·아크 flash·공허 smoke를 재사용하고 무기 속성색 파티클/짧은 링을 더한다.
원작 잠자리 전용 원본 VFX 모델을 확보한 것은 아니다. cosmetic backend 실패는 폭발 피해를 취소하지 않는다.
음향은 사용자 제공 archive에서 이미 가공된 같은 속성 수류탄 impact의 **임시 재사용**이다. 정확한 Dragonfly 음원/실청취 검증이라고 하지 않는다.
새 모델/텍스처/Ogg 및 HUD buff 행을 만들지 않는다. 잠자리는 지속 버프가 아니며 실제 보조 피해는 비정밀 피해 숫자로 표시한다.
W76 허기/XP/핫바 프레임 suppression과 offhand 위 HUD 표시는 유지한다. 잔여 바닐라 아이콘/숫자/toast는 여전히 후속 범위다.

## 검증 상태

구현/자동 시험/실게임 결과는 [W77 QA](../qa/2026-10-24/w77/README.md)에 단계별로 기록한다. 최종 Gate5/6 각각629 required GameTest와568 JUnit이 통과했고 같은 최종 JAR의 격리 Vision 검증6경우도 통과했다. 솔라·아크·공허 정밀 처치에서 주변 HP20→14.444445와 실제 색상 폭발 PNG를 확인했다. 몸통/특성 없음/벽 차폐의 주변 HP는20을 유지했다.
열린 shulker의 실제 bounding-box 중심 및 동일 stack의 다른 무기 ID 편집은 추가 회귀시험으로 보정했다. 초기 gate/native와 보정 후 최종 증거를 분리한다. Gate4의 새 동맹 fixture 간 scoreboard 경합은 fixture 환경을 격리해 해결했고 최초 실패를 보존한다.
6396개 기존 client asset은 불변이다. 새 QA 팩은 과거 BetterModel 예시/폐기된 정의를 포함하지 않아 W76 팩과 바이트가 다르지만 현재53개 item의 모델/부모/텍스처 의존성은 의미적으로 동일했다. 서버 팩과 실제 클라이언트 다운로드는 바이트 일치한다. 모든 애니메이션의 시각적 동일성 보장은 아니다.
검증용 server/client와 임시 잠자기 방지는 종료했다. native 내부 입력/서버 판정/실제 framebuffer 증거이며 OS 키보드·실청취·다인 성능 검증이 아니다. 전용 음원/VFX와 잔여 바닐라 UI·리소스 경고는 후속 범위다.
전체 무기/경이 효과/장전 손모션/정확한 원작 음원/다인 성능 목표는 계속 active다.
