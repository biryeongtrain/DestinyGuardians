# W206 — 5무기 1인칭 파지 병렬 보정

2026-10-28. 사용자의 “다른 모델도 한 번에 4~5개, 에이전트 수도 늘려 병렬 작업” 지시를 적용한다. W205 활 수정과 같이 팔을 늘리는 대신 무기·양손·장전 부품을 동일한 카메라 공간 변환으로 가까이 배치한다.

## 배치와 소유권

| 무기 | Worker | 유지할 접점·기능 |
|---|---|---|
| Ammit AR2 | Sartre | 앞쪽 lower beam, 분리 탄창, 원본 AR 팔 방향 |
| Blast Furnace | Curie | lower foregrip, 뒤쪽 불펍 탄창, 기존 W152 조준경 통로 |
| Hammerhead | Singer | 앞쪽 하부 받침, 드럼/급탄구, W154 탄띠 방향 |
| Dust Rock Blues | Faraday | pump 아래 받침, 고정 loading port, shell 단위 장전 |
| Izanagi’s Burden | Carson | 긴 앞몸통 받침, 79큐브, scope와 CMD6 일반/Honed 분기 |

각 worker는 dirty 기준선을 독립 CoW로 복제한 Git worktree에서 자신의 `art/weapons/w206/<id>/profile.json`과 `review.md`만 작성했다. Master는 공유 로더·생성기·테스트·Vision/CU를 맡는다. 공용 게임 창이나 fixture를 여러 worker가 동시에 조작하지 않는다. 원본 SSD와 메인 checkout의 기존 변경은 보존한다.

## 적용 경로

`first_person_framing_w205.load()`가 무기별 profile을 읽어 기존 family 설정 위에 합친다. 생성기는 profile의 SHA-256을 입력 manifest에 기록한다. 선택적인 contact override는 W201의 right/left/reload 접점에만 병합한다.

- `translation`, `rotation`, uniform `scale`: 같은 변환을 무기·장전 부품·손 접촉 프레임에 적용한다. hip에서 ADS로 전환할수록 0으로 보간한다. 양의 Z는 카메라 쪽 이동이다.
- 이번 다섯 무기는 `cameraDepth`를 사용하지 않는다. 따라서 full ADS의 무기 display는 기존 값을 유지한다. 손의 방향/접점은 별도 보정되므로 실제 시야는 Vision으로 확인한다.
- `keepMeshSupport`: 원본 wrist 사이 간격을 그대로 옮기는 대신 리모델링된 무기의 실제 왼손 파지점을 유지한다. 정확한 source FK의 방향·twist·전완 길이는 계속 쓴다. 장전 중에는 기존 moving-part/port 접점을 따라간다.
- `sourceViewRotation`: 원본 리그를 현재 카메라 구도에 맞추는 방향 보정이다. 원본 카메라를 복구한 값이 아니다. 팔 길이 override나 연장 geometry는 추가하지 않는다.
- 3인칭은 기존 item graph fallback이다. 기존 surface geometry/UV·조준경·전투·사운드·재장전 타이밍은 이번 배치에서 재설계하지 않는다.

무기별 근거 이미지·원본 리그 ID·보정값 이유는 각 `review.md`에 있다. 이 worker 문서는 통합 전 후보 조사이며, 실제 native 확인 결과는 아래 QA 보고서가 우선한다. 원본 추출물에 source camera가 없어 원작 화면의 정확한 투영 복원을 주장하지 않는다.

## 검증·정리

5개 결과를 취합하여 한 번의 기본 생성·targeted codec/skin 검사·assemble, 한 격리 서버/클라이언트에서 hip/fire/reload/ADS/3인칭을 확인한다. 실제 결함으로 값을 수정하면 해당 경로만 재확인한다. 작은 미술 변경에 전체 전투 gate를 반복하지 않는다.

배치 증거·최종 값·미검증 범위·아티팩트와 완료 worktree 정리는 [W206 QA](../qa/2026-10-28/w206/README.md)에 기록한다. 고유 delta만 복구 묶음으로 보관하고 완료 worktree는 같은 배치에서 제거한다.
