# W207 — 장전 연속성과 Dust Rock Blues 탄 삽입

사용자 피드백: W206 5무기의 장전이 Ace/Izanagi 과거 문제처럼 끊기며 샷건에 장전 모션이 없다. 기존 5 worker와 독립 worktree를 재사용하되 W206 전체 dirty 작업본으로 refresh한 후 새로운 배타 범위를 위임했다.

## 원인과 변경

1. Ammit/Blast/Hammer의 21포즈 bank와20단계 selector를61포즈/60단계로 개선. 내부 key마다 smoothstep으로 정지하던 곡선을 공유 접선 C1 Hermite로 변경. 실제 탄창 교체의 의도된 hold와 원래 장전 시간은 유지.
2. 손 리그의 nearest21-frame 선택을 평가 joint 위치 보간 + 정규화 shortest-arc quaternion slerp로 변경. idle 진입/복귀를 연결. Izanagi CMD6 ordinary/Honed 분기 연결. Arm 길이는 idle source 전완 길이를 유지한다.
3. Dust는 WeaponInsertPresentation 지원 목록에 없었다. 새 float4 initial0..1/loop2..3/return4..5를 기존 실제 탄 삽입 cycle에 연결. 총을 기울이고 손과 shell이 loading port로 이동하며 마지막6tick은 cosmetic 복귀. 탄약 이전은 기존 WeaponCycle 성공 시점 그대로다.
4. Dust 손은 initial에서 shell을 잡고 loop마다 loading port를 따라가며 return에서 앞손잡이로 돌아온다. phase 경계에서 idle로 튀지 않는다.

## 근거와 한계

새 generator/근거는 art/weapons/w207/. 입력 mesh/UV/texture와 기존 ADS·3인칭 fallback을 보존한다. W206 카메라 쪽 배치는 총/손/가동 부품에 동일하게 적용하며 팔을 늘리지 않는다.

Ammit/Blast source-map의 여러 reload tag는 무기별 variant가 확정되지 않았다. 80A8A395/80A8A36A를 방향 retarget의 명시적 calibration으로 선택했다. 실제 탄창 손 위치는 리모델링 mesh 접점이 정한다. 이 선택은 정확한 무기별 원본 애니메이션 또는 카메라 복구 주장이 아니다.

61포즈는60fps 보장이 아니다. held-item 모델 상태는 서버 tick에 맞추어 최대 약20Hz로 전달되며 클라이언트 연속 보간이 없다. 이번 변경은 추가 양자화 손실·중간 waypoint 정지·빠진 장전 연결을 없애는 범위다. 실제60fps 보간은 별도 렌더링 경로가 필요하다.
