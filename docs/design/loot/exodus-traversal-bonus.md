# 엑소더스의 추락 도보 이동 보상

2026-11-09 사용자 요청: 엑소더스는 연결된 맵을 직접 걸어서 진행하므로, 더 긴 플레이 시간에 대한 완료 보상을 추가한다. 아래 수치는 Minecraft 프로젝트의 경제 조정이며 원작 드롭률이 아니다.

| 참가자 1인당 완료 보상 | 기존 / 악마의 소굴 | 엑소더스 변경 후 |
|---|---|---|
| 확정 전설 무기 굴림 | 1회 | 2회 |
| 개인 상자 미광 | 40~60 | 80~120 |
| 상자 추가 보상 | 50% 확률로 1회 | 동일 |

`destiny/loot/tables.json`의 `exodus_completion`을 활동 `exodus_crash`에 연결한다. 기존 공용 `Loot.activityComplete` → `LootRoller` → `Loot.collect` 획득 경로로 완료 무기를 두 번 굴린다. 동일 무기가 나올 수 있으며 각 굴림의 특성은 기존 규칙을 따른다. 보관 공간 부족 시 기존 획득 처리 정책이 적용된다.

긴 필수 이동 구간의 보상은 완료당 고정 추가분이다. 대기 시간·이동 거리 누적에 비례해 지급하지 않으며, 구간별 반복 지급을 추가하지 않는다. 엑소더스의 기존 `completeAt` 완료 중복 방지와 완료 시 같은 월드에 있는 참가자 선별을 그대로 사용한다. 개인 상자의 개봉·자동 정리 지급도 기존 공용 경로를 따른다.

활동별 보상 선택만 데이터로 분리한다. 다른 공격전, 적 처치 보상, 상자의 등급 가중치 및 엔그램 해독은 변경하지 않는다.
