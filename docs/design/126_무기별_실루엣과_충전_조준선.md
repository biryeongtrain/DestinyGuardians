# 126. 무기별 실루엣과 실제 충전 조준선 (W112)

## 목표와 범위

공통 무기군 그림 대신 실제 보유 무기별 윤곽을 표시하고, 융합 계열을 발사하기 전 서버가 실제로 충전 중임을 읽을 수 있게 한다. UI를 별도 전투 상태 기계로 만들지 않는다.

## 무기별 silhouette

- W30 기본63개 + 사용자 원본 모델에서 변환된 Ace/Izanagi2개 =65개. 각195pack파일(items/model/item-atlas PNG). 현재63개는 models/weapon/<family>, 두경이는 models/item/weapon에서 읽는다.
- 원본 기반 제품의14,544cuboids/87,264faces를 회전 포함 YZ 측면 투영한다. 실제 존재 face union이므로 stock/trigger 공간을 사각박스로 메우지 않는다. 색/UV opacity는 버린 geometry mask이며 공식 HUD sprite 추출이 아니다.
- neutral white RGBA,160x64,8x BOX coverage,최소4px padding. gun/bow는 -Z 총구/화살이 왼쪽, +Y가 위. sword/glaive만 명시적으로 +Y 칼날을 오른쪽으로 수평 배치한다. Bow는 세로 비율을 보존하므로 가로 점유가 작다.
- selected80x32,stowed50x20로 같은2.5:1canvas비율을 지킨다. 과거68x20을 그대로 재사용하면 새 outline을 눌러 늘리므로 수정했다. 위치/레이어/탄약 계산과 두 stowed 실제 inventory 소유권은 유지한다.
- Golden Gun은 실제 held gun의 silhouette를 빌리지 않고 기존 hand_cannon super fallback을 유지한다. 새 그림은 ammo digit/damage/ammo type glyph를 대체하지 않는다.
- generator `scripts/build_weapon_hud_w112.py --verify`는 source/output hashes와 manifest/contact sheet를 재현 비교한다. `--self-test`는 rotation/holes/face selection과 unsupported geometry 거부를 검증한다. 현재 cuboids에는 triangles가 없고 미지원mesh를 familyfallback으로 숨기지 않는다.

## 충전 상태 출처

`WeaponRuntime.chargeState`는 이미 존재하는 owner/level/current stack/accepted entry/profile/cycle만 읽는다. WeaponHandling/로드아웃·생존/관전/궁극기·reload eligibility를 존중하며 bind·timer advance·item component 저장·ammo 지급·발사·lease 갱신을 하지 않는다.

- 대상: Erentil FR4, Hollow Words, Dream Breaker, Null Composure, Coriolis Force, Line in the Sand, Stormchaser. 기존 W46 charge11..20ticks/burst1..9/정확spacing을 변경하지 않는다.
- CHARGING: accepted profile duration과 cycle의 실제 chargeElapsed를 나눈다. 두손은 현재6tick heartbeat lease, 한손은 실제 owned native use가 있어야 표시한다. copied item/edited definition은 원래 charge를 빌리지 않는다.
- BURSTING: 실제 유료 첫 bolt 후 `1+cycle.burstIndex`를 emitted로 본다. 첫발만 ammo를 결제하는 기존 sharedBurstAmmo 정책 유지. 버튼을 놓아도 이미 결제된 미완료 bolt는 진행되므로 HUD도 그 실제 상태를 보여준다. 완료되면 즉시 idle이며 별도 ready/회복 timer를 꾸미지 않는다.
- accepted inventory stow hook은 fusion/LFR pending transaction도 same-tick 취소한다. 원래 object가 즉시 돌아와도 old charge를 복구하지 않는다. cadence deadline은 기존 cancel 원칙대로 유지한다.

## 조준선 표현

기존 두 node(frame/dot)는 고정 소유권. charge 시 frame이16구간으로 최대25%안쪽 수축하고 네 개의 gold solid tick이 접근한다. burst 때 white tick의 길이가 실제 남은/전체 bolt 비율을 나타낸다. Dot는 중앙에서 움직이지 않는다.

- 기본 MAX_NODES2 유지, active charge일 때만4추가, 최대6.
- post-effect aboveHand pass는 기존과 같고 원래bow/shotgun/rocket lock code는 보존한다. scope가 뜨면 기존 policy대로 전체 hip reticle을 숨긴다.
- idle·cancel·reload·stow·nonfusion·관전·궁극기·disconnect에는 정확 prefix만 정리한다. 타 HUD를 지우지 않는다.
- authored Destiny-inspired feedback이며 원작 픽셀 단위 조준선/움직임과 동일하다고 주장하지 않는다. 짧은 zero-spacing burst를 보기 좋게 늘려 가짜 burst 시간을 만들지 않는다.
