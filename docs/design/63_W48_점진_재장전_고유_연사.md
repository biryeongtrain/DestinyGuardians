# W48 — 점진 재장전과 고유 연사

## 이번 변경

- 선택63개 실제 공식 socket/intrinsic 설명을 감사해 총15개 연사 정책 확정.
  기존12개에 Aisha’s Embrace, Dead Man Walking XX7463, IKELOS_SG_v1.0.1 추가.
  단순 Rapid-Fire 명칭이나 비고유 Full Auto Trigger System 퍽을 자동 적용하지 않음.
- Long Arm(8293111)은 처음20tick, 이후13tick마다2발씩 실제 저장 탄창에 삽입.
  최대14발, 마지막 한 칸은1발만. **속도는 참고 기반 구현값이며 공식 정확값이 아님.**
- HUD는 초기·반복 삽입의 실제 기한을 따로 표시. 화면 조회가 탄약을 바꾸지 않음.
  교체·스킬·새 입력 중단 시 이미 넣은 탄은 유지하고 미래 삽입은 취소.
- 유한 예비탄·W47 보존탄에도 동일한 원자적 삽입 규칙 적용. Primary 무한 예비탄과
  유한 탄창은 구별. 늦게 도착한 tick은 한 batch만 옮기고 누적 무료 삽입하지 않음.

## 코드 경계

`WeaponReloadPolicy`는 W46 역사적 곡선 위의 별도 selected-ID override.
`WeaponProfile`은 initial/repeat/batch 전달, `WeaponCycle`은 서버 기한만 진행,
`WeaponMagazine`은 실제 탄약 이동, `WeaponRuntime.ammunition`은 순수 읽기.
`WeaponFirePolicy`는 고유/기본 연사만 결정하고 cadence/burst/탄약을 변경하지 않음.
기존20인자 생성자는 첫/반복 기한 동일·shotgun batch1을 유지해 호환.
