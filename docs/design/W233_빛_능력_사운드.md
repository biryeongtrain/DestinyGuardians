# W233 빛 능력 사운드 대조·적용

## 근거와 선정

사용자 전달본 `/Volumes/qf-ssd/Destiny-Light-Abilities-2026-10-28`을 읽기 전용 원본으로 사용한다. `CUE-SHEETS.json`의 SHA-256은 `2e0272bdaf54ef9253e6163e5d5f092c0692a96f9242fdb5f731b1786dc14aad`이다. 469개 능력별 행 중 26행에는 원본 클립 프레임 연결이 있고, 280행은 숫자 이름뿐이다. 능력별 중복을 포함한 행 수이며 고유 이벤트 수와 다르다.

원본 경로 문자열·클립 연결을 우선하고, FNV-1 이름 해시 후보는 후보임을 표시하여 채택한다. 시퀀스 StartTime/Duration을 검증 없이 절대 게임 시각으로 적용하지 않는다. 공용 ready/fail·금속 피격·다른 무기 타격 후보를 궁극기 시전으로 바꾸지 않는다. 숫자 후보만 제공되거나 단계가 미확정인 능력은 기존 임시 연결을 보존하며 정확한 원작 음원으로 표시하지 않는다.

헌터·타이탄 선정은 각각 고정 워크트리1·4의 배타적 selection JSON으로 반환하고 master가 워록 선정·공용 변환·연결·통합 검증을 수행한다. 원본 SSD·미저장 Blender·다른 월드는 변경하지 않는다. 이번 작업은 사운드이며 새 애니메이션의 적용을 뜻하지 않는다.

## 변환과 재현

`art/audio/w233/*-selection.json`은 event/group/sound/WEM과 채택 이유, 보존 범위를 기록한다. `scripts/audio/import_light_ability_audio.py`는 큐시트와 선택한 원본 OGG 해시를 검증하고 이벤트당 한 WEM만 가져온다. Wwise 뱅크 내부의 레이어/랜덤/상태 분기를 복원한 것이 아니며, 뱅크의 모든 WEM을 겹치거나 이어붙이지 않는다.

선택 파일은 `assets/destiny/sounds/light_w233/`에 모노48kHz Vorbis q5로 저장한다. gain0.5를 적용하며 trim·loop·피치·속도 변경은 없다. 같은 WEM은 중복 인코딩하지 않는다. 전부 끝까지 디코딩하고 유한 PCM·무음/클리핑·길이·채널·실제 sounds.json 연결을 확인한다. `applied.json`에 이전 연결, 원본 이름/신뢰도/프레임/시퀀스, 원본/출력 해시를 기록한다.

```sh
rtk proxy python3 scripts/audio/import_light_ability_audio.py \
  --source /Volumes/qf-ssd/Destiny-Light-Abilities-2026-10-28 \
  --ffmpeg /Users/qf/IdeaProjects/DestinyGuardians/run/private-sources/w33/tools/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1 --check
```

## 재생 동작

신성 폭탄의 선택 시전음은 발동 때 한 번 재생하고, release의 이전 임시 시전음은 억제한다. 실제 폭발 판정은 `soundAt`에 착탄 좌표와 능력 path를 전달해 프레젠테이션 종료와 무관하게 올바른 위치/능력으로 전송한다. 그림자사격 W36의 사용자 지정 연속 음원과 칼날 장전의 1회 투척 정책은 유지한다. 치유 균열은 워록 고유 class.cast를 사용한다. 강화 균열은 원본 후보가 있어도 현재 능력 자체가 구현되지 않아 활성 연결하지 않는다.

## 검증 범위

컴파일·관련 패킷 GameTest·원본/출력 디코딩·Vision 팩 로드/실제 능력 입력/서버 음원 전송 근거를 나누어 기록한다. Vision 스크린샷·서버 패킷 로그는 스피커 소리 청취나 원작 A/B 비교를 증명하지 않는다. 독립적인 acoustic 청취와 모든 Wwise 레이어의 정확 복원은 미검증이다. 단계별 최종 결과는 `docs/qa/2026-10-29/w233/README.md`에서 갱신한다.

최종 선정은 헌터9·타이탄8·워록11개, 합계28개 이벤트/25개 고유 파일이다. 원본 프레임 연결10개와 이름 후보18개를 구분한다. 타이탄 궁극기의 투사체 착탄 및 대혼란 타격음도 실제 판정 center를 soundAt으로 전달한다. 세부 연결 전후는 QA mapping-audit.json, 청음용 링크 표는 exports/light-abilities-w233/README.md에 있다.

최종 확인: 패킷 GameTest2/2, 새28개 재생 명령·서버 패킷, Vision 실제 능력 입력5개와 팩 로드를 확인했다. OpenAL 초기화 성공 및 음원 로드 오류 없음. 빌드/패키지 검사는 통과했으며 전체 JUnit2079개 중2069통과/10실패로 W232의 실패 ID집합과 같다. 전체 회귀 성공 또는 청취 검증으로 확대해 해석하지 않는다. QA 서버·클라이언트는 종료했고 사용자48시간 잠자기 방지는 유지했다. 미확정 후보·미구현 강화 균열·근접 만료/확장 궁극기 단계의 추가 검토는 retained 기록을 따른다.
