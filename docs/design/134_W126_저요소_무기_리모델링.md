`minecraft-weapon-art-design` 스킬을 읽은3worker가 독립 dirty-seeded CoW worktree에서 자산·generator·targeted test까지 제작했다. master는 각12파일 before/after SHA를 대조해 통합하고9개 팩 교체 경로를 연결했다. 원본 canonical rip 파일을 덮어쓰지 않는 W123 migration namespace를 호환 유지한다.

작은 나사·패널선·그립 요철은 UV에, 열린구조·포구·관측 시차·동작 부품은 실제 입체에 배분했다. 원작 PBR이나 원본 메시 완전동등성 복원이 아니라 게임용 재설계다. 파지display·axis·scale·탄창anchor·전투/오디오/HUD코드는 보존한다.
