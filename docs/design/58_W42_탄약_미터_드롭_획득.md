# W42 — 탄약 미터·개인 탄약 상자·예비탄 획득

이전 W41은 무료 월도 근접·방패 구현 및223GameTest/189JUnit을 마친 progress다.

확인하지 못한 숫자를 원작 exact값으로 표시하지 않는다. armor/perk/mod 전체는 후속 범위로 유지한다.

## 구현 목표 / 인수
- 실제 성공한 피해·최종 처치·유효기간 내 지원에서만 개인 특수/중화기 미터 진행.
  투사체가 날아가는 동안 무기를 바꿔도 발사 시점 무기의 탄종/stat으로 분류한다.
  빈 월도 근접은 특수탄 투사체 처치로 오분류하지 않는다.
- 개인 소유의 녹색/보라색 3D 상자. 다른 유저에게 전이·복제되지 않으며 벽 너머 획득 금지.
  안전하지 않은 지점 또는 생성 한도에서는 지급 부채를 보존하고 다음 안전한 처치로 이월.
- 실제 장착된 같은 탄종 무기의 **예비탄만** 증가. 탄창·재장전 deadline·다른컴포넌트 보존.
  만탄/미장착이면 소모하지 않고, 두 Special은 분배하되 상자 하나로 두 배 보급하지 않는다.
- HUD는 다음 상자까지의 녹색·보라색 진행을 실제 서버 상태로 표시. 읽기 자체는 충전/생성하지 않는다.
- 생성/획득/사망/월드 이동/접속 해제/서버 종료 및 메모리·display 상한을 자동 테스트한다.

## 구현 구조
- `AmmoMeters`: 개인 persistent/copyOnDeath attachment. 100,000점=상자1개, 최대32개분의 지급 부채.
- `AmmoGeneration`: 발사 시점 탄종/공식 기본 Ammo Generation stat(hash1931675084)을 보존한다.
  원문 정의/버전/hash는 `art/weapons/w42/stat-provenance.json`에 기록했다. 검은 stat0 예외다.
- `AmmoEconomy`: 실제 HP/흡수체력 감소에만 피해 기여를 등록한다. 최종 처치/10초 내 지원을
  각각 정산하며 적대 `Enemy`만 인정한다. 시체·무적 피해 거부·패시브 동물은 진행하지 않는다.
  UUID뿐 아니라 실제 세션/엔티티 identity도 확인한다. 최대2,048표적·8기여자·개인24상자로 제한한다.
- `AmmoBrickVisual`: 개인에게만 watch를 등록한 충돌 없는 item_display1개/상자.
  상자는 일반 아이템이 아니며 인벤토리 토큰/그림자 예비탄을 만들지 않는다.
- `AmmoMeterHud`: 능력 HUD 아래 녹색/보라색 각16단계 진행선, 최대6노드.
  장착 탄종이 없거나 궁극기/관전/사망이면 해당 표시를 숨긴다. 빈 손이어도 실제 장착 탄종 미터는 유지한다.
- `WeaponMagazine.addReserve`: 용량까지 예비탄만 채우고 탄창·재장전 완료시각·모델/그립/월도 에너지는 유지한다.

## Minecraft용 수치 (원작 정확한 곡선 아님)
`stat=clamp(공식 기본 stat,0,100)`. 처치당 다음 점수를 더하고 지원은 절반이다.

| 피해 출처 | 특수탄 미터 | 중화기 미터 |
|---|---:|---:|
|Primary|4,000+60×stat|1,600+24×stat|
|Special|1,500+25×stat|2,000+30×stat|
|Heavy|3,000+30×stat|700+10×stat|
|능력/무료 월도 근접|2,000|1,000|
|궁극기|1,500|750|

일반 상자당 기본 예비탄: 저격/융합/산탄/특수유탄3(rapid_fire4), 월도4, 추적40,
정밀 LFR5/나머지LFR3, 로켓1, 중유탄3, 기관총25, 검8.
두 Special은 무기별 지급량을 장착 수로 나누고 최소1발이다. 만탄/미장착이면 상자를 소모하지 않는다.
이 표는 Minecraft 튜닝이며 원작 전체 reserve/archetype/mod 곡선을 그대로 복원한 값이 아니다.

## 상자 수명·실패 경계
안전한 바닥을 아래8블록까지만 찾고 강제 chunk load를 하지 않는다. 낭떠러지/유체/블록 내부나
24상자 한도에서는 미터를 차감하지 않고 다음 유효 처치로 이월한다. 실제 생성한 경우에만1개분을 차감한다.
플레이어 **몸**에서1.5블록 이내이며 충돌 ray가 통과해야 획득한다. 후방 궁극기 카메라로 원격 획득하지 않는다.
상자는2,400서버틱 후 소멸한다. 사망/월드 이동/접속 해제/서버 종료 때 장면 상자는 제거되지만 미터는 보존한다.
이미 생성한 상자는 영속 월드 드롭이 아니므로 사망/접속 해제 시 다시 환불하지 않는다.

## 아트·근거 경계
녹색/보라색 상자는 각각21큐브인 자체 근사 아트다. 원작 리핑/유료 마켓 에셋을 추출한 모델이 아니다.
`art/blockbench/ammo/`의 편집 가능한 bbmodel과 deterministic generator/manifest를 함께 제공한다.
공개 Compendium/Ammo Database의 갱신 시점도 대조했지만 오래된 perk/월도 표를 최신 exact값으로 쓰지 않았다.
능력 지원은 실제 피해 지원만 구현했다. 아군 버프 지원, finder/scout/scavenger, 강화 상자, 적 등급,
정확 stat 변환 곡선, PvP, 전체 perk/mod는 후속 범위다.
