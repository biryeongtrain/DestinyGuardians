# 05. 적·보스 모델 명세

적은 서버 엔티티(판정·AI) 위에 **BetterModel 모델**을 씌워 만듭니다. 모델은 보이는 모습만 담당하고, 체력·이동·판정은 서버 엔티티가 담당합니다.

## 1. 구조

```
서버 엔티티 (바닐라 기반 커스텀 몹, 보이지 않음)
 └─ BetterModel EntityTracker (모델·애니메이션)
     └─ 커스텀 히트박스 (애니메이션 회전을 따라감)
```

- 기반 엔티티의 판정 크기는 모델 크기에 맞춥니다.
- 머리 판정은 `h_weakpoint` 본 위치(`hitBoxPosition`)를 매 판정마다 읽어 계산합니다. 모델과 판정이 어긋나지 않습니다.

## 2. 본 이름 규칙

| 본 | 용도 | 필수 |
|---|---|---|
| `root` | 전체 회전 기준 | 필수 |
| `h_weakpoint` | 정밀(머리) 판정 중심 | 필수 |
| `muzzle_*` | 사격 발사 위치 | 원거리 적 필수 |
| `fx_*` | 이펙트 부착 위치 (눈 발광, 손 마법 등) | 선택 |
| `shield` | 속성 보호막 표시용 | 보호막 적 필수 |

## 3. 필수 애니메이션

| 이름 | 길이 가이드 | 반복 | 서버 이벤트 |
|---|---|---|---|
| `idle` | 40틱 | 반복 | – |
| `walk` | 20틱 | 반복 (이동 속도에 맞춤) | – |
| `attack` | 8~20틱 | 1회 | 발사·타격 틱 기록 |
| `hit` | 4~6틱 | 1회 | – |
| `stagger` | 20틱 | 1회 | 정예 이상 |
| `death` | 20~30틱 | 1회 | 끝나면 엔티티 제거 |
| `spawn` | 20틱 | 1회 | 등장 연출 (선택) |

보스는 위에 더해 **메카닉 애니메이션**(보호막 전개, 광역 공격 예고, 격노)을 레이드 기획서에 맞춰 추가합니다.

## 5. 명세서 템플릿

```
ID:
세력 / 등급:
크기(블록) / 본 상한 / 텍스처:
포인트(1~2개):
필수 애니메이션: idle, walk, attack(이벤트 틱: ), hit, death
추가 애니메이션:
발사 본(muzzle_*):
약점 본(h_weakpoint): 위치 설명
속성 보호막: 없음 / Arc / Solar / Void
VFX 부착 본(fx_*):
사운드: 공격 / 피격 / 사망
```
