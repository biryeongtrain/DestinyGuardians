# 13. 헌터 구현 로그

목표: **헌터 직업 구현** (이동·회피·수류탄·근접·궁극기, 속성 3종, 입력·HUD·저장).
검증: Fabric GameTest·JUnit([minecraft-testing]) + Copper Golem 비전 클라이언트 26.3 실제 화면.
작업 브랜치: `feat/hunter`. 단계마다 이 문서에 기록합니다.

## 범위

| 영역 | 내용 | 관련 문서 |
|---|---|---|
| 수호자 상태 | 직업, 직업별 장착(Loadout), 쿨타임, 궁극기 에너지 – 플레이어 데이터 첨부로 저장, 사망 후 유지 | 11 W2-02 |
| 능력 틀 | `Ability` + 등록부 + JSON 수치(`data/<ns>/destiny_ability/**.json`) + 실행·쿨타임 서비스 | 11 W2-01, W2-05, W2-06 |
| 입력 | 바닐라(공중 점프, 웅크리기 두 번, F, 웅크리기+F, 웅크리기+좌클릭, 궁극기 중 좌클릭) + GCB(Z·V·C·X·좌클릭) | 12 |
| 헌터 이동 | 2단 점프 / 3단 점프 | 메인 3-1-1 |
| 직업 능력 | 도박꾼의 회피(근접 재충전) / 명사수의 회피 – 입력 방향 구르기, 무적 6틱, BetterModel limb 구르기 | 04 |
| 수류탄 | Arc 섬광(실명) / Solar 소이(연소) / Void 소용돌이(끌어당김·지속 피해) | 06 |
| 근접 | Arc 연속 타격(돌진, 처치 시 증폭) / Solar 칼 투척(연소) / Void 연막탄(억제, 본인 투명) | 06 |
| 궁극기 | Arc 아크 지팡이 / Solar 황금 총 / Void 그림자 사격(닻: 약화·억제) | 04, 07 |
| 키워드 | 실명·증폭·연소·약화(받는 피해 ×1.3)·억제 | 메인 3-1-6 |
| HUD | DisplayHud: 능력 쿨타임 줄, 궁극기 게이지 | 08 |
| 화면 효과 | 궁극기 중 26.3 포스트 이펙트 `destiny:super/<속성>_active` | 07 |

## 진행 기록

### H1. 핵심 구조 (2026-10-22)

- `guardian/`: `GuardianClass`, `Element`(01 팔레트 색), `AbilitySlot`, `Loadout`, `GuardianData`(코덱·첨부), `GuardianRuntime`(비저장), `Guardians`
- `ability/`: `Ability`, `AbilityRegistry`(+ `SimpleJsonResourceReloadListener` 로 `destiny_ability` 수치), `AbilityService`(틱·쿨타임·궁극기 에너지·i-frame), `Tasks`(지속 효과), `Motion`, `SuperSession`
- `combat/`: `Combat`(PvE 대상 판정·능력 피해·처치 시 궁극기 에너지), `Keyword`, `Statuses`
- `fx/`: `Fx`(파티클·사운드), `SimProjectile`(엔티티 등록 없는 서버 계산 투사체 + Polymer 가상 item_display), `PlayerAnimations`(BetterModel limb, 본인 시점별 표시), `PostEffects`
- `input/`: `GuardianAction`, `InputRouter` + Mixin(`handlePlayerInput`·`handlePlayerAction`·`handlePunch`, 서버 스레드 지점)
- `compat/gcb/GcbInputBridge`: GCB-server 키·시점 이벤트. GCB-server 체크아웃(`gcb_server_dir`)이 있으면 includeBuild, 없으면 이 패키지를 빼고 빌드
- `ability/hunter/`: `HunterJump`, `HunterDodge`, `HunterGrenade`, `HunterMelee`, `HunterSuper`, `HunterAbilities`(등록·속성별 기본 장착)
- `hud/CombatHud`, `command/GuardianCommands`(`/guardian class|subclass|equip|info|super|reset|action`)
- 결과: `./gradlew compileJava` 성공
