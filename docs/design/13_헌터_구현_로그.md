## 진행 기록

### H1. 핵심 구조 (2026-10-22)

- `guardian/`: `GuardianClass`, `Element`(01 팔레트 색), `AbilitySlot`, `Loadout`, `GuardianData`(코덱·첨부), `GuardianRuntime`(비저장), `Guardians`
- `ability/`: `Ability`, `AbilityRegistry`(+ `SimpleJsonResourceReloadListener` 로 `destiny_ability` 수치), `AbilityService`(틱·쿨타임·궁극기 에너지·i-frame), `Tasks`(지속 효과), `Motion`, `SuperSession`
- `combat/`: `Combat`(PvE 대상 판정·능력 피해·처치 시 궁극기 에너지), `Keyword`, `Statuses`
- `fx/`: `Fx`(파티클·사운드), `SimProjectile`(엔티티 등록 없는 서버 계산 투사체 + Polymer 가상 item_display), `PlayerAnimations`(BetterModel limb, 본인 시점별 표시), `PostEffects`

- `compat/gcb/GcbInputBridge`: GCB-server 키·시점 이벤트. GCB-server 체크아웃(`gcb_server_dir`)이 있으면 includeBuild, 없으면 이 패키지를 빼고 빌드
- `ability/hunter/`: `HunterJump`, `HunterDodge`, `HunterGrenade`, `HunterMelee`, `HunterSuper`, `HunterAbilities`(등록·속성별 기본 장착)
- `hud/CombatHud`, `command/GuardianCommands`(`/guardian class|subclass|equip|info|super|reset|action`)
- 결과: `./gradlew compileJava` 성공

### H4. 표시 품질·궁극기 플레이어 모델 보강 (2026-10-22)

- 실제 화면에서 발견한 전투 HUD 초소형 글자를 확대하고, 능력 줄을 왼쪽 아래로 정렬.
- BetterModel 설치본의 기본 `steve.bbmodel` 리그를 시작 시 읽어 `config/bettermodel/players/guardian_hunter.bbmodel` 최초 생성. 기본 roll 유지, 직접 작성한 Arc 지팡이·Solar 조준·Void 활 자세 루프 추가. 서버 아티스트 파일이 있으면 덮어쓰지 않음.
- 궁극기 활성/종료에 limb 루프/정리를 연결. 본인 1인칭 숨김 규칙 유지.
- `/destiny debug owner-view <player> first|third`는 비전 전용 클라이언트에서 서버의 시점별 표시 분기만 검증하는 OP용 QA 명령. 실제 GCB 네트워크 전송 검증과 구분.
- `compileJava` 성공. 변경 후 실제 화면 재검증 진행.

- H4 실제 화면: Arc(청색)·Solar(황색)·Void(보라색) 포스트 이펙트 및 각 속성의 limb 자세가 실제 프레임버퍼에서 표시됨. HUD 글자 확대 확인. 캡처: `hunter_{arc,solar,void}_model_post.png`.
- 오프라인 MinigameQA는 기본 템플릿 스킨으로 보임. 인증 계정 스킨·Vulkan·GCB 실클라이언트 전송은 별도 미검증.
- 궁극기 장비는 전용 `ITEM_MODEL`을 사용하는 바닐라 스택으로 보강: 황금 총·아크 지팡이·그림자 활의 큐브 모델, BetterModel 오른손 bone 장비 표시 연결. 인벤토리를 바꾸지 않음. 변경 후 캡처 재취득 예정.

### H5. 월드·수명·피해 회귀 수정 (2026-10-22)

- `Combat`에 명시적 월드 오버로드를 추가. 시전자/대상이 같은 월드인지 확인하고, 장판·닻은 시전 당시 월드를 사용.
- 투사체/작업의 소유자를 추적. 시전자가 죽거나 제거되거나 월드가 달라지면 취소. 사망·접속 종료·차원 이동·직업/서브클래스 전환 및 서버 종료에서 정리.
- 연소 소유자와 처치 경로 연결. 바닐라 화염 틱과 능력 연소 틱 모두 사망 이벤트를 통해 1회 보상.
- 사망/관전 중 능력 실행과 HUD 재생성 차단. GameTest 가짜 플레이어 정리도 같은 cleanup 경로 사용.
- 무조건 통과하던 투사체 테스트를 실제 생성·만료·holder 해제 확인으로 교체.
- JUnit 리소스 검사 2개 통과(포스트 체인·uniform/GLSL 연결, 전용 무기 모델 경로). 테스트 레이아웃 검사는 성공. 1.21용 검사기가 26.3 `src/gametest`·`.snbt`를 인식하지 못하는 경고 1개 있음.

- H5 수정 후 기존 필수 GameTest 17/17 통과. 데이터 코덱·사망 복사 및 경계 조건 회귀 테스트 추가 중.
- 검증 환경 주의: `runServer`는 빌드 클래스 디렉터리를 직접 참조함. 실행 중 컴파일로 record 시그니처가 바뀌어 lazy load가 섞인 `NoSuchMethodError` 1회 발생. 서버를 중지하고 전체 컴파일/테스트를 마친 다음 새 JVM으로 검증하도록 순서를 변경.

### H6. 패킷·경계·지속 피해·저장 테스트 확장 (2026-10-22)

- 메인 테스트에 데이터 JSON 코덱 왕복·직업별 장착 유지, 사망 후 Fabric AFTER_RESPAWN 첨부 복사 테스트 추가.
- 최초 확장 실행 33개 중 31개 통과. 실패 2건은 테스트 fixture를 수정: Cow 기본 HP10을 HP40으로 올려 13 피해 측정, 첨부 복사를 실제 Fabric `AFTER_RESPAWN` 이벤트 시점에 확인. 기능 경로는 그대로 유지.

- H6 회귀 검사가 실제 포팅 문제를 추가 발견: 26.3의 피격 재사용 대기 필드는 `LivingEntity.damageCooldownTime`. 기존 `setInvulnerableTime(0)`은 다른 무적 상태 API라 연속 피해가 13 대신 차액 3만 들어갔음. 능력 피해·연소 틱과 검증 fixture를 정확한 필드로 수정.

- H6 최종 자동 검증: 2026-10-22 04:52:31 KST `./gradlew runGameTest build --console=plain` 성공. 필수 GameTest **33/33**, JUnit **2/2** 통과.
- 소용돌이는 2회 이상 피해와 닻 방향 속도를 확인. NoAI fixture는 실제 이동이 생략될 수 있어 이동 또는 끌림 속도로 판정. Arc 근접은 처치·증폭·회복까지 확인.
