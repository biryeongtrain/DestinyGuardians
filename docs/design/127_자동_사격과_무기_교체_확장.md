## 설정 사용

`/destiny settings full_auto`는 상태만 조회한다. `on`/`off`는 OP 없이 본인 설정만 변경한다. 기본 off이며 Fabric persistent bool attachment와 copyOnDeath를 사용한다. 원작의 옵션을 서버 커맨드로 제공한 것이지 바닐라 설정 화면을 수정한 것은 아니다. 실제 재접속/사망 클라이언트 검증과 API 설정 사실은 구분한다.

- 설정 on은 전체65개 중57개 총기의 유지 사격을 지원한다. 활·검·Salvager’s Salvo는 기존 release/근접 동작을 유지한다. Full Auto Melee는 미구현이다.
- base profile의 automatic/cadence/charge/burst/cost/damage는 변경하지 않는다. 살아있는 본인 현재 item과 실제 native use 또는6tick twohand heartbeat만 반복을 허용한다.
- fusion/LFR은 이전 유료 burst와 firing lockout 뒤 새 전체 charge를 다시 거친다. shared ammo는 charge당1이며 bolt마다 결제하지 않는다.
- 수동 reload 중에는 held input을 버퍼링하지 않는다. 발사로 탄창이 빈 reload는 실제 유지 입력만 이어갈 수 있으며 fusion은 완료 후 다시 충전한다.
- 설정이 실제 바뀌면 unpaid hold/charge만 폐기한다. 유료 burst·기존 reload·발사 deadline은 보존한다. no-op 설정은 입력을 끊지 않는다. twohand는 실제6tick을 넘는 새 press gap을 요구한다.
