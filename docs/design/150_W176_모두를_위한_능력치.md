# W176 — 모두를 위한 능력치 (Stats for All)

## 원작 근거와 범위

기본 특성 hash **1583705720**만 구현한다. 강화판1409206216은 별개다. 고정 Bungie 소켓과 Clarity 원문에서 확인한 현재 선정 대상은 Ammit AR2, Aisha’s Embrace, Dimensional Hypotrochoid, Retrofit Escapade의 **3번 소켓**이다. 전체 무기군에 일괄 부여하거나 기존 무기에 기본 선택하지 않는다.

서로 다른 적3명에게 각각3초 이내 간격으로 피해를 주면 **10초** 동안 handling/reload+35, stability/range+10, falloff거리×1.05, reload duration×.95를 얻는다. 활성10초는 재발동/연장할 수 없으며 **직접 피해량 배율은 없다**. 원문에 없는 Minecraft의 정확한 집계 경계/수명 규칙은 아래 로컬 구현 정책과 구분한다.

## 실제 전투 연결

- 실제 지불된 무기 emission이 양수 HP+absorption 손실을 낸 뒤 원본 token의 session에 적UUID를 누적한다. 같은 적 반복/면역0피해/빗나감/능력은 누적하지 않는다. 치명타/처치는 필요하지 않다. 유료 폭발/파동은 실제 피해를 준 여러 적을 집계할 수 있다.
- 새 UUID만60tick 수집창을 갱신한다. 중복은 창을 늘리지 않는다. 정확한 deadline은 만료이며, 세번째 적이200tick window를 시작한다. 활성 중에는 다음 주기를 미리 쌓지 않는다. 이는 원문의3초/비갱신을 유한 server tick으로 대응시킨 정책이다.
- 동일한 원본 equipped ItemStack, owner/level/GuardianData/runtime/class/정확한 선택 소켓에 묶는다. 복사NBT, backpack, 교체/해제/사망/정리 이후의 낡은 token은 새 session에 보상을 줄 수 없다. HUD/조회만으로 session을 만들거나 적을 누적하지 않는다.
- 수납·장전 시 기존 수집/활성 deadline은 흐르게 두며 pause/refresh하지 않는다. 수납 상태에서는 HUD가 숨겨지고 원본을 다시 들면 남은 시간만 표시한다. 이 수납/장전 세부는 원문에 명시되지 않은 로컬 정책이다.

## 네 가지 스탯의 적용

1. **안정성**: 기존 서버 recoil/bloom/피격flinch의 effective stability에+10. 원작 recoil 엔진 전체를 추출한 것은 아니다.
2. **사거리**: 기존 W43 hip 곡선을 공식 range+10(cap100)으로 재평가하고 양쪽 falloff endpoint에1.05를 곱한다. 그 뒤 기존 W44 ADS 보간을 적용한다. floor/정밀 배율/탄속·최대 trace·blast radius는 바꾸지 않는다. Dimensional의 range-independent 폭발 sentinel은 그대로다.
3. **조작성**: 기존 역사적 ready/stow/ADS 곡선에 stat+35를 적용한다. Ammit의 같은 roll에서 Adrenaline Junkie+20, Retrofit의 Frenzy+100이 활성일 때 더한 뒤100cap과 단일 tick 반올림을 수행한다. 큰 보너스를 작은35로 덮지 않는다.
4. **장전**: 실제 수락 시점에 공식 reload stat+35와.95scalar를 한 번 snapshot한다. Retrofit의 별도4번 Frenzy가 활성이라면35+100을 cap100한 곡선에.95를 적용한다. 중간 만료로 진행 중 장전을 느리게 하지 않는다. 탄약 credit/용량/음원은 기존 경로를 유지한다.

## 표시·애니메이션·검증

실제 remaining1..200만 six-node TIMER로 표시하고, ceil(ticks/20)1..10초를 사용한다. 수집2/3을 활성 buff로 보여주지 않는다. 기존4행 cap/우선순위와 이전 snapshot 생성자를 보존한다. STATS FOR ALL label은 동일 타이포그래피의 저작 자산이며 공식 sprite/현대 원작 HUD 전체 복제는 아니다.

별도 제품인 Brass Attacks의 개별1인칭 장전은 기존 형상·UV·탄약/장전시간/음원을 유지하고 실제 플레이 영상의 탄창 교환 흐름을 참고한다. 추출된 손bone/손IK/새3인칭 장전은 아니다.

최종 장전 표현은 기존111개 요소에 내부 탄창 몸체와 연결 목2개를 추가한113요소다. 밑판만 움직이던 V1과 연결이 떠 있던 V2는 반려했고, V3의 연결된 탄창과 정지 외관을 오프라인에서 확인했다. 최종 전체JUnit1,548/실제FabricGT13/pack 비교는 통과했지만 새 Vision 월드PNG는 아직 확보하지 못했다.

실제 실행 결과/첫 실패/수정과 미검증 범위는 [W176 QA](../qa/2026-10-27/w176/README.md)에 기록한다. 자동 테스트나 오프라인 모델 비교를 native 입력·실제 월드PNG·청취·다인FPS 수락으로 확대하지 않는다. 전체 무기/HUD/audio 목표는 계속 진행 중이다.
