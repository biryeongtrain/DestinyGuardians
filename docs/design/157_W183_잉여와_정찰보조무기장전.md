# W183 — 잉여와 정찰·보조무기 장전

## 잉여(Surplus): 실제 능력 충전 상태가 권한

공식 base 특성 `3436462433`의 실제 무작위 소켓 9개만 선택 가능하다. 기본 지급이나 enhanced 특성 대체는 아니다.

- 적용 무기: Ammit AR2, High Albedo, Brass Attacks, Biting Winds, Beloved, Apostate, Deafening Whisper, Canis Major, Code Duello. 모두 socket 3.
- 현재 장착하고 등록된 수류탄·근접·직업 능력의 충전 완료 개수를 센다. 해당 능력 ID/슬롯/직업이 실제 장착값과 일치해야 한다. 궁극기·점프·미등록/잘못된 슬롯·비활성 직업은 제외한다.
- 현재 Hunter 구현은 슬롯별 한 충전이다. 원작의 다중 charge 시스템이나 별도 가짜 타이머를 만들지 않았다.
- 0/1/2/3개 충전 시 안정성은 0/5/15/25, 조작성은 0/5/25/60, 재장전 능력치는 0/10/25/60이다. 현 Clarity/DDC 자료의 60을 사용하며 과거 기억의 50으로 대체하지 않는다.
- 실제 소유·장착된 아이템만 보너스를 받는다. HUD/ADS/안정성/장전은 현재 주무기, 교체 모션은 선택 직전의 실제 장착 incoming/outgoing 객체도 허용한다. 같은 데이터의 복사 아이템은 권한이 아니다.
- 실제 능력 사용·쿨다운 회복 시 관측값이 즉시 바뀐다. 수락한 장전 계획은 그 시점의 immutable 값이며 이후 충전 변화가 이미 수락한 시간을 다시 바꾸지 않는다.
- 합법 동반 특성은 Snapshot 4개, Frenzy 2개, Adrenaline Junkie/Rapid Hit/Threat Detector 각각 1개다. 총 raw 능력치를 cap한 후 원작 곡선과 합법 scalar를 적용해 한 번만 올림한다. 이미 올림한 시간을 곱하지 않는다.
- 대미지·사거리·정확도 배율이나 무료 탄약은 부여하지 않는다. 활은 nock reload만 변경하며 draw 시간은 유지한다.

HUD는 기존 Destiny 스타일의 초록 COUNT 행에 SURPLUS ×1–3을 표시한다. 실제 지속시간이 없으므로 타이머를 만들지 않는다. 0개이거나 무기 권한이 없으면 즉시 숨긴다. 기존 21종 행 우선순위/표시 상한과 28인자 이하 Snapshot 호환 생성자를 유지한다.

## Patron of Lost Causes

원작 동일 무기 영상의 총구를 세움 → 뒤쪽 bullpup 탄창 교환 → seat → 빠른 낮춤/복귀를 참조했다. 96개 본체와 2개 통탄창, 합계 98요소와 기존 UV/안료/조준경을 보존한다. 로컬 15발·200 RPM·39틱 장전과 음원·실탄 권한은 변경하지 않는다. 원작의 가려진 손/탄창 궤적과 수치 각도는 authored이며 추출된 skeleton이 아니다.

## High Albedo

원작 동일 무기의 비스듬히 들어올리기 → 그립 하단 탄창 교환 → 안쪽 회전 → 복귀를 참조한다. 초기 결과는 canonical에 탄창 밑판만 있어 밑판만 이동했다. master가 이 한계를 확인하여 그대로 수락하지 않았고, reload 전용의 원작 근거가 있는 탄창 몸체를 보완하도록 반환했다. canonical·ADS·안료·27발/3점사/491 RPM/36틱 장전은 보존해야 한다. 보완 결과는 기존 99개 본체 + 원래 밑판 1개 + reload 전용 shaft/rib 11개, 총 111요소다. 길고 리브가 있는 탄창은 실제 원작 프레임을 근거로 했으며 세부 치수와 가려진 면은 authored다. 새 shaft는 원래 atlas UV를 쓰고 장착 시 그립 내부에 들어간다. 진행도 0/1은 canonical 전체 그래프로 직접 복귀하므로 원본 100요소와 외관을 보존한다. 초기 밑판만 이동한 결과와 수정 로그를 별도 보존했다.

## 수락 경계
