# W43 — 정밀 타격 · 거리 감쇠 · 확정 피해 숫자

## 범위와 원작 근거

- 원작 정밀/몸통 구분, 거리별 피해 감소, 흰색/노란색 피해 피드백을 서버 권위 PvE 사격에 연결한다.
- [Bungie 시즌 22 프리뷰](https://www.bungie.net/7/en/News/Article/season-22-weapons-preview) (2023-08-16)는 줌과 피해 감쇠 분리/ADS 별도 scalar를 설명하는 역사적 근거다. 당시 표를 현재 정확 수치로 주장하지 않는다.
- [Bungie 2026-05-29 무기 프리뷰](https://www.bungie.net/7/en/News/Article/dev_insights_weapons_artifacts_focusing_preview)의 최신 변경도 대조: High-Impact AR ADS 1.7→1.6, Pulse ADS 변경, 여러 프레임의 몸통/정밀 피해 및 PvE scalar 변경. 이번은 hip-fire만이며 OP preview ADS 변환으로 전투 보너스를 주지 않는다.
- 실제 곡선은 공개 [d2foundry/oracle_engine](https://github.com/d2foundry/oracle_engine/tree/dcd0c7d302b056ffbb532edcb711d724a17ca8c1) 2026-05-20 commit을 고정하여 선택 63종에 필요한 데이터만 추출했다. 커뮤니티 자료이며 6월 패치 이전 스냅샷: 현재 모든 balance와 동일하다는 주장이 아니다.
- 원본 `build.rs`의 정밀 인코딩은 `pve_crit_mult / 51 + 1.5`다. JSON 원시값을 배수로 사용하지 않는다. `art/weapons/w43/extraction.json`에 category/subfamily/원본 SHA256/commit/한계, MIT-LICENSE와 UNLICENSE를 보존한다.

## 구현 계약

- 개별 무기의 공식 Manifest Range(stat 1240592695, W40 고정 정의)를 곡선에 대입. 시작 = offsetStart + vppStart×Range, 끝도 같은 선형식. 시작 전 100%, 끝까지 선형 감소, 이후 floor 유지.
- 예: Austringer Range46 → hip20.14~30.38m / floor33%, 정밀1.5배. 원작 1m를 서버 1block에 대응한 튜닝이며 실제 피해 단위는 기존 Minecraft HP다.
- 총기/비폭발 투사체 96block 안전 범위. 로켓/유탄 폭발 범위·검/월도 근접 범위는 기존대로. 미로딩 chunk 전 종료하며 강제 chunk load하지 않는다.
- `destiny:weapon_precision_humanoids` tag에 명시한 인간형에만 상단25% weakspot. 실제 AABB 첫 교차면 기준, aim-assist margin만 스친 경우 정밀 불가. 아기/스케일은 실제 box 비례. 상단25%와 absorption>0 정밀 비허용은 Minecraft 정책이며 원작 모든 적 weakspot 복제 아님.
- 폭발/검/월도 근접 정밀 없음. Fusion/Glaive projectile은 추출 ratio1. 기존 적대/아군/길들인 동물/플레이어 비대상 정책 유지.
- 산탄은 target별 한 번에 합산 피해. 몸통/정밀은 각각 합산하고 실제 HP+absorption 감소분을 요청 피해 비율로 나눈 피드백: 각 pellet의 HP를 따로 측정했다고 주장하지 않는다.
- 투사체는 발사 당시 entry/원래 stack/이동한 거리를 유지. 무기를 바꾸거나 발사자가 이동해도 비행 중 피해 프로필을 바꾸지 않는다. 기존 월도 적중 에너지와 탄약 경제 attribution 유지.
- `WeaponDamageNumbers`: 실제 감소를 관측한 뒤에만 흰색 몸통/노란색 정밀 숫자. 양수 Minecraft HP 반올림(최소1), 과잉피해/무적/벽/빗나감에 가짜 수치 없음. 원작 정밀 단위 수천 피해로 변환하지 않는다.
- 소유자만 보는 Polymer TextDisplay,16서버틱 상승,4~96block 거리비례scale/상승(원거리 가독성 보정),24개/유저·256개 전체 상한, ManualAttachment/명시적 watcher. 사망·차원·접속세션·해제·서버 종료 정리. 서버 thread 한정.
