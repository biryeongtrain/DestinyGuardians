# W324 장비 보상 시스템 (공용 루트)

데스티니 장비 획득 흐름을 공용 코드(`kim.biryeong.destiny.loot`)로 구현했다. 활동은 테이블 이름만 지정하고, 굴림·보관·연출은 공용 계층이 맡는다.

## 구성
- **드랍 테이블** `src/main/resources/destiny/loot/tables.json`: 가중치 항목(무기 필터 또는 엔그램 등급), 굴림 수, 발동 확률. `activities`(완료 보상·보상 상자), `enemies`(일반/정예/보스 처치 드랍), `engramTables`(엔그램 해독 테이블).
- **무기 굴림** `LootRoller`: 카탈로그 필터로 무기를 고르고, 무기의 공식 특성 열(소켓)마다 구현된 특성 하나를 무작위로 넣는다(같은 특성 중복 없음). 특성은 무기에 귀속된다.
- **획득 경로** `Loot.collect` → `GearAcquisition.store`: 보관함(인벤토리 3–35, 슬롯당 9)에 넣는다. 보관 칸이 가득 차면 무기를 전설 엔그램으로 보관한다(우체국 대체). 엔그램은 최대 10개, 넘치면 즉시 해독한다.
- **엔그램** `LootProfile`(영구 attachment): 장비 화면 상단 엔그램 줄에서 좌클릭으로 해독한다.
- **월드 드랍** `WorldDrop`: 소유자에게만 보이는 개인 드랍. 걸어서 줍고 2분 뒤 사라진다. 여러 개는 부채꼴로 흩어진다.
- **보상 상자** `LootChest`: 개인 상자. 클릭하거나 1.5초 서 있으면 열린다. 활동 종료 시 열지 않은 상자는 자동 지급된다.
- **획득 알림** `LootToast`: 좌측 카드(아이콘·이름·출처). 장비 화면이 열려 있으면 숨긴다.
- **기본 무장**: 튜토리얼(또는 Guardian Rises) 완료자에게 1회 크보스토프 7G-02(물리 슬롯), 스터본 오크, 엣지 트랜싯(유탄 발사기)을 무작위 특성으로 지급·장착한다.
- **처치 드랍**: `Enemy` 처치 시 처치자에게만 드랍. `LootTagged`로 등급 지정(악마의 소굴 몹), 미지정 몹은 최대 체력으로 분류(≤60 일반, ≤500 정예, 초과 보스). 확률 일반 3%, 정예 12%, 보스 50%.
- **악마의 소굴**: 세픽스 처치(완료) 시 참가자 전원에게 완료 보상(랜덤 레전더리 무기+랜덤 특성)과 보상 상자.

## 아이콘
Bungie 매니페스트(245114.26.10.13.2000-1-bnet.66137)의 무기·특성·엔그램 아이콘 189개를 96px로 가져왔다(`scripts/gear/fetch_manifest.py` → `import_bungie_icons.py`, 출처 `destiny/gear/bungie-icons.json`). 스킨 무기(캠페인)는 모델을 그대로 표시한다.

## 특성 전수 구현 (W320–W323)
매니페스트 기준 레전더리 63종의 특성 열 122종 중 미구현 44종을 4개 배치로 구현했다(W320 A, W321 B, W322 C, W323 D, 각 JSON의 DDC 행·로컬 정책 참고). 고정 롤 레전더리의 큐레이티드 풀 11건도 기존 퍽에 추가했다. 중화기 스냅샷 조준경은 DDC "Special and Power?" 0.8x를 로컬 정책으로 적용했다.
`LootGameTests.everyOfficialTraitIsImplemented`가 스냅샷(`src/gametest/resources/destiny/trait-pools.json`)의 모든 무기·열·특성이 선택 가능함을 검사한다.

## 관리자 명령
`/destiny loot roll|drop|chest <player> <table>`, `engram <player> <tier>`, `decode <player>`, `starter <player>`, `reset_starter <player>`, `status <player>`.

## 미구현·근사
엔그램/상자 전용 원본 사운드는 없어 전송음과 바닐라 음을 쓴다. 방어구 드랍은 방어구 시스템 미연결로 제외. 특성별 근사·미구현 항목은 각 배치 JSON `localPolicies`에 있다.
