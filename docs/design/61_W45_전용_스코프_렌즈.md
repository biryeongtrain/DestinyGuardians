# W45 — 전용 스코프 · 렌즈 정렬

## 범위 / 인수조건
W44의 실제 배율·거리감쇠·반동은 유지하고, 조준 시 총 뒷면/불투명 렌즈가 가리는 문제를 교정한다.
선정된 저격총3종·선형융합2종을 대상으로 한다. 전체 무기 목표의 일부 단계이며 완료 선언이 아니다.

- 실제 ADS 세션이 중간 전환점을 넘으면 SCOPE 포즈. 단순 OP 프리뷰는 실제 ADS/사거리 보너스가 아니다.
- 실물 ITEM_MODEL은 그대로. Polymer 전송 모델만 display_context wrapper로 바꾸고 저격총 양쪽1인칭만 빈 모델.
  LFR는 양쪽1인칭에 원본 몸체를 보존한 열린3D 조준기 변형을 사용한다. 평면 receiver로 대체하지 않는다.
  GUI/드롭/3인칭은 기존 ADS 모델 하위트리를 그대로 재사용, boolean0 양손 그립/컴포넌트 보존.
- 실제 서버 ray는 계속 화면 중앙960,540. Bite chevron은 꼭짓점, hollow ring은 구멍 중심을 거기에 배치.
- scope HUD 2개 이내. 프레임 normal z0 / 조준점 above-hand z6. 기존 탄약·체력·능력 HUD는 마스크 위.
- 재장전/능력/궁극기/빈손/아이템·차원 교체/사망/관전자/접속 정리 시 scope 종료, HIP 및 이전 FOV 복원.
  외부 FOV 소유권을 감지하면 같은 tick에 scope를 해제하고 외부 값을 덮어쓰지 않는다.
- HUD는 탄약·피해·진행도를 변경하지 않는다. 원본542 무기/황금총 에셋은 불변.

## 실제 게임플레이 참고
영상과 대표 contact frame을 로컬에서 직접 확인했다. URL·제목·원본SHA·관찰은
`art/weapons/w45-models/references.json`. 다운로드 원본은 gitignored `run/private-sources/w45`에만 둔다.

|Line in the Sand|상단이 좁은 열린 사다리꼴, 밝은 외측 금속/보라 내측 라인|

모든 그림은 직접 재작성한 근사 표현이다. 공식 sprite 추출/픽셀 단위 일치/현재 원작 sandbox 인증이 아니다.
저해상도 영상의 작은 조준점·발광색은 근사이며 추가 고해상도 참조 조정 가능.
LFR 1인칭은 원본 cuboid 몸체·텍스처를 보존하고 상단의 막힌 voxel scope만 자른 별도3D 변형이다.
Line의 밝은금속/보라내측 사다리꼴, Stormchaser의 열린 U뿔을 추가하며256cube한도 내이다.
원본 source 모델의 정확한 optic mesh를 그대로 가져온 것/원작 애니메이션 복제라고 주장하지 않는다.

## 바닐라 서버 제약 — 숨기지 않는 한계
바닐라 서버는 F5 시점 변경을 수신하지 않는다. DisplayHud GLSL/26.3 Globals에도 신뢰 가능한 perspective flag가 없다.
따라서 **scope HUD는 모든 시점에서 실제 ADS를 따라간다**. F5에서 scope를 자동 숨긴다고 주장하지 않는다.
시점을 강제하거나 Vision 전용 client 기능을 제품에 의존시키지 않는다. held-item만 vanilla display_context로
저격총1인칭 숨김/3인칭 보존된다. LFR는 1인칭 전용3D scope 변형/3인칭 원본 보존이다.
원작처럼1인칭 전용 overlay까지 하려면 별도 신뢰 가능한 client/shader 컨텍스트 설계가 후속이다.

스나이퍼 frame3840 정사각 CENTER 정렬, 원형/다각형 aperture는 화면비에 따라 찌그러지지 않는다.
검은 외부 여백은32:9까지 커버하도록 잡았으며 그보다 넓은 화면은 별도 검증 대상이다.
초기 실게임에서 vanilla crosshair가 hollow ring을 덮는 것을 발견했다. 따라서 필수팩의 바닐라
crosshair/attack-indicator4개 sprite를 투명화하고, 일반 아이템·빈손·궁극기에는 FallbackAimHud의 작은
조준점1개를 표시한다. 실제 무기/스코프/월도 조준점과 중복하지 않으며 재장전·사망·관전자 때 정리한다.
공유 필수팩이므로 Guardian 아닌 유저에게도 적용된다. 사용자 options·GUI설정은 변경하지 않는다.
vanilla hotbar/아이템이름·F3 debug축 십자선 제거까지 완료한 것은 아니다.
