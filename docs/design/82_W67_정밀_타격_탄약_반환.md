# W67 — 정밀 타격으로 탄창 탄약 반환

## 플레이 변화

공식 base 소켓이 확인된 무기에 선택형 **Triple Tap / Fourth Time's the Charm**을 연결한다.
기본 지급·무기 생성·상시 무한 탄창이 아니라, 실제 유료 발사 뒤 정밀 피해가 확인될 때만 반환한다.

- Triple Tap: 정밀 타격3회마다 탄창에1발 생성.
- Fourth Time's the Charm: 정밀 타격4회마다 탄창에2발 생성.
- 각 정밀 타격 사이 제한은2초(40서버tick). 첫 번째부터 마지막까지의 총2초 제한이 아니다.
- 예비탄0이어도 작동하지만 기본 탄창 용량을 넘지 못한다. 예비탄·저장된 legacy overflow를 가져오지 않는다.
- 완료한3/4회 묶음은 소비한다. 가득 찬 탄창에 반환하지 못한 탄약을 대기 보상으로 저장하지 않는다.
- 몸통 타격·빗나감·능력·melee·무효 피해는 카운터를 올리거나 시간을 갱신하지 않는다.
- 실제 무기 처치는 필요하지 않다. 유효한 양의 정밀 피해이면 비치명타도 센다.

명령: `/destiny perk select triple_tap` 또는 `/destiny perk select fourth_times_the_charm`.
기존 `/destiny perk list|status|clear`와 실제 소켓별 배타/공존 규칙을 따른다.

## 탄약·연사·재장전

탄창 생성은 `WeaponMagazine.generateLoaded`라는 명시적인 특성 보상 연산이다.
기존 reserve pickup·장전 transfer·명사수 회피와 구분한다. 유한 총탄도 반환되므로 총보유 탄약 증가 자체가 의도한 특성 효과다.
총보유량의 정수 상한과 기존 저장 초과분 보존은 계속 지킨다.

반환은 재장전 완료 사건이 아니므로 Kill Clip을 활성화하거나 장전 모션/소리를 재생하지 않는다.
발사 비용·cadence·Handling·ADS·장전 시간도 리셋하지 않는다.
한 tick에 여러 burst bolt가 처리돼도 앞 bolt가 반환한 탄약을 다음 bolt의 오래된 로컬 복사본으로 덮어쓰지 않는다.
마지막 탄 발사에서 반환되면 실제 탄창이 비어 있지 않으므로 빈 탄창 자동 장전을 시작하지 않는다.

## 소유권과 실제 타격

카운터는 플레이어 UUID만이 아니라 실제 소유 ItemStack identity에 귀속한다.
수납해도 마지막 정밀 타격부터 시간이 계속 흐른다. 같은 tick의 교체/복귀나 HUD 조회로 갱신하지 않는다.
복사본·NBT 로드·다른 소유자에게 진행도를 직렬화하지 않는다.
사망·관전·disconnect·level 변경·소유 상실·실제 특성 편집은 해당 세션을 무효화한다.

발사체는 발사 때의 원본 세션 token을 보관한다. 실제 양의 정밀 착탄만 원본 무기에 반영하며,
원래 소유자가 계속 가진 원본이 수납돼 있어도 작동한다. 현재 든 다른 총이나 이미 버린 총에 주지 않는다.
한 emission의 token은 한 번만 카운트할 수 있다. 현재 구현의 pellet 합산 damage transaction을 여러 가상 정밀 타격으로 부풀리지 않는다.
burst의 각 bolt는 별도 실제 emission이다. 향후 관통/다중 precision projectile은 원작별 별도 검증이 필요하다.
현재 정확한 base pool은8개 무기의9개 선택지(TT5/FTTC4)이며 전부 hitscan이다.
따라서 원본 token의 projectile 경로가 연결돼 있어도 이 단계에서 해당 특성의 실제 발사체 발동을 검증했다고 주장하지 않는다.
선정9소켓에는 burst 무기도 없어 burst 로컬 복사본 수정은 기존 burst 회귀로만 검사하며 특성 부여를 조작한 가짜 실험을 만들지 않는다.

## HUD와 시청각

반환된 실제 탄창 수치는 기존 Destiny 스타일 장탄수 HUD에 그대로 나타난다. 예비탄 표시는 그대로다.
원작 근거 없이 숨겨진 hit counter에 새 지속 buff row/초시계/스택을 만들지 않는다.
이번 단계에서 무기 모델·텍스처·음원·새 모션을 추가하지 않는다.

## 출처·서버 정책·검증 경계

[공식 소켓/정의·출처 구분](../../art/weapons/w67/reference-notes.md) ·

공식 manifest는 정밀 타격 trigger·반환량·정확한 무기 소켓을 증명한다.
2초 between-hits·수납 유지·reserve 비소비·기본 탄창 상한은 exact-base light.gg 커뮤니티 측정이다.
enhanced의3초나 경이 catalyst를 base 소켓에 섞지 않는다. TT2.5초라는 초기 기억은 최신 exact-base 자료의2초에 따라 기각했다.

40tick 정확한 경계에서 만료, body/miss에서 별도 초기화 없이 정밀 타격 시각만 사용,
재장전/스킬에 확인되지 않은 추가 reset을 넣지 않는 것, emission 중복 방지와 ItemStack identity는 명시적인 서버 통합 정책이다.
원작 엔진 trace나 모든 입력별 실제 Destiny 검증으로 표현하지 않는다.

실제 Minecraft 화면·키 입력·청취는 별도 미완료다. W62에서 승인된 격리 진단1회 이후 이번에 새 클라이언트 실행은 하지 않는다.
전체 무기/HUD/음향/애니메이션·다인/거리/성능 목표는 계속 진행 중이다.
