# W209 — 기관단총·핸드캐논 파지와 원본 리그 연결

Recluse의 방아쇠 그립/앞 지지점과 Austringer 양손 파지를 구분한다. 두 무기의 장전은 원본 source.blend에서 직접 평가한61pose와 genuine shoulder–elbow–wrist 사슬을 사용한다. 일반 핸드캐논/기관단총에도 보조 손을 유지하는 공통 설정을 적용했다.

## 원본과 등록

원본은 Recluse80A8A192, Austringer80A8A53D. 두 source.blend에는 Armature/action만 있으며 mesh/camera가 없다. 기존21개와 겹치는 평가 행렬의 오차는0.0이고, 새61개는 원본 action의 직접 평가다. SSD 원본과 사용자 Blender scene은 보존했다. 원본 시간3초/4.2초는 source provenance이며 실제 게임 장전 속도는 기존 게임플레이 시간에 맞춘 정규화 재생이다.

weapon4A0810C4, left elbow897A1504/wrist8C83CB67, right elbowA3781DCD/wristDE9D6BEA를 사용한다. source elbow의 직접 부모 shoulder D1232BA2/17025F50도 같은61좌표와 idle/ADS1개씩 총126pose에서 평가했다. forearm 축은 elbow→wrist와 elbow matrix Y 횡축으로 구성한다. 손목X 종축 일치로 발생하는 가짜 회전 flip을 피한다.

## 최종 공통 부모 방식

`sourceFullChain`은 어깨 원본을 확인한 두 무기만 사용한다. C는 source X-forward/Z-up에서 canonical -Z-forward/Y-up 등록이다. source W0/Wt, forearm Ft, upper Ut에 대해 현재 무기 body는 Rready·C·W0^-1·Wt·C^-1, forearm은 Rbody·C·Wt^-1·Ft로 표현한다. 따라서 body와 양팔은 M=Rready·C·W0^-1 하나의 부모를 공유한다. upper는 forearm·Ft^-1·Ut로 연결한다. 원본 weapon translation도 같은 등록/기존32배 보정으로 이동한다.

각 팔의 palm translation은 중립 그립에서 고정 보정한 뒤 source wrist의 weapon-relative 이동도 따라간다. 매 프레임 탄창/실린더의 수동 접점에 손을 고정하지 않는다. 그 방식은 source-pass3에서 낮게 내려가는 원본 손을 높은 실린더 옆으로 옮겨 위팔이 하늘로 솟는 결함을 만들었다. source wrist 좌표를 그대로 새 mesh에 복사한 IK는 아니다. 분리 탄창은 기존 접촉 envelope 동안 원본 왼손 이동에 맞춰 translation을 보정하지만, 총에 연결된 실린더는 원본 손을 따라 움직이지 않고 기존 힌지를 유지한다. authored moving part의 body-relative 회전/이동은 보존하고 그 부모 body만 원본 weapon pose로 바꾼다. idle/ADS/reload 모두 같은 source forearm 등록을 사용해 진입/회복 때 수동 종축으로 바뀌는 snap을 피한다.

기타 어깨 미확인 무기는 기존 mesh-ready 파지와 source weapon-parent swing을 사용한다. contact-relative delta를 오른쪽에 곱하거나, ready 접촉만 재구성해 왼손 handling rotation을 지우는 경로는 사용하지 않는다. sidearm 한손 정책은 이 범위에 포함하지 않는다.

## 피부와 길이

BetterModel의 rightArm/leftArm(EMPTY) 및 rightForeArm/leftForeArm 실제 피부 RGB를 사용한다. upper 전용 UV/소매 영역을 읽으며 아래팔 색상을 복제하지 않는다. upper color offsets320/448, 기존 forearm64/192는 유지한다. 커스텀 스킨의 선택적9-color armor prefix를 처리한다. 공식26.3 기본 스킨18종의 upper/base/sleeve도 동결 데이터로 보강했다. 손가락과 플레이어별 pack은 추가하지 않는다.

아래팔은 기존 정상 source elbow–wrist 길이를 유지하며, upper는 source shoulder–elbow 원점 거리(약 .27271×기존32배 보정)다. 위팔 elbow 원점[8,8,8]을 아래팔 열린 elbow 끝에 연결하고 upper 길이7.5 기준으로 정상 크기를 맞춘다. 팔 늘리기나 숨김으로 연결을 대체하지 않는다. reloadCameraLower는 전체 조립체에 HC1.5/SMG2.5의 작은 envelope만 적용한다.

## 검수와 한계

사용자 필수 순서 Blender→61pose→Vision→담당 agent 피드백/수정→Vision을 AGENTS.md에 고정했다. source-pass1은 횡방향 팔/노출, source-pass2와 source-pass3는 잘못된 upper 방향/수동 palm pin으로 불수락했다. 담당 agent 두 명에게 실제 PNG와 구간을 전달하고 공통 부모 식을 검산받았다. 최종 source-final의 실제 PNG에서 두 무기의 위팔 솟음 해소·양손 대기·ADS 가시성·장전 복귀를 수락했다. QA README와 visual-review.json에서 범위/잔여 사항을 별도로 기록한다. 대표5종native15개,Python49개,Java61개는 통과했으며, 다른3종의 전체 source IK를 수락한 것은 아니다.

원본 카메라·원본 전체 mesh/finger IK를 복원했다고 주장하지 않는다. 손바닥 접점 보정 때문에 원본 shoulder의 절대 화면 위치가 같다는 보장도 없다. 서버 item-model 선택은 약20Hz이며61pose가 바닐라60fps 연속 보간을 뜻하지 않는다. 게임플레이 탄약/장전 시간/음원/3인칭 carrier 정책은 보존한다.
