# W56 검 동작별 음향과 실제 접촉 연결

## 목표와 범위

이전에는 모든 검/강공격이 W33 Falling Guillotine의 `Swing_Reg_1` 하나를 승인 즉시 재생했다.
이제 사용자 공유 Drive의 **동작명이 있는15이벤트·51변형**을 구분하고 실제 접촉/발사/충돌과 가드 진입에 연결한다.
기존84이벤트와68개 보호파일, 기존번역은 그대로 유지한다. 원본검/황금총geometry/UV/안료/애니메이션·HP·비용·cadence는 바꾸지 않는다.

음원 이름/폴더를 실시간으로 확인했으나 **청취 또는 native 재생 검증을 한 것은 아니다**.
원본 action label과 로컬측정/가공/게임내발생시점은 서로 다른 증거다.

## 재생 정책

### 약/강공격

- 입력 승인 즉시 소리를 내지 않는다. 이미 비용/cadence가 승인된 W54 contact가 실제 BM frame cue에 도달할 때 한 번 재생한다.
- 약공격은 적이 없어도 swish가 나지만 적수마다 반복하지 않는다. 다중cleave의 중복 대상·피해 규칙은 유지한다.
- 강공격은 프레임/선정무기 기준, Crown의 `Heavy_Air_Att` 선택은 **승인 당시** onGround=false snapshot이다. 지상/공중 발동 금지나 별도 물리 효과를 새로 만들지 않는다.
- caster는 실제발사cap이허용돼projectile을만드는릴리스에서1회, 실제 world hit 위치에서1회충돌을낸다. 원거리충돌을몸근처에미리재생하지 않는다.
- 교체/스킬/guard/외부camera로 windup이 취소되면 아직 재생하지 않은 attack음도 사라진다. 비용환불은 없다.
- 전체 원본action을 한 번 재생하는 자체 timing이다. 녹음 내부 transient를 원작프레임에 sample단위로 맞췄다고 주장하지 않는다. 이미 발생한 one-shot의 자연 tail은 남을 수 있다.

### 가드

- 서버의 실제guard 유효상태(탄약·energy·cadence·현재주손)를 사용한다. sneak만 누른상태로 소리를 만들지 않는다.
- `SwordGuardAudio`가 false→true edge에만 bounded one-shot을 낸다. held중 반복하지 않는다.
- 동일 owner의8tick 재진입 제한은 자체 스팸방지값이다. 억제된 edge는 계속누르는중 늦게 재생하지 않는다.
- 취소시 edge만release하고 방금재생한 시간은 유지하므로 같은tick/stack교체/skillcleanup으로 제한을 우회하지 않는다.
- Guard source의 세부 raise/hold/blockhit 구분은 확인하지 못했다. 이 단계의 edge배치는 자체 정책이며 native 지속loop가 아니다.
- **StopSound를 쓰지 않는다.** 바닐라의StopSound는이벤트키/채널단위라 A의guard해제가같은이벤트를재생하는B의tail까지끊을수있다.1.097–6.794초 이하의자연one-shot만사용하며지속loop/재생중첩의실제믹스는추후청취검증한다.
