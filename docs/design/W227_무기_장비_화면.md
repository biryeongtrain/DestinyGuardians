# W227 무기 장비 화면

범위는 무기 장비 화면과 물리·에너지·파워 세 슬롯이다. 갑옷, 타이탄·워록, 시련의 장은 후속 작업으로 남긴다. 퍽 확장은 중단했다.

## 화면과 조작

`/메뉴` 또는 기본 E(인벤토리) 키로 화면을 열고 닫는다. E를 다시 누르면 닫히며, GCB 사용자는 기존 0 키도 보조 입력으로 사용할 수 있다. 열기는 생존 상태에서 바닥에 서 있고, 궁극기·다른 카메라·탑승·다른 컨테이너를 사용하지 않을 때 허용한다.

Shift+Q로 메뉴를 여는 기능은 제거했다. 메뉴가 닫힌 상태에서 일반 무기의 Q·Shift+Q·Ctrl+Q는 일반 장전이다. 이자나기의 짐은 Q로 일반 장전, Shift+Q 또는 Ctrl+Q(`DROP_ALL_ITEMS`)로 특수 장전을 시도한다. 장전 성공·거절과 무관하게 실전 무기는 버려지지 않는다. 메뉴가 열려 있으면 Q 계열 입력은 버리기만 취소하며 메뉴를 닫거나 장전을 시작하지 않는다.

왼쪽에 세 장착 슬롯을 세로로 배치한다. 선택한 슬롯의 여분 소유 무기는 옆의 3×3 격자에 표시하며, 보관량이 많으면 페이지를 넘긴다. 오른쪽에는 선택한 무기의 모델, 이름, 희귀도, 속성·탄약 종류, 프레임, 기본 수치와 현재 탄창을 표시한다. 표시하는 수치 막대는 공식 정의의 기본 수치이며 일시적 전투 버프를 합산한 수치가 아니다.

마우스 시점 변화가 HUD 안의 포인터를 움직인다. 바닐라 서버가 받을 수 있는 회전 패킷을 사용하며 OS 포인터를 해제하는 방식은 아니다. WASD로 선택 테두리를 이동하고 좌클릭 또는 Space로 장착한다. E·우클릭 또는 `/메뉴` 토글로 닫는다. 단축키와 마우스 포인터는 같은 화면 좌표와 버튼 영역을 사용한다.

화면 문구와 분류·능력치는 한국어로 표시하며, 무기65종의 이름은 고정된 Bungie 공식 한국어 정의에서 가져온다. 원래 무기 식별자와 전투 수치는 바꾸지 않는다. 한글 획이 사라지지 않도록 최소18 기준 픽셀, 주요 라벨20 픽셀, 상세 이름26 픽셀을 사용한다. 긴 카드 이름은 축소하지 않고 말줄임하며 상세 패널에 전체 이름을 표시한다. 프레임·탄약·속성은 화면 전용 한국어 라벨을 사용한다.

화면은 개인 전용 DisplayHud로 표시한다. 배경·장비 정사각형·희귀도 테두리·선택 표시·텍스트·포인터를 별도 노드로 유지하고 변경된 노드만 갱신한다. 무기 미리보기는 기존 GUI 모델을 사용하며 실제 인벤토리에는 넣지 않는다.

## 인벤토리와 전투 연결

세 장비 슬롯은 실제 핫바 0·1·2에 연결한다. `WeaponEquipmentService`가 소유 인벤토리 0~35에서 개수 1의 실제 전투 무기만 조회한다. 클릭할 때 인덱스와 원본 ItemStack 참조를 다시 확인하고, 해당 분류 슬롯의 무기를 원래 보관 칸으로 맞바꾼다. 탄약·이관 보존탄·퍽·사용자 컴포넌트를 포함한 원본 객체를 보존한다.

서로 다른 분류의 경이 무기는 동시에 한 개만 장착할 수 있다. 현재 두 경이 무기 모두 물리 슬롯이므로 실제 카탈로그로 서로 다른 분류의 경이 충돌을 실행할 수 없다. 해당 조건 검사는 코드에 존재하지만 조건부 테스트를 실제 충돌 검증으로 보고하지 않는다.

메뉴가 열린 동안 사격·능력·아이템 사용·월드 상호작용 패킷을 서버 스레드에서 가로챈다. WASD는 메뉴 선택으로 소비한다. 메뉴 전용 이동·점프 속성 modifier를 적용하고 위치 패킷의 이동 주장을 소비하며, 필요하면 바닐라 위치 보정 패킷을 보낸다. 외부 이동이나 카메라 전환, 피격·사망·접속 종료·차원 변경·서버 종료 때 화면을 회수한다. 닫기는 자기 modifier와 자기 HUD만 지우고 이전 키 입력을 복원하지 않는다.

메뉴를 볼 때 바닐라 핫바 아이콘과 선택 아이템 이름이 화면에 겹치지 않도록 수신자 전용 인벤토리 패킷의 핫바 표현만 숨긴다. Polymer의 실제 사용 가능한 아이템 운반체·개수·왕복 데이터는 유지하고 빈 아이템으로 대체하지 않는다. 열기와 닫기 때 전체 상태를 재전송하며 서버 원본·커서·다른 컨테이너는 바꾸지 않는다.

## 파일과 검증

- `inventory/WeaponScreen`: 화면 세션, 명령, 입력 처리, 수명 관리.
- `inventory/WeaponScreenControls`: 유한 회전값과 yaw 경계를 처리하는 포인터.
- `inventory/WeaponScreenLayout` / `WeaponScreenHud`: 공통 버튼 좌표와 실제 화면.
- `inventory/WeaponEquipmentService`: 소유 조회와 실제 장비 교체.
- `inventory/WeaponScreenText` / `w227-ko.json`: 화면 한국어와 공식 무기 이름.
- `inventory/WeaponScreenPresentation` / `mixin/WeaponScreenPresentationMixin`: 메뉴 동안 바닐라 핫바 표현 투영.
- `mixin/WeaponScreenInputMixin`: 바닐라 패킷 경로의 메뉴 입력.

진행 기록과 실제 결과는 [W227 QA](../qa/2026-10-28/w227/README.md)에 모은다. 순수 좌표 검사, 서버 인벤토리·입력 검사, Vision 실제 프레임 검수를 구분한다. 기존 미커밋 통합본과 격리 워크트리의 출처도 기록한다.

### 인벤토리 키 감지

InventoryRedirection의 recipe seen 방식을26.3에 맞춰 사용한다. 생존·모험 인벤토리의 client-only 레시피 북을 감지용4항목으로 관리해 목록 첫 페이지를 보장한다. 실제 해금은 변경하지 않으며 작업대·화로 등 서버 제작 화면에서는 원래 목록·책 설정을 복원한다. 공중 등 열기 조건이 맞지 않으면 바닐라 인벤토리가 유지된다. 레시피 북이 없는 크리에이티브 화면 등에서는 `/메뉴`를 사용한다. 바닐라 인벤토리가 짧게 보일 가능성이 있는 서버 감지 방식이다.
