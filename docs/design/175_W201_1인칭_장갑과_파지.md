# W201 — 1인칭 손·장갑과 장전 파지

사용자 요청: 전투·장전 시 플레이어 손이 실제로 보이도록 한다. 서버사이드 26.3 Fabric/Polymer와 기존 원본 무기/장전 표현을 유지한다.

## 구현

- 새 손·짧은 전완 모델은 저작한 헌터식 장갑이다. 플레이어 스킨 자동 적용이나 추출된 1P 손 메시 복원으로 보고하지 않는다.
- 기존 표시 그래프의 파지·ADS·교체·장전 분기를 복제한 별도 1P overlay를 만든다. 원본 모델·UV와 3P/GUI/ground/fixed/head 분기는 보존한다.
- 손은 기존 무기 본체와 움직이는 탄창/실린더에 같은 변환으로 연결한다. 부품 접촉·전환 보정은 저작한 것으로 표시하며 미확정 hash 본을 손 본으로 임의 명명하지 않는다.
- 실제 탄약·장전 완료·사격 cadence와 퍽은 변경하지 않는다. 새 selector나 입력 상태는 만들지 않는다.
- 검은 기존 BetterModel 플레이어/검 경로를 유지한다. 다른 카메라에서 팔이 중복 표시되지 않도록 리소스의 1P context에서만 overlay한다.

## 배치

별도 CoW worktree 두 개에서 장갑 모델/텍스처와 무기별 접촉점을 병렬 제작한다. master는 표시 그래프 생성기와 Polymer 최종 wire-carrier 연결, 검사·Vision 통합을 소유한다. 고유 결과를 export하고 통합·검증 후 작업본을 정리한다.

## 단계 기록

1. 26.3/Polymer0.18.4와 기존 장전·scope·좌우손/교체 경로를 확인했다. item JSON의 frame 선택은 연속 보간이 아니므로 이번 손 추가를 60fps 손 IK로 설명하지 않는다.
2. worktree 기준선 70,228파일, SHA256950beb3bd6676970b60adefb82fa2fd46c7b505f790ab1812e23016896cba73a. 소유 파일은 QA batch.json에 기록했다.
3. 이전 W200에서 export만 남았던 Pulse Monitor10개 파일을 baseline 검증 후 통합했다. 이는 기존 공유 코드가 참조하던 빠진 타입을 복원한 선행 작업이며 W200실게임 검증 완료를 의미하지 않는다.

## 검증 계획

출력 파싱·참조·요소 예산과 실제 26.3 모델 파서, 최종 Polymer carrier에서 표시 alias/roundtrip 보존을 확인한다. 격리 Vision 한 세션에서 에이스/듀크/이자나기/자동소총의 기본 파지·사격·장전·조준·좌우손을 취합하고 실제 PNG를 본다. 다른 무기군은 생성 범위와 직접 본 범위를 구분한다. 작은 미술 변경에 전체 퍽 테스트를 반복하지 않는다.

## 완료 결과

60종(검 제외),239개 표시 경로를 생성하고 양손52큐브를 추가했다. 조립 최대308개다.34개 소총형 받침손은 native 확인 후 손바닥을 위로, 전완을 사용자 방향으로 보정했다. 장갑·보호대와 저작한 접촉점은 별도 생성기에서 재현한다.

관련 JUnit16개와 실제 Polymer GameTest1개 통과 후 마지막 미술 보정에 W201 codec3개/assemble을 다시 확인했다. Vision에서 에이스·아미트·이자나기·듀크·Biting Winds의 대표 동작과 스코프/3P를 취합했다. 왼손 주사용·Honed·궁극기 전용 아이템과 전수 화면 검증은 수행하지 않았다.
