# 10. AI 작업 요청서 템플릿·QA

AI에게 작업을 맡길 때 아래 템플릿을 채워서 함께 보냅니다. 항상 **01 아트 스타일 가이드**와 해당 분야 문서를 같이 첨부합니다.

## 공통 머리말 (모든 요청에 붙임)

```
프로젝트: Destiny Guardians (Minecraft 26.3, Fabric 서버사이드, 바닐라 클라이언트)
참고 문서: 01_아트_스타일_가이드.md, <분야 문서>
금지: 원작 에셋 추출·트레이싱, 01 팔레트 밖 속성 색, 예산 초과
산출물 저장 위치: art/<분류>/<ID>
요청서 ID: REQ-<분류>-<번호>
```

## 1. 컨셉 시트 요청 (이미지 AI)

```
요청서 ID: REQ-CONCEPT-001
대상 ID: weapon/hand_cannon/ace_of_spades
종류: 경이 핸드캐논
포인트: 측판의 스페이드 문양, 금색 테두리
형태 키워드: 짧고 두꺼운 실린더, 굵은 손잡이
색: 몸체 #2B2F36, 장식 #CEAE33, 발광 없음
출력: 정면/측면/후면 3면도, 흰 배경, 글자 없음, 로우폴리 블록 스타일
```
