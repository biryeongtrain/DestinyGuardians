# W61 — 살상 탄창과 무기 버프 HUD

## 범위와 사용

장탄수·재장전 시스템의 두 번째 특성으로 **살상 탄창(Kill Clip)**을 연결한다.
선정된 정확한 Bungie 무기 hash 63개 중 13개만 허용한다. 12개는 공식 randomized pool,
Antiope-D 1개는 해당 무기의 고정 초기 소켓이다. `plugSetHash=669`는 **fake reusable set**이며 랜덤 롤 근거가 아니다.
기본/기존 무기에 자동으로 부여하지 않고 강화형·경이·검·프리뷰는 제외한다.

```text
/destiny perk list
/destiny perk select kill_clip
/destiny perk select auto_loading_holster
/destiny perk status
/destiny perk clear
```

명령은 일반 플레이어가 소유한 실제 전투 무기의 허용된 소켓만 바꾼다. 무기·탄약을 생성하지 않는다.
같은 소켓은 배타적이고 다른 소켓은 공존한다. Duke Mk.44는 ALH/KC가 둘 다 소켓4이므로 교체되고,
Gnawing Hunger(3/4), Dust Rock Blues(4/3), Bad Omens(3/4)는 둘 다 선택할 수 있다.
이는 프로토타입 선택 정책이며 원작 획득 경제·전체 제작/랜덤 롤 시스템의 구현은 아니다.

## 근거와 명시적 자체 정책

- [공식 Bungie 6.3.0](https://www.bungie.net/7/en/News/article/destiny2_update_630): 33%→**25%** 증가 및 활성 중 재발동 갱신.
- [light.gg 기본형 연구](https://www.light.gg/db/de/items/1015611457/kill-clip/?_=707): 처치 후 **3.6초 내 재장전 완료**, **5초** 지속, 수납 시 활성 버프 제거.
  서버20Hz 변환은72/100tick이다. 절대 타이밍과 수납은 커뮤니티 측정이며 공식 수치 필드가 아니다.
- [명사수 회피 연구](https://www.light.gg/db/items/426473316/marksmans-dodge/): 재장전 특성을 발동시키는 수동 재장전으로 분류.
- [ALH 커뮤니티 위키](https://d2.destinygamewiki.com/wiki/Auto-Loading_Holster): 자동 장전 총집은 on-reload 특성을 발동하지 않는다.
- [근거·미확인 항목](../../art/weapons/w61/references/mechanics.json), [공식 소켓 근거](../../art/weapons/w61/references/socket-pools.json),
  [입력 SHA와 재현](../../art/weapons/w61/references/provenance.json), [읽기 전용 추출기](../../scripts/extract_kill_clip_w61.py).

다음은 원작 세부 실측으로 주장하지 않는 **자체 통합 정책**이다.
1. 마지막 실제 무기 처치의72tick 이내(끝점 포함)에 실제 탄약 이동이 완료되어야 한다. 장전 시작만으로는 발동하지 않는다.
2. 한 처치의 자격은 최초 성공 장전에서 소비한다. 산탄총은 첫 성공 삽입이 발동이며 다음 삽입만으로 갱신하지 않는다.
3. 새 처치 후 성공 재장전은 활성 버프를100tick으로 갱신한다. 중첩으로1.25배 이상 증가하지 않는다.
4. 수납은 활성 버프뿐 아니라 미발동 처치 자격도 버린다. 미발동 자격의 원작 수납 유지 여부는 미확인이다.
5. 회피라도 가득 찬 탄창/예비탄0으로 실제 이동이 없다면 발동하지 않는다. 회피 이벤트 분류와 별개인 보수적 조건이다.
6. 투사체는 발사 시 증뎀을 스냅샷한다. 버프 만료/교체 뒤 명중해도 해당 발사 피해는 유지한다.
   다만 처치 자격은 발사 원본의 같은 owner/level/실물/session이 여전히 주 손에 있을 때만 받는다.
   원작 투사체의 정밀 스냅샷 시점은 이 조사로 확정하지 않았다.

## 서버 연결

`WeaponKillClip`은 owner/level/실제 ItemStack별 transient 세션을 유지한다. 무기 피해 거래가 실제 final blow를
확정한 경우만 해당 발사 토큰에 처치를 기록한다. 능력·궁극기·월도 근접·검 근접은 토큰이 없어 발동하지 않는다.
다른 무기를 든 뒤 맞은 투사체 처치가 현재 무기의 자격으로 옮겨가지 않는다.
일반/빈 탄창 자동 재장전 완료와 명사수 실제 탄약 이동에만 연결하며 ALH 수납 장전 경로는 호출하지 않는다.
피해1.25배는 거리감쇠·정밀 계산 후 한 번 적용하고 피해 숫자는 실제 HP 감소량을 사용한다.
죽음/접속 종료/차원/관전/궁극기/다른 실물/특성 명령 변경은 세션을 버린다. 버프는 저장·오프라인 복구하지 않는다.

기존 W60 LongTag hash+IntTag socket은 읽기 전용으로 인식한다. 실제 선택 변경 때만
`destiny_weapon_trait_sockets` CompoundTag(소켓 문자열→LongTag hash)로 이관한다.
유효하지 않은 현대 소켓 타입이 legacy 값을 우회 복구하지 않도록 하고, clear는 특성 키들만 제거한다.
탄약/모델/lore/다른 custom data와 사격 cadence·Handling은 유지한다.

## HUD

왼쪽 능력 묶음 위에 녹색 긍정 버프 마커, 흰색 `Kill Clip`, `0:05` 카운트다운을 표시한다.
실제 남은tick을 올림한 초이며 종료tick에 행을 지운다. 처치만 하거나 선택만 했을 때는 표시하지 않는다.
기존 DisplayHud/Polymer 방식, 독자 제작 평면 스프라이트와 W39 숫자 재사용, 고정6노드/동일 엔티티 캐시이다.
HUD 조회는 세션 생성·타이머 진행·탄약 수정이 없는 읽기 전용이다. 비수호자에게도 무기 버프는 보인다.

[오프라인 스프라이트 조합](../../art/hud/w61-perks/offline-preview.png)은 원본 텍스처 검토용으로 **게임 화면이 아니다**.
원작 HUD 배치를 참고한 독자 재현이지 모든 해상도에서 원작과 동일한 픽셀 결과를 검증한 것은 아니다.
글꼴 파일은 배포하지 않고 로컬 시스템 glyph만 래스터화했다.
