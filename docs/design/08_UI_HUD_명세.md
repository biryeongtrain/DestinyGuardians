# 08. UI·HUD 명세 (DisplayHud)

HUD와 인터랙티브 UI는 minigame-lib의 **DisplayHud**로 만듭니다. 원리는 메인 문서 3-1-5에 있습니다. 이 문서는 **화면별로 무엇을 어디에 그리는지**와 **AI에게 맡길 그래픽 리소스**를 정합니다.

## 1. 좌표·레이어 규칙

- 기준 해상도 **1920×1080**. 좌표 원점은 왼쪽 위, 단위는 기준 해상도 픽셀
- 정렬: `LEFT`(왼쪽 가장자리 기준), `CENTER`, `RIGHT`. 화면 비율이 달라도 정렬 기준 가장자리에 붙어 있음
- 안전 영역: 가장자리에서 40px 안쪽
- 바닐라 GUI(핫바·체력·채팅)와 겹치지 않게: **하단 중앙 180px 높이는 바닐라 핫바 영역**으로 비움
- z 순서: 배경 패널 0 → 게이지 채움 1 → 아이콘 2 → 글자 3 → 커서·강조 4

## 2. 요소 종류와 그래픽 리소스

| 요소 | DisplayHud 클래스 | 그래픽 리소스 | 제작 |
|---|---|---|---|
| 아이콘 (능력·무기) | `TextDisplayHud` + 폰트 글리프 | `assets/destiny/textures/font/hud/*.png` (32×32) | AI 이미지 → 픽셀 정리 |
| 패널 배경 | `TextDisplayHud` + 큰 글리프 | 256×256 9분할 패널 이미지 | AI 이미지 → 사람 정리 |
| 게이지 (궁극기·보호막) | `BlockDisplayHud`(단색 막대) 또는 글리프 단계 이미지 | 단계 이미지 0~20 | 코드 생성 가능 |
| 숫자·문구 | `TextDisplayHud` | 커스텀 폰트(선택) | – |
| 3D 미리보기 (무기 회전) | `ItemDisplayHud` | 03의 무기 모델 | 기존 모델 재사용 |

### 2-1. 폰트 글리프 규칙
- 폰트 파일: `assets/destiny/font/hud.json` (bitmap provider)
- 문자 코드: 사설 영역 `U+E000`부터 분류별로 묶음 (`E000~E0FF` 능력, `E100~E1FF` 무기, `E200~E2FF` 패널·장식)
- 글리프 목록은 `art/ui/glyphs.csv`(ID, 코드, 파일, 크기)로 관리하고 폰트 JSON은 스크립트로 생성

| `hud:crosshair_hit` | 적중 표시 (정밀 적중은 노란색) | CENTER | 960, 540 | 24 | 적중 시 4틱 표시 |

- **2026-10-22 사용자 결정:** 바닐라 체력/흡수 하트는 숨기고 데스티니처럼 상단 중앙의 얇은 체력 바로 대체합니다.
  필수 서버 팩의 하트 44종 투명 텍스처를 사용하며, 직업 none도 대체 체력 바를 표시합니다.
  실제 흡수량만 보조 막대로 표시하고 별도 보호막 게임플레이를 가정하지 않습니다.
- **현재 구현이 위 초기 표보다 우선:** 체력 (960,76) 424×7 / 흡수 (960,65) 최대424×4.
  궁극기 다이아몬드 (120,856) 80×80, 가로 충전 막대 (176~406,856) 230×5.
  수류탄·근접·회피 타일 (104/174/244,948) 53×53, 아이콘 37×37, 아래 48×4 충전 밑줄.
  H10 가독성 피드백: 좌하단 전체 배치·간격을 약 20% 확대하고 체력 바 두께를 5→7px로 조정.
  한글 상태 줄과 중앙 `궁극기 NN%` 텍스트는 더 이상 그리지 않습니다.
- 원작의 배치·비례·단색 실루엣을 따르되 아트는 직접 제작한 벡터입니다. 핫바/배고픔/방어구/경험치는
  Minecraft 생존 및 슬롯 조작을 보존하기 위해 유지합니다. 일반 무기 탄약 패널은 구현 후 연결합니다.
- 값이 자주 바뀌는 요소는 **바뀔 때만** 갱신합니다. 쿨타임 원형처럼 연속 변화는 1초 단위 + 보간으로 처리합니다.

## 5. 인터랙티브 화면

### 5-1. 공통 입력 `[결정 필요: 메인 문서 3-1-5의 커서 방식 A/B/C]`

방식 B(핫바 선택)를 기준으로 적습니다.

| 입력 | 동작 |
|---|---|
| 핫바 스크롤 / 숫자 키 | 항목 이동 |
| 우클릭 | 선택·확인 |
| 웅크리기 | 뒤로 / 닫기 |
| F (손 바꾸기) | 탭 전환 |

- 화면이 열려 있는 동안 서버가 이동을 막고, 핫바 슬롯 변경 패킷을 커서 입력으로 씁니다. 슬롯 위치는 다시 원래대로 돌려 놓습니다.
- 방식 A(시점 커서)로 바꾸면 이 표의 "항목 이동"만 시점 변화량으로 바뀝니다.

### 5-2. 스킬 트리 화면

```
┌───────────────────────────────────────────────────────────────┐
│ [타이탄] [헌터] [워록]                    ← 직업 탭 (F로 전환)   │
│                                                               │
│  궁극기 ◆      수류탄 ◆     근접 ◆      직업 능력 ◆             │
│  측면 ◆ ◆      파편 ◆ ◆ ◆ ◆                                   │
│                                                               │
│  ┌ 선택지 목록 (가로 스크롤) ───────────────────────────┐       │
│  │ [Arc 아이콘] [Solar 아이콘] [Void 아이콘] ...       │       │
│  └──────────────────────────────────────────────────┘       │
│                              ┌ 설명 패널 (오른쪽에서 밀려 들어옴) ┐│
│                              │ 이름 / 속성 / 효과 / 쿨타임       ││
│                              └────────────────────────────────┘│
└───────────────────────────────────────────────────────────────┘
```

| 단계 | 화면 상태 | 연출 |
|---|---|---|
| 열기 | 배경 패널 페이드 인, 슬롯 순차 등장 | 슬롯마다 2틱 간격, 크기 0 → 1 보간 4틱 |
| 슬롯 포커스 | 강조 테두리(`#F2C14E`) + 크기 1.1 | 보간 2틱 |
| 슬롯 선택 | 선택지 목록 표시 | 아래에서 위로 이동 보간 4틱 |
| 선택지 포커스 | 설명 패널 갱신 | 오른쪽에서 밀려 들어옴 (`HudMover`) |
| 확정 | 슬롯 아이콘 교체, 속성 색 섬광 | 크기 1.3 → 1 보간 4틱 |
| 닫기 | 전체 페이드 아웃 | 4틱 후 요소 제거 |

### 5-3. 무기 정보 화면
- 왼쪽: `ItemDisplayHud`로 무기 3D 모델 천천히 회전
- 오른쪽: 수치 막대 (피해량, 연사, 사거리, 안정성, 조작성, 재장전) – 03·메인 문서 3-2-4 항목
- 아래: 특성 칸 (총열, 탄창, 특성 1, 특성 2). 선택 시 교체 후보 목록

### 5-4. 상점 화면
- 왼쪽: 상품 목록 (아이콘 + 이름 + 가격)
- 오른쪽: 상품 미리보기(3D) + 설명 + 구매 버튼
- 상단: 미광체 보유량

## 7. minigame-lib 2.0.0 (26.3) ✅

2026-10-22 `port/26.3` 브랜치(태그 `2.0.0+26.3`) 기준. DisplayHUD 2.2 Beta 구조로 포팅되었습니다.

| 항목 | 내용 | 이 프로젝트에서 쓰는 곳 |
|---|---|---|
| 가상 Display | 월드에 추가되지 않는 가상 엔티티. 패킷으로만 소유자에게 보이고 탑승 패킷에 자동으로 합쳐짐 | 모든 HUD |
| `GlobalHud.text/item/block(id)` | 여러 플레이어가 공유하는 HUD. `show/hide/remove` | 레이드 HUD(보스 체력·격노 타이머)를 화력팀 전원에게 하나로 |
| `setAboveHand(true)` | 1인칭 손 위에 HUD를 그림 (`minigamelib:above_hand_trigger` 아이템 모델 사용) | 조준점 적중 표시, 탄약처럼 손 모델에 가려지면 안 되는 요소 |
| `updateWhenDataChanged()` | 값이 바뀔 때마다 자동으로 메타데이터 전송 | 탄약, 쿨타임 숫자 |
| `TextDisplayHud.setOpacity(n, time)`, `setBackgroundColor()` | 투명도 보간, 배경색 | 패널 페이드 인·아웃 |
| 리스폰·차원 이동 | 자동 재전송 | – |

- **좌표**: 코드 기준으로 1920×1080, **왼쪽 위 원점**입니다(기본값 940, 540 = 화면 중앙). 이 문서의 좌표는 이 기준입니다. ⚠️ minigame-lib README 예시는 `setLocation(-900, -480)`처럼 중앙 기준 값을 쓰고 있어 코드와 다릅니다. 첫 HUD 작업(W3-06)에서 실제 화면으로 확인합니다.
- **기본값 변경**: `DisplayHudManager` 기본값이 unit 100/100, alignmentGap 1,000,000으로 바뀌었고 셰이더 `displayhud.glsl`과 맞춰져 있습니다. `configure(...)`로 바꿀 때는 셰이더 값도 같이 바꿔야 합니다.
- **덮어쓰는 바닐라 파일**: 코어 셰이더 `text.vsh/fsh`, `entity.vsh`, `item.vsh`, `block.vsh`, `rendertype_outline.vsh`, 포스트 효과 `entity_outline.json`. (09-3)
