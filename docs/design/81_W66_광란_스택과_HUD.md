# W66 — 광란(Rampage) 스택과 HUD

## 실제 플레이 변화

공식 소켓 풀이 확인된 무기에서 `/destiny perk select rampage`로 선택한다.
기본 부여·무기 생성·탄약 지급은 하지 않는다. 같은 소켓의 살상 탄창/자동 장전 총집 등은 교체되고,
다른 공식 소켓의 특성은 함께 선택할 수 있다.

- **실제 해당 무기 처치 → 광란 x1 → x2 → x3.** 정밀 처치는 필수 조건이 아니다.
- 처치한 공격은 발사할 때의 배율로 적용되고, 획득한 스택은 이후 공격에 적용된다.
- 피해 배율은1.10 /1.21 /1.331. 실제 지역 PvE 기본 피해에 곱하며 원작 적 체력 수치 재현은 아니다.
- 추가 처치는 최대3스택 상태에서도 시간을 갱신한다. 재장전은 필요 없고 스택도 지급하지 않는다.
- 90서버tick(4.5초)마다 **3→2→1→0**, 한 번에 전부 사라지지 않는다.
- 수납해도 원래 ItemStack의 시간이 계속 흐른다. 같은 tick의 수납/복귀로 시간 갱신할 수 없다.
- HUD는 실제 든 무기의 `Rampage x1/x2/x3`와 **다음 한 스택 감소까지**의 시간을 표시한다.
  0스택에는 관련6개 node를 제거한다. 기존 Kill Clip/Outlaw의 node ID와 비활성시 위치를 유지한다.

## 상태와 발사체 귀속

`RampageCycle`의 query는 순수하다. HUD를 덜 갱신하거나 수납 중이어도 실제 서버 tick으로 감소량을 계산한다.
여러 감소 구간이 지난 뒤 돌아오면 지난 시간을 모두 반영하며 갱신 시점부터 새4.5초를 주지 않는다.

`WeaponRampage`는 플레이어·level·실제 소유 ItemStack identity에만 세션을 둔다.
복사본/NBT 저장·로드/다른 유저에게 버프를 옮기지 않는다. 사망·관전·disconnect·level변경·소유 상실·특성 편집은 정리한다.
재장전/일반 스킬 취소는 시간을 리셋하거나 추가 스택을 주지 않는다.

발사체는 발사할 때 피해 배율과 원본 세션을 캡처한다. 착탄 전에 스택이 감소하거나 무기를 바꿔도 이미 발사한 피해는 바뀌지 않는다.
원본 무기를 계속 소유하고 특성도 그대로일 때의 실제 발사체 처치는 원본 무기에만 귀속한다. 현재 든 다른 무기에 보상을 주지 않는다.
능력·월도 melee·다른 무기·비치명타격/피해 실패는 광란 처치로 처리하지 않는다.

현 GL의 기본 blast는 무기 자체의 피해이므로 해당 배율을 받는다.
아직 없는 Explosive Payload/Dragonfly 등 **다른 특성의 추가 폭발**을 증폭한다고 주장하지 않는다.
새 음향·무기 모델·장전 알고리즘은 추가/변경하지 않았다.
