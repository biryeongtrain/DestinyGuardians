# W228 슬롯에서 무기와 퍽 구성

테스트 장비 화면에서 **슬롯 선택 → 새 무기 → 무기군 → 무기 → 퍽 선택 → 로드아웃에 추가** 순서로 구성한다. 최종 추가 전에는 실제 장비·인벤토리를 변경하지 않는다.

## 사용

1. `/destiny inventory` 또는 `/destiny inventory test`, 웅크리기+Q로 연다.
2. 왼쪽 물리·에너지·파워 슬롯을 고르고 **새 무기**를 누른다.
3. 해당 슬롯에 사용할 수 있는 무기군을 고른 뒤 무기를 선택한다. 구현된65종을 슬롯·무기군별로 나눠 표시하며 페이지를 넘길 수 있다.
4. 장착 예정 무기의 **데미지 퍽 / 유틸리티 퍽**을 각각 한 개씩 고른다. **없음**으로 해제할 수 있다. 해당 무기의 정확한 원작 소켓 풀에 속하며 구현된 퍽만 나온다. 같은 소켓을 요구하는 조합은 이유와 함께 선택 불가로 표시한다. 경이 고유 특성은 유지한다.
5. **로드아웃에 추가**를 누르면 선택한 슬롯에 실제 무기와 퍽을 적용한다. 뒤로 또는 닫기를 누르면 작성 중인 선택만 버리고 원래 장비는 보존한다.

마우스 시점 포인터·WASD로 선택, 좌클릭/Space로 확정, 우클릭/Q/F로 닫는다. 메뉴가 열려 있는 동안 이동·사격·능력 사용은 차단한다. JVM `-Ddestiny.testArmory=false`로 신규 테스트 장착을 끌 수 있다.

## 확정과 아이템 보존

무기군·무기 카탈로그는 읽기 전용이며 미소유 카드에 기본 탄창을 표시한다. 퍽 선택은 세션에만 있는 작성 중 무기에 적용하며, 유저 인벤토리에 지급하지 않는다. 최종 추가 때 소유권·실제 슬롯·정확한 퍽 tuple을 다시 검증한다. 잘못된 조합은 인벤토리 변경 전에 거부한다.

소유한 동일 무기는 재사용하면서 탄약을 유지하고 선택한 퍽을 적용한다. 미소유 무기는 최종 확정할 때 생성해 소유자 표식을 남긴다. 본인에게 지급한 테스트 무기는 교체할 수 있지만 일반 장비는 보관 칸3~35에 보존하며, 빈 칸이 없으면 변경 전에 거부한다. 관련 없는 아이템이나 인벤토리를 지우지 않는다. 실제 장비는 핫바0·1·2다.

## 한국어와 출처

77개 구현 퍽 이름과 설명은 공식 Bungie 한국어 정의를 사용한다. 직접 피해 증가가 있는22개를 데미지, 나머지55개를 유틸리티로 분류한다. 혼합 특성은 직접 피해 증가를 우선한다. **원작 설명**은 Destiny 2의 설명으로, Minecraft에서 모든 문장·수치를 동일하게 구현했다는 뜻은 아니다.

정의 버전: `245114.26.10.13.2000-1-bnet.66137`. 전체200MB 원본은 임시 폴더에만 보관한다. 단순 수치 퍽을 전수 재검사하지 않고 새 구성·확정·인벤토리 동작을 검증한다. 검증 근거와 한계는 `docs/qa/2026-10-28/w228/README.md`에 남긴다.
