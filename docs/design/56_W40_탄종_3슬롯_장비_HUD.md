## 동작
- Slot KINETIC/ENERGY/POWER와 Ammo PRIMARY/SPECIAL/HEAVY 독립.
  Austringer=물리일반, Ammit=에너지일반, Bite of the Fox=물리특수, Beloved=에너지특수.
- Primary는 유한탄창/무한예비탄. 0발이면 기존server reload deadline완료후 탄창이 찬다.
  reserve=MAX_INT 같은 가짜수치를 저장하지 않는다. 저장된구형primary예비탄은0으로정규화/탄창은보존.
- Special/Heavy는 기존 유한예비탄/부분재장전/취소/버스트/서버쿨다운유지.
- 일반유저는 소유한 live아이템을 들어 /destiny loadout equip.
  실제item reference를1/2/3 hotbar로이동하고 같은bucket기존무기는원래source보관slot으로swap.
  빈대상만즉시이동. 일반아이템/다른canonical슬롯을위험하게덮어쓰면트랜잭션전체거부.
  새탄/새무기를생성하지않고 원래탄창/예비탄/texture/그립컴포넌트보존.
- 성공후 실제 vanilla selected-slot packet으로선택을동기화, 이후 1/2/3/휠의native핫바변경사용. /destiny loadout select <kinetic|energy|power> UI대응명령도 소유슬롯만선택.
  장비모드에서는 canonical부적합/추가보관슬롯무기는사격불가. 다른 일반아이템·능력은별개.
- Fabric Boolean attachment persistent/copyOnDeath. 기존 standalone디버그무기는명시장비전까지호환.
  OP /destiny weapon standalone [player]는아이템변경없이 QA호환모드로복귀. 일반유저에게권한없음.
- 현재63종은모두Legendary. 경이1무기제한코드는있지만실제경이카탈로그/특성은아직구현하지않음.
- HUD: 큰현재탄/작은예비탄 또는∞, 슬롯별실제속성glyph, white/green/purple탄종표식.
  선택무기아래 실제다른2슬롯만 표시. 미장착행숨김. stowed특수/중화기는탄창+예비탄총합.
  궁극기동안일반행숨김, 황금총은실제shots표시후기존장비복귀.
  glyph metadata캐시재사용,최대26 ammo노드. 일반HUD/후방궁극기/H29·W38모델은변경하지않음.
