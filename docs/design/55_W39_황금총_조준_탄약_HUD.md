# W39 황금총 조준 및 탄약 HUD

## 인수조건
- 황금총은 1인칭에서 넓은 옆면 대신 전방을 조준하는 총구 방향. GUI/3인칭/메시/색/반동 유지.
- 기존 서버 ItemStack의 탄창·예비탄을 읽기만 하는 HUD. 우클릭 발사, 웅크리기+우클릭 재장전 유지.
- 좌측 능력 타일 오른쪽 선택무기 패널, 큰 탄창/작은 예비탄, 얇은 흰 테두리 및 무기군 실루엣.
- 소량 주황/빈 탄창 빨강. 재장전 완료 이전에는 탄을 채워 보이지 않고 실제 서버 남은 tick 기반 하단 진행선.
- 프리뷰/빈손/관전자/사망 정리. 황금총 실제 3발의 소모 표시, 타 궁극기 중 숨김.
- 기존 W38 월도/다른 무기/프로필 밸런스 불변.

## 참고
- https://www.youtube.com/watch?v=HUAIKQL728w — Nezarec's Whisper 실게임 253초 HUD.
- 로컬 기존 영상 프레임 run/private-sources/w37/nezarec-253.png (외부 원본 재배포하지 않음).
- 실제로 소유하지 않은 부무기 줄/속성은 만들지 않는다. 현 primary 예비탄은 유한(데스티니2의 무한 primary 탄 정책까지 변경하는 범위는 아님).
- 숫자는 로컬 Arial Narrow Bold 숫자만 rasterize, 원본 폰트 미배포. 실루엣·패널 자체 제작.
- 모든 표시 서버사이드 DisplayHud ItemDisplay, QA client의 HUD 렌더러 추가 없음.

## 구현
WeaponRuntime.ammunition은 현재 주손과 owner/dimension 일치 시 재장전 상태를 읽는다. bind/tick/save를 하지 않는다.
AmmoHud는 자체 무기 상태를 저장하지 않고 매 tick 스냅샷 기반으로 변경된 glyph만 전송한다.
보통 7~11 quads, 재장전2개 추가. 10자리 int까지 지원하며 오래된 자릿수는 제거한다.
완료와 HUD 콜백 순서에 따라 최대1서버tick 지연 가능. gameplay는 HUD에 의존하지 않는다.
