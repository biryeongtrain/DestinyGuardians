# W210 — 원본61과 다섯 무기 팔 리깅

대상: Ace of Spades, Izanagi’s Burden, Beloved, Gnawing Hunger, First In Last Out. 전체 무기 목표의 부분 배치다. 원본 평가→61 pose→1차 실제 검수→담당 agent 피드백→통합 후 재검수를 마쳤다. FILO의2차 결과는 기각하고 무기·팔의 원본 자세를 함께 유지하는3차 보정을 수락했다. 샷건 음원 분리 후 전체/실제 부분/발사 중단도 다시 검수했다. 전체 무기 goal은 계속 활성이다.

## 원본 평가

SSD의 source.blend 다섯 개를 독립 headless Blender 5.4 alpha에서 열어 실제 action/유일 slot을 선택했다. 상완 원점→팔꿈치→손목의 직접 부모 관계를 확인했다. 장전11개 action을 원래 frame range에서61 pose로 평가하고 idle/ADS1 pose를 유지했다. 이전21 pose에 해당하는 위치는 모두 오차0으로 재평가됐다. 원본 .blend/source-map/bone-map과 평가 전 캐시 해시를 기록했다. 원본은 저장하지 않았다.

원본에는 Armature만 있고 메시·카메라는 없다. armature_object 행렬(row-major, column vectors)을 사용하며 object matrix_world를 다시 적용하지 않는다. x32는 기존 모델 단위 보정이지 원본 미터 증명이 아니다. Beloved/자동소총/샷건 selector의 공유 action을 정확한 무기 전용 카메라·이벤트로 주장하지 않는다.

## 적용

W209의 sourceFullChain 경로를 이번 다섯 profile에만 명시적으로 켠다. 무기 본의 rest-relative 이동과 팔 방향/손목 이동을 같은 무기 부모 좌표에서 합성한다. 중립 메시 파지점은 보존한다. 정상 길이의 실제 플레이어 스킨 상완/전완을 붙이고 손가락은 만들지 않는다. 어깨를 새로 읽은 공유 캐시만으로 다른 무기의 상완이 자동 출력되지 않도록 출력과 manifest를 모두 profile로 제한한다.

이자나기는 CMD6 일반0..1 / Honed2..3 / 충전 idle4의 기존 분기를 유지한다. 샷건 원본의 일반 full reload에는 탄별 삽입 이벤트가 없다. FILO의 contacts.reload.sourceShellPoseHold=true는 initial에서 원본 .35 port 자세로 접근하고, loop에서 무기 본과 양팔의 원본 샘플을 함께 유지한다. return에서는 같은 자세를 smooth weight로 기본 파지에 직접 혼합한다. 일반 장전의 큰 총몸 회전과 원본 상완이 서로 다른 좌표를 따라가는 문제를 피하기 위한 명시적 저작 리타깃이며, 추출된 탄별 이벤트 재생이라고 주장하지 않는다. 기존 탄 가시성/탄 이동/게임플레이 시간은 유지한다. contacts.reload.sourcePalmContactFit=true는 기존 handling weight로 왼손을 탄 접촉점에 맞춘다. 원본 굽힘과 정상 팔 길이는 유지하며 정확한 원본 손목 경로 재생은 아니다.

## 작업 책임과 검수

무기별 agent는 독립 worktree의 profile/review 두 파일만 소유한다. master가 공유 알고리즘·캐시·생성물·빌드·CU/Vision을 소유한다. 1차 실제 PNG/입력 검수→담당 agent에 캡처/문제 구간 전달→반환 수정 통합→2차 동일 시나리오 검수 순서를 지킨다. 1차 양호하더라도 담당 agent에 검토를 보낸다.

대상 검수는 hip의 파지, 장전의 부품 접촉과 팔 단면/가림, ADS 조준부, 복귀다. 이자나기의 일반/Honed와 샷건 삽입 반복/부분/중단은 별도 기록한다. 명령 완료와 화면 수락은 별도다. 원본61은 바닐라60fps 보간 인증이 아니며 범위 밖 무기/스킨/3인칭/오디오/성능을 검증했다고 하지 않는다.

증거: [W210 QA](../qa/2026-10-28/w210/README.md). 실제 출력 요소는 생성 manifest에서 조립체당1000 이하를 확인한다. 최종 통합·검수 후 고유 worker delta를 보관하고 필요 없는 완료 worktree만 같은 배치에서 제거한다.

후속 사용자 요청으로 샷건 장전 소리를 분리했다. 시작의 긴 전체 클립 대신 실제 탄 이동마다 짧은 삽입 cue를 보내고, 마지막 자연 종료에는 삽입+마무리 cue를 한 번 보낸다. 발사 중단을 종료로 오인하는 timer/`!reloading` 판정은 없다. 다른 무기군과 탄약/장전 시간은 유지한다. [오디오 구현·검증](../qa/2026-10-28/w210/AUDIO_FIX.md)에 출처·실패 fixture·최종45개 자동 검사·Vision3개·미청취 한계를 기록했다.
