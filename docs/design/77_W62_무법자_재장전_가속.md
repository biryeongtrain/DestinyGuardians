# W62 — 무법자와 실제 재장전 가속

## 범위와 사용

무법자(Outlaw)를 정밀 처치·실제 재장전 시간·버프 HUD에 연결한다. 정확한 선정 무기 hash63개 중13개만 지원하며,
12개는 공식 randomized trait pool, Halfdan-D 1개는 고정 초기 소켓이다. fake reusable set650을 랜덤 풀로 취급하지 않는다.
기본 부여/강화형/경이/검/프리뷰/다른 이름동일 버전은 제외한다. 또 다른 기본 hash1528281896도 조사했지만 선정 소켓에는 없었다.

```text
/destiny perk list
/destiny perk select outlaw
/destiny perk select kill_clip
/destiny perk status
/destiny perk clear
```

일반 플레이어가 소유한 실제 무기의 공식 허용 소켓만 변경한다. 무기/탄약을 생성하지 않는다.
Duke Mk.44(Outlaw2/KC4), Bygones(4/3), Blast Furnace·Claws of the Wolf·Lonesome·Dead Man Walking·Apostate(3/4)
7종은 KC와 공존한다. Chattering Bone은 둘 다3번 소켓이므로 교체한다.
완전한 획득 경제·랜덤 롤·제작 시스템은 여전히 별도 목표다.

## 근거와 수치

- [공식2.9.0](https://www.bungie.net/7/en/News/article/49188): 과거+100→+50, 시간배율0.8→0.9, 재장전 stat의 범위/곡선과 scalar 구분.
- [공식3.0.0.1](https://www.bungie.net/7/en/News/article/49819): 이후+50→**+70**. 오래된+50을 현재 계약으로 사용하지 않는다.
- [light.gg 정확한 기본형](https://www.light.gg/db/ko/items/1168162263/outlaw/): **6초**, 수납 시 제거는 커뮤니티 연구이다.
  강화형7초를 적용하지 않는다.6초는 서버20Hz에서120tick으로 변환한다.
- [공식 소켓 근거](../../art/weapons/w62/references/socket-pools.json), [근거 등급/미확인](../../art/weapons/w62/references/mechanics.json),
  [시간 계산](../../art/weapons/w62/references/reload-timings.json), [입력SHA/재현](../../art/weapons/w62/references/provenance.json),
  [읽기 전용 추출기](../../scripts/extract_outlaw_w62.py).

실제 선택된 무기의 공식 Reload Speed4188031367을 읽고 `r=min(100,base+70)`로 계산한다.
기존 W46의 고정된 oracle_engine 커뮤니티 곡선에 `r`을 넣고, 초 단위 결과에0.9를 곱한 뒤 **한 번만**20Hz 올림한다.
`ceil(20*0.9*(evpp*r*r+vpp*r+offset))`이다. 기존 정수tick에0.9만 곱해+70 효과를 누락하지 않는다.
예: Duke 기본59tick→33tick, Austringer33, Halfdan23, Bygones24, Apostate40, 두 산탄총 반복 삽입9tick.
W46 곡선은2026-05-20 커뮤니티 근사로, 현재 원작 모든 롤/빈 탄창/모드/정확한 탄약 이동시점의 실측은 아니다.

## 실행과 소유권

- 무기 피해 거래에서 실제 final blow와 정밀 성분이 확정되었을 때 발사 원본 세션에만120tick을 부여/갱신한다.
  단순 정밀 명중/몸통 처치/능력 처치/근접/로켓 폭발은 무법자를 부여하지 않는다.
- 세션은 owner/level/실제 ItemStack에 묶인다. 수납·같은tick 교체 후 복귀·다른 실물/소유자·사망/접속 종료/차원/관전/궁극기는 이전 버프를 복구하지 않는다.
- 실제 재장전 시작에서 유효 계획을 캡처한다. `WeaponCycle`은 원래 탄창/삽입 단위·탄약 비용·사격 deadline을 유지하고 시간만 바꾼다.
  수동Q·빈 탄창 자동 재장전은 같은 경로이다. 가득 찬 탄창/예비탄0을 채우거나 새 사격을 예약하지 않는다.
- 기존 탄약 HUD/장전 진행/해당 모델 progress는 캡처한 실제 phase를 사용한다. HUD 조회는 새 세션 생성/탄약 이동/버프 연장이 없다.
- KC는 원래대로 실제 재장전 완료 때만 발동한다. 서로 다른 공식 소켓이 허용하는 경우 무법자 가속 장전 후 KC가 이어진다.
  ALH의 수납 장전과 명사수 즉시 탄약 이동 자체를 시간제 장전 애니메이션으로 바꾸지 않는다.
- 특성 명령은 원래 NBT 소켓 이관 정책을 유지하며 실제 변경 때 관련 transient 버프를 비운다.

## 아직 실측되지 않은 통합 정책

1. 진행 중 장전은 시작 때 캡처한 전체 시퀀스의 시간으로 끝낸다. 도중 만료/새 정밀 처치가 deadline을 당기거나 늘리지 않는다.
2. 버프는 장전에서 소비되지 않는다.120tick 안에 새로 시작한 장전들은 사용할 수 있고 새 정밀 처치는120tick으로 갱신한다.
3. 두 산탄총 첫 삽입9tick은 기존 W46 first=repeat fallback을 유지한 **자체 정책**이다. 커뮤니티 반복 삽입 곡선이 정확한 첫 지연을 증명하지 않는다.
4. Parcel의 혼합 pellet 거래는 확인된 정밀 성분이 있는 실제 처치를 정밀 거래로 분류한다.
   원작의 lethal pellet 순서/혼합 판정은 미확인이다. 로켓 splash를 정밀로 취급하거나 소유권을 다른 총으로 넘기지 않는다.
5. 원작 정확한 reload animation/탄약 이동 지점/오디오 타임스트레치까지 재현한 것은 아니다. 기존 원본 음원과 cue를 보존한다.

위 항목을 원작 확정 사실로 보고하지 않는다. 전체 목표 완료의 근거로 쓰지 않는다.
