# H22 — 공허 활 시위가 당겨진 상태 유지

## 요청·해석

H21 체공 화면을 본 사용자가 “시위가 당겨지지 않아 보인다. 처음부터 당겨진 모델도 괜찮다”고 요청했다.
H20의 geometry에는 실제4단계 V 시위가 있지만, ready는 직선 rest이고 최대 draw는 T+6 부근의
매우 짧은 구간뿐이다. T+7에 즉시 rest로 바뀌므로 화면 대부분에서 당긴 실루엣을 읽기 어렵다.
geometry 자체가 전혀 없었다고 단정하지 않는다.

사용자가 허용한 **궁극기 준비부터 pre-drawn 유지**를 선택했다. 활만 교체해 손을 시위에서
떼어놓지 않도록 상체도 기존 full-draw 포즈로 맞춘다. H21 웅크림/도약, 후방3인칭 중앙 구도,
실제 T+7발사와 aim·피격·낙하 정책은 유지한다.

## H22-S1 — 비파괴 저작

`scripts/build_shadowshot_h22.py`는 신규 파일만 생성한다.

- `art/blockbench/animations/guardian_hunter_h22.bbmodel`
- `src/main/resources/destiny/animation/hunter_h22.animation.json`
- `art/blockbench/supers/shadow_bow_h22_drawn.bbmodel`
- `src/main/resources/assets/destiny/models/item/shadow_bow_h22_drawn.json`
- `src/main/resources/assets/destiny/items/shadow_bow_h22_drawn.json`

Rig/skin·나머지17clip은 H21과 동일. Void 두 clip도 네 다리/cape 곡선은 보존했다.
Ready 전체와 attack .00~.30의 상체를 기존 H21 .25 full-draw 포즈로 고정한다.
오른손은 볼 옆 nock, 왼손은 grip에 유지한다. 이후 기존 follow-through를 거쳐 새 ready로 복귀한다.
RootY만 동일한 floor-fit으로 다시 계산하며 .30의 전체 포즈는 H21과 정확히 같다.
따라서 eyeY−.2098875m 상대 발사원점 보정/실제 서버 hop에는 변경이 없다.

새 활은 기존 H20 stage3의 V 시위를 유지한다. 두 cord의 중심선/끝점/arrow nock는 그대로,
단면은 .08×.10→.24×.24 model units로 보강하고 기존 texture의 밝은 연보라 작은 UV를 사용한다.
활 몸체 디테일·기존 텍스처 파일·arrow geometry·native handed transforms는 보존한다.
새 emissive shader/원작 메시/텍스처 추출은 아니다.

```sh
rtk proxy python3 -B scripts/build_shadowshot_h22.py
rtk proxy python3 -B scripts/build_shadowshot_h22.py --verify
```

정적 검사: ready 전체 및 pre-release를 .005초 간격 FK로 검사해 hand–nock/cheek gap<.0001
model units, 화살 정면 유지. 두 V 절반은 같은(16.24,8,8)nock로 만난다.
이는 저작 검사이며 실제 native 전송/화면 인수와 구분한다.

## H22-S2 — 런타임 연결

- 선택 모델/리소스 H22, `CREATE_NEW` 유지. 설치 H21/H20/H19/H15 덮어쓰기 없음.
- `SuperVisuals.item(VOID)`/`drawnBow()`/`bowStage(0..3)` 모두 새 pre-drawn 모델.
  기존4단계 API는 호환되지만 시각 상태는 모두 taut이다.
- 실제 T+7 release는 `releasedBow()`의 기존 H20 rest/무화살 모델로 교체한다.
  발사 이후에도 nocked arrow가 손에 복제되어 남지 않는다.
- 실제 contact regression은 hard-coded H20 stage 파일 대신 **현재 선택된 stack의 모델 JSON**을 읽는다.
  기존 엄격한 native contact 오차 상한은 완화하지 않는다.
