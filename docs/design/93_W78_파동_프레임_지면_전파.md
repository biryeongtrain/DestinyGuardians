# W78 — 파동 프레임 지면 전파

## 범위와 출처

Deafening Whisper(981718087)의 Wave Frame1395789926과 Dimensional Hypotrochoid(1311684613)의 Compressed Wave Frame2571259936을 실제 발사 경로에서 구분한다. 다른 일반 유탄·로켓·검 투사체는 기존 동작을 유지한다.

[출처 조사](../../art/weapons/w78/reference-notes.md)의 공식 manifest와 패치 이력에 따라 **지면 접촉 → 전진 파동**을 구현한다. 특수탄 파동15m는 Bungie8.0.0.1의 발표값이며2026현재 샌드박스의 전수 실측값이라고 하지 않는다. 중화기 파동 길이는 미확인이다. 과거 heavy width+40%를 special 대비1.4배로 오해하지 않는다. 선정된 두 무기의 base Blast Radius는 모두50이다.

| 값 | Deafening Whisper | Dimensional Hypotrochoid | 근거 경계 |
|---|---:|---:|---|
| 전파 길이(block) |15|12|special은 발표15m를1:1대응,heavy는로컬설계|
| 폭(block) |3|5|로컬설계,원작절대치미확인|
| 속도(block/tick) |0.75|1|로컬설계,Velocity stat의물리변환아님|
| 높이(block) |1.5|1.5|로컬설계|
| 직접/파동 피해 |기존profile의0.2배/1배|동일|Minecraft HP튜닝,원작split복제아님|

원작은 impact/detonation/self-damage가 전혀 없다고 주장하지 않는다. 이번 PvE 모드는 임의의 구형 대인 폭발을 추가하지 않고, 직접 접촉과 지면 파동을 분리한다. 현재 self/PvP 피해는 제외한다. 공허/시공 색이 volatile/slow/freeze를 자동 부여하지 않는다.

## 실행 계약

- 기존 WeaponRuntime의 유료 발사/탄창/발사주기/자동 장전은 그대로 사용한다. 파동에 추가 탄약 비용이나 재지급은 없다.
- 각 파동은 원래 Shot 내부에 존재한다. 발사 때의 무기·피해/perk 토큰·탄약 처치 귀속을 유지한다. 수납해도 날아간 탄은 다른 무기의 속성으로 바뀌지 않는다.
- 위쪽을 향하는 실제 collider 면에 착탄해야 전개된다. 벽/천장/전투원 반사는 역사적 커뮤니티 관찰을 참고한 로컬정책(감쇠0.65,최대6회)이다. 직접 접촉 피해와 이후 한 번의 wave 접촉은 별도 성분이다.
- 조준 직후 카메라 방향을 다시 읽지 않는다. 수직 발사는 발사 시의 수평 yaw를 fallback으로 사용한다.
- 사망/제거/관전/차원 불일치 및 명시 cleanup으로 종료한다. 활성 파동도 기존 플레이어당16프로젝트타일 cap과100tick lifetime 안에 포함된다.
- 각 wave의 대상 identity 집합으로 중복 접촉을 제거한다. 여러 유저/서로 다른 wave 사이에 공통 면역 timer를 만들지 않는다.

## 지형과 피해 판정

전방0.25block,폭 방향 최대0.5block 간격의 lane으로 실제 collision-shape 지면을 조사한다. 최대0.6상승/1.0하강,반블록 slab은 추종하고 지원면이 없거나 벽이면 해당 lane은 멈춘다. 연속 지형 메시 전체를 복구한 것은 아니며 아주 작은 틈/복잡한 곡면은 이 이산 규칙의 한계다.

처음 lane도 impact에서 옆으로 실제 지원면/충돌 연결을 확인해 생성한다. 단순히 먼 옆 좌표에 땅이 있다는 이유로 벽/갭 너머에 파동을 새로 만들지 않는다. 매 tick의 swept strip과 실제 target AABB를 수평4축 SAT 및 수직 겹침으로 비교하고, collider LOS를 별도로 확인한다. 플레이어/동맹/길들인 동물은 제외한다. 지형 파괴·화염·블록 변경은 없다.

clip 전에는 실제 ray 전체의 chunk rectangle을 확인한다. native traverseBlocks의 displacement×1e-7 endpoint 확장을 포함한다. 기존 비행 loadedEnd도 실제 전체 ray 또는 반환할 prefix를 검사한다. 일부 불필요한 이웃 chunk까지 보수적으로 요구할 수 있지만 새 chunk를 로드하지 않는다.

후보 처리/누적 접촉은128로 제한한다. 이 값은 최초 entity spatial enumeration/sort 자체를128로 만드는 것은 아니다. 최대 부하 검증을 대신하지 않는다.

## 연출·검증 경계

기존 무기 모델/텍스처/HUD/Ogg는 변경하지 않는다. 기존 제공 archive의 유탄 impact 음향을 지면 전개 시 한 번 사용하고, 공허/시공색 raised particle crest로 진행 위치를 표시한다. 원작 전용 wave mesh/화면효과/음향 일치나 실청취 완료가 아니다.

검증 단계·실패·최종 수치는 [W78 QA](../qa/2026-10-24/w78/README.md)에 기록한다. 초반 새 SNBT fixture의 palette 변환 문제와 공통 HunterTest scoreboard 이름 경합은 생산 피해 결함과 구분한다. 원래 테스트 assertion을 제거하지 않는다.

전체 무기·경이 특성·개별 애니메이션·HUD 완전 일치·정확 음원·다인 성능 목표는 계속 active다.
