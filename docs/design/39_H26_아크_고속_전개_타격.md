# H26 — 아크 고속 전개와 강한 타격

## S1 요청 / 작업 경계

사용자: 전개와 휘두름이 느리다. 실제 게임플레이의 역동적인 리듬을 참고한다.
H25 전기/공허 에너지와 H24 지팡이를 보존하며 Arc 전개·공격만 수정한다.
후방 서버카메라, 바닐라 입력/물리, 공허/솔라/일반스킬은 유지한다.
기존 H15~H25 아트/설치파일은 덮어쓰지 않고 H26 신규 버전을 설치한다.

## S2 목표 타이밍 (마인크래프트용 설계값, 원작 실측 주장 아님)

- 예비동작은 짧게, 지팡이 각속도는 타격 구간에 집중, 관성 잔동작은 짧게 회수.
- 전개에도 실제 강한 휘두름을 넣고, 첨부했던 넓은 웅크림/가로 지팡이 실루엣은 짧게 유지.
- 접점과 서버 피해/번개 잔광은 같은 계약. 공격속도만 바꾸고 피해·사거리·지속시간은 유지.
- 신규 자동검증: 선택 리소스, 타이밍 계약, 변경범위, 큰 각변위/짧은 타격구간,
  실제 BetterModel 중간프레임 양손 접점과 기존 입력 잠금/중복/취소 회귀.
