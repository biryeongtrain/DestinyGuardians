# W283 GCB 마우스 입력 및 무기군 실습

## 제품 동작
- 설치 감지는 기존 GCB handshake/version을 사용한다. GCB-mod의 KEY_ATTACK / KEY_USE 눌림과 해제로 각각 발사와 홀드 ADS를 구동한다. 바닐라 입력은 변경하지 않는다.
- GCB 글레이브는 좌클릭 투사체, 우클릭 무료 근접, Shift 방패. 검은 기존 좌클릭 약공격 / 우클릭 강공격 / Shift 가드다.
- native use/release/punch는 GCB 총기 발사를 중복 실행하지 않는다. 버튼별 exact item/level token으로 활·원격 유탄 해제 소유권을 구분한다. 메뉴/스킬/무기 교체/접속 종료는 발사 없이 취소한다.
- 기존 GCB는 채팅/일시정지/포커스 상태를 보내지 않는다. 클라이언트 변경 없이 이 순간을 서버에서 관측할 수 없다. 해제 누락으로 무한 사격하지 않도록 한 번의 좌클릭 홀드를 300 server ticks(20 TPS에서 15초)로 제한한다. 만료 후 실제 해제/재입력이 필요하다. 이 제한을 즉시 GUI 취소라고 주장하지 않는다. ADS는 실제 KEY_USE 해제까지 유지된다.

## 튜토리얼
기존 사격→정조준→재장전 뒤 무기군 실습(ARSENAL)을 추가한다. 전체 단계는 15개이며 재접속 이수 정책 revision 1은 유지한다. 이미 이수한 계정에게 새 이수를 강제하지 않는다.

일반탄: 핸드 캐논 / 자동 소총 / 파동 소총 / 정찰 소총 / 기관단총 / 보조 무기 / 활.
특수탄: 산탄총 / 저격총 / 융합 소총 / 추적 소총 / 유탄 발사기 / 글레이브.
중화기: 기관총 / 중화기 유탄 발사기 / 로켓 발사기 / 선형 융합 소총 / 검.

각 항목은 실제 카탈로그 대표 무기 한 개와 거리별 표적 한 개를 사용한다. 현재 연습 무기로 탄약을 소비하고 직접 표적을 처치해야 진행한다. 설명을 읽을 시간이 끝나고 발사 입력이 해제되어야 교체한다. GCB는 조준 버튼도 놓아야 한다. 이전 무기의 홀드가 다음 무기의 공격으로 이어지지 않는다. 대여 무기를 들고 있지 않거나 해당 실습에서 탄약을 소비하지 않은 처치는 다음 무기로 넘기지 않는다. 탄약 소비 뒤 같은 무기를 든 채 능력으로 마무리하는 경우까지 피해 종류로 구별하지는 않는다.

일반탄 무한 예비와 유한 탄창, 특수탄 녹색 보급, 중화기 보라색 보급을 설명하며 장비 슬롯과 탄약 종류가 별개임을 안내한다. 새 설명은 자막이며 기존 한국어 음성을 임의로 새 대사로 재사용하지 않는다.

## 장비 및 비용
원래 3개 장비 슬롯/선택 슬롯/loadout 상태를 persistent attachment에 보관하고 대여품에 소유 UUID를 표시한다. 완료/중단/접속 종료/다음 접속 복구에서 원래 장비를 반환한다. 실습 중 장비 편집 창은 막는다. 새로 얻은 별도 아이템은 보존한다. 대여품의 바닥난 탄약만 보충한다. 표적은 동시 1개, 대여 무기는 1개이며 다음 실습 전 발사체와 이전 표적을 정리한다. 원본 자산/클라이언트 소스 변경은 없다.

운영자 전용 `/튜토리얼 단계 <family>`로 각 무기 실습을 재현할 수 있다. 예: `linear_fusion_rifle`. 기존 단계 생략과 동일한 권한이며 장비 보관·복구 경로를 그대로 사용한다.
