# W212 — 기관단총·파동소총 원본 리그 장전

대상: Antiope-D, Bug-Out Bag, Cold Denial, Bygones. 기존 무기의 외형·UV·조준경·탄약·장전 시간·사운드를 유지하고, 원본 팔 체인과 61포즈 장전 표현을 연결한다. 헌터/무기/HUD 전체 목표의 일부 배치이며 전체 구현 완료를 뜻하지 않는다.

## 원본 평가

- 별도 background Blender 5.4.0 Alpha에서 SSD의 원본 `source.blend`를 열어 action/OBSlot, weapon·shoulder·elbow·wrist를 평가했다. 원본·매핑·기존 캐시 공통 샘플의 최대 오차는 0, 입력 파일 해시는 평가 전후 동일하다.
- 기관단총 `submachine_gun_cdf8185c`: 장전 `80A8A170`, 원본 1..91프레임, 21→61포즈. idle `80A8A16E`, ADS `80A8A177`.
- 파동소총 `pulse_rifle_b4d01502`: `80A8A36A`, `80A8A368`, `80A8A366`을 각각 61포즈로 대조. 이번 후보는 명시적으로 `80A8A36A`를 선택한다. 원본 범위 1..105. idle `80A8A422`, ADS `80A8A330`.
- 두 파일 모두 Armature만 있고 메시·카메라는 없다. 공유 무기군 리그이므로 해당 무기 고유 애니메이션/원작 카메라 복원으로 보고하지 않는다. 실제 손 접촉은 현재 무기 의미 부품에 맞춰 검수한다.

원본 보고서와 본 검토 PNG: [W212 source](../qa/2026-10-28/w212/source/source-review.json). SSD 원본은 수정하지 않는다.

## 구현과 검수

- 4개 독립 worktree에 무기별 generator/profile/review만 배타 배정한다. dirty 제품 입력 140,599개를 독립 inode로 복제했다. master는 shared profile loader, 리그 캐시/action 선택, runtime routing, 손 overlay 생성과 게임 검수를 담당한다.
- 신규 `weapon_reload_w212_<id>`는 61포즈/60구간을 사용한다. 기존 영상 기준 움직임의 hold와 의미 부품을 보존하며 이동 구간은 C1 Hermite 곡선으로 연결한다. ADS/inspect, 음수 inactive, 비1인칭 fallback을 보존한다.
- 원본 어깨→팔꿈치→손목 체인을 사용한다. 손가락 없는 사용자 스킨 팔을 유지하고, 팔 길이를 늘려 접촉 문제를 덮지 않는다. 동시 출력 요소 상한은 팔 포함 1,000개다.
- 필수 순서: 원본 Blender 확인 → 61포즈 → 첫 Vision → 담당자에게 정확한 검수 이미지/수정 요청 → 통합 → 두 번째 Vision.
- 시나리오: 각 무기 native 발사, 빈 탄창 fixture 후 native 장전, ADS, 기본 파지 복귀. fixture는 서버 준비이며 실제 입력 증거와 구분한다.

첫 Vision4종 검수와 담당자 피드백을 마쳤다. Antiope-D·Bug-Out Bag은 좁은 탄창이 block palm에 가려지는 문제를 측면 파지점으로 보정하고, 원본 이동에 중복되던 extra 하강2.5를 제거했다. Antiope는 탄창 안착 뒤 source support hand가 foregrip으로 복귀하는 .60..70에 attachment를 해제한다. 파동소총2종은 검수 근거상 no-change다. 통합 후 두 번째 Vision도 완료했다. 4종 실제 발사·장전·ADS12시퀀스, 장전 후30/36/28/38발 복귀 및 입력중립을 확인했다. 관련 JUnit13/13, source binding1/1, 최종 build를 통과했다. master가8개 실제sheet와SMG raw3개를 검수해 수락했다. 실행 결과·수정·제약·worktree 정리는 [단계 로그](../qa/2026-10-28/w212/step-log.md)에 누적한다. 61포즈와 서버 갱신은 바닐라 60fps 연속 보간 보증이 아니다.

최종 판정과 미검증 범위는 [실제 화면 검수](../qa/2026-10-28/w212/visual-review.json)에 기록했다. Pulse2종의 상단muzzle crop은 후방handling이 보이는 현재 구도로 유지한다. 원본은 공통 bone-only 리그여서 mesh carrier/hold와 합친 표현이며 exact finger/magazine IK 또는 continuous60fps 보증이 아니다.
