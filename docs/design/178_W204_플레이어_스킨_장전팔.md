# W204 — 플레이어 스킨으로 보이는 1인칭 손·전완

## 사용자 요구

실제 플레이어 스킨의 손으로 장전한다. 손가락은 만들지 않고 Minecraft 기본 팔 실루엣을 사용한다. BetterModel·Stable Player Display·Danse의 구현을 확인한다. 처음 제안한 유저별 텍스처 ZIP/추가 팩 방식은 사용자 지시로 폐기했다. 폐기한 코드는 recovery에 격리했으며 제품에 연결하지 않는다.

## 선택한 구현

설치된 BetterModel 3.5.1 `SkinManager.complete` → `SkinData.rightForeArm/leftForeArm`의 DynamicUV 색 데이터를 사용한다. 공통 모델 하나와 outgoing CustomModelData 색 배열로 표현한다. 스킨별 리소스 팩·재접속·팩 재수락은 필요 없다. BetterModel이 기존에 제공하는 비동기 스킨 조회/캐시를 이용하며 packet encoding 중 HTTP 대기를 하지 않는다.

- 기본 팔은4×6×4, slim 팔은3×6×4의 하반부 스킨 영역을 사용한다. 닫힌 손끝과 짧은 전완이며 분리된 손가락은 없다.
- 현재 전완의 위쪽 열린 단면을 제외한 픽셀 면 수는 classic112, slim96개다. 양팔 최대224개를 기존 무기 조립 예산에 합산한다.
- CMD flag8=스킨 준비, flag9=slim; colors64..175=오른팔,192..303=왼팔이다. 기존 float/flag0..1/string/color 앞부분을 보존한다.
- 소매 레이어는 BetterModel의0/1/2 alpha 구분에 따라 기본 표면 색에 합성한다. 소매의 별도 돌출 두께는 구현하지 않는다. 실제 색과 소매 표시 설정을 반영한다.
- 스킨 요청과 수신은 서버 tick에서 관측한다. 완료 callback은 inventory·게임 상태를 변경하지 않는다. 완료 시 선택 슬롯만 재전송하며 권한/탄약/서버 ItemStack은 바꾸지 않는다. 같은 UUID 재접속도 실제 player 객체를 구분한다.
- W201 접촉 프레임을 유지한다. 본체 손잡이는 오른손, 탄창·실린더·장전 부품은 왼손이 따라간다. 활 시위 경로와 ADS·이자나기 경로도 기존 그래프를 재사용한다. 3인칭/GUI/바닥 등은 기존 그래프 그대로다. 검/궁극기 전용 표시에는 적용하지 않는다.
- 스킨이 준비되지 않았거나 수신에 실패하면 다른 유저/헌터 장갑으로 대체하지 않는다. 텍스처가 없는 UUID는 vanilla 기본 스킨 선택 규칙에 맞는 공통 기본 팔 데이터를 사용한다.

## 리서치 판단

[BetterModel](https://github.com/toxicity188/BetterModel)의 현재 구현과 설치된3.5.1 API를 함께 확인했다. 팔 limb는 DynamicUV 색 배열과 공통 모델을 사용한다. 기존 전신 tracker를 1인칭에 그대로 표시하면 머리·몸통과 카메라 충돌이 생길 수 있어 사용하지 않았다. 직접 player limb 데이터를 이용해 기존 무기 표시 그래프에 결합한다.

[Stable Player Display 26+](https://github.com/vladislavvc/stable_player_display)는 profile이 붙은 player_head special renderer와 Y marker를 해석하는 entity shader로 스킨 UV를 이동한다. CC0이며 해당 fork의 명시 지원은26.2다. 배포 모델은 thirdperson_righthand 기반이므로26.3 native firstperson으로 바로 적용된다고 단정하지 않는다. 공통 core shader 교체와 기존 셰이더 병합이 필요한 대안으로 남겼다.

[Danse](https://github.com/tomalbrc/danse)는26.3 서버사이드 스킨 팔을 지원하고 픽셀별 tint/CMD 경로를 사용한다. 현재 root license는 AGPLv3다. 해당 코드를 복사하지 않고 BetterModel의 기존 public API와 별도 작성한 자산 생성기를 사용한다.

[TheFirstPerson-BetterModel](https://github.com/RTUStudio/TheFirstPerson-BetterModel)의 기본 브랜치는 오래된 BetterModel fork이며 README만으로 현재26.3 1인칭 구현을 증명할 수 없다. 실제 적용 근거로 과장하지 않는다.

세부 소스 경로·커밋·셰이더 조건은[리서치 기록](../qa/2026-10-27/w204/skin-render-research.md)에 남긴다. 최종 수행 검사·실화면 범위는 같은 QA 폴더 README에 기록한다.

## 자산 검사 중 보정

첫 생성의 pretty JSON은 약2.07GB였고512MB JUnit 모델 파서에서 OOM이 발생했다. 1인칭 실행이 확정된 그래프에서 다른 display context 분기를 제거하고 중복 동일 조건을 접은 뒤 JSON을 compact 직렬화했다. 생성 wrapper239개 합계는478,688,520bytes이며 별도 스킨 팩은 아니다. 후속 모델 codec 포함 targeted33개가 통과했다. 프레임별 tint 중복은 vanilla 스키마 한계로 남아 있어 native 실제 팩 로드·메모리/화면 검증을 별도로 한다.
