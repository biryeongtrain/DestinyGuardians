## Vision 실화면 (GCB 클라이언트)
| 단계 | 확인 | 화면 |
|---|---|---|
| 각성 | 어둠 효과, 고스트 등장·대사, 마우스 안내 | 01-awaken |
| 이동 | 실제 W 입력으로 걸으면 첫 문 열림 | — |
| 직업 | 원 3개·아이콘·색·설명 패널, 서 있으면 선택(워록) | 02-class-hall |
| 빛 | 회전 파편, 아크 선택 → 섬광·토스트 | 03-light-shard |
| 무장 | 장비 창 안내, 시간 초과 시 기본 무기 지급 | 04-equip |
| 사격 | 실제 우클릭 사격으로 표적 처치 카운트 | 05-range |
| 정조준·재장전 | 실제 좌클릭/장전 입력으로 진행 | — |
| 기동 | 실제 질주 12블록, 공중 활공, 틈 건너기 | 06-traverse |
| 수류탄·근접·직업 능력 | 해금 전 사용 거부, 해금 후 사용 시 진행 | 07-grenade |
| 궁극기 | 훈련장 입장 시 에너지 가득, 발동·적 6기 | 08-super |
| 완료 | 빛의 문 진입 → 「전설이 되십시오」 → 타워 이동 | 09-finish |

능력 단계(수류탄·근접·직업 능력·궁극기)는 `/guardian action`으로 같은 InputRouter 경로를 호출해 검증했다. 키 입력 자체는 기존 GCB/바닐라 경로를 그대로 쓴다.

## 수정한 문제
- 고스트가 카메라에 붙어 화면을 가림 → 엔티티 부착 오프셋 대신 디스플레이 변환으로 시야 앞 오른쪽에 배치.
- 자막이 길면 줄바꿈이 위로 넘침 → 직접 줄바꿈, 마지막 줄 기준 배치.
- 단계가 바뀌어도 이전 단계 대사가 남음 → 새 단계 진입 시 이전 대사 제거.
- 포털 뒷벽 구멍 → 막음.

## 미검증
