# W286 PvP 특수·중화기 피해 조정

2026-10-31 사용자 지정 밸런스. 원작 DDC 확정 수치가 아니라 Minecraft 로컬 PvP 정책이다. 기존 W263/W267 출처 테이블을 보존하고 서버의 플레이어 대상 피해 변환에서만 별도로 적용한다. 클라이언트 변경 없음.

## 기준

20 HP 플레이어, 피해 증가 퍽·추가 보호막·궁극기/지원 필드 피해 감소가 없는 상태. 기존 maxHealth 비례 정규화 유지. 아래 수치는 Minecraft HP이며 기존 PvP 피해 숫자 HUD는 230 기준 표시를 유지한다(16 HP는 HUD184). 거리 감쇠 및 방어 효과를 우회하는 즉사 처리는 추가하지 않는다.

| 종류 | 근거리/유효 사거리 기본 정책 |
|---|---|
| 산탄 샷건 | 산탄당 최소2 HP, 12발 전체 최소24. 5블록까지 감쇠 시작점을 보장. 더 강한 기존 프레임 값 보존 |
| 슬러그 샷건 | 몸 최소16, 머리 최소24. 헤드 조건부 한 방 |
| 저격총 | 몸 최소12, 머리 최소24. 더 높은 기존 피해 보존 |
| 융합소총 | 프레임 공통 투사체당4, 5발 적중 시20. 연사 수/충전 시간/탄약 소모 유지 |
| 특수 유탄 | 직격16. 파동형도 직격/지면 파동 각각16, 같은 플레이어에게 같은 탄의 직격+파동 중복 적용 방지 |
| 글레이브 | 투사체16, 근접10 |
| 추적소총 | 틱당 몸3/머리4, 지속 추적 필요 |
| 기관총 | 몸10/머리12. BB·HH·BH 모두2발 |
| 나머지 중화기 | 직접 명중 몸 최소24. 기존 더 큰 피해 보존. 선형 융합의 점발도 투사체 단위. 검은 유료 기본 공격 기준 |

융합4/특수 유탄16은 기존 환산 피해가 그보다 높았던 경우에도 사용자 요청 고정값을 적용한다. 다른 무기는 위 최소값보다 이미 높으면 유지한다. 일반탄 및 PvE 기본 피해는 변경하지 않는다. 빈 검은 기존3피해 경로, 검 에너지/콤보 배율, 탄약·벽 차단·발사 간격·산포·보호막·궁극기 저항은 유지한다.

## 직격 수정

폭발 중심에서 피해자 몸통 중심까지의 거리로 직격 피해까지 줄던 경로를 수정했다. 실제 EntityHitResult의 PvP 직접 피해자는 전체 피해를 받고, 주변 피해자와 지형/원격 폭발은 기존 방사형 감쇠를 적용한다. 벽 차단 및 한 번의 폭발 순회는 그대로다. PvE의 기존 직격/폭발 계산은 유지한다.

## 검증 범위

- catalogKillThresholdsAndPveIsolation: 등록된 모든 특수·중화기와 일반탄/PvE 분리, 5블록 샷건, 기본 체력/변경 maxHealth, 퍽 배율 보존.
- blastWaveFalloffAndUnpaidSwordBudgets: 직격/주변 폭발, 파동 분할, 검 감소 배율.
- controlActualHealthAndPaidGrenadeDirectHit: 독립 환경 배치에서 실제 로그인·시련의 장 참가·피해 허용 후, 특수/중화기 전수 Combat/hurtServer 체력+흡수 손실, 실제 탄약 소모 유탄 비행/직격, 기관총2회 몸 피해 처치.

자동 서버 검증이며 native 입력·Vision·다인원 밸런스 플레이테스트 증거가 아니다. 이번 변경에서 클라이언트를 실행하거나 장전/궁극기 모션을 재검수하지 않았다.

## 검증 중 수정한 fixture

초기 전수/분리2개는 통과했다. 실제 Control 테스트를 추가한 뒤에는 세 가지 fixture 오류를 수정했다: Combat.damage의 반환값은 명중 여부가 아니라 처치 여부인데 반대로 검사했던 것, 무기 준비 중 ADS 입력을 보낸 것, 매치 중 새 아이템을 넣어 정상적인 탄약 유입 방지에 의해 탄창이 비워진 것. 최종 fixture는 참가 전에 실제 장비를 등록해 첫 생명 탄약을 지급받고, 준비가 끝난 후 ADS를 입력한다. 이 과정에서 제품의 탄약 보호나 준비 시간은 변경하지 않았다.

추가 fixture 진단: 기존 스폰에서 Y+12는 자벨린-4 천장 내부였다. 비행 기록에서 탄이 벽에 반사되고, 피해자 HP 감소의 source가 `inWall`임을 확인했다. Y+64 공중 사격 위치로 옮긴 뒤 플레이어 AABB 충돌 없음·시선 ray 차단 없음·발사 직전20 HP를 명시적으로 검사한다. 천장 내부 시도는 유탄 피해 검증으로 취급하지 않는다.
