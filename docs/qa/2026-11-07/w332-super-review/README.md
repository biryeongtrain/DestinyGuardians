# W332 전체 궁극기 모션 검수

검수 대상은 현재 장착 가능한 궁극기19종이다. 원본조사·재생곡선/패킷 검사·실제 클라이언트 PNG 검수를 구분한다. `source-catalog.*`는 변경 전 연결 상태를 기록한 기준 자료이며, 최종 강공격 입력은 W333의 우클릭이다.

## 구현

- 궁극기 표시 모델의 초기 표시와 매 틱 갱신에2틱 보간을 적용했다. 원본40Hz 평가/서버20Hz 최종 표시와 별도이며, 보간을 공격 쿨타임으로 추가하지 않는다.
- Shadowshot 지상/공중1.3초 원본 포즈, Daybreak 공중 시전1.566667초 Base 원본을 연결했다.
- Nova Warp 충전 대기는 원본의 길이0인 정적 포즈를2초 hold로 구성했다. 충전 종료는1.266667초 Additive 원본을 단독 리타게팅한 근사이며, 미해독 Base 합성을 완전히 재현했다는 의미가 아니다. 기존 충전/공격 수치는 유지한다.
- 설치된 limb 파일은 내용 버전으로 분리하여 이전 CREATE_NEW 파일 때문에 새 동작이 누락되지 않도록 한다.
- 현재 GCB 수신기는 vanilla display entityData에 duration을 전달한다. 별도의 프레임 보간 기능은 확인되지 않아 기본2틱을 사용한다. GCB 실클라이언트 수락 검사는 수행하지 않았다.

## 실제 검수 증거

`native/` 및 `review-ledger.json`, `master-png-review.json`에 다른17궁극기의 지상/공중 시작34시나리오를 저장했다. Master가 각 실제 캡처 시트를 직접 확인했다. 이34회는 RMB/템포 후속 이전 빌드이며, 해당17궁극기의 동작 곡선/경로는 후속 변경 대상이 아니다. Arc Staff/Spectral Blades의 최종 검수는 W333에 기록한다.

관찰 범위는 시전·해당 입력에 반응한 공격 포즈·표시 모델/텍스처·카메라 복귀이다. 지상17회는 자연 종료의 cameraIsPlayer=true까지 추적했다. 공중 시작 뒤 자연 낙하하므로 후반 공격 전체를 공중 공격 검수로 계산하지 않는다. 실제 피해/오디오/모든 렌더 프레임 인증은 이 PNG 검수의 범위가 아니다. 캡처 중 FPS는 대체로20–45였으며60fps 품질을 인증하지 않는다.

기존 한계: Golden Gun은 현재1인칭 일반 총기 실루엣이 남으며 제공 Light 패키지에 전용 원본은 없다. Storms Edge는 목표 없는 플랫폼에서 첫 투척 후 플레이어 시점으로 돌아와3개 목표 연속 순간이동까지 검증한 것은 아니다. Burning Maul 등의 원본 없는 구간은 자체 제작 동작으로 구분한다.

초기 서버 검사는 제품26개+프레임워크1개 중25/27통과했다. 실패2개는 W333 새 콤보 fixture의 공격 전 목표 HP1000→999로 최종 성공으로 처리하지 않았다. 초기 XML을 보존하고 후속 수정/결과를 W333에 기록한다.

최종 수락: 두 근접 궁극기의 수정 후 기본 클라이언트 검수는 W334/W335에 완료했다. 합계19종·지상/공중 시작38시나리오의 실제 master 검수 기록을 최종 ledger에 저장했다. 이는 모든 동작이 원작과 정확히 같거나 모든 중간 프레임/60fps를 인증했다는 뜻이 아니다.
