# W328 — 개인 무기 보관함과 전투 슬롯 제한

최종 범위: 실제 장착 무기1–3은 유지하고, 나머지 무기만 플레이어별 영구 보관함으로 이전한다. E 화면에 장착/보관 무기를 함께 표시하고 원본 아이템을 교환한다. GUI 밖4–9 입력은 발사·장전 lifecycle 전에 취소한다.

## 손 표시 — 사용자 정정 반영

처음에는 전용 무기 손까지 셰이더에서 숨겼으나 사용자가 이를 지적했다. 최종본은 `profile_view/sample.fsh`를 변경 전과 동일하게 복원했다. **파지·ADS·장전의 전용 손을 유지하며, 실제 빈1–3슬롯의 바닐라 맨손만 숨긴다.** 맨손 숨김은 해당 플레이어에게만 보내는 투명 아이템 표시로 구현한다. 서버 인벤토리에 아이템을 생성하지 않으며 GUI에서는 표시용 아이템도 제거한다. 바닐라 팔을 셰이더로 식별해 삭제했다고 주장하지 않는다.

## 구현 메모

기존 과다 보유 무기도 전부 유지하고 페이지로 표시한다. 신규 획득은 기존 무기군별9개 제한을 유지한다. 토큰은1000부터 단조 증가하며, 교환은 정확한 원본객체 소유권을 확인한다. 일반 아이템은 변경하지 않는다. 창고/판매/우편의 보관 무기 선택 경로를 연결했다. 실제 우편 송신이나 경매 게시 검증은 수행하지 않았다.

초기Mixin 패킷 클래스 경로 오류와 두 GameTestfixture 오류를 수정하고 중앙 실행에서 재검증했다. 관리자 gear equip의 전설ID/스킨 충돌도 카탈로그 우선으로 수정했다.

일반 프로필/월드와 원본 리핑 데이터는 건드리지 않았으며 QA는 /tmp/destiny-devils-qa-20261103의 승인된 격리 환경에서 진행했다. 임시 QA클라이언트의 hotbar1–9/E/Q native지원은63JUnit/34Node검사를 통과했으며 제품에 클라이언트 모드를 요구하는 변경이 아니다.

초기 hands-integration.json의 shader discard는 최종 요구사항이 아니다. restore-weapon-hands-manifest.json에 따라 shader가 원본으로 복구됐고 최종커밋에는shader변경이 없다. 첫 실행의 잘못된 손숨김 캡처는 최종손검증증거로 사용하지 않는다.
