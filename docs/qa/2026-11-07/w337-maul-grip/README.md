# W337 — 큰망치 양손 파지 수정

불타는 망치의 양손 위치와 실제 망치 자루 축을 교정했다. 사용자가 지적한 이전 실제 화면은 `native/maul-before-w336.png`, 같은 기본 시점의 수정 후는 `native/maul-idle-08.png`이다. `native/maul-before-after.jpg`는 왼쪽이 이전, 오른쪽이 수정 후인 실제 화면 비교다.

W336은 손목 IK 목표에 도달하는 수치를 확인했지만, 실제 소품 자루와 두 손의 접촉은 제대로 수락하지 못했다. 회전만 리타게팅한 기본 FK 손 위치에 원본 변화량을 더하는 과정에서 Maul의 실제 R2 손 간격이 왜곡됐고 자루 축도 양손 사이와 맞지 않았다.

Maul의 R2 절대 가슴 기준 손목 위치를 리타게팅해 양팔 IK를 다시 풀었다. 실제 아래팔 skin의 끝 손바닥 부피를 구하고, 실제 모델 `continuous_heavy_shaft`의 Y3.6–25.6과 thirdperson +2Y 변환을 반영해 소품을 맞췄다. 왼손은 소매 시작4.75보다0.5 안쪽인 rawY5.25를 잡고, 오른손은 실측 간격만큼 위를 잡는다. 손가락 관절을 새로 복원한 것은 아니다.

첫 두 손 맞춤은 망치 머리가 오른팔에 겹쳤다. 실제 cuboid 부피 검사로 확인한 뒤 손목·몸·무기 회전을 유지하고 소품만 자루 방향으로 옮겼다. 대표 idle3.425초 자세에서 머리와 오른 위팔의 분리 여유0.224u, 아래팔0.484u를 확인했다. 이 검사는 대표 한 자세이며 모든 프레임의 무관통 인증이 아니다. 최종 직렬화된5개 루프496개40Hz/끝점 자세에서는 실제 자루와 두 손바닥 부피의 교차를 확인했다. 자세·정면/측면 렌더와 수치는 `art/animation/w337/maul-grip/`에 있다. 그 폴더의 before 그림은 첫 두 손 맞춤, after는 최종 소품 이동을 비교한다. 원래 한 손이 벗어난 그림과 중간 결과는 `/tmp/w337-maul-grip/first-fit-preserved`에 별도 보존했다.

변경은 Maul 대기·네 방향 이동5개 루프의 팔/아이템 채널에 한정된다. 다른26개 R2 루프의 원시 clip 바이트, Maul의 나머지 본·원본 주기·기존 시전/공격/회피·사운드·게임플레이 코드는 보존했다. 최종 R2 클래스 리소스 SHA256은 `1e4d4811e8e7d04c043fa5e76c97888c99045a92e74707cfb6e0b95fdbb0da99`이다. 초기 delta와 후속 slide-delta를 함께 적용한 결과다.

실제 Gradle 빌드·관련18개 단위/모델 검사를 통과했다. master가 실제 native 입력의 전체 대기 주기, 네 방향과 정지, LMB 공격 후 파지·이동 복귀 시트를 직접 확인했다. 첫 third-front 시점은 너무 가까워 접촉 수락에 사용하지 않았고, 한 번의 낮춘 시선 근접 시점으로 자루와 손 배치를 추가 관찰했다. 실제 머리/팔 가림은 남으므로 모든 각도의 완벽한 손가락 접촉을 주장하지 않는다. 이번 배치에 별도 Maul 강공격·실제 서버 GameTest·GCB 추가 보간·성능 인증은 실행하지 않았다. 현재 화면과 검증 범위는 master-png-review.json에 있다.

R3 타이탄 달리기 작업과 한 번의 통합 빌드·격리 클라이언트 세션을 사용했다. 최종 JAR·명령·정확한 해시는 build-final-validation.json, 팩188,236,924바이트/CRC 통과는 pack-validation.json에 있다. 입력·장비·시점·HUD 복구 후 자기 client/server만 종료하고 임시 pause 값을60으로 복구했으며, 자기 bounded awake wrapper도 종료했다(cleanup.json). 기존 미커밋 변경·일반 Minecraft 프로필·사용자 Blender/Blockbench 작업은 보존했다.
