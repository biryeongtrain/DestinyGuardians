# W327 무기 24종 최적화·실화면 검수

## 범위와 책임

이번에 추가·수정한 W327 24종을 master가 모두 검수했다. 기존 전체 무기 카탈로그 전수 인증은 아니다. 에이전트는 모델·ADS 수정만 담당했고, master가 격리 Minecraft 26.3 클라이언트의 native 입력, 실제 PNG, 서버 탄약 상태를 대조했다. 사용자가 허용한 격리 백그라운드 모드를 사용했다.

## 확인한 항목

- 24종 각각 1인칭, 3인칭 앞·뒤, ADS, 발사, 장전 중간, 복귀 화면.
- ADS와 발사는 native client 입력. 장전 시각 검수는 서버 명령으로 유발했으며 물리 Q키 검증으로 간주하지 않는다. Eyasluna와 단발 무기의 탄창 소진 자동 장전은 별도 화면으로 관찰했다.
- 24종 모두 서버 탄약 소비와 최종 탄창 충전·장전 종료 확인. 원본 결과는 `all24-ammo-evidence.json`.
- 첫 전수 검수 18종 통과, 6종 수정 요청. Rufus·Deliverance·Forbearance의 중앙 조준선 가림, Succession·Cataclysmic의 누락 스코프 참조는 수정 후 master 재검수 통과.
- Subjunctive의 첫 수정은 사용되지 않는 W151 경로여서 재검수 실패. 실제 W153 경로로 교체 후 중앙 조준선·발사·장전·복귀 재검수 통과. 실패 증거는 보존했다.

## 최적화와 팩 로드

23개 조립체의 본체+탄창 요소는 14,694→10,752개, 26.83% 감소했다. 중복 full/body+magazine은 이중 합산하지 않았다. Subjunctive는 이번 요소 감소 집계에서 제외했다.

초기 아틀라스 용량 초과와 두 번째 혼합 아틀라스 오류를 기록하고 수정했다. 최종 라우팅은 실제 모델 면을 동일 아틀라스에 두며, 텍스처 해상도는 이번 배치에서 낮추지 않았다. 잘못된 Subjunctive W151 부모 참조가 전체 미사용 모델 제거를 중단한 용량 증가도 수정했다. 실제 최종 ZIP 바이트·SHA는 `pack.json`, 실제 Gradle assemble JAR 정보는 `build.json`에 기록한다.

## 증거와 한계

- 전체 24종 PNG·native 상태: `/tmp/w327-opt-native-20261107/all-weapons/<id>/`
- 6종 수정 재검수: `/tmp/w327-opt-native-20261107/recheck/<id>/`
- Subjunctive 최종 경로 재검수: `/tmp/w327-opt-native-20261107/subj-final/subjunctive/`
- 12개 동시 디스플레이의 실제 형상·텍스처는 확인했다. FPS 표본은 10으로 유지됐고 유휴 제한의 영향을 분리하지 못했으므로 성능 개선이나 FPS 수락으로 보고하지 않는다.
- 짧은 대표 장면 검수다. 모든 각도·거리·퍽 조합, 원본 장전 동작의 완전한 일치, 스피커 청취는 인증하지 않았다.
- 이 배치의 최종 실행은 Gradle assemble 및 기존 atlas routing 4개 테스트 결과에 근거한다. 과거 전체 JUnit에는 기존 실패가 있었으며 전체 gate가 모두 통과했다고 주장하지 않는다.
