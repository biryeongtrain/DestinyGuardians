# 백그라운드 Vision 클라이언트 FPS 값의 의미

3인 실행에서는 클라이언트 FPS가 29–30으로 나왔고, 클라이언트 1개만 남긴 솔로 BL 유지 120초에서는 10이었다(`solo-bl-fps.json`). 클라이언트 수를 줄였는데 FPS가 내려갔으므로 이 값은 렌더 성능이 아니라 프레임 제한값이다. 솔로 실행 중 `control/state`는 `fps 10`, 백그라운드 렌더 상한 60, CPU 프레임 시간 스냅샷 2.5–4.4ms였다. 측정 시점은 BL 이후 SP 구간이다. 이 프레임 시간 기준으로는 렌더 여유가 크지만, 스냅샷은 GPU 시간을 포함하지 않는다.

결론적으로 백그라운드 클라이언트의 FPS는 공격전 수락 지표로 쓰지 않는다. 실제 FPS는 포그라운드 창에서 측정해야 하며 아직 하지 않았다.

함께 확인한 내용: 솔로 실행은 3인 기준 수치로 진행되므로 세픽스가 플레이어를 반복해서 다운시켰다. 그때마다 `SP_RECOVER1`에서 체크포인트로 재시작했고, `destiny devils leave` 후 탑으로 정상 복귀했다(`solo-phases.json`).
