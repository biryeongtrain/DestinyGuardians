# 공격전 연출·보상 상자·체력 조정 (악마의 소굴)

사용자 요청 4건. 수치는 Minecraft 이식용 튜닝이며 원작 확정값이 아니다.

## 1. 종료 대사(자발라)는 처치 뒤 6초 쉬고 나온다
`DevilsDirector.COMPLETION_SPEECH_DELAY = 120` tick. 세픽스가 쓰러지면 보상 상자·완료 HUD가 먼저 나오고, 120 tick 뒤에 `80b59f28`이 큐에 들어간다. 일시정지·체크포인트 무효화와 같은 clock/generation 규칙을 따른다(무효화되면 예약 취소). 귀환 타이머(600 tick)는 그대로이며 대사(365 tick)가 그 안에 끝난다.
실화면: 완료 HUD "귀환까지 29초" → "24초"에서 자발라 자막 시작(`completion-zavala-after-delay.png`). 청취는 하지 않았다.

## 2. 보상 상자 25% 확대 + 발광
`LootChest.SIZE = 1.25` (모델·뚜껑 경첩·상호작용 판정·안내문 높이·접근 거리 동일 배율). 본체/뚜껑에 금색 glow 윤곽과 full-bright, 먼 곳 금빛 광선 밀도를 올렸다.
실화면: 상자가 지형 뒤에 가려져도 금색 윤곽이 벽 너머로 보인다(`chest-outline-through-wall.png`). 상자 모델을 가까이서 가림 없이 찍은 이미지는 없다(1.25배 크기는 코드·수치 확인).

## 3. 체력
| | 이전(W342) | 이후 |
| --- | ---: | ---: |
| 워커 코어 | 200 (원래 1600의 1/8) | **1600** |
| 워커 다리 장갑 | 12.5 (원래 100의 1/8) | **100** |
| 세픽스 프라임 | 550 (원래 2200의 1/4) | **2200** |
| 보호막 서비터 | 60 | **120** (보스 복구와 별개로 2배) |
브릭(700)과 다른 일반 적은 그대로. 요청의 "1/4 너프 복구"에서 워커는 실제로 1/8이었으므로 둘 다 W342 이전 값으로 되돌렸다. 세픽스 임계값(67%/33%)·워커 증원 임계값은 체력 비율로 계산되어 자동으로 따라간다.
빛 슈퍼 한 방(11→110)으로 일반 적이 쓰러진다는 W342 테스트는 서비터(120)만 예외로 두었다.

## 4. 시작 대사 씹힘 + 암전 로딩 화면
원인: 런치 커튼이 걷히기 전에 run이 `RUNNING`이 되어 브리핑(착지 연출·음악·22초 대사)이 검은 화면 뒤에서 시작됐다.
- `DevilsBriefingGate`: 커튼을 거친 run은 모든 멤버의 런치 커튼이 걷힌 뒤 20 tick 쉬고 `director.begin`. 명령으로 시작한 run(커튼 없음)은 즉시. 400 tick 타임아웃. 그동안 목표 HUD 숨김.
- `LaunchLoadingScreen`: 검은 화면 동안 활동 이름, 궤도 점 스피너 + "게임을 불러오는 중…", 얇은 진행 막대 + %, 로드 확인 후 "준비 완료" 100%를 14 tick 보여 주고 커튼이 걷히면서 이름/유형 타이틀 카드가 같이 사라진다. 진행도는 실제 맵 빌드 진행(`Launcher.progress`)에 수렴하며 뒤로 가지 않고, 클라이언트 로드 전에는 96%를 넘지 않는다. 진행도를 모르는 활동은 시간 기반 곡선.
- 글리프: `destiny:loading_ui` 비트맵 폰트(`scripts/ui/build_loading_ui.py`로 생성). GUI 계층(title/subtitle/actionbar)이라 검은 post effect 위에 보인다.
- `minecraft/lang` ko_kr·en_us의 `multiplayer.downloadingTerrain`을 "게임을 불러오는 중..."/"Loading..."으로 교체(차원 이동 때 바닐라 "Loading terrain..." 화면). 기존 143개 언어 오버레이 테스트는 두 로케일만 예외로 갱신.

실화면(`loading-43.png`, `loading-ready-100.png`, `title-card-fade-in.png`): 격리 서버+Vision client(키 입력 없음, 서버 콘솔로 탐색기 조작)로 화력팀 탐색기 → 플레이 → 카운트다운 → 로딩 화면 → 로드 후 타이틀 카드 → 브리핑 시작까지 확인했다. 서버 로그: 런치 11:13:49 → 브리핑 11:14:05.
`vanilla-loading-terrain-before-lang.png`는 교체 전 바닐라 화면 기록이다. 교체 후 문구는 팩 ZIP(`assets/minecraft/lang/ko_kr.json`)에서 확인했고 그 화면을 다시 캡처하지는 못했다(약 1초).
