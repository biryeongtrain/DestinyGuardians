# W231 칼날 장전 투척음 중복 수정

## 변경

칼날 장전 한 번에 준비·두 fan·종료에서 총4개의 긴 후보 음원이 겹쳐 전송됐다. 사용자에게 들린 약6번을 패킷6개라고 단정하지 않는다. 첫 칼 투척 시점에 기존 `hunter.solar.blade_barrage.fire`를 시전당1회만 재생하고, 두 번째 fan 및 준비·종료의 중복 음원은 생략한다. 새 시전은 다시1회 재생한다. 칼14개·두 fan·피해·카메라 타이밍은 바꾸지 않았다.

기존OGG와 sounds.json을 수정하지 않았다. 다른 궁극기, 다른 플레이어의 사운드 재생을 전역 cooldown/stop으로 막지 않는다. 시전별 lease의 fan 수를 사용한다.

## 검증

- W230관련 GameTest18/18 통과. 등록된 근처 fake listener의 실제 `ClientboundSoundPacket`을 수집해 전체 시전 동안 `fire`1개만 나감을 확인했다. 다음 시전 후 누적2개이며 두 시전 모두14칼·두 fan을 유지한다.
- 전체 JUnit2076개 중2070통과/기존6실패/오류0. W230기준 실패집합과 정확히 동일하며 신규 실패0이다. `failure-comparison.json` 참조.
- 서버 패킷 수 검증과 실제 청취는 구분한다. 이번 수정은 실제 스피커/루프백 청취 검증은 하지 않았다. 모션·모델은 변경하지 않았다.
- 기존 dirty/untracked 작업을 보존한 통합 checkout 기준이며 이번 커밋만으로 clean HEAD 독립 재현을 보장하지 않는다.

서버 수정본을 재기동해야 반영된다. 패키지 결과는 `package-final.json`, 단계별 추적은 `진행기록.md`를 참조한다.
