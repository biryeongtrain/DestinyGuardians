# W230 궁극기 10종 통합 검증

## 결과와 사용법

추가 궁극기10종을 플레이 가능한 상태로 연결했다. `/guardian supers`에서 목록을 확인하고, 직업·속성에 맞춰 `/guardian equip destiny:<직업>/<ID>`로 장착한다. 기존 발동 입력은 웅크리기+손바꾸기다. 상세 조작은 [통합 설계](../../../design/W230_추가_궁극기_통합.md)를 따른다.

- 헌터: 칼날 장전, 스펙트럼 칼날, 폭풍결집, 폭풍의 칼날.
- 타이탄: 천둥충돌, 불타는 망치, 새벽의 수호물.
- 워록: 빛의 샘, 혼돈 범위, 신성 차원.
- 기존 대혼란의 주먹: SSD 원본 발동·공중·착지 모션 교체, 별도 제작한 지상 펀치 추가.

모델·이펙트·HUD·사운드 경로와 서버 후방 카메라를 연결했다. 설치형은 시전 후 카메라를 해제하고 유한 시간 동안 장판/돔을 유지한다. 이동형은 기본 공격·강공격 또는 점멸과 소모/만료를 연결했다. Ward 외부 피해·투사체 방어, Well 무기 피해 강화와 회복, 순간이동의 몸체 통과 검사 등을 행동 검사에 포함했다.

## 구현·시각 수정

SSD11개 `.blend`/46개 action을 격리 Blender에서 직접 평가했다. 원본에 없는 대기·이동·일부 공격은 authored로 구분했다. 최종68클립이며 신규 모션은61pose다. 61pose만으로 바닐라60FPS 연속 재생을 보장하지 않는다.

1차 실제 PNG를 담당 agent에게 전달한 뒤 Gathering 투척 후 가상손 지팡이 잔류를 제거했다. Fists 지상 펀치를 추가하고 공중 공격의 실제 접지에서 착지 모션을 재생하게 했다. Maul 회전/내려찍기의 공격 폭을 보완했다. 2차 실제 native 입력·PNG로 재검수했다.

실제 팩 적재 중 확인한 아틀라스 초과는 신규28장 UV를 무손실 재배치해 해결했다. 신규 텍스처 픽셀은23,068,672에서1,818,624로 감소했다. 리샘플링·모델 기하 변경 없이 실제 사용 면과 gutter를 옮겼으며, 실제 팩 로딩도 통과했다.

## 실제 화면 수락과 범위

master가 `native-r2/r2-cast-contact.jpg`, `r2-action-contact.jpg`, `r2-field-contact.jpg`와 대표 원본 PNG를 직접 열어 확인했다. 선택 PNG10장과 각 궁극기 서버 샘플·neutral 상태를 함께 보관한다. 원본 전체676개 파일은 `/private/tmp/destiny-w230-native-r2/frames`에 있으며 임시 경로는 영구 보관을 보장하지 않는다.

확인한 항목은 counted Blade의3인칭 몸 표시, Gathering 투척 후 손 소품 해제와 식립 전기장, Ward 외부 돔 형상, Well 장판 중심의 수직 식립검·지면 접점이다. R2 Fists는 실제 서버 `w229_titan_arc_attack`, 공중·착지 clip을 관찰했다. 정지 PNG는 공격의 일부 순간을 보여주며 전체 체감 부드러움이나 모든 접촉 프레임을 인증하지 않는다.

R1 첫 cold Blade는 서버 카메라 상태와 실제 몸 표시가 불일치했다. R2는 집계제외 모델 warmup1회 뒤11종을 검사했다. 첫 cold cast 문제의 완전 해결로 확대하지 않는다. Gathering 원거리 투척 probe1회도 집계제외다. 투사체가 짧게 지나가므로 비행축 정밀 정렬은 확정하지 않았다. Chaos는 채널 자세·전방 청색효과를 확인했으나 후방 축 구도로 손/광선의 정확한 연결·길이는 판정이 제한된다.

Hunter/Titan/Animation/Art/Warlock 읽기 전용 재검수는 확정 결함 없이 수락했다. Maul은 허리 높이의 좌우 회전과 위→아래 강타, Fists는 팔 자세 변화·전진 타격 및 무릎 굽힌 착지가 표본에서 읽힌다. 최대 펀치 신전·양손 연속 접촉·정확한 지면 접촉점은 몸과 FX에 가려 제한된다. Ward 격자 모아레는 관찰되며 UV 누락과 구분한다. 적군 빨강14쌍은 자산을 준비했지만 관전자별 PvP 팀 라우팅·Spectral BM 피부/칼의 관전자별 투명 렌더를 전수 검증하지 않았다.

## 음원·잔여 차이

32OGG 중28키를 기본 연결했다. Ward4후보는 기본 연결에서 제외하며 Storm’s Edge 전용 음원은 미확보 fallback이다. 실제 로그25개 고유 sound key는 매핑과 일치했다. Blade/Spectral/Maul impact3키는 이 실행 로그에서 관찰되지 않았다. 로그는 청취 결과가 아니며 실제 청취는 미검증이다. 일부 숫자 파일 역할과 Minecraft 피해·반경·속도는 임시값이다. DDC 원작 값과 구분한다.

Nova는 바닐라 입력 경로에 맞춰 탭→12틱 자동 완충 폭발로 대응했으며 원작 hold-release 완전 복제가 아니다. Spectral은 소유 바닐라 은신과 적대 AI 표적 해제를 구현했다. 누락 원본은 별도 제작 모션으로 채웠으므로 모든 원작 애니메이션·특성·상태이상·힘의 보주 재현을 뜻하지 않는다.

## 패키지·정리

최종 제품은 `build/libs/destiny-guardians-0.1.0+26.3.jar`이며 SHA256은 `3c133f4a68d5b63d54244b7078164d00671f5474064c88c1a6ccafbeb475baf7`이다. JAR 안의 최종 모션·Well 모델이 소스와 동일함을 확인했다. 파일 크기·Sources 해시는 package-artifacts.json, 엔트리 비교는 package-entry-checks.json에 둔다.

R2 종료 전에 `leaseActive:false`, `heldKeys:[]`, `pendingSteps:0`, native 이동 중립, `cameraIsPlayer:true`를 확인했다. 소유 client/server wrapper는 모두 exit0이며 포트8102/25611은 비어 있다. 사용자48시간 caffeinate PID79904는 유지했다. 일반 프로필·SSD 원본·Blender/Blockbench 작업과 고정 worktree는 보존했다.

커밋은 이번 소유 경로만 선택한다. 기존 탄약 작업의 Combat 변경과 다른 테스트 등록·worktree 슬롯 상태는 unstaged로 보존한다. 원격 push는 하지 않는다.
