# W227 단계별 작업 기록

1. 이전 퍽 작업 대기와 장비 화면 목표를 구분했다. 장비 화면은 DisplayHud를 사용하며 갑옷을 제외한다.
2. W226 미커밋 작업을 보존했다. 기존 통합본의 컴파일에 필요한 반환 완료 Gutshot 파일만 해시를 확인해 복구했으며 퍽 범위는 확장하지 않았다.
3. 고정 워크트리4·5를 재사용하고 현재 dirty/untracked 통합본을 외부 복구본과 함께 갱신했다. 인벤토리 서비스와 HUD를 분담하고 master가 입력·세션·중앙 검사를 맡았다.
4. Computer Use에서 Finder 데스크톱을 확인했다.8102·25611은 미점유,48시간 caffeinate PID79904는 실행 중이었다. OS 입력은 보내지 않았다.
5. 화면 세션·시점 변화 포인터·WASD 반복·좌클릭/Space 장착·닫기를 구현했다. 바닐라 스레드 검증 뒤에 게임 입력을 소비한다.
6. 화면 전용 이동·점프 속성 제한과 피격·사망·접속 종료·차원 이동·카메라/외부 위치 변경 회수를 추가했다. 인벤토리를 복사하지 않고 실제 소유 객체를 맞바꾼다.
7. 실제 입력 패킷·탄약 보존·수명 정리 GameTest와 포인터·공통 좌표 단위 검사를 추가했다. 모델/리그는 변경하지 않았다.
8. 서비스 검토에서 개수1·정확한 소유 참조·분류·경이 제한을 쓰기 전에 검증하고 같은 슬롯 재선택은 재장전/쿨다운을 건드리지 않음을 확인했다. 장착 목록과 여분 목록은 중복 표시하지 않는다.
9. 최초 관련 빌드의26.3 API 이름 오류3개를 실제 JAR로 대조해 수정했다. 재실행에서 단위10/10·assemble·compileGametestJava가 통과했다.
10. 서버 첫 실행의 쿨다운 검사 기준 오류를 담당자에게 돌려 수정했다. 실제 탄약을 비교하는 기준으로 재실행해11/11 통과했다. 현재 카탈로그상 서로 다른 분류의 경이 충돌은 실행하지 못했다.
11. HUD의 중복 FRAME 접미사를 제거하고 기본 능력치 표시를 명시했다. 전체 단위 검사·assemble을 한 번 실행했다.
12. 전체2,061개 중2,055개 통과, 음원/입자 기대값6개 실패를 기록했다. 이번에 해당 자산은 바꾸지 않았지만 W227 이전 전체 기준선을 별도 실행한 것은 아니다. 같은 실패 확인을 위한 전체 반복은 하지 않았다.
13. 첫 native 세션에서 WASD·마우스 시점 포인터·스페이드 에이스 실제 장착·에너지 선택·우클릭 닫기를 확인했다. 실제 PNG의 글자 상향 치우침과 바닐라 핫바/이름 겹침을 발견해 정확한 이미지를 HUD 담당자에게 전달했다.
14. 반환된 한국어·baseline·글자 폭 맞춤 delta를 기준/결과 해시 대조 후 통합했다. Bungie 공식 한국어 정의에서65개 이름을 추출하고 화면 안내도 한국어로 변경했다. 서버 원본을 보존하는 수신자 전용 핫바 표현을 추가했다.
15. 한국어·핫바 표현 통합 후 관련 단위10/10·assemble·compileGametestJava가 통과했다(target-3). 패킷 snapshot/원본 보존·다른 메뉴 통과·닫기 복원 검사를 서버 검사에 추가해 재실행한다.
16. 수정 후 서버11/11 통과(server-3). Finder 데스크톱·포트/프로세스 소유권을 다시 확인하고 별도1800초 awake wrapper 안에서2차 native 세션을 시작했다.
17. 2차 native에서 세 분류 실제 장착·WASD·포인터·우클릭 닫기·중립 입력·소유 프로세스 종료를 확인했다. 실제 PNG에서 baseline/핫바 겹침은 해결됐으나 작은 한국어 획이 소실돼 가독 크기 하한과 말줄임 수정을 HUD 담당자에게 요청했다.
18. HUD 담당자가 실제2차 PNG 세 장을 검수하고 최소18px·주요20px·폭 초과 말줄임 수정본을 반환했다. base/deeaff1 및 결과45a4b296 해시를 확인해 통합하고 관련 검사·빌드(target-4)를 시작했다. 인벤토리/입력/전투 코드는 바꾸지 않아 서버 전체를 다시 반복하지 않는다.
19. 가독성 수정 뒤 단위10/10·assemble·compileGametestJava 통과(target-4). 제품코드 변경은 HUD뿐이며 동일 서버 동작검사를 반복하지 않았다. 3차 격리 coordinator를 awake wrapper 안에서 시작해 최종 PNG와 조작을 확인한다.
20. 3차 실제 PNG에서 작은 한글·카드·기본 능력치·푸터 가독성과 기준선 정렬, 겹침 제거를 수락했다. 세 분류 장착·WASD·포인터·클릭·우클릭 닫기 재통과. lease/키 중립, 소유 server/client 종료0, 포트 해제와48시간 assertion 보존을 확인했다. HUD 담당자에게 최종 수락 결과를 전송했다.
21. 신규 제품15파일·설계·이번 QA만 대상으로 커밋 범위를 준비한다. 공유 Java는 HEAD에 W227 삽입만 적용한 blob을 stage하고, 두 registry에는 W227 항목만 추가한다. 기존 W226 등 미커밋 통합본은 포함하지 않는다. 재사용 슬롯4·5는 idle-needs-refresh로 남긴다.
