# W234 검증 실패 정리

사용자 요청에 따라 W233 전체 회귀의10개 실패 원인을 수정한다. 기존 dirty 통합본을 보존하고 고정 슬롯1·4를 갱신해 퍽 원본 검증과 파티클 검사를 병렬 배정했다. 사운드 연결·원본 해시·모노 OGG·전체 자산 목록 검증을 삭제하거나 검사를 건너뛰지 않는다.

1. 사운드의 W102 시점 영구 목록 가정을 수정. 각 단계의 기존 연결표/출처 해시에서 전체 현재 인덱스를 재구성한 뒤 역사적 단계의 검사를 수행한다. W2102개·W22917개·W23032개·W23325개의 이후 파일을 명시적으로 포함하며 예전209개 파일은 기존 해시를 유지한다. 알 수 없는 이벤트/파일과 누락·변조는 여전히 실패한다.
2. W233 교체 과정에서 빠진 헌터 자막9개를 기존 previousDefinition에서 복구. import 도구도 메타데이터와 최초 연결 이력을 유지하게 수정한다. 음원 선택·OGG 바이트·재생 타이밍·Java 게임 동작은 변경하지 않는다.

최종 결과: 전체 JUnit2091개 통과·실패0·오류0·건너뜀0. 자세한 과정과 첫 실패 원본은 아래에 보존한다. W233 봉인 증거는 변경하지 않는다.

3. W233원본 대조 --check 통과:28개 연결·25개 모노48kHz파일을 전부 디코딩했고 원본/출력 해시·매핑 확인. 기존 OGG바이트는 모두 불변이다. metadata unit2개 통과. 별도 임시 사본에서 실제 import를2회 수행해 전체 인덱스와 최초 previousDefinition 불변 및 이후 --check 통과를 확인했다. 제품 원본에는 재인코딩하지 않았다.

4. 사운드 JUnit34개 통과(실패0·오류0·건너뜀0). W33/W56/W98/W102의 기존 검증과 새 현재구성/누락·변조 거부 검사를 포함한다. W229·W230 provenance에 기록된18/32개 행의 출력 파일 해시·크기도 실제 자산과 일치한다. 파티클 worker 수정본은 main의 사전 해시를 확인한 뒤 통합했으며 제품 converter는 변경하지 않았다.

5. 파티클 JUnit4개 통과(실패0·오류0·건너뜀0). 입력 모델의 texture alias closure와 face sprite로 대상 집합을 독립적으로 계산해, 해당 모델 전체 보정·실제 텍스처 존재·particle 이외 JSON 보존·중복 적용 무변경을 확인한다. 예상98→120으로 숫자만 교체하지 않았다. 복구한 자막9개의 한국어·영어 번역도 모두 존재한다.

6. 퍽 worker11개 경로를 사전/사후 해시 대조 후 통합. 원본4종 전체를9,035,688바이트 ZIP에 보존해 원래 절대 경로와 W83 사본 없이도 검증한다. 부모의 오프라인 검증87개 pin·생성기4개·출력14개·음성 사례9개 통과. 원래 /tmp plugSets는 여전히 없고, 역사적 manifest·생성기·출력 수치는 변경하지 않았다.

7. 첫 전체 회귀2091개 중2090통과/1실패. W233의 기존10개 실패는 전부 해결됐지만, 기존 FirstPersonHandsW201Test가 약42MB 이후 JSON을 Gson으로 읽는 중 Java heap space 부족으로 실패했다. 이 결과를 full-r1.json에 보존했다. Gradle daemon의3GiB와 별개로 테스트 JVM은 기본512MiB였으므로 test.maxHeapSize만2GiB로 명시한다. 검사 데이터/codec/대상/검사 수를 줄이거나 skip하지 않고 전체를 재실행한다. 기존 build.gradle의 다른 미커밋 ZIP64 변경은 보존하며 이번 커밋에는 테스트 힙 설정만 선별한다.

8. 테스트 JVM의 실제 `-Xmx2g` 적용을 확인한 뒤 전체 재실행 성공(1분11초). JUnit2091개 통과/실패0/오류0/건너뜀0. W233의10개 실패와 첫 전체 실행의1인칭 native codec 메모리 실패 모두 통과했다. 전체 suite·원래10개 사례의 통과 여부는 full-final.json에 기록했다. 최종 소스/fixture20개 해시는 QA 중 불변이다.

9. assemble/compileGametestJava 통과. 완성 JAR의 sounds.json과25개 새 OGG가 소스와 바이트 단위로 일치한다. 검증용 원본 압축본은 서버 JAR에 포함되지 않는다. Java 게임 동작·음원 선택·재생 타이밍은 그대로이며, 런타임 자산 변경은 자막9개 복구뿐이다. 이번 배치는 테스트·출처 해소·메타데이터 수정이므로 새 Vision/청취 검증은 실행하지 않았다. 게임 서버·클라이언트는 기동하지 않았고 기존 중지 상태와48시간 잠자기 방지 프로세스를 유지했다.

10. 슬롯1·4 worker를 종료하고 워크트리는 삭제하지 않고 보존했다. 다음 배치용 idle-needs-refresh로 표시했다. 기존 미커밋 코드와 build.gradle ZIP64 변경은 보존하며 이번 소유 파일·공유 파일의 해당 변경만 커밋한다. 원격 push는 수행하지 않는다.
