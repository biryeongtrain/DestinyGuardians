# 희귀도별 엔그램·장비 획득음

사용자가 제공한 File0040.wav를 일반·고급·희귀, File0041.wav를 전설, File0042.wav를 경이에 연결했다. 최상급 엔그램은 기존 전설 분류를 따른다. 출처·원본 해시·변환 결과와 재생 규칙은 `art/audio/loot-acquisition/README.md`, `manifest.json`, `sounds-fragment.json`에 남겼다.

기존의 임시 전송/경험치 획득음과 인챈트 해독음을 교체했다. 획득자에게만 PLAYERS 카테고리, volume=1, pitch=1로 전송한다. 세 원본 모두 48kHz·스테레오·전체 길이를 보존했고, 원본 WAV 해시를 전후 대조했으며 변환된 OGG 전체 디코딩을 확인했다. 경이의 6.148초 꼬리를 자르지 않았다. 신규 OGG 합계는 **209,927바이트**다.

## 검증

- 실제 서버 GameTest **3/3 통과**. 준비 136,578ms 뒤 시험 시계를 시작했으며 시험 시간은 2.504초였다. `gametest-result.txt`.
- 다섯 희귀도와 최상급 엔그램, 실제 스킨 희귀도, 일반 장비 지급, 엔그램 해독, 보관함 초과의 엔그램 대체, 실패 시 무음, 기본 무장 개별 재생/중복 지급 억제를 확인했다. 다른 플레이어에게 획득 패킷이 전달되지 않는 것도 확인했다.
- 음원 관련 JUnit **22/22 통과**. `audio-targeted.json`. OGG 식별 헤더·스테레오·48kHz·끝 granule, 출력 해시와 사용자 지정 파일/이벤트의 대응을 검사한다. 원본 길이는 각각 126912/61376/295104 샘플이다.
- 신규 세 이벤트·파일 해시를 기존 `ReviewedAudioW234`의 명시적 검증 계층에 등록했다. 기존 전체 목록에서 새 이벤트가 거부되던 초기 전체 검사 실패 8건 중 새 5건은 이 등록 전에 발생했다. 수정 후 관련 22개 검사를 통과했다. 새 세 UI 획득음만 정확한 id로 스테레오를 허용하며, 기존 위치 기반 무기 효과음의 모노 검사는 유지한다.
- 최종 전체 검사는 **2,844개 중 기존 실패 3건**이다. `FireVariantsW98Test`의 기존 음원 QA 자료 누락, `GoldenGunHudW122AssetTest`의 기존 검사 소스 누락, `MinorPveBalanceW342Test`의 기존 피해량 기대값 불일치가 남아 있다. 이번 작업의 새 실패는 없다. `full-gate.json`.
- 실제 Gradle JAR의 세 음원과 변경된 클래스 일치, SHA-256은 `artifact.json`에 기록한다. 공용 팩 ZIP의 세 음원·이벤트와 실제 생성 용량은 `pack-audit.json`으로 확인한다.
- 실제 생성된 공용 팩은 **133,473,935바이트**로 250MB 목표 이내다. 세 OGG를 ZIP에서 꺼내 해시를 대조했고 이벤트 정의도 확인했다. JAR는 **424,213,928바이트**이며 팩 ZIP과 구분한다.
- 범용 리소스팩 검사기도 새 세 음원의 실제 ZIP 추출본에 적용했다. 세 사운드 참조와 JSON은 통과했으나, 이 검사기의 숫자 전용 메타데이터 검사는 기존 26.3 생성기의 `min_format: [97,1]`을 처리하지 못해 1건을 거부한다. 메타데이터를 변경하거나 이 범용 검사를 전체 통과로 표시하지 않는다. `resource-validator.txt`. OGG 헤더·해시·길이 검증과 실제 서버 검증은 위의 별도 검사 결과다.

## 범위와 정리

서버 패킷 검증과 원본/변환 파일·팩 검증이다. Vision 클라이언트와 실제 스피커 청취 검증은 수행하지 않았다. 원본 녹음에 음량 조정이나 정규화를 적용하지 않았으므로 인게임 청취 밸런스를 수락했다고 표현하지 않는다.

격리 GameTest 경로는 `/tmp/loot-acquisition-qa/gametest`다. 이전 소유 QA 폴더를 CoW 복사했고 level.dat의 독립 inode/같은 해시를 확인했다. 필터는 `destiny-test:acquisition_sound_game_tests*`, 준비 상한은 600초였다. `keep_awake.py --seconds 1200`으로 감쌌고 서버 종료를 확인했다.

완성된 공용 팩을 검사하기 위한 별도 격리 서버는 `/tmp/loot-acquisition-qa/server`, 루프백 포트 25638을 사용한다. 이전 폰트 QA 서버를 CoW 복사하며 원본 QA와 일반 Minecraft 프로필을 보존한다. 현재 세 음원이 포함된 ZIP이 완성된 것을 확인한 뒤 소유 서버를 정상 종료한다. 실행 상한은 1200초이며 종료 결과는 `cleanup.json`에 남긴다.
