# 엑소더스 이동 구간 완료 보상 · 2026-11-09

사용자 요청에 따라 완료당 개인 확정 전설 무기 굴림을 1회에서 2회로, 상자 미광을 40~60에서 80~120으로 올렸다. 긴 필수 도보 이동에 대한 고정 완료 보상이며 대기 시간/걸음 수를 추적하지 않는다. 변경 범위는 `tables.json`의 엑소더스용 완료 테이블/활동 연결과 설명이다. 기존 공용 지급 코드, 완료 중복 방지, 상자 지급·정리 경로를 재사용한다.

수정 전 JSON과 비교해 엑소더스의 두 필드 및 새 완료 테이블/설명 외 모든 기존 데이터가 같음을 확인했다. 기존 `LootTablesTest` 7개 실패 0, Gradle `jar` 성공. 실제 산출 JAR의 보상 JSON이 수정된 소스와 바이트 단위로 같다. 결과와 산출물 해시는 `validation.json`에 있다.

정적 보상 수치·테이블 선택만 변경했으므로 새 테스트나 전체 gate, 클라이언트/Vision 검사는 실행하지 않았다. 이번 결과를 실제 전투 완료·상자 수령의 새 실화면 검증으로 표현하지 않는다. 원작 수치가 아닌 이 프로젝트의 경제 조정이다.
