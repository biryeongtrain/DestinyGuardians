# W261 점령전 입장 대립 구도

상태: 3대3 실게임 구도·인트로 종료 후 이동/탑 복귀 검증 완료. 운영 재개는 아래 기록.

사용자 요청: 맵 풍경 소개 뒤 양 팀 수호자가 서로 마주 보는 대치 구도.

- Alpha는 동쪽(-90도), Bravo는 서쪽(90도)을 바라보도록 변경했다. 기존 야외 무대 중심과 2.4블록 팀 간격은 유지하고, 각 팀 줄은 시선에 수직으로 배치된다.
- 최종 순서는 맵 소개100틱 → 입장 전체130틱 → Alpha50틱 → Bravo50틱 → 착지 후 전체 대립70틱이다. 전체400틱을 유지하며 카메라는 대치축의 같은 남쪽에서 양 팀을 번갈아 비춘다.
- 원본 입장 모션6개와 길이·타이밍은 수정하지 않는다. 마주 보는 구도는 직접 구성한 연출이며 원작 카메라 복원이라고 주장하지 않는다.
- 운영 접속자0명 확인 후 서버 정상 종료. 테스트/운영 JVM4GB 유지. 기존 dirty 변경과 고정 worktree 보존.
- master는 Runtime/중앙 빌드/Vision, 이전 맵 담당은 읽기전용 무대·원본 궤적 및 후속 PNG 검수. 하나의 구도 변경을 형식적으로 여러 소스 작업으로 분리하지 않는다.

Java25 compileJava/compileGametestJava 통과(29초). 카메라/무대 좌표만 변경하는 미술 작업이므로 새 단위 테스트나 전체 전투 gate를 추가하지 않고 실제 인트로와 종료 후 이동/복귀를 확인한다.

맵 담당 정적 검수: Alpha−90도/+X, Bravo+90도/−X, 팀별Z83.1/85.5/87.9에6명 모두Y84지지·빈 공간 확보. Bravo BBD0 원본frame189→190 급변 보간이(39,86,98)구조물을 지날 가능성은 실제 PNG 확인 대상으로 남긴다. 원본 모션 자체는 이번 변경 대상이 아니다.

1차 Vision은 진행/입력/탑복귀 완료. 근접 컷의 모델은 표시되지만 Bravo컷에worldborder가 노출됐고 wide가 착지 전에 끝나므로 수락 보류. 맵 담당의 지형가림0 후보 카메라로 교체하고, 팀별 컷을50틱씩으로 조절해 마지막70틱에 착지 후 양팀 wide를 추가한다. 전체400틱/원본모션 길이는 유지한다.

원본 최종 player_root heading은 약−28/−51/−60도였다. 입장 tracker yaw를 시전 시 무대 방향으로 고정하고, 루트부터 자식까지 동일 GLOBAL 회전 보정을 적용한다. BM은 자식에서 부모 GLOBAL을 상쇄하므로 같은값을 전체서브트리에 적용하며 루트 위치는 건드리지 않는다. 원본 시간별 회전차와 기울기는 유지하고 최종 수평 heading만 맞춘다. 원본6클립 최종 전방벡터/기울기 검사를 추가했다.

2차 준비: source6개 최종 heading/tilt검사1개와self-carrier회귀8개 통과. 기존 visual counterpart fixture를 실제QA1+가상5(3대3)으로 확장했다. max-players나 제품 세션 정책은 변경하지 않는다. 원본 Blender는 W260에서 직접평가한 동일해시 자료이며 이번엔 raw원본모션을 다시 변환하지 않았다.


## 2차 Vision 결과

- Danmo/OpenGL·서버/클라이언트4GB, 실제QA1명+가상상대역5명으로3대3 검수. [Alpha컷](vision-r2/intro-17.png), [Bravo컷](vision-r2/intro-20.png), [최종대립](vision-r2/intro-24.png).
- 여섯 모델이 모두 표시되고, 최종 컷에서 양팀이 서로를 향해 줄을 이룬다. source루트의 비스듬한 최종몸방향을 보정한 상태이며 각 클립의 고유 팔/다리/머리 동작은 남아 있다.
- 검수 컷에서 카메라 앞 구조물/월드보더 노출 없음. 루트기준 위치·팀별간격 유지. r1의border노출은 실패 이미지로 보존했다.
- 종료 후 정상1인칭으로 복귀, native전진8틱+중립3틱 완료: (-117.5,84,34.5)→(-115.83553946405242,84,34.054123195519686). [입력기록](vision-r2/post-intro-native.json).
- [탑 복귀](vision-r2/tower-return.png)와 생존/자기카메라 확인. lease=false, heldKeys=[], pendingSteps=0, native입력중립. 소유QA서버exit0, clientwrapper는stop(SIGINT/-2)로 종료했다.
- 각 캡처는 표본이다. 빠른 원본진입의 매프레임 무관통이나 모든FOV/화면비 검증을 주장하지 않는다. 시선은 원본머리포즈를 보존한 팀대치 방향이며 개별 플레이어를 추적하는 눈동자/머리IK는 아니다.
- 대표배우는 기존과 동일하게 팀당최대3명이다. 경기참가자 제한과 별개이며 이번 변경에서 세션인원 정책은 바꾸지 않았다.
- 새로운 텍스처/메시/음원을 추가하지 않았다. 원본 애니메이션과 timing리소스 SHA256이 같음을 [확인](source-preserved.json)했다.

맵담당의2차PNG검수도17/20/24를직접보고수락했다. 최종wide의6명전신·마주봄·간격·border없음확인, 추가수정요청없음.
