# W267 플레이어 체력20 기준 피해 조정

## 기준

사용자가 데스티니와 비슷한 처치력을 체력20에서 대략 맞추도록 요청했다. 기존 W263 무기 어댑터와 같은 `데스티니230HP → MC 최대체력(기본20)` 환산을 능력 접촉에도 사용한다. 실제 피해 감소·약화·흡수·퍽은 환산 뒤 기존 경로에서 적용한다. 표에 없는 원작 수치를 확정값으로 꾸미지 않고 현 구현의 타격횟수·주기를 고려한 근사값은 별도 기록한다.

## 구현 범위

- 헌터·타이탄·워록의 수류탄, 근접능력, 기본/확장 궁극기별 실제 타격 지점에 PvP 전용 환산을 연결한다. 발사할 때의 능력 객체/ID를 전달하여 현재 장착한 다른 궁극기의 피해를 빌려오지 않는다.
- 기존 무기50종의 확인값은 유지하고, 기존 표에서 빠진15종의 현재 타격 단위에 맞춘 값도 추가한다.
- 몬스터에게는 기존 로컬 피해를 유지한다. 투사체 수/모션/범위/쿨다운은 이번 수치 작업에서 바꾸지 않는다.
- 공통 PvP 스코치는 중복 바닐라 불 피해를 만들지 않고, DDC x50의 대표값6.5HP/0.56초를 11틱 간격으로 근사한다. 현재 스택·점화 모델은 구현하지 않으며, 기존 시전별 지속시간을 사용한다. 최소0.1MC HP를 남기는 비치명 피해다. 몬스터의 기존 스코치 경로는 유지한다.

## 작업 추적

1. 운영 서버 접속자0명 확인 후 정상 종료. 기존 변경은 `/private/tmp/destiny-w267/before`에 기준선 보존.
2. 고정 worktree 슬롯1~4를 재사용하되 기존 stale 파일을 덮어쓰지 않도록 각 슬롯의 신규 `w267-delta` 아래에 담당 소스만 최신 main에서 복사했다. 원본 슬롯 전체 갱신 또는 clean clone 빌드로 주장하지 않는다.
3. master는 공통 환산기·스코치·중앙 검증·통합·커밋·서버를 담당한다. worker는 직업별4파일 또는 무기 표와 출처 문서만 소유한다.
4. 사용자의 수치 테스트 예외를 적용해 개별 값별 테스트를 추가하지 않는다. 데이터·타격 지점 연결을 검수하고, 기존 실제 PvP 피해 회귀에 스코치 중복불/비치명 확인만 추가한다.

## 서버 복구와 변경 보존

격리 QA는 exit0로 정상 종료했다. 통합 checkout의 이번 delta만 선택 stage했고 기존 미커밋 모션·사운드·자산 변경은 보존했다. HunterMelee/HunterSuper는 기존 미커밋 구현과 HEAD의 함수 문맥이 달라 이번 피해 어댑터 부분만 HEAD 문맥에 맞춰 커밋했다. 검증한 환경은 기존 작업을 포함한 통합 checkout이다.
