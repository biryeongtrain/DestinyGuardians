# W274 제블린-4 재색칠·플레이 정비

참고: Adam Williams의 Javelin-4 (시베리아 발사 시설, 원형 로켓 룸, 안전 주황색 도색).

## 문제 확인
- 기존 W260 베이크는 청록 테라코타 24%, 스톤브릭/스무스스톤 34%로 단조롭고, 실내가 어두웠다.
- 보행망은 정상: 거점 A/B/C와 양 팀 스폰이 모두 같은 최대 보행 영역(약 39k칸)에 연결되어 있다.

## 변경 (`scripts/crucible/retheme_javelin_w274.py`, 원본은 `art/crucible/`에 보존)
- 재질 재배치: 실내 바닥 체커+16칸 이음선, 벽 패널 교차+주황 벨트, 실외 눈·얼음 지면, 흰 패널 변주, 구리 녹청 변주, 주황 위험 표시(바닥 사선).
- 조명: 보행망 위 4칸 격자에 `light[level=15]` 2,242개(실내 한정) + 천장 시라이트.
- 거점 패드(석영+주황/흰 8분할 링), 스폰 패드(알파 청록/브라보 주황).
- 엄폐물 34개(컨테이너·방벽·상자), 스폰/거점 13칸 이상 거리, 통로 3칸 여유 확인.
- 결과 복셀 764,487개, 팔레트 47. 보행 연결성 재검증: 거점·스폰 모두 최대 영역.

## 검증
- 단위 `*Crucible*` 통과. 실제 Vision 클라이언트(GCB 4.2 포함)로 입장해 A·B·로켓 룸 캡처(이 폴더). GCB 4.2 접속·설치 메시지도 확인.
- 미검증: 다인 대치 중 시야/교전 체감, 성능 측정, 천장 판(y134) 외관 개선(내부는 깊은 슬레이트 유지).
- 탑(Tower) 맵: 지속 월드이며 W243/W245 원장 기반 적용 패스라 별도 패스가 필요해 이번에는 변경하지 않았다.
