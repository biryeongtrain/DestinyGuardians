# W264 궁극기 시전음 팀별 수신

## 요청과 동작

- 상대 팀 궁극기: 같은 경기 월드의 상대 팀 전원에게 거리와 관계없이 1회 전달한다. 죽어 있는 팀원도 수신 대상이다.
- 아군 궁극기: 시전자와 반경 32블록 안의 같은 팀원만 수신한다. 32블록은 기존 `DestinySounds.AUDIBLE_RADIUS`를 유지한 서버 기준이며 원작 거리의 실측값이라고 주장하지 않는다.
- 적 시전음은 수신자의 눈 위치로 전송해 바닐라 거리 감쇠로 묵음이 되는 문제를 피한다. 아군은 시전 위치를 유지하므로 방향과 거리 감쇠가 적용된다. 각 플레이어는 한 경로로만 받아 근처 적도 두 번 듣지 않는다.
- 경기 외 플레이어와 다른 월드에는 경기 시전 알림을 전송하지 않는다. 경기 밖에서는 기존 근처 재생을 유지한다.
- 발사·충돌·종료음, 수류탄·직업능력·무기 소리와 개인 궁극기 준비 알림은 기존 경로를 유지한다.
- 칼날 장전은 기존 단일 투척음(`super.fire`)이 시전음이다. 무음 처리된 start/end를 되살리지 않는다. 공허 사격의 연속 시전음도 분할하거나 중복 재생하지 않는다.

## 작업 추적

1. 운영 서버 접속자 0명 확인 후 정상 종료. 4GB·online-mode 설정 유지.
2. `SuperCastSounds`에 수신 대상을 분리하고 헌터 기본 궁극기와 `ClassAbilityEffects` 공통 경로 연결. 미등록 음원의 바닐라 대체음에도 같은 수신 규칙 적용.
3. master는 제품 코드·서버, 슬롯 3 sub-agent는 신규 GameTest 파일만 담당. 고정 worktree는 stale 상태여서 현재 main API를 읽고 신규 파일만 작성하며 전체 갱신이나 검증 성공을 주장하지 않는다.
4. `minecraft-testing`과 Vision 26.3 스킬 참조. CU 확인 결과 Mac이 잠겨 있어 실제 클라이언트·청취 검증은 실행하지 않았다. 서버 패킷 검증 결과와 청취를 구분한다.

## 검증

검증 완료 범위와 제한을 아래에 기록한다.

- 관련 사운드·점령전 JUnit 53개 통과. 전체 JUnit 2,301개에서 기존 자산 검사 4개와 새 소스 해시 검사 1개 실패. 새 실패는 `HunterSuper.java`의 시전음 호출 교체로 W122 생성 기록이 오래된 경우였다.
- 기본 Python에는 Pillow가 없어 생성기 1회 실패. 앱 번들 Python으로 동일 생성기를 실행해 성공했다. 출력 4개 SHA256은 모두 기존과 같고, manifest 입력 해시 중 HunterSuper만 달라졌다. 과거 QA 파일은 변경하지 않았다. 해당 검사를 별도로 재실행한다.

- W122 소스 기록 재생성 후 황금총 HUD 검사 6개 통과. 팩 출력은 변경되지 않았고 추가 음원·텍스처도 없다.

- 첫 서버 패킷 검사는 전송 로그가 있음에도 같은 틱 수신 목록이 비어 실패했다. fixture에 Connection/channel flush를 추가하고 먼 대상은 맵 내부 64블록으로 옮겼다. 첫 실패 로그는 `gametest-r1.txt`에 보존했다. 제품 코드 변경 없이 다시 확인한다.

## 최종 결과

- 관련 JUnit 53개와 HUD 기록 갱신 검사 6개 통과. 전체 검사의 기존 자산 실패 4개는 미해결이며, 새 소스 해시 실패는 재생성 후 통과했다. 전체 gate 통과라고 보고하지 않는다.
- 서버 GameTest **4/4 통과**: 신규 팀·거리 수신 및 PvE 경로 2개, 기존 Nova·Blade/Rift 회귀 2개. 아군 31.875/32/32.125블록, 적 64블록, 근처 적 중복 없음, 미등록 이벤트 대체음, 실제 헌터 발동과 중복 시전 거부를 검증했다.
- r1의 실패는 fixture 전송 버퍼 flush 누락이었다. r2는 패킷 목록을 실제로 읽어 수신자·이벤트·좌표·볼륨·피치를 확인했다. native 클라이언트/음성 출력의 청취 증거는 아니다. Mac 잠금으로 Vision·실제 청취는 미실행이다.
- master가 반환 fixture의 flush와 맵 내부 위치를 수정했다. 최초 통합 SHA는 `integration.json`, 최종 fixture SHA는 `gametest-r2.json`에 있다.
- QA는 정상 종료했다. 운영은 기존 online-mode=true / 4GB / andlist OP 설정으로 재개한다. 신규 음원·모델·텍스처를 추가하지 않았다.
- W264 변경만 선택 커밋하며, HunterSuper 등의 기존 미커밋 작업은 그대로 유지한다. 검증 대상은 현재 통합 작업 디렉터리이며 clean clone 독립 빌드 인증은 아니다.
