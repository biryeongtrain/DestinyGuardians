# W270 직업 능력·점프 사운드

## 1. 원본 확인

`/Volumes/qf-ssd/Destiny-Class-Jump-Sounds-2026-10-30`의 CUES·시퀀스·뱅크·루프 메타데이터를 읽었다. 원본은 읽기 전용으로 보존한다. 확인된 회피, 균열, 공중 점프, 점멸, 리프트·활공 뱅크를 사용한다. 방벽·추진기 후보는 확정되지 않아 기존 소리를 유지한다. 불사조 강하 전용 소리는 전달본에 없다.

## 2. 병렬 구현

- ikelos 슬롯: 음원 변환 스크립트·파생 OGG·출처/선택 근거.
- mindbender 슬롯: 헌터 회피·워록 치유 균열의 성공 시점 연결.
- parcel 슬롯: 발동·중단·다인 충돌 GameTest.
- master: 점프 런타임·sounds.json 통합·서버/클라이언트 QA.

현재 워록 직업능력 구현은 치유 균열만 있다. 강화 균열 소스를 찾았다는 이유로 새 능력을 추가하지 않는다.

## 3. 재생 규칙

회피는 승인된 모션 시작에 한 번, 치유 균열은 준비/실제 생성/자연 소멸에 각각 한 번 재생한다. 거절·취소에는 생성/소멸 소리를 내지 않는다. 헌터 공중점프는 실제 추가 도약에만 재생하며 점멸은 출발점과 도착점 소리를 구분한다.

리프트·활공은 시전자를 따라가는 바닐라 엔티티 사운드를 사용한다. 중단 패킷은 엔티티가 아닌 이벤트 이름을 대상으로 하므로 동시 시전자별 32개 별칭 슬롯을 둔다. 착지·재입력·연료 소진·장비 변경·메뉴 정리·사망·접속 종료 때 소유 별칭만 정지한다. 소리를 매 틱 재생하지 않는다. 전체 슬롯 사용 시 기존 시전자의 소리를 뺏지 않는다.

## 4. 검증

단위 테스트 44개 통과(점프 물리 37, 음원 자산 4, 출처 레이어 3). 관련 GameTest는 중복을 제외한 14개가 최종 통과했다(신규 사운드 6, 신규 회피 카메라 3, 기존 직업능력 3, 기존 명사수 회피 2). 첫 균열 검사는 fixture 바닥 부족으로 실패하여 명시적인 돌 지지 블록을 추가한 뒤 통과했다. 실패와 재검사 기록을 모두 남겼다. 실제 Danmo 입력 7개 사운드 시나리오와 추가 4개 직업능력 카메라 시나리오가 완료됐고 모든 lease·native 키가 중립으로 복귀했다.

생성된 팩에서 새 75개 이벤트(11개 원본 이벤트+64개 시전자 별칭)와 OGG 11개의 해시가 일치했다. OGG 합계 261,649바이트(약256KiB). 클라이언트 OpenAL 초기화·팩 로드·누락 음원 오류 부재를 확인했다. 실제 출력 소리를 녹음·청취해 원작과 비교한 결과는 아니다.

## 5. 사용자 추가 요청: 헌터 회피 카메라

첫 Vision에서 두 회피가 모두 `cameraIsPlayer=true`로 남음을 확인했다. 사용자가 직업 능력 시전 중 전부 3인칭을 요구했다. 헌터 회피 시작 경로에 기존 서버 후방 카메라를 연결하고, 회피 리그·카메라 준비가 실패하면 효과/재장전/소리를 승인하지 않도록 수정했다. 접촉 틱에 손·무기를 복구하지 않고 동작 종료까지 유지한다. 타이탄 방벽·워록 균열은 기존 ClassAbilityCast의 3인칭 경로를 다시 확인했다.


헌터 도박꾼·명사수 회피, 타이탄 방벽, 워록 치유 균열 모두 실제 입력에서 시전 중 `cameraIsPlayer=false`, 종료 후 `true`를 확인했다. 회피는 해당 모션이 끝나거나 교체될 때 카메라를 돌려주며 교체된 다른 모션을 강제로 중단하지 않는다. 시전 중 1인칭 무기를 숨기고 종료 후 복원한다. 인벤토리 무기 carrier도 보존됐다. 밝은 테스트 바닥에서 PNG를 직접 확인했다.
